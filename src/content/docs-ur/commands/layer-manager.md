# LayerManager

`LayerManager` کمانڈ ایک ٹیبل کھولتی ہے جس میں ڈرائنگ کا ہر لیئر درج ہوتا ہے، اور اس کی **Freeze**، **Lock**، **Plot**، **Color**، **Lineweight** اور **Linetype** ترتیبات براہِ راست قطار میں ہی قابلِ ترمیم ہوتی ہیں۔ نئے لیئرز شامل کرنے اور موجودہ لیئرز کا رویہ بدلنے کی یہ مرکزی جگہ ہے — باقی لیئر کمانڈز ([LayerMakeCurrent](../layer-make-current/)، [LayerMatch](../layer-match/)، [LayerIsolate](../layer-isolate/)، [LayerUnfreezeAll](../layer-unfreeze-all/)) ہر ایک اسے کھولے بغیر ایک مخصوص کام کرتی ہے۔

## Layer Manager کھولنا

- ٹرمینل میں `LayerManager` ٹائپ کریں، **یا**
- لیئر پینل میں **Layer Manager** بٹن پر کلک کریں۔

ڈائیلاگ ایک تیرتے پینل کے طور پر کھلتا ہے؛ پہلے کچھ منتخب کرنے کی ضرورت نہیں۔

## لیئر ٹیبل

| کالم | کیا کنٹرول کرتا ہے |
|--------|-------------------|
| Name | لیئر کا نام، ٹیبل میں صرف پڑھنے کے لیے دکھایا جاتا ہے (بناتے وقت ایک بار طے ہوتا ہے) |
| Freeze | لیئر کی اشیاء چھپاتا ہے اور اَن فریز ہونے تک انتخاب سے باہر رکھتا ہے |
| Lock | لیئر کی اشیاء کو چھپائے بغیر ترمیم سے روکتا ہے |
| Plot | پرنٹ یا PDF برآمد کرتے وقت لیئر کی اشیاء شامل ہوں یا نہ ہوں |
| Color | لیئر کا ACI رنگ — رنگ منتخب کرنے والا کھولنے کے لیے سواچ پر کلک کریں |
| Lineweight | لیئر کی لائن موٹائی — لائن ویٹ منتخب کرنے والا کھولنے کے لیے چِپ پر کلک کریں |
| Linetype | لیئر کا ڈیش پیٹرن — لائن ٹائپ منتخب کرنے والا کھولنے کے لیے چِپ پر کلک کریں |

Freeze، Lock یا Plot بدلنا فوراً اثر انداز ہوتا ہے — الگ سے محفوظ کرنے کا کوئی مرحلہ نہیں۔ جن اشیاء کا رنگ، لائن ویٹ یا لائن ٹائپ **ByLayer** (ڈیفالٹ) ہے وہ یہاں طے کی گئی قدر لے لیتی ہیں؛ جن کی اپنی الگ قدر ہو وہ متاثر نہیں ہوتیں۔

## لیئر شامل کرنا

1. ٹیبل کے نیچے **+ Add Layer** پر کلک کریں۔
2. نام ٹائپ کرکے تصدیق کے لیے **Enter** دبائیں، یا منسوخ کرنے کے لیے **Escape**۔

لیئر کے ناموں میں حروف، ہندسے، خالی جگہ اور `_`، `-`، `$` ہو سکتے ہیں۔ خالی نام، پہلے سے زیرِ استعمال نام، یا کسی اور حرف والا نام موقع پر ہی خرابی کے ساتھ مسترد ہو جاتا ہے، اور قطار دوبارہ کوشش کے لیے کھلی رہتی ہے۔

نئے لیئرز **اَن فریز، اَن لاک، قابلِ پلاٹ** شروع ہوتے ہیں، رنگ 7 (سفید/سیاہ)، Lineweight Default اور Linetype Continuous کے ساتھ — وہی ڈیفالٹ جو [Import](../import/) خالی ڈرائنگ میں لیئر `0` کو دیتی ہے۔

## یہاں کیا نہیں ہو سکتا

حذف کرنے کا کوئی بٹن نہیں ہے — لیئرز بننے کے بعد کبھی ہٹائے نہیں جاتے، صرف فریز کیے جاتے ہیں یا بغیر استعمال چھوڑ دیے جاتے ہیں۔ ٹیبل میں یہ بھی ظاہر نہیں ہوتا کہ کون سا لیئر *موجودہ* ہے؛ وہ لیئر پینل کی ڈراپ ڈاؤن سے منتخب کرکے یا [LayerMakeCurrent](../layer-make-current/) سے طے ہوتا ہے، اس ڈائیلاگ سے نہیں۔

## کی بورڈ حوالہ

| کلید | عمل |
|-----|--------|
| `Enter` | نئے لیئر کے نام کی تصدیق (شامل کرتے وقت) |
| `Escape` | لیئر شامل کرنا منسوخ کریں، یا ڈائیلاگ بند کریں |
