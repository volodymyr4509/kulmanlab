# File Manager

`فائلمدیر` کمانڈ آپ کے براؤزر کے مقامی اسٹوریج میں محفوظ ہر ڈرائنگ کا ایک **تھمب نیل گرڈ** کھولتی ہے، جو آخری بار محفوظ ہونے کے وقت کے مطابق ترتیب دیا جاتا ہے۔ اسے پچھلی ڈرائنگ دوبارہ کھولنے، اس کا نام تبدیل کرنے، یا اسے حذف کرنے کے لیے استعمال کریں۔

## File Manager کیسے کھولیں

- ٹرمینل میں `فائلمدیر` ٹائپ کریں، **یا**
- اسکرین کے اوپر File پینل میں **File Manager** ٹول بار بٹن (تاریخ آئیکن) پر کلک کریں۔

پینل کینوس کے بائیں طرف کھلتا ہے، اور جیسے ہی آپ کوئی دوسری کمانڈ شروع کرتے ہیں یا کوئی فائل [درآمد](../import/) کرتے ہیں یہ خود بخود بند ہو جاتا ہے — تاکہ یہ کبھی بھی ایسی ڈرائنگ کے اوپر باقی نہ رہے جسے یہ ابھی تک فہرست میں شامل نہیں کرتا۔ ہر بار یہ ایک تازہ فہرست کے ساتھ دوبارہ کھلتا ہے۔

## تھمب نیل گرڈ

ہر محفوظ ڈرائنگ ایک کارڈ ہے جو ایک لائیو-رینڈر شدہ تھمب نیل، اس کا نام، اور آخری بار کب اپ ڈیٹ ہوئی یہ دکھاتا ہے۔ تھمب نیلز ہر بار پینل کھلنے پر موقع پر بنائے جاتے ہیں — کچھ بھی پہلے سے رینڈر یا محفوظ نہیں ہوتا — اس لیے تھمب نیل بننے کے دوران کارڈ لمحہ بھر کے لیے ایک placeholder آئیکن دکھاتا ہے۔ یہی placeholder اس وقت بھی ظاہر ہوتا ہے جب بننا ناکام ہو جائے، یا ڈرائنگ میں واقعی ابھی تک کوئی شے موجود نہ ہو۔

| عمل | طریقہ |
|--------|-----|
| ڈرائنگ **کھولیں** | اس کے تھمب نیل پر کلک کریں — موجودہ کینوس کا مواد تبدیل کر دیتا ہے |
| **نام تبدیل کریں** | پنسل آئیکن پر کلک کریں، یا نام پر ڈبل-کلک کریں |
| **حذف کریں** | ٹریش آئیکن پر کلک کریں، پھر تصدیق کریں |

اگر ابھی تک کوئی فائل محفوظ نہیں ہوئی، پینل "No files saved" دکھاتا ہے۔ اگر فائلیں ایک اسکرین میں سما نہ سکیں، گرڈ کے نیچے **Page 1 of N** کنٹرولز ظاہر ہوتے ہیں۔

جو فائل فی الحال ایڈیٹر میں کھلی ہو اس کا کارڈ ایک اینٹ رنگ کی انگوٹھی سے نشان زد ہوتا ہے، اور اس میں **حذف کرنے کا بٹن موجود نہیں ہوتا** — کھلی فائل کو حذف کرنے سے اس کا محفوظ شدہ ڈیٹا مٹ جاتا جبکہ کینوس اسے دکھاتا ہی رہتا، اور اگلی ترمیم اسے فوراً واپس محفوظ کر دیتی۔ اس کا نام تبدیل کرنا اب بھی دستیاب ہے۔

## فائل حذف کرنا

ٹریش آئیکن پر کلک کرنے سے فوری حذف نہیں ہوتا — یہ اس کارڈ پر ایک تصدیقی اوورلے فعال کرتا ہے ("Delete this file?" کے ساتھ **Delete** / **Cancel** بٹن)، کیونکہ حذف کرنا مستقل ہے اور واپس نہیں کیا جا سکتا۔ **Cancel** پر کلک کرنا، کسی دوسرے کارڈ کے ٹریش آئیکن پر کلک کرنا، یا کارڈ پر کہیں اور کلک کرنا — سب زیر التوا تصدیق کو کچھ حذف کیے بغیر خارج کر دیتے ہیں۔

## فائل کا نام تبدیل کرنا

پنسل آئیکن پر کلک کریں (یا فائل کے نام پر ڈبل-کلک کریں) تاکہ اسے وہیں ترمیم کیا جا سکے، پھر تصدیق کے لیے **Enter** یا منسوخ کرنے کے لیے **Escape** دبائیں۔ نام تبدیل کرنے کی درخواست مسترد ہو جاتی ہے اگر نیا نام:

- خالی ہو، یا 100 حروف سے لمبا ہو،
- پہلے سے کسی دوسری محفوظ فائل کے زیر استعمال ہو (بڑے/چھوٹے حروف سے قطع نظر)،
- ایک نقطے پر ختم ہو، یا
- کوئی Windows-محفوظ شدہ ڈیوائس نام ہو جیسے `CON`، `PRN`، `AUX`، `NUL`، `COM1`–`COM9`، یا `LPT1`–`LPT9`۔

وہ حروف جو فائل کے نام میں درست نہیں ہوتے (`\ / : * ? " < > |`) ٹائپ کرتے ہی خود بخود ہٹا دیے جاتے ہیں۔ نام تبدیل کرنے سے صرف لیبل بدلتا ہے — یہ گرڈ میں ڈرائنگ کی پوزیشن پر اثر نہیں ڈالتا، کیونکہ وہ آخری بار محفوظ ہونے کے وقت کے مطابق ترتیب دی گئی ہے، نام کے مطابق نہیں۔

## اپنے کام کا بیک اپ لیں — براؤزر اسٹوریج مستقل نہیں ہے

KulmanLab ڈرائنگز **IndexedDB** میں محفوظ کرتا ہے، جو آپ کے براؤزر میں بنایا گیا ایک ڈیٹابیس ہے:

- فائلیں **صرف مقامی طور پر آپ کے ڈیوائس پر** محفوظ ہوتی ہیں — کچھ بھی سرور پر اپ لوڈ نہیں ہوتا۔
- ہر براؤزر اور ڈیوائس کی اپنی آزاد اسٹوریج ہوتی ہے۔ ایک کمپیوٹر پر Chrome میں محفوظ ڈرائنگ Firefox میں، یا کسی دوسری مشین پر ظاہر نہیں ہوتی۔
- یہ اسٹوریج **بغیر کسی انتباہ کے صاف ہو سکتی ہے** — سائٹ ڈیٹا یا براؤزنگ ہسٹری صاف کرنے سے، ڈسک اسپیس کم ہونے سے، پرائیویٹ/incognito ونڈو استعمال کرنے سے، براؤزر یا OS دوبارہ انسٹال کرنے سے، یا ڈیوائس بدلنے سے۔ ان میں سے کوئی بھی آپ کو وہاں موجود چیز بحال کرنے کا موقع نہیں دیتا۔

**ڈرائنگ کو محفوظ رکھنے کا واحد قابل بھروسہ طریقہ یہ ہے کہ اسے اپنی خود کی اسٹوریج میں [برآمد](../export-manager/) کریں۔** جب ممکن ہو `.json` (KulmanLab کا مقامی فارمیٹ) استعمال کریں — یہ ہر شے کو بالکل محفوظ کرتا ہے؛ جب آپ کو دیگر CAD ٹولز کے ساتھ مطابقت درکار ہو تو `.dxf` استعمال کریں۔ ایسا کسی بھی چیز کے لیے کریں جسے کھونا آپ کو ناگوار گزرے گا، اور براؤزر ڈیٹا صاف کرنے، براؤزر یا ڈیوائس بدلنے، یا مشین کچھ عرصے کے لیے رکھ دینے سے پہلے۔

## اسٹارٹ اپ پر خودکار فائل لوڈنگ

جب آپ KulmanLab CAD کھولتے ہیں، ایپ خود بخود اسٹوریج سے **سب سے حال ہی میں ترمیم شدہ فائل** لوڈ کرتی ہے۔ آپ کو ہر بار File Manager سے دستی طور پر کھولنے کی ضرورت نہیں۔

## اسٹوریج منظم کرنا

آپ جتنی ڈرائنگز محفوظ کر سکتے ہیں اس کی کوئی مقررہ حد نہیں، لیکن براؤزر اسٹوریج محدود ہے۔ اگر آپ کو اسٹوریج انتباہات نظر آئیں، File Manager سے پرانی فائلیں حذف کریں — یا اس سے بہتر، انہیں پہلے برآمد کر لیں تاکہ کچھ ضائع نہ ہو۔

ایک ہی وقت میں تمام محفوظ ڈرائنگز ہٹانے کے لیے، [WipeStorage](../wipestorage/) کمانڈ استعمال کریں۔

## فائل کے نام

نئی اور درآمد شدہ فائلوں کو ایک سادہ نام ملتا ہے — کوئی ٹائم اسٹیمپ شامل نہیں کیا جاتا۔ اگر وہ نام پہلے سے استعمال میں ہو، تو ایک Finder/Explorer طرز کا لاحقہ خود بخود شامل کیا جاتا ہے (`plan (2)`, `plan (3)`, …) تاکہ کچھ بھی اوور رائٹ نہ ہو۔ آپ ہمیشہ [نام تبدیل کر کے](#فائل-کا-نام-تبدیل-کرنا) بعد میں فائل کو زیادہ واضح نام دے سکتے ہیں۔
