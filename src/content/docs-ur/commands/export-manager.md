# Export Manager

`exportmanager` کمانڈ موجودہ ڈرائنگ کو آپ کے فائل سسٹم میں ڈاؤن لوڈ کرتی ہے۔ دو فارمیٹس دستیاب ہیں، ساتھ ساتھ کارڈز کے طور پر دکھائے گئے: دوسرے CAD ٹولز کے ساتھ مطابقت کے لیے **DXF** اور KulmanLab CAD کے اندر مکمل وفاداری کے ساتھ محفوظ کرنے کے لیے **JSON** — ہر کارڈ بالکل بتاتا ہے کہ وہ فارمیٹ کون سی اینٹیٹی اقسام ساتھ لے کر جاتا ہے۔

## ایکسپورٹ کیسے کریں

1. فائل پینل میں ٹول بار کے **Export** بٹن (ڈاؤن لوڈ آئیکن) پر کلک کریں، یا ٹرمینل میں `exportmanager` ٹائپ کریں۔
2. **Export Manager** پاپ اپ کھلتا ہے جو JSON اور DXF کارڈز ساتھ ساتھ دکھاتا ہے، ہر ایک بتاتا ہے کہ کیا ایکسپورٹ ہوتا ہے (اور DXF کے لیے، کیا چھوٹ جاتا ہے)۔
3. فارمیٹ منتخب کرنے کے لیے کسی کارڈ پر کلک کریں — **JSON** یا **DXF**۔
4. **Export \<FORMAT\>** بٹن پر کلک کریں۔ فائل خود بخود آپ کے ڈیفالٹ ڈاؤن لوڈز فولڈر میں ڈاؤن لوڈ ہو جاتی ہے۔

ایکسپورٹ کیے بغیر پاپ اپ بند کرنے کے لیے `Escape` دبائیں۔

## فارمیٹ منتخب کرنا

| فارمیٹ | ایکسٹینشن | سب سے بہتر کس کے لیے | حدود |
|--------|-----------|------------------------|-------|
| **JSON** *(نیٹو)* | `.json` | KulmanLab CAD میں دوبارہ کھولنے کے لیے کام محفوظ کرنا | دوسرے CAD ٹولز کے ساتھ مطابق نہیں |
| **DXF** | `.dxf` | FreeCAD، LibreCAD وغیرہ کے ساتھ شیئر کرنا | Hatches، Dimensions، Leaders، اور Text ایکسپورٹ نہیں ہوتے |

**JSON کب استعمال کریں:** جب بھی آپ اپنے کام کی مکمل کاپی محفوظ کرنا چاہیں۔ JSON KulmanLab کا نیٹو فارمیٹ ہے اور ہر اینٹیٹی کو بالکل محفوظ رکھتا ہے — Dimensions، Leaders، Hatches، اور تمام لیئر ڈیٹا سمیت۔

**DXF کب استعمال کریں:** جب آپ کو ڈرائنگ کسی ایسے شخص کو دینی ہو جو کوئی اور CAD ایپلیکیشن استعمال کرتا ہو۔ ایکسپورٹ شدہ فائل AC1032 DXF فارمیٹ استعمال کرتی ہے اور زیادہ تر DXF-مطابق ٹولز میں کھولی جا سکتی ہے۔

## ہر فارمیٹ میں کیا ایکسپورٹ ہوتا ہے

### JSON ایکسپورٹ

ہر اینٹیٹی قسم شامل ہے:

- Lines، Circles، Arcs، Ellipses، Polylines، Splines
- Text
- Dimensions (linear، aligned، continued، radius، diameter)
- Leaders (multileaders)
- Hatches، ان کے pattern، scale، angle، اور origin سمیت
- Layers اور Linetypes

### DXF ایکسپورٹ

صرف جیومیٹری اینٹیٹیز شامل ہیں:

- Lines، Circles، Arcs، Ellipses، Polylines (`LWPOLYLINE` کے طور پر ایکسپورٹ)، Splines
- Layers اور Linetypes

**DXF میں ایکسپورٹ نہیں ہوتا:** Hatches، Dimensions، Leaders، اور Text۔ Dimensions اور Leaders KulmanLab کے مخصوص ڈیٹا سٹرکچرز استعمال کرتے ہیں جنہیں معیاری DXF میں وفاداری سے پیش نہیں کیا جا سکتا؛ Hatches ابھی تک DXF میں بالکل بھی ایکسپورٹ نہیں ہوتے، اگرچہ وہ اس سے امپورٹ ہوتے ہیں؛ Text ایکسپورٹ بھی ابھی تک نافذ نہیں کیا گیا۔ اگر آپ کی ڈرائنگ میں ان میں سے کوئی ہے، تو انہیں محفوظ کرنے کے لیے JSON یا [Print Manager](../print-manager/) استعمال کریں۔

## ایکسپورٹ شدہ فائل کا نام

ڈاؤن لوڈ شدہ فائل کا نام موجودہ ڈرائنگ فائل کے مطابق رکھا جاتا ہے (مثلاً `myplan.json`)۔ ایکسٹینشن منتخب کردہ فارمیٹ کے مطابق تبدیل ہو جاتی ہے۔

## Export Manager اور Print Manager کے درمیان فرق

| خصوصیت | Export Manager | Print Manager |
|--------|-----------------|-----------------|
| آؤٹ پٹ | ویکٹر سورس فائل (.dxf / .json) | راسٹر تصویر (.png / .jpeg / .webp / .pdf) |
| دوسرے ٹولز میں ترمیم پذیر | ہاں (DXF) | نہیں |
| Layers اور Linetypes محفوظ رکھتا ہے | ہاں | نہیں (فلیٹ رینڈر ہوتا ہے) |
| Dimensions اور Leaders حاصل کرتا ہے | صرف JSON | ہاں |

جب آپ کو ترمیم پذیر فائل درکار ہو تو **Export Manager** استعمال کریں۔ جب آپ کو بصری سنیپ شاٹ درکار ہو تو [Print Manager](../print-manager/) استعمال کریں۔
