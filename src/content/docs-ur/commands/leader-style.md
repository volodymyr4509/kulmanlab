# LeaderStyle

`رہنما` کمانڈ نام والے رہنما انداز کا منتظم کھولتی ہے۔ ہر نیا [Leader](../leader/) بنتے وقت *موجودہ* انداز کی ترتیبات نقل کرتا ہے۔

## انداز میں ترمیم

`رہنما` لکھیں یا تشریحی پینل میں **رہنما لائن کا انداز** پر کلک کریں۔ ✓ موجودہ انداز دکھاتا ہے؛ نام کے پاس پنسل سے نام تبدیل کریں۔ پیش منظر ڈرائنگ والے ہی رینڈرر سے فوراً تازہ ہوتا ہے۔

| خانہ | کام |
|---|---|
| متن کا اتصال | اوپر، درمیان، نیچے یا زیر خط |
| تیر کا سرا / تیر کا سائز | ہر بازو کے سرے کا نشان اور سائز |
| لینڈنگ کا خلا | لینڈنگ اور متن کے درمیان جگہ |
| متن کی گردش | لیبل کا زاویہ، ڈگری میں |
| متن کا انداز | [TextStyle](../text-style/) سے فونٹ، اونچائی، موٹا اور ترچھا ایک بار نقل کرتا ہے |
| فونٹ / متن کی اونچائی | لیبل کا فونٹ اور اونچائی |
| موٹا / ترچھا | آزاد متن وضع کاری |
| متن کا فریم | لیبل کے گرد مستطیل فریم |

**نیا** منتخب انداز کی نقل بناتا ہے۔ `Standard` کا نام تبدیل یا اسے حذف نہیں کیا جا سکتا؛ موجودہ انداز بھی حذف نہیں ہو سکتا۔ **موجودہ بنائیں** صرف بعد میں بننے والے رہنماؤں پر اثر ڈالتا ہے—پہلے سے موجود اشیا نہیں بدلتیں۔ خالی، دہرایا ہوا یا DXF کے لیے ناموزوں نام **ٹھیک ہے** کو غیر فعال رکھتا ہے۔ درآمد شدہ تشریحی انداز پوشیدہ مگر محفوظ رہتے ہیں۔

## محفوظ کرنا اور DXF

KulmanLab `MLEADERSTYLE` ریکارڈ درآمد اور برآمد کرتا ہے۔ نام، تیر کا سرا اور سائز، لینڈنگ وقفہ، متن اونچائی، اتصال، فریم اور تشریحی پرچم انداز کے خانوں کے طور پر محفوظ رہتے ہیں۔ برآمد پر گروپ `342` ملتے فونٹ، موٹائی، ترچھے پن اور اونچائی والے متن کے انداز کی طرف اشارہ کرتا ہے؛ کوئی مماثلت نہ ہو تو `Standard` استعمال ہوتا ہے۔ یہ DXF حوالہ ایپ کی ایک بار نقل کو زندہ ربط نہیں بناتا۔ ایک اتصال قدر بائیں اور دائیں دونوں DXF خانوں میں لکھی جاتی ہے۔

مزید دیکھیے: [Leader](../leader/)، [LeaderAdd](../leader-add/) اور [LeaderRemove](../leader-remove/)۔
