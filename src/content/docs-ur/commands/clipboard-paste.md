# ClipboardPaste

`کلپبورڈچسپاں` کمانڈ وہ اشیاء پڑھتی ہے جو [ClipboardCopy](../clipboard-copy/) نے **سسٹم کلپ بورڈ** پر لکھی تھیں، اور انہیں موجودہ نقشے میں آپ کے منتخب کردہ نقطے پر رکھتی ہے۔ چونکہ یہ اصل سسٹم کلپ بورڈ ہے، ماخذ کوئی دوسرا نقشہ، دوسرا براؤزر ٹیب، یا اسی دن پہلے کا کوئی سیشن بھی ہو سکتا ہے۔

## چسپاں کرنے کا طریقہ

1. `Ctrl+V` دبائیں (macOS پر `Cmd+V`)، یا ٹرمینل میں `کلپبورڈچسپاں` لکھیں۔
2. جب تک براؤزر کلپ بورڈ کا متن سونپتا ہے، پرامپٹ **reading clipboard…** دکھاتا ہے۔
3. لوڈ ہوتے ہی پرامپٹ **pick insertion point** بن جاتا ہے اور جیومیٹری کا پیش منظر آپ کے کرسر کے ساتھ چلتا ہے۔
4. اشیاء رکھنے کے لیے **کلک کریں**۔ وہ نقشے میں شامل ہو جاتی ہیں اور منتخب رہتی ہیں۔

پیش منظر کاپی کے **حوالہ نقطے** سے بندھا ہوتا ہے — اصل انتخاب کی مشترکہ حد کا نچلا بایاں کونہ۔ وہی کونہ آپ کے کرسر کے نیچے رہتا ہے، چنانچہ کاپی کی گئی اشیاء کی باہمی ترتیب بعینہٖ برقرار رہتی ہے۔

## چسپاں کرتے وقت کیا ہوتا ہے

| مرحلہ | رویہ |
|-------|------|
| **نئی شناخت** | ہر چسپاں کی گئی شے کو نیا id ملتا ہے، لہٰذا دو بار چسپاں کرنے سے دو خودمختار مجموعے بنتے ہیں |
| **منتقلی** | اشیاء کرسر − حوالہ نقطہ کے برابر کھسکائی جاتی ہیں |
| **پرتوں کا ادغام** | ہدف نقشے میں جو بھی حوالہ دی گئی پرت موجود نہیں، وہ نام کے مطابق شامل کر دی جاتی ہے |
| **لائن ٹائپ کا ادغام** | ہدف نقشے میں جو بھی حوالہ دیا گیا لائن ٹائپ موجود نہیں، وہ نام کے مطابق شامل کر دیا جاتا ہے |
| **انتخاب** | پچھلا انتخاب ہٹ جاتا ہے اور چسپاں کی گئی اشیاء ہی انتخاب بن جاتی ہیں |

### پرتوں اور لائن ٹائپ کا ادغام

غائب جدول اندراجات شامل کی جاتی ہیں؛ **جو موجود ہیں انہیں چھوا نہیں جاتا**۔ اگر کلپ بورڈ `WALLS` نام کی سرخ پرت لائے اور ہدف نقشے میں پہلے سے نیلی `WALLS` موجود ہو، تو ہدف کی تعریف جیتتی ہے اور چسپاں کی گئی اشیاء اسی میں شامل ہو جاتی ہیں — یعنی وہ نیلی ہوں گی۔ چسپاں کرنے سے ہدف نقشے میں کچھ بھی از سرِ نو متعین نہیں ہوتا۔

مختلف پرت روایات والے نقشوں کے درمیان کاپی کرتے وقت یہ اہم ہے: نقشہ بدل کر چسپاں کرنے کے بعد اگر رنگ توقع کے مطابق نہ ہوں تو [Layer Manager](../layer-manager/) دیکھیں۔

## جب کلپ بورڈ میں چسپاں کرنے کو کچھ نہ ہو

ClipboardPaste صرف وہی مواد قبول کرتی ہے جو ClipboardCopy نے بنایا ہو۔ کلپ بورڈ پر باقی ہر چیز — سادہ متن، کوئی لنک، کوئی تصویر، کسی اور ایپلی کیشن کا JSON — مسترد کر دی جاتی ہے اور ٹرمینل بتاتا ہے:

```
Clipboard has no copied entities
```

اگر براؤزر کلپ بورڈ تک رسائی سے مکمل انکار کر دے تو پیغام **Blocked by the browser: allow clipboard in site settings, by the address bar** ہوتا ہے۔ دونوں صورتوں میں کمانڈ نقشہ بدلے بغیر ختم ہو جاتی ہے۔

## کی بورڈ حوالہ

| کلید | عمل |
|------|-----|
| `Ctrl+V` / `Cmd+V` | ClipboardPaste چلائیں |
| `Escape` | منسوخ کریں — اشیاء ضائع کر دی جاتی ہیں اور کچھ شامل نہیں ہوتا |

پڑھنے کے مرحلے میں منسوخ کرنا محفوظ ہے: اگر کلپ بورڈ اُس وقت جواب دے جب آپ پہلے ہی منسوخ کر چکے ہوں یا کوئی اور کمانڈ شروع کر چکے ہوں، تو دیر سے آنے والا نتیجہ اُس وقت جاری کام میں مداخلت کرنے کے بجائے ضائع کر دیا جاتا ہے۔

## ٹیبز کے درمیان کاپی کرنا

نقشوں کے درمیان معمول کا طریقۂ کار:

1. ماخذ نقشہ کھولیں، جیومیٹری منتخب کریں، `Ctrl+C` دبائیں۔
2. دوسرے ٹیب پر جائیں — یا ایپ کا دوسرا ٹیب کھول کر کوئی اور فائل لوڈ کریں۔
3. `Ctrl+V` دبائیں اور اندراج نقطے پر کلک کریں۔

دونوں ٹیبز کا ماخذ ایک ہی ہے اور وہ سسٹم کلپ بورڈ مشترک رکھتے ہیں، لہٰذا کچھ اپ لوڈ نہیں ہوتا اور کوئی سرور شامل نہیں ہوتا۔ مواد پورے وقت آپ کے اپنے کلپ بورڈ پر JSON متن ہی رہتا ہے۔

## معاون اشیاء

ClipboardCopy جس بھی قسم کی شے لکھ سکتی ہے، ClipboardPaste اسے واپس پڑھ سکتی ہے — اسی ترتیب کے ساتھ جو اصل `.json` فارمیٹ استعمال کرتا ہے۔
