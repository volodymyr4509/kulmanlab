# ClipboardCopy

`ClipboardCopy` کمانڈ منتخب اشیاء کو آپ کے **سسٹم کلپ بورڈ** پر JSON متن کے طور پر لکھتی ہے۔ چونکہ یہ میموری کے کسی بفر کے بجائے اصل کلپ بورڈ استعمال کرتی ہے، کاپی کی گئی جیومیٹری نقشے سے باہر بھی زندہ رہتی ہے: [ClipboardPaste](../clipboard-paste/) کے ذریعے اسے کسی دوسری فائل، دوسرے براؤزر ٹیب، یا بعد میں کھولی گئی ونڈو میں چسپاں کر دیں۔

[Copy](../copy/) سے فرق یہی ہے: Copy ایک ہی حرکت میں موجودہ نقشے کے اندر اشیاء کی نقل بناتی ہے، جبکہ ClipboardCopy انہیں ایسی جگہ رکھتی ہے جہاں سے بالکل مختلف نقشے میں بھی اٹھایا جا سکے۔

## شروع کرنے کے دو طریقے

**پہلے منتخب کریں، پھر کاپی** — تیز راستہ:

1. کینوس پر ایک یا زیادہ اشیاء منتخب کریں۔
2. `Ctrl+C` دبائیں (macOS پر `Cmd+C`)، یا ٹرمینل میں `ClipboardCopy` لکھیں۔
3. اشیاء فوراً کلپ بورڈ پر لکھ دی جاتی ہیں اور کمانڈ ختم ہو جاتی ہے۔

**پہلے چلائیں، پھر منتخب کریں** — بغیر کچھ منتخب کیے شروع کرنا:

1. انتخاب خالی ہوتے ہوئے `Ctrl+C` دبائیں یا `ClipboardCopy` لکھیں۔
2. پرامپٹ دکھاتا ہے **pick objects to copy — Enter or Space to confirm**۔
3. **اشیاء منتخب کریں** — انفرادی اشیاء کو انتخاب میں شامل یا خارج کرنے کے لیے کلک کریں، یا رقبے سے منتخب کرنے کے لیے گھسیٹیں۔
4. انتخاب کاپی کرکے باہر نکلنے کے لیے **Enter** یا **Space** دبائیں۔

بغیر کچھ منتخب کیے **Enter** یا **Space** دبانے سے کمانڈ محض ختم ہو جاتی ہے، کلپ بورڈ کو چھوئے بغیر۔

## کیا کاپی ہوتا ہے

کلپ بورڈ کا مواد محض جیومیٹری سے زیادہ لے کر جاتا ہے، تاکہ کسی اجنبی نقشے میں چسپاں کرنے پر بھی سب درست دکھے:

| حصہ | مقصد |
|-----|------|
| **اشیاء** | ہر منتخب شے کی مکمل ترتیب شدہ صورت |
| **حوالہ نقطہ** | انتخاب کی مشترکہ حد کا نچلا بایاں کونہ — جسے ClipboardPaste کرسر سے جوڑتی ہے |
| **پرتیں** | صرف وہ پرتیں جن کا کاپی کی گئی اشیاء واقعی حوالہ دیتی ہیں، نام کے مطابق |
| **لائن ٹائپ** | صرف وہ لائن ٹائپ جن کا کاپی کی گئی اشیاء واقعی حوالہ دیتی ہیں، نام کے مطابق |

کاپی کے ساتھ صرف *حوالہ دی گئی* جدول اندراجات جاتی ہیں — ماخذ نقشے کی پوری پرت اور لائن ٹائپ جدولیں نہیں۔ ہیچ پیٹرن بالکل ساتھ نہیں بھیجے جاتے اور ضرورت بھی نہیں: کسی نقشے کی پیٹرن جدول اندرونی طے شدہ مجموعہ ہوتی ہے، اور آپ کی اپ لوڈ کردہ `.pat` فائلیں فی صارف ذخیرے میں رہتی ہیں جو پہلے ہی ٹیبز کے درمیان مشترک ہے، لہٰذا چسپاں کیا ہوا ہیچ اپنا پیٹرن خود ڈھونڈ لیتا ہے۔

## تصدیق

کامیابی پر ٹرمینل بتاتا ہے کہ کتنی اشیاء لکھی گئیں:

```
3 entities copied to clipboard
```

اگر براؤزر کلپ بورڈ تک رسائی سے انکار کر دے تو ٹرمینل **Copy failed: clipboard access denied** دکھاتا ہے اور کچھ نہیں لکھا جاتا۔ یہ براؤزر کا اجازت سے متعلق فیصلہ ہے، نقشے کی خرابی نہیں — نیچے [کلپ بورڈ کی اجازتیں](#کلپ-بورڈ-کی-اجازتیں) دیکھیں۔

## کمانڈ کے دوران انتخاب

| طریقہ | رویہ |
|-------|------|
| **کلک** | کرسر کے نیچے والی شے کو انتخاب میں شامل یا خارج کرتا ہے |
| **دائیں گھسیٹنا** (سخت) | باکس کے اندر مکمل طور پر آنے والی اشیاء شامل کرتا ہے |
| **بائیں گھسیٹنا** (قاطع) | باکس کی حد کو کاٹنے والی اشیاء شامل کرتا ہے |
| **Enter** / **Space** | انتخاب کی تصدیق کرکے کاپی کرتا ہے |

## کی بورڈ حوالہ

| کلید | عمل |
|------|-----|
| `Ctrl+C` / `Cmd+C` | ClipboardCopy چلائیں |
| `Enter` / `Space` | موجودہ انتخاب کاپی کریں، یا کچھ منتخب نہ ہو تو باہر نکلیں |
| `Escape` | کاپی کیے بغیر منسوخ کریں |

## کلپ بورڈ کی اجازتیں

سسٹم کلپ بورڈ پر لکھنے کے لیے براؤزر کی اجازت درکار ہوتی ہے۔ عملاً، کلید دبانے سے شروع ہونے والی کاپی موجودہ ڈیسک ٹاپ براؤزرز میں بغیر پوچھے دے دی جاتی ہے، مگر وہ صفحہ جس کا فوکس چلا گیا ہو، یا سخت کلپ بورڈ ترتیبات والا براؤزر، انکار کر سکتا ہے۔ رسائی سے انکار کا پیغام دکھے تو صفحے کو فوکس دینے کے لیے کینوس پر ایک بار کلک کریں اور دوبارہ کوشش کریں۔

چونکہ مواد عام JSON متن ہے، اس کے بعد آپ جو بھی کاپی کریں گے وہ اس کی جگہ لے لے گا — متن کی ایک سطر ہو یا کوئی لنک۔ اگر درمیان میں آپ نے کلپ بورڈ کسی اور کام کے لیے استعمال کیا ہے تو چسپاں کرنے سے پہلے دوبارہ کاپی کر لیں۔

## معاون اشیاء

ClipboardCopy ہر قسم کی شے پر کام کرتی ہے۔ اشیاء اسی طریقہ کار سے ترتیب دی جاتی ہیں جو اصل `.json` برآمد استعمال کرتا ہے، لہٰذا راستے میں کچھ ضائع نہیں ہوتا۔
