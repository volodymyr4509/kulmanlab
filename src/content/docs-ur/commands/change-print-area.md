# ChangePrintArea

`ChangePrintArea` کمانڈ وہ مستطیل علاقہ طے کرتی ہے جسے [Print Manager](../print-manager/) برآمد کرتا ہے۔ یہ Print Manager کے چھپے ہوتے خالی کینوس پر چلتی ہے اور دو مخالف کونے لیتی ہے — [Rectangle](../rectangle/) جیسے ہی دو کلک، اس لیے ٹائپ کیے گئے نقاط اور سنیپنگ بالکل اسی طرح کام کرتے ہیں۔

## علاقہ منتخب کرنا

1. ٹرمینل میں `ChangePrintArea` ٹائپ کریں، یا Print Manager کے سائیڈبار میں **Change Area** پر کلک کریں۔ Print Manager چھپ جاتا ہے اور کینوس انٹرایکٹو ہو جاتا ہے۔
2. **پہلے کونے پر کلک کریں**، یا درست نقطے کے لیے `X,Y` ٹائپ کرکے **Enter** دبائیں۔
3. **مخالف کونے پر کلک کریں**، یا دوبارہ `X,Y` ٹائپ کریں۔

Print Manager نئے علاقے کے ساتھ دوبارہ کھلتا ہے، اور پیش نظارہ اس علاقے کے درست تناسب کے مطابق سائز بدل لیتا ہے۔

کونے کسی بھی دوسرے نقطے کے انتخاب کی طرح گرپس اور تقاطع پر سنیپ ہوتے ہیں، سو اندازے کے بجائے کھینچی گئی جیومیٹری کے مطابق کٹائی کی جا سکتی ہے۔ دونوں کونوں کی ترتیب اہم نہیں: مخالف کونے وہی مستطیل بناتے ہیں۔

منسوخ کرنے کے لیے `Escape` دبائیں۔ کچھ نہیں لکھا جاتا، سو Print Manager اسی علاقے کے ساتھ دوبارہ کھلتا ہے جو پہلے سے تھا۔

## علاقہ کہاں یاد رکھا جاتا ہے

انتخاب مجموعی طور پر نہیں بلکہ ہر سیاق کے لیے الگ محفوظ ہوتا ہے:

| سیاق | خانہ |
|---|---|
| Model سپیس | ایک مشترکہ خانہ |
| ہر لے آؤٹ | اپنا خانہ، الگ رکھا ہوا |

اسی لے آؤٹ — یا Model — میں Print Manager دوبارہ کھولنے پر ری سیٹ ہونے کے بجائے اس سیاق کی آخری کٹائی بحال ہو جاتی ہے، اور لے آؤٹ بدلنے پر ہر ایک کا علاقہ برقرار رہتا ہے۔

یہ صرف میموری میں رہتا ہے۔ صفحہ دوبارہ لوڈ کرنے پر تمام محفوظ علاقے مٹ جاتے ہیں اور Print Manager نیچے دی گئی ڈیفالٹ اقدار پر لوٹ آتا ہے۔

## ڈیفالٹ علاقہ

موجودہ سیاق کے لیے کچھ محفوظ نہ ہو تو Print Manager اس پر کھلتا ہے:

| سیاق | ڈیفالٹ |
|---|---|
| Model سپیس | تمام اینٹٹیز کا باؤنڈنگ باکس — وہی وسعت جس پر [Fit](../fit/) زوم کرتا ہے |
| ہر لے آؤٹ | پوری شیٹ |
