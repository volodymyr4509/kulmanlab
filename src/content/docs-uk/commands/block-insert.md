# Block Insert

Команда `ВставитиБлок` відкриває палітру попередніх переглядів усіх блоків креслення й розміщує вибраний. Створюйте блоки командою [Block Create](../block-create/) або відкрийте файл DXF, що їх містить.

## Розміщення блока

1. Введіть `ВставитиБлок` або клацніть **Вставити блок** на панелі **Блоки**. Палітра закріплюється ліворуч із плиткою перегляду на кожен блок, по дванадцять на сторінці; стрілки під плитками перегортають сторінки.
2. Вводьте в **Пошук блоків**, щоб відфільтрувати плитки за назвою.
3. Задайте **Масштаб** (більший за 0) і **Поворот** у градусах. **Повторювати вставлення** типово ввімкнено.
4. Клацніть плитку блока. Блок слідує за курсором: клацніть, щоб розмістити його за базовою точкою, або введіть X,Y для точного положення. Коли курсор прив'язаний до кута, можна ввести довжину.
5. Коли **Повторювати вставлення** ввімкнено, блок і далі слідує за курсором для наступної копії, доки не натиснете **Escape**. Коли вимкнено, команда завершується після однієї копії.

## Варто знати

- Щоб видалити блок, клацніть кошик на його плитці й підтвердьте. Блок, на який є посилання в кресленику, видалити не можна: плитка каже **Використовується, не можна видалити**.
- Креслення без блоків показує в палітрі **У цьому кресленні немає блоків**.
- **Escape** закриває палітру, коли нічого не розміщується. Це одна з закріплених панелей, яких ліворуч показано лише по одній.
