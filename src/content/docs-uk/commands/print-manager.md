# Менеджер друку

Команда `PrintManager` відкриває **Менеджер друку** — спеціальне вікно експорту з попереднім переглядом, вибором формату (PNG / JPEG / WebP / PDF), вибором Style (Default / Monochrome / Blueprint) та необов'язковим обрізанням ділянки. Нічого не надсилається на фізичний принтер — результат завантажується як файл.

## Відкриття Менеджера друку

Натисніть кнопку **Print** на панелі інструментів або введіть `PrintManager` у терміналі. Менеджер друку відкривається негайно, показуючи попередній перегляд поточного вікна перегляду.

Попередній перегляд рендериться тим самим шляхом коду, з тією самою роздільною здатністю в пікселях, що й файл, який ви зрештою експортуєте — зміна Quality, Style або ділянки експорту миттєво повторно рендерить попередній перегляд, тож те, що ви бачите, і є тим, що завантажується, а не наближенням до цього.

## Макет Менеджера друку

Вікно складається з двох панелей:
- **Ліва бічна панель** — всі елементи керування експортом.
- **Права панель** — полотно попереднього перегляду, що оновлюється при зміні налаштувань.

### Елементи керування бічної панелі

| Елемент | Опис |
|---------|------|
| **Change Area** | Обрізати до довільного прямокутника на полотні (дивіться нижче) — справді обрізає експортоване зображення, зокрема на макеті з паперовим простором, а не лише попередній перегляд на екрані |
| Спадне меню **Quality** | Встановлює роздільну здатність експорту (дивіться нижче) |
| Спадне меню **Style** | Default, Monochrome або Blueprint — див. *Стилі друку* нижче. Monochrome за замовчуванням для чистого друку |
| Список **Format** | PNG, JPEG, WebP або PDF |
| Кнопка **Export** | Генерує та завантажує файл |

## Стилі друку

Спадне меню **Style** керує як кольором чорнила, яким малюються об'єкти, так і фоном сторінки:

| Стиль | Чорнило | Фон сторінки |
|-------|---------|--------------|
| **Default** | Власний колір кожного об'єкта | Білий |
| **Monochrome** *(за замовчуванням)* | Суцільний чорний, незалежно від кольору об'єкта/шару | Білий |
| **Blueprint** | Суцільний білий, незалежно від кольору об'єкта/шару | Глибокий прусський синій, з ледь помітною довідковою сіткою |

Blueprint відтворює вигляд традиційного архітектурного ціанотипного друку — білі лінії на темно-синьому аркуші. Її довідкова сітка масштабується відносно розміру сторінки, а не DPI, тож виглядає з однаковою густотою за будь-якого налаштування Quality, а не густішає зі збільшенням роздільної здатності.

## Якість і роздільна здатність

Спадне меню **Якість** встановлює DPI, з яким рендериться експорт:

| Quality | DPI |
|---------|-----|
| Draft | 72 |
| Normal *(за замовчуванням)* | 150 |
| Presentation | 300 |
| Max | 600 |

Вища якість дає більше та чіткіше зображення при тому самому фізичному розмірі — товщина ліній масштабується разом із роздільною здатністю, тож лінія зберігає ту саму *фізичну* товщину на папері за будь-якого налаштування Якості, а не виглядає тоншою зі збільшенням DPI. Єдиний виняток — тонка лінія (товщина `0`), яка традиційно визначається як "найтоншу лінію, яку може намалювати пристрій виводу" — вона залишається фіксованою шириною 1 піксель на будь-якому рівні Якості, точно так само, як поводиться на живому полотні.

Зміна Якості миттєво повторно рендерить попередній перегляд, тож ви бачите реальну чіткість (і компроміс щодо розміру файлу) перед експортом.

## Вибір довільної ділянки для експорту

Типово попередній перегляд показує обмежувальну рамку всіх об'єктів у просторі Моделі — ту саму протяжність, до якої масштабує [Fit](../fit/) — або весь аркуш на макеті. Щоб експортувати певну область:

1. Натисніть **Change Area** — Менеджер друку ховається і полотно стає інтерактивним.
2. **Клацніть перший кут** прямокутника експорту.
3. **Клацніть протилежний кут** — Менеджер друку знову відкривається з вибраною ділянкою у попередньому перегляді.

Натисніть `Escape` під час вибору ділянки для скасування та відновлення попередньої ділянки.

Полотно попереднього перегляду динамічно змінює розмір відповідно до **точного співвідношення сторін** вибраної ділянки, тому попередній перегляд є піксельно точним.

Вибрана область запам'ятовується окремо для простору Моделі та для кожного макета до перезавантаження сторінки — див. [ChangePrintArea](../change-print-area/).

## Формати експорту

| Формат | Найкраще для | Примітки |
|--------|-------------|----------|
| **PNG** | Без втрат, чіткі лінії | Фон сторінки стилю вбудовано, без прозорості |
| **JPEG** | Менший файл для надсилання | Якість 95%, легке стискання |
| **WebP** | Найменший файл для веб | Та ж якість 95%, краще стискання ніж JPEG |
| **PDF** | Документи готові до друку | Зображення вбудоване в контейнер PDF з DPI обраної Quality, розміром так, щоб сторінка друкувалася в справжньому фізичному масштабі |

Експортований файл називається `kulman-<мітка часу>.<розширення>` та завантажується автоматично.

## Роздільна здатність та фон

- **Експорт простору моделі / вікна перегляду**: обмежено до 2000 × 2000 пікселів за стандартної якості Normal (150 DPI), пропорційно масштабовано до вибраної ділянки; межа також масштабується разом із Quality — Draft має нижчу межу, Presentation і Max — вищу (до 8000 × 8000 при Max/600 DPI).
- **Експорт макета (паперовий простір)**: розмір визначається безпосередньо з розмірів паперу макета при обраному DPI — наприклад, аркуш A4 (210 × 297 мм) при якості Normal експортується приблизно у 1240 × 1754 px — тож не підпадає під обмеження 2000 px вікна перегляду.
- Фон відповідає обраному **Style** друку — білий для Default і Monochrome, глибокий прусський синій для Blueprint (див. *Стилі друку* вище).
- Шари, позначені як **не для друку**, виключаються з експорту.

## Довідник клавіатури

| Клавіша | Дія |
|---------|-----|
| `Escape` (під час вибору ділянки) | Скасувати вибір ділянки, відновити попередню |
| `Escape` (у Менеджері друку) | Закрити Менеджер друку |
