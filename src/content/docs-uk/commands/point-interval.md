# Point Interval

Команда `ТочкиЧерезІнтервал` ставить [точки](../point/) з фіксованим кроком уздовж об'єкта, як пікети вздовж траси. Сам об'єкт не змінюється: точки — нові об'єкти на поточному шарі й у поточному кольорі, зручні для прив'язки.

## Точки з кроком

1. Введіть `ТочкиЧерезІнтервал` у терміналі або виберіть **Point Interval** у випадному меню масивів на панелі Edit.
2. **Клацніть об'єкт біля кінця, з якого почати** — лінію, полілінію, дугу, коло, еліпс або сплайн. Усе інше відхиляється, і можна вибрати знову.
3. **Введіть довжину кроку.** Під час введення точки показуються на об'єкті.
4. Натисніть **Enter** або **Space**, щоб поставити їх. Команда завершується.

## Де опиняються точки

- Перша точка стоїть за один крок від початку, решта — через крок одна від одної, з вимірюванням уздовж об'єкта, разом із кривими. На самому початку точки немає.
- На відкритому об'єкті — лінії, відкритій полілінії, дузі, частині еліпса чи відкритому сплайні — відлік іде від кінця, біля якого ви клацнули. Залишок біля дальнього кінця лишається без позначки: дальній кінець отримує точку, лише коли крок укладається рівно.
- На замкненому об'єкті — колі, замкненій полілінії, повному еліпсі чи замкненому сплайні — відлік іде від власного початку об'єкта, хоч де ви клацнете: коло — від кута 0 проти годинникової стрілки, замкнена полілінія — від першої вершини. Точки закінчуються перед початком.
- Довжина 0 чи менша, довша за об'єкт або така, що дала б понад 32767 точок, відхиляється: термінал пояснює чому й очищує її, щоб ви могли ввести знову.

Backspace видаляє останній символ. Escape починає спочатку, щоб вибрати інший об'єкт. Enter або Space до вибору об'єкта завершує команду.
