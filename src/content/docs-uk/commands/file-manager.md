# File Manager

Команда `МенеджерФайлів` відкриває **сітку мініатюр** усіх креслеників, збережених у локальному сховищі вашого браузера, відсортованих за часом останнього збереження. Використовуйте її, щоб повторно відкрити попередній кресленик, перейменувати його або видалити.

## Відкриття File Manager

- Введіть `МенеджерФайлів` у терміналі, **або**
- Клацніть кнопку **File Manager** на панелі інструментів (іконка історії) у панелі File у верхній частині екрана.

Панель відкривається з лівого боку полотна і закривається автоматично, щойно ви запускаєте іншу команду або [імпортуєте](../import/) файл — тож вона ніколи не залишається над кресленником, якого ще не містить у списку. Кожного разу вона відкривається заново зі свіжим списком.

## Сітка мініатюр

Кожен збережений кресленик — це картка з мініатюрою, згенерованою наживо, його назвою та часом останнього оновлення. Мініатюри створюються на місці щоразу, коли відкривається панель — нічого не рендериться заздалегідь і не зберігається — тому картка на мить показує іконку-заповнювач, поки її мініатюра малюється. Той самий заповнювач з'являється також, якщо генерація не вдається або якщо кресленик справді ще не містить жодного об'єкта.

| Дія | Як виконати |
|-----|-------------|
| **Відкрити** кресленик | Клацніть його мініатюру — замінює поточний вміст полотна |
| **Перейменувати** | Клацніть іконку олівця або двічі клацніть назву |
| **Видалити** | Клацніть іконку кошика, потім підтвердьте |

Якщо ще жодного файлу не збережено, панель показує "No files saved". Якщо файлів більше, ніж вміщується на одному екрані, під сіткою з'являються елементи керування **Page 1 of N**.

Картка файлу, який наразі відкритий у редакторі, позначена кільцем акцентного кольору і **не має кнопки видалення** — видалення відкритого файлу стерло б його збережені дані, тоді як полотно все ще показувало б його, а наступна ж правка просто зберегла б його назад. Перейменування залишається доступним.

## Видалення файлу

Клацання на іконку кошика не видаляє файл негайно — воно активує накладку підтвердження на цій картці ("Delete this file?" з кнопками **Delete** / **Cancel**), оскільки видалення незворотне і не може бути скасоване. Клацання **Cancel**, клацання іконки кошика іншої картки або клацання деінде на картці скасовує очікуване підтвердження, нічого не видаляючи.

## Перейменування файлу

Клацніть іконку олівця (або двічі клацніть назву файлу), щоб редагувати її на місці, потім натисніть **Enter** для підтвердження або **Escape** для скасування. Перейменування відхиляється, якщо нова назва:

- порожня або довша за 100 символів,
- вже використовується іншим збереженим файлом (без урахування регістру),
- закінчується крапкою, або
- є зарезервованою системною назвою пристрою Windows, такою як `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9` або `LPT1`–`LPT9`.

Символи, недопустимі в назві файлу (`\ / : * ? " < > |`), автоматично видаляються під час введення. Перейменування змінює лише мітку — воно не впливає на позицію кресленика в сітці, оскільки вона визначається часом останнього збереження, а не назвою.

## Резервне копіювання роботи — сховище браузера не є постійним

KulmanLab зберігає кресленики в **IndexedDB** — базі даних, вбудованій у ваш браузер:

- Файли зберігаються **лише локально на вашому пристрої** — нічого не завантажується на сервер.
- Кожен браузер і пристрій має власне незалежне сховище. Кресленик, збережений у Chrome на одному комп'ютері, не з'явиться у Firefox або на іншій машині.
- Це сховище **може бути очищене без попередження** — через очищення даних сайту чи історії перегляду, брак місця на диску, використання приватного/інкогніто вікна, перевстановлення браузера чи ОС, або перехід на інший пристрій. Жодна з цих подій не дає можливості відновити те, що там було.

**Єдиний надійний спосіб зберегти кресленик у безпеці — [експортувати](../export-manager/) його у власне сховище.** Використовуйте `.json` (рідний формат KulmanLab), коли можливо — він зберігає кожен об'єкт точно; використовуйте `.dxf`, коли потрібна сумісність з іншими CAD-інструментами. Робіть це для всього, що було б прикро втратити, і перед очищенням даних браузера, зміною браузера чи пристрою, або відкладанням машини на деякий час.

## Автоматичне завантаження файлу при запуску

Коли ви відкриваєте KulmanLab CAD, застосунок автоматично завантажує **останній змінений файл** зі сховища. Вам не потрібно щоразу вручну відкривати його з File Manager.

## Керування сховищем

Немає фіксованого обмеження на кількість креслеників, які можна зберегти, але сховище браузера скінченне. Якщо ви помітили попередження про сховище, видаліть старіші файли з File Manager — або, ще краще, спочатку експортуйте їх, щоб нічого не втратити.

Щоб видалити всі збережені кресленики одразу, скористайтеся командою [WipeStorage](../wipestorage/).

## Назви файлів

Нові та імпортовані файли отримують просту назву — без вбудованої мітки часу. Якщо ця назва вже зайнята, автоматично додається суфікс у стилі Finder/Explorer (`plan (2)`, `plan (3)`, …), щоб нічого не було перезаписано. Ви завжди можете дати файлу зрозумілішу назву пізніше, скориставшись [перейменуванням](#перейменування-файлу).

## Пов'язані команди

- [Import](../import/) — завантажити кресленик з вашої файлової системи в сховище браузера
- [Export Manager](../export-manager/) — завантажити кресленик у вашу файлову систему
- [New File](../new-file/) — почати порожній кресленик (також зберігається автоматично)
- [WipeStorage](../wipestorage/) — очистити всі збережені файли зі сховища браузера
