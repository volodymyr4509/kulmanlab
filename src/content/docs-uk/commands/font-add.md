# FontAdd

Команда `ШрифтДодати` відкриває системний вибір файлу для завантаження власного шрифту `.ttf`, не відкриваючи спочатку діалог [Font Manager](../font-manager/). Це те саме завантаження, яке запускає кнопка **Add Font** у Font Manager — FontAdd це просто прямий шлях до нього з терміналу.

## Завантаження шрифту

1. Введіть `ШрифтДодати` у терміналі або натисніть **Add Font** у нижній частині діалогу [Font Manager](../font-manager/).
2. Виберіть файл `.ttf` у системному вікні вибору. Підтримуються лише шрифти TrueType — `.otf` та `.woff`/`.woff2` не підтримуються.

Команда завершується одразу після відкриття вікна вибору файлу — жодного подальшого кліку чи введення в терміналі не потрібно. Шрифт реєструється й з'являється в групі **User** одразу після вибору файлу.

## Що відбувається при завантаженні

- Назва файлу (без розширення) стає назвою шрифту. Завантаження `MyFont.ttf` додає шрифт з назвою `MyFont`.
- Завантаження файлу, назва якого збігається з наявним власним шрифтом, **замінює** його.
- Шрифт зберігається назавжди в браузері (IndexedDB) і автоматично завантажується знову при наступному відкритті KulmanLab CAD — він не прив'язаний до поточного креслення.

## Довідник клавіатури

FontAdd не має власної взаємодії з клавіатурою — уся команда зводиться до нативного вікна вибору файлу браузера. Скасування цього діалогу (або невибір файлу) залишає список шрифтів без змін.
