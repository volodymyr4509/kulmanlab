# ClipboardCopy

Команда `КопіюватиВБуфер` записує вибрані об'єкти у ваш **системний буфер обміну** як текст JSON. Оскільки використовується справжній буфер обміну, а не внутрішній, скопійована геометрія переживає межі креслення: вставте її в інший файл, у другу вкладку браузера або у вікно, яке відкриєте пізніше, за допомогою [ClipboardPaste](../clipboard-paste/).

Саме цим вона відрізняється від [Copy](../copy/): Copy дублює об'єкти всередині поточного креслення за один рух, тоді як ClipboardCopy кладе їх туди, звідки їх можна забрати в зовсім іншому кресленні.

## Два способи почати

**Спершу вибрати, потім копіювати** — швидкий шлях:

1. Виберіть один або кілька об'єктів на полотні.
2. Натисніть `Ctrl+C` (`Cmd+C` на macOS) або введіть `КопіюватиВБуфер` у терміналі.
3. Об'єкти одразу записуються в буфер обміну, і команда завершується.

**Активувати, потім вибирати** — почати без вибору:

1. Натисніть `Ctrl+C` або введіть `КопіюватиВБуфер` з порожнім вибором.
2. Підказка показує **pick objects to copy — Enter or Space to confirm**.
3. **Виберіть об'єкти** — клацайте, щоб додавати чи прибирати окремі об'єкти, або протягніть для вибору областю.
4. Натисніть **Enter** чи **Space**, щоб скопіювати вибране й вийти.

Натискання **Enter** чи **Space** без вибору просто завершує команду, не торкаючись буфера обміну.

## Що копіюється

Вміст буфера обміну несе більше, ніж просто геометрію, щоб вставка в чуже креслення все одно виглядала правильно:

| Складова | Призначення |
|----------|-------------|
| **Об'єкти** | Повна серіалізована форма кожного вибраного об'єкта |
| **Опорна точка** | Лівий нижній кут сукупних меж вибраного — саме її ClipboardPaste прив'язує до курсора |
| **Шари** | Лише ті шари, на які справді посилаються скопійовані об'єкти, за назвою |
| **Типи ліній** | Лише ті типи ліній, на які справді посилаються скопійовані об'єкти, за назвою |

Разом із копією подорожують лише *згадані* записи таблиць, а не всі таблиці шарів і типів ліній вихідного креслення. Візерунки штрихування не додаються — і не потрібні: таблиця візерунків креслення — це вбудований типовий набір, а завантажені вами файли `.pat` лежать у сховищі користувача, яке вже спільне для вкладок, тож вставлене штрихування знаходить свій візерунок саме.

## Підтвердження

У разі успіху термінал повідомляє, скільки об'єктів записано:

```
3 entities copied to clipboard
```

Якщо браузер відмовляє в доступі до буфера обміну, термінал показує **Copy failed: clipboard access denied**, і нічого не записується. Це рішення дозволів браузера, а не помилка креслення — див. [Дозволи буфера обміну](#дозволи-буфера-обміну) нижче.

## Вибір під час команди

| Спосіб | Поведінка |
|--------|-----------|
| **Клацання** | Додає чи прибирає об'єкт під курсором із вибраного |
| **Протягування вправо** (строге) | Додає об'єкти, повністю розташовані в рамці |
| **Протягування вліво** (перетин) | Додає об'єкти, що перетинають межу рамки |
| **Enter** / **Space** | Підтверджує вибір і копіює |

## Довідник клавіш

| Клавіша | Дія |
|---------|-----|
| `Ctrl+C` / `Cmd+C` | Активувати ClipboardCopy |
| `Enter` / `Space` | Скопіювати поточний вибір або вийти, якщо нічого не вибрано |
| `Escape` | Скасувати без копіювання |

## Дозволи буфера обміну

Запис у системний буфер обміну потребує дозволу браузера. На практиці копіювання, викликане натисканням клавіші, надається без запиту в сучасних настільних браузерах, але сторінка, що втратила фокус, або браузер зі суворими налаштуваннями можуть відмовити. Якщо бачите повідомлення про відмову, клацніть один раз на полотні, щоб повернути фокус сторінці, і спробуйте знову.

Оскільки вміст — це звичайний текст JSON, усе, що ви скопіюєте після, замінює його — рядок тексту, посилання. Скопіюйте ще раз перед вставкою, якщо тим часом користувалися буфером обміну для чогось іншого.

## Підтримувані об'єкти

ClipboardCopy працює з усіма типами об'єктів. Об'єкти серіалізуються тим самим механізмом, що й рідний експорт `.json`, тож дорогою нічого не втрачається.
