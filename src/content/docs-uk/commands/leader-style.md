# LeaderStyle

Команда `СтильВиноски` відкриває менеджер іменованих стилів виносок. Кожна нова [Виноска](../leader/) під час створення копіює параметри *поточного* стилю.

## Редагування стилю

Введіть `СтильВиноски` або натисніть **Стиль виноски** на панелі анотацій. ✓ позначає поточний стиль; олівець біля назви дає змогу її змінити. Попередній перегляд одразу оновлюється тим самим засобом візуалізації, що й креслення.

| Поле | Призначення |
|---|---|
| Прив’язка тексту | Вгорі, Посередині, Внизу або Підкреслення |
| Тип / Розмір стрілки | Символ і розмір на кінці кожного плеча |
| Відступ полиці | Проміжок між полицею і текстом |
| Поворот тексту | Кут напису в градусах |
| Стиль тексту | Одноразово копіює шрифт, висоту, жирний і курсив із [TextStyle](../text-style/) |
| Шрифт / Висота тексту | Гарнітура й висота напису |
| Жирний / Курсив | Незалежне форматування |
| Текст у рамці | Прямокутна рамка навколо напису |

**Новий** дублює вибраний стиль. `Standard` не можна перейменувати або видалити; поточний стиль також не видаляється. **Зробити поточним** впливає лише на майбутні виноски — наявні об’єкти не змінюються. Порожні, повторювані або неприпустимі для DXF назви блокують **OK**. Імпортовані анотативні стилі приховані, але зберігаються.

## Збереження та DXF

**OK** застосовує всі зміни; **Закрити** або `Escape` їх відкидає. KulmanLab читає й записує записи `MLEADERSTYLE`. Назва, тип і розмір стрілки, відступ, висота, прив’язка, рамка та анотативна ознака зберігаються як поля стилю. Поворот, шрифт, жирний і курсив — це типові параметри KulmanLab, що копіюються у виноску під час створення.

Дивіться також [Leader](../leader/), [LeaderAdd](../leader-add/) і [LeaderRemove](../leader-remove/).
