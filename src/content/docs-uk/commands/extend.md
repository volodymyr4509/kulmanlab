# Extend

Команда `Подовжити` розтягує найближчу кінцеву точку [Line](../line/), [Arc](../arc/), [Ellipse](../ellipse/) або відкритої [Polyline](../polyline/), на яку наведено курсор, до найближчого перетину, який вона утворила б з іншим об'єктом на кресленні. Наведіть курсор поблизу кінцевої точки, яку хочете розтягнути — попередній перегляд показує розтягнутий об'єкт — потім клацніть, щоб застосувати.

Розтягувати можна лише об'єкти зі справжньою кінцевою точкою. [Circle](../circle/) та повний (360°) Ellipse завжди є замкненими формами без кінцевої точки, тому їх ніколи не можна розтягнути — так само як замкнену Polyline або Rectangle. Частковий Ellipse (еліптична дуга) та Arc мають кінцеві точки і розтягуються так само, як Line.

## Розтягування об'єкта

1. Введіть `Подовжити` у терміналі або натисніть кнопку **Extend** на панелі інструментів.
2. **Наведіть курсор поблизу одного кінця** об'єкта, який хочете розтягнути — попередній перегляд показує його розтягнутим до найближчої межі в цьому напрямку.
3. **Клацніть**, щоб застосувати розтягування.

Команда залишається активною після кожного розтягування, тому можна продовжувати наводити та клацати, щоб розтягнути більше об'єктів. Натисніть **Enter**, **Пробіл** або **Escape** для виходу.

```
  До:                          Після:

  ──────           |           ──────────────|
  (коротка лінія)  (межа)      (розтягнута до межі)
```

## Як обирається кінцева точка

Команда визначає, до якого кінця курсор ближче:

- **Line та відкрита Polyline** — курсор ближче до кінцевої точки розтягує кінець вперед; курсор ближче до початкової точки розтягує початок назад.
- **Arc та частковий Ellipse** — курсор ближче до одного з кутових кінців нарощує дугу в цьому напрямку, огинаючи той самий центр і радіус (або ту саму форму еліпса), поки не досягне наступної межі.

Промінь — або, для Arc та Ellipse, власне коло чи крива об'єкта — випускається з обраного кінця, і **найближчий перетин** з будь-яким іншим об'єктом (крім самого об'єкта та ігнорованих типів) стає новою кінцевою точкою.

Якщо в цьому напрямку перетину не знайдено, попередній перегляд не з'являється, і клацання нічого не робить.

## Винятки меж

Наступні типи об'єктів ігноруються як межі — об'єкт не розтягується, щоб зустріти їх:

- Text / Mtext
- Multileader
- Spline

Усі інші типи (Line, Arc, Circle, Ellipse, Polyline, Dimension) слугують дійсними межами.

Якщо перший або останній сегмент Polyline сам є дуговим сегментом (намальованим перемикачем Arc), його розтягування нарощує дугу вздовж її власного кола — так само, як розтягування окремого Arc — замість того, щоб трактувати його як прямий сегмент.

## Довідник клавіатури

| Клавіша | Дія |
|---------|-----|
| `Enter` / `Пробіл` | Вийти з режиму extend |
| `Escape` | Вийти з режиму extend |

## Підтримувані об'єкти

| Об'єкт | Можна розтягнути? |
|--------|----------------|
| Line | Так |
| Arc | Так |
| Ellipse | Так — лише якщо це вже часткова дуга; повний еліпс не має кінцевої точки |
| Circle | Ні — завжди замкнена форма без кінцевої точки |
| Polyline (відкрита) | Так |
| Polyline (замкнена) / Rectangle | Ні — завжди замкнена форма без кінцевої точки |
| Text, Spline, Dimension, Leader | Ні |

## Extend проти Trim

| | Extend | Trim |
|---|--------|------|
| Що робить | Розтягує кінцеву точку об'єкта до межі | Видаляє сегмент об'єкта |
| Тригер | Наведення поряд з кінцевою точкою для розтягування | Наведення на сегмент для відрізання |
| Результат | Кінцева точка рухається назовні | Об'єкт розділяється або коротшає |
| Підтримувані об'єкти | Line, Arc, Ellipse, Polyline | Line, Arc, Circle, Ellipse, Polyline |
