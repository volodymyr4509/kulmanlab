# TextStyle

Команда `СтильТексту` відкриває менеджер стилів. Створюйте іменовані стилі, редагуйте їхні типові параметри та вибирайте *поточний* стиль. Новий [Текст](../text/) копіює його налаштування під час створення.

## Робота з менеджером

Введіть `СтильТексту` або натисніть **Стиль тексту** на панелі **Анотації**. ✓ позначає поточний стиль; подвійне клацання робить стиль поточним.

| Поле | Призначення |
|---|---|
| Перейменування | Використовуйте олівець біля назви для редагування у списку; `Standard` перейменувати не можна. |
| Шрифт / Висота | Шрифт і обов’язкова додатна висота. Нульові або від’ємні значення стають `1`; менеджер приймає лише значення понад `0`. |
| Жирний / Курсив | Незалежні перемикачі форматування |
| Міжрядковий інтервал | Відстань між рядками |
| Горизонтальне вирівнювання | Ліворуч, по центру, праворуч або за шириною |
| Рамка | Прямокутна рамка для нового тексту |

Попередній перегляд використовує той самий рушій, що й полотно, і показує два рядки. Шрифт, висота, жирність, курсив, рамка, інтервал і вирівнювання оновлюються одразу; індикатор показує масштаб вписування. Нові стилі типово вирівнюються **ліворуч**.

**Новий** дублює вибраний стиль. **Видалити** не видаляє `Standard` або поточний стиль. **Зробити поточним** впливає лише на майбутній текст. Порожні, повторні чи недопустимі для DXF назви блокують **OK**. Імпортовані анотативні стилі приховані, але зберігаються.

## Збереження та DXF

**OK** зберігає зміни; **Закрити** або `Escape` відкидає їх. `↑` і `↓` рухаються списком. Назва, файли шрифту, висота, жирний, курсив і анотативний прапорець належать стилю DXF. Рамка, інтервал і вирівнювання — параметри KulmanLab для окремого тексту, а не поля таблиці STYLE.

Дивіться також [Text](../text/), [FontManager](../font-manager/) і [MatchProperties](../match-properties/).
