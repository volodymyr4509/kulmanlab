# Fillet

Команда `Скруглення` заокруглює кут між двома сегментами [Line](../line/), [Arc](../arc/) або [Polyline](../polyline/), вставляючи дотичну дугу заданого радіуса та обрізаючи (або об'єднуючи) вибрані об'єкти до цієї точки.

Fillet працює з об'єктами **Line, Arc та Polyline** — включно з прямими та дуговими сегментами полілінії.

## Використання Fillet

1. Введіть `Скруглення` у терміналі або натисніть кнопку **Fillet** на панелі інструментів.
2. **Введіть радіус заокруглення** та натисніть **Enter**.
3. **Клацніть першу лінію, дугу або сегмент полілінії** — частина, яку ви клацаєте, визначає яка сторона будь-якого перетину зберігається.
4. **Наведіть на другий об'єкт** — пунктирний попередній перегляд дуги показує результат. Перемістіть курсор на сторону, яку хочете зберегти.
5. **Клацніть**, щоб застосувати.

```
  До:                        Після Fillet (радіус r):

  ──────────────              ──────────╮
                │                        ╰────
                │
```

## Вибір сторони для об'єктів, що перетинаються

Коли два об'єкти перетинаються, заокруглення застосовується до кута, визначеного позиціями кліків — частина кожного об'єкта **на тій же стороні, що й курсор**, зберігається.

- Клацніть поруч з одним кінцем першого об'єкта, щоб вибрати ту половину.
- Перемістіть курсор до бажаної половини другого об'єкта — пунктирний попередній перегляд оновлюється в реальному часі.

## Що створює команда

Результат залежить від того, що ви вибрали:

- **Два незалежні об'єкти Line/Arc**, або будь-яка пара без відкритої полілінії: обидва обрізаються до точок дотику **T1**/**T2**, і між ними вставляється новий об'єкт Arc.
- **Два сегменти однієї полілінії, що мають спільну кутову вершину**: жодного нового об'єкта — заокруглення стає частиною самої полілінії. Кутова вершина замінюється двома точками дотику, а дуга між ними зберігається як bulge цього ребра — точно так, як заокруглений кут полілінії проходить туди й назад через DXF.
- **Усе інше за участю відкритої полілінії** — дві різні відкриті полілінії, або відкрита полілінія й незалежний об'єкт Line/Arc: обидва об'єднуються в **одну нову полілінію**, зберігаючи кожну сторону до її точки дотику й з'єднуючи їх дугою заокруглення як ще одним bulge-сегментом, замінюючи вихідні об'єкти.

Вставлена або продовжена дуга успадковує поточні налаштування товщини лінії, кольору, шару та типу лінії (або налаштування самої полілінії, коли вона входить до її складу).

## Кути без реального кута для заокруглення

Якщо два вибрані сегменти вже сходяться дотично у спільній вершині — прямий кут полілінії, або лінія, що плавно переходить у дуговий сегмент дотичного продовження — реального кута, який міг би заокруглити коло, немає. Fillet виявляє це і відмовляє з повідомленням `cannot fillet: no tangent circle fits there` замість того, щоб намалювати небажану петлю.

## Довідник клавіатури

| Клавіша | Дія |
|---------|-----|
| `0`–`9`, `.` | Додати цифру до значення радіуса |
| `Backspace` | Видалити останній введений символ |
| `Enter` / `Пробіл` | Підтвердити введений радіус і перейти до вибору об'єкта |
| `Escape` | Скасувати та скинути |

## Підтримувані об'єкти

| Об'єкт | Підтримується |
|--------|---------------|
| Line | Так |
| Arc | Так |
| Polyline (прямий або дуговий сегмент) | Так |
| Circle, Ellipse | Ні |
| Text, Spline, Dimension, Leader | Ні |

## Fillet проти Chamfer

| | Fillet | Chamfer |
|---|--------|---------|
| Тип кута | Заокруглена дуга | Прямий зріз |
| Введення | Один радіус | Дві відстані (d1, d2) |
| Вставлений об'єкт | Arc | Line |
| Підтримувані об'єкти | Lines, Arcs та Polylines (прямі або дугові сегменти) | Lines та Polylines (лише прямі сегменти) |
