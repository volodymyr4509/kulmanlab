# Менеджер експорту

Команда `exportmanager` завантажує поточний кресленик у вашу файлову систему. Доступні два формати, показані як картки поруч одна з одною: **DXF** для сумісності з іншими інструментами CAD і **JSON** для збереження з повною точністю в межах KulmanLab CAD — кожна картка точно перелічує, які типи об'єктів переносить цей формат.

## Як експортувати

1. Натисніть кнопку **Export** на панелі інструментів (іконка завантаження) на панелі файлів або введіть `exportmanager` у терміналі.
2. Відкривається спливне вікно **Менеджер експорту**, показуючи картки JSON та DXF поруч одна з одною, кожна перелічує, що експортується (а для DXF — що пропускається).
3. Натисніть на картку, щоб вибрати формат — **JSON** або **DXF**.
4. Натисніть кнопку **Export \<FORMAT\>**. Файл автоматично завантажується у вашу типову теку завантажень.

Натисніть `Escape`, щоб закрити спливне вікно без експорту.

## Вибір формату

| Формат | Розширення | Найкраще для | Обмеження |
|--------|-----------|--------------|-----------|
| **JSON** *(власний)* | `.json` | Збереження роботи для повторного відкриття в KulmanLab CAD | Не сумісний з іншими інструментами CAD |
| **DXF** | `.dxf` | Обмін із FreeCAD, LibreCAD тощо | Hatches, Dimensions, Leaders та Text не експортуються |

**Коли використовувати JSON:** будь-коли, коли хочете зберегти повну копію своєї роботи. JSON — це власний формат KulmanLab, який точно зберігає кожен об'єкт — включно з Dimensions, Leaders, Hatches і всіма даними шарів.

**Коли використовувати DXF:** коли потрібно передати кресленик комусь, хто використовує іншу CAD-програму. Експортований файл використовує формат DXF AC1032 і може бути відкритий у більшості інструментів, сумісних із DXF.

## Що експортується для кожного формату

### Експорт JSON

Включено кожен тип об'єктів:

- Lines, Circles, Arcs, Ellipses, Polylines, Splines
- Text
- Dimensions (лінійний, вирівняний, послідовний, радіус, діаметр)
- Leaders (мультивиноски)
- Hatches, включно з їхнім патерном, масштабом, кутом і початковою точкою
- Layers та Linetypes

### Експорт DXF

Включено лише геометричні об'єкти:

- Lines, Circles, Arcs, Ellipses, Polylines (експортуються як `LWPOLYLINE`), Splines
- Layers та Linetypes

**Не експортується в DXF:** Hatches, Dimensions, Leaders та Text. Dimensions і Leaders використовують специфічні для KulmanLab структури даних, які не можна достовірно представити у стандартному DXF; Hatches наразі взагалі не експортуються в DXF, хоча вони й імпортуються з нього; експорт Text також ще не реалізовано. Якщо у вашому кресленику є щось із цього, використовуйте JSON або [Менеджер друку](../print-manager/), щоб зберегти це.

## Назва експортованого файлу

Завантажений файл отримує назву за поточним файлом креслення (наприклад, `myplan.json`). Розширення змінюється відповідно до вибраного формату.

## Різниця між Менеджером експорту та Менеджером друку

| Функція | Менеджер експорту | Менеджер друку |
|---------|---------------------|-------------------|
| Вивід | Векторний вихідний файл (.dxf / .json) | Растрове зображення (.png / .jpeg / .webp / .pdf) |
| Редагується в інших інструментах | Так (DXF) | Ні |
| Зберігає Layers і Linetypes | Так | Ні (рендериться плоско) |
| Захоплює Dimensions і Leaders | Лише JSON | Так |

Використовуйте **Менеджер експорту**, коли вам потрібен файл, який можна редагувати. Використовуйте [Менеджер друку](../print-manager/), коли вам потрібен візуальний знімок.

## Пов'язані команди

- [Import](../import/) — відкрити файл DXF або JSON
- [Менеджер друку](../print-manager/) — експортувати полотно як зображення PNG, JPEG, WebP або PDF
- [File Manager](../file-manager/) — переглянути креслення, збережені в сховищі браузера
