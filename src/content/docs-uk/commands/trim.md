# Trim

Команда `Обрізати` видаляє частину [Line](../line/), [Arc](../arc/), [Circle](../circle/), [Ellipse](../ellipse/) або [Polyline](../polyline/), що знаходиться між двома сусідніми точками перетину, розділяючи об'єкт на одну або кілька частин, що залишаються. Сегмент для відрізання визначається позицією курсора — наведіть на частину яку хочете видалити та клацніть для підрізання.

## Підрізання об'єкта

1. Введіть `Обрізати` у терміналі або натисніть кнопку **Trim** на панелі інструментів.
2. **Наведіть на сегмент** який хочете видалити — попередній перегляд підсвічує точно ту частину що буде відрізана.
3. **Клацніть** для видалення цього сегмента.

Команда залишається активною після кожного підрізання, тому можна продовжувати наводити та клацати для відрізання більше сегментів — на тому самому об'єкті або на іншому. Натисніть **Enter**, **Пробіл** або **Escape** для виходу.

```
  До:                           Після відрізання середнього сегмента:

  ──────●──────●──────          ──────●          ●──────
      перетин  перетин            (ліва частина) (права частина)
                                  (середній сегмент видалено)
```

## Як визначається сегмент для підрізання

Команда проектує позицію курсора на об'єкт з наведенням та знаходить всі точки перетину цього об'єкта з іншими об'єктами. Ці перетини ділять об'єкт на сегменти — для Line, Arc або відкритої Polyline власні кінцеві точки об'єкта слугують додатковими фіксованими межами. Повне Circle або Ellipse, або замкнена Polyline (включно з Rectangle), не мають власних кінцевих точок, тому потрібно щонайменше дві точки перетину, перш ніж їх взагалі можна буде підрізати. Сегмент, чий інтервал містить проекцію курсора, підсвічується і буде видалений при кліку.

- **Line, Arc та відкрита Polyline** — видалений сегмент може бути ведучою частиною (перед першим перетином), середньою частиною (між двома перетинами, розділяючи об'єкт на дві частини), або хвостовою частиною (після останнього перетину).
- **Circle, Ellipse та замкнена Polyline/Rectangle** — оскільки немає фіксованого початку чи кінця, можна видалити лише дугу між двома *точками перетину*. Якщо перетинів менше двох, попередній перегляд не з'являється і клацання нічого не робить. Решта форми стає єдиною частиною, що залишається.

## Що виробляє підрізання

| Об'єкт | Результат після підрізання |
|--------|------------------------|
| Line | До двох коротших об'єктів Line |
| Arc | До двох коротших об'єктів Arc |
| Circle | Один об'єкт [Arc](../arc/) — замкнена форма кола зникає, тому частина, що залишається, зберігається як дуга |
| Ellipse | Один об'єкт Ellipse з початковим і кінцевим кутом — частина, що залишається, лишається Ellipse, тепер частковим |
| Polyline (відкрита) | До двох коротших об'єктів Polyline |
| Polyline (замкнена) / Rectangle | Один відкритий об'єкт Polyline — замкнена форма зникає, тому частина, що залишається, зберігається відкритою |
| Spline | До двох коротших об'єктів Spline — кожен шматок є тією самою кривою на меншій ділянці, що зберігається контрольними вершинами (точки апроксимації сплайна Fit відкидаються); замкнений сплайн залишає один відкритий шматок |

## Підтримувані об'єкти

| Об'єкт | Можна підрізати? |
|--------|----------------|
| Line | Так |
| Arc | Так |
| Circle | Так — потрібно 2 або більше точок перетину |
| Ellipse | Так — потрібно 2 або більше точок перетину |
| Polyline (відкрита) | Так |
| Polyline (замкнена) / Rectangle | Так — потрібно 2 або більше точок перетину |
| Spline | Так — замкнений сплайн потребує 2 або більше точок перетину; сплайн також обрізається там, де він перетинає сам себе |
| Text, Dimension, Leader | Ні |

Об'єкти, що використовуються як **межі різання**, можуть бути Line, Arc, Circle, Ellipse, Polyline або Spline. Об'єкти Text, Dimension і Leader ніколи не реєструють перетинів, тому не можуть бути й межами.

**Дугові сегменти** Polyline (намальовані перемикачем Arc або імпортовані) підрізаються так само, як і прямі сегменти — наведіть курсор на дугову частину між двома перетинами та клацніть. Обрізаний край зберігає свою кривизну; змінюється лише довжина.

## Trim проти Extend

| | Trim | Extend |
|---|------|--------|
| Що робить | Видаляє сегмент об'єкта | Розтягує кінцеву точку лінії до межі |
| Тригер | Наведення на сегмент для відрізання | Наведення поряд з кінцевою точкою для розтягування |
| Результат | Об'єкт розділяється або коротшає | Кінцева точка лінії переміщується до межі |
| Підтримувані об'єкти | Line, Arc, Circle, Ellipse, Polyline, Spline | Line, Arc, Ellipse, Polyline |
