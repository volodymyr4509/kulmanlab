# HatchAdd

Команда `HatchAdd` відкриває системний вибір файлів для завантаження файлу візерунків штриховки `.pat`, не відкриваючи спершу діалог [Hatch Manager](../hatch-manager/). Це те саме завантаження, яке запускає кнопка **Add .pat File** у Hatch Manager — HatchAdd лише прямий шлях до нього з термінала.

## Завантаження файлу візерунків

1. Введіть `HatchAdd` у терміналі або натисніть **Add .pat File** унизу діалогу [Hatch Manager](../hatch-manager/).
2. Виберіть файл `.pat` у системному вікні. Приймається лише стандартний формат візерунків штриховки.

Команда завершується щойно відкривається вибір файлів — далі немає ані запиту, ані клацання, ані введення в терміналі. Візерунки реєструються й з'являються у групі **User**, щойно файл вибрано.

## Що відбувається при завантаженні

- **Файл `.pat` — це вмістище, а не один візерунок.** Один файл зазвичай визначає багато іменованих візерунків, і всі вони додаються разом. Саме тут HatchAdd відрізняється від [FontAdd](../font-add/), де один `.ttf` — це один шрифт.
- **Сам файл не зберігається.** Його читають один раз, розділяють на візерунки, і кожен зберігається окремо під власним іменем. Тому пізніше можна вилучити один візерунок, не зачепивши тих, що прийшли разом із ним — і тому група **User** перелічує їх за абеткою імен, а не за файлом походження.
- **Візерунок, ім'я якого збігається з наявним, заступає його.** Це передбачений спосіб покласти авторитетні означення поверх власних наближень KulmanLab: завантажте справжній `acad.pat`, і його версії `ANSI31` та інших стандартних імен перебирають справу на себе.
- **Візерунки зберігаються для користувача, а не для креслення.** Вони живуть у браузері (IndexedDB), самі завантажуються наступного разу, коли ви відкриєте KulmanLab CAD, і доступні в кожному кресленні.
- **Файл без дійсних означень візерунків не додає нічого.** Бібліотека лишається точно такою, якою була.

## Довідник клавіатури

HatchAdd не має власної взаємодії з клавіатурою — уся команда є вбудованим діалогом вибору файлів браузера. Скасування цього діалогу (або невибір файлу) лишає бібліотеку візерунків без змін.

## Пов'язані команди

| Команда | Що робить |
|---------|-----------|
| [Hatch Manager](../hatch-manager/) | Переглядати бібліотеку візерунків із живим зразком і вилучати завантажені візерунки |
| [Hatch](../hatch/) | Заповнює замкнену область візерунком із бібліотеки |
| [FontAdd](../font-add/) | Той самий ярлик прямого завантаження для шрифтів `.ttf` |
