# LayerManager

Команда `МенеджерШарів` відкриває таблицю з усіма шарами креслення, у якій налаштування **Freeze**, **Lock**, **Plot**, **Колір**, **Товщина лінії** та **Тип лінії** редагуються просто в рядку. Це центральне місце, щоб додавати шари, видаляти невикористані та налаштовувати поведінку наявних — решта команд шарів ([LayerMakeCurrent](../layer-make-current/), [LayerMatch](../layer-match/), [LayerIsolate](../layer-isolate/), [LayerUnfreezeAll](../layer-unfreeze-all/)) виконують по одній конкретній дії, не відкриваючи її.

## Відкриття Layer Manager

- Введіть `МенеджерШарів` у терміналі, **або**
- Натисніть кнопку **Layer Manager** на панелі шарів.

Діалог відкривається як плаваюча панель; заздалегідь нічого вибирати не потрібно.

## Таблиця шарів

| Стовпець | Що контролює |
|----------|----------------|
| Name | Назва шару, показана в таблиці лише для читання (задається один раз, при створенні) |
| Freeze | Приховує об'єкти шару і виключає їх із вибору, доки шар не буде розморожено |
| Lock | Забороняє редагування об'єктів на шарі, не приховуючи їх |
| Plot | Чи включаються об'єкти шару при друку або експорті в PDF |
| Color | Колір ACI шару — клацніть на зразок, щоб відкрити вибір кольору |
| Lineweight | Товщина лінії шару — клацніть на чіп, щоб відкрити вибір товщини |
| Linetype | Візерунок штрихів шару — клацніть на чіп, щоб відкрити вибір типу лінії |
| ✕ | Видаляє шар, коли його ніщо не використовує — див. [Видалення шару](#видалення-шару) |

Перемикання Freeze, Lock або Plot діє негайно — окремого кроку збереження немає. Об'єкти, для яких колір, товщина лінії чи тип лінії встановлені як **ByLayer** (значення за замовчуванням), беруть те, що ви задасте тут; об'єкти з власним явним перевизначенням залишаються без змін.

## Додавання шару

1. Натисніть **+ Add Layer** внизу таблиці.
2. Введіть назву та натисніть **Enter** для підтвердження, або **Escape** для скасування.

Назви шарів можуть містити літери, цифри, пробіли та `_`, `-`, `$`. Порожня назва, вже використовувана, або та, що містить інший символ, відхиляється з вбудованим повідомленням про помилку, а рядок залишається відкритим для нової спроби.

Нові шари починають як **розморожені, розблоковані, придатні до друку**, з кольором 7 (білий/чорний), товщиною лінії Default і типом лінії Continuous — ті самі значення за замовчуванням, які [Import](../import/) присвоює шару `0` у порожньому кресленику.

## Видалення шару

Кожен рядок завершується кнопкою **✕**, яка вилучає шар із креслення. Видалення відбувається одразу — підтвердження немає — але пропонується лише для шарів, від яких ніщо не залежить:

| Ситуація | Стан кнопки |
|----------|-------------|
| Шар порожній | Активна — *Delete layer* |
| Шар призначено щонайменше одному об'єкту | Неактивна — *Cannot delete: assigned to at least one entity* |
| Шар `0` | Кнопки немає взагалі |

**«Використовується» стосується всього креслення**, а не лише того, що ви бачите. Об'єкт на компонуванні (просторі аркуша) рахується так само, як і в просторі моделі, тож шар може виглядати порожнім на екрані й усе одно не видалятися. Заморожені шари не виняток: заморожування ховає об'єкти, але не знімає з них призначення, тож заморожений шар з об'єктами лишається невидаленним.

Шар `0` не можна видалити ніколи. Це запасний шар, який гарантовано має кожне креслення, тож кнопка для нього просто не малюється, а не показується неактивною.

### «…is now in use and can't be deleted»

Часом ✕ виглядає доступною, але клац відхиляється банером угорі панелі:

```
"WALLS" is now in use and can't be deleted
```

Це не суперечність. Щоб з'ясувати, які шари використовуються, треба обійти кожен об'єкт креслення, тож результат кешується й перебудовується лише тоді, коли змінюється кількість об'єктів — дешево за сотень об'єктів, але не за сотень тисяч. Перенесення наявного об'єкта на шар кількості не змінює, тож неактивний стан рядка може на мить застаріти. Клац перевіряє все наново, перш ніж щось видаляти, — саме тому відмова стається під час клацання, а не шар зникає, поки на нього ще щось посилається.

Закрийте банер його власною **✕**. Шар лишається недоторканим.

## Чого тут не можна зробити

Таблиця не показує, який шар є *поточним*; це задається у випадному списку панелі шарів або командою [LayerMakeCurrent](../layer-make-current/), а не в цьому діалозі. Назви шарів також фіксуються при створенні — шар можна видалити й створити заново, але не перейменувати.

## Довідник клавіатури

| Клавіша | Дія |
|---------|-----|
| `Enter` | Підтвердити назву нового шару (під час додавання) |
| `Escape` | Скасувати додавання шару, або закрити діалог |

| Команда | Що робить |

| [LayerIsolate](../layer-isolate/) | Заморозити всі шари, крім шарів вибраних об'єктів |
| [LayerUnfreezeAll](../layer-unfreeze-all/) | Розморозити всі шари за один крок |
