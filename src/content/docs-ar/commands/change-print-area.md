# ChangePrintArea

يحدد أمر `ChangePrintArea` المنطقة المستطيلة التي يصدّرها [Print Manager](../print-manager/). يعمل على لوحة الرسم بينما يكون Print Manager مخفيًا، ويأخذ ركنين متقابلين — النقرتان نفسهما في [Rectangle](../rectangle/)، لذا تعمل الإحداثيات المكتوبة والانجذاب بالطريقة نفسها تمامًا.

## اختيار منطقة

1. اكتب `ChangePrintArea` في المحطة، أو انقر **Change Area** في الشريط الجانبي لـ Print Manager. يختفي Print Manager وتصبح لوحة الرسم تفاعلية.
2. **انقر الركن الأول**، أو اكتب `X,Y` واضغط **Enter** لإحداثي دقيق.
3. **انقر الركن المقابل**، أو اكتب `X,Y` مرة أخرى.

يُفتح Print Manager من جديد والمنطقة الجديدة في المعاينة، التي يتغير حجمها لتطابق نسبة العرض إلى الارتفاع لتلك المنطقة بدقة.

تنجذب الأركان إلى المقابض والتقاطعات مثل أي اختيار نقطة آخر، فيمكنك الاقتصاص وفق الأشكال المرسومة بدل التقدير بالعين. ترتيب الركنين غير مهم: الركنان المتقابلان يحددان المستطيل نفسه.

اضغط `Escape` للإلغاء. لا يُكتب شيء، لذا يُفتح Print Manager من جديد بالمنطقة التي كانت لديه أصلًا.

## أين تُحفظ المنطقة

يُحفظ الاختيار لكل سياق على حدة، لا بشكل عام:

| السياق | الخانة |
|---|---|
| فضاء Model | خانة واحدة مشتركة |
| كل تخطيط | خانته الخاصة، محفوظة على حدة |

إعادة فتح Print Manager على التخطيط نفسه — أو على Model — تستعيد آخر اقتصاص لذلك السياق بدل إعادة الضبط، والتنقل بين التخطيطات يترك منطقة كل واحد كما هي.

يُحفظ هذا في الذاكرة فقط. إعادة تحميل الصفحة تمسح كل المناطق المحفوظة، ويعود Print Manager إلى القيم الافتراضية أدناه.

## المنطقة الافتراضية

إذا لم يكن هناك شيء محفوظ للسياق الحالي، يُفتح Print Manager على:

| السياق | الافتراضي |
|---|---|
| فضاء Model | المربع المحيط بكل الكيانات — المدى نفسه الذي يقرّب إليه [Fit](../fit/) |
| كل تخطيط | الورقة كاملة |
