# TextStyle

يفتح أمر `نمط` مدير أنماط النص. أنشئ أنماطاً مسماة وعدّل إعداداتها الافتراضية واختر النمط *الحالي*. ينسخ [النص](../text/) الجديد إعدادات النمط الحالي عند إنشائه.

## استخدام المدير

اكتب `نمط` في الطرفية أو انقر **نمط النص** في لوحة **التعليق**. تشير ✓ إلى النمط الحالي، والنقر المزدوج يجعل النمط حالياً.

| الحقل | الوظيفة |
|---|---|
| إعادة التسمية | استخدم رمز القلم بجانب الاسم لتحريره في القائمة؛ لا يمكن إعادة تسمية `Standard`. |
| الخط / الارتفاع | خط وارتفاع موجب إلزامي. تتحول القيم الصفرية أو السالبة إلى `1`؛ ولا يقبل المدير إلا قيماً أكبر من `0`. |
| عريض / مائل | تنسيق مستقل |
| تباعد الأسطر | المسافة بين سطور النص |
| المحاذاة الأفقية | يسار أو وسط أو يمين أو ضبط |
| الإطار | إطار مستطيل حول النص الجديد |

تستخدم المعاينة نفس عارض اللوحة وتعرض سطرين. يتحدث الخط والارتفاع والعريض والمائل والإطار والتباعد والمحاذاة فوراً؛ وتوضح القراءة مقياس الملاءمة. تكون الأنماط الجديدة بمحاذاة **يسار** افتراضياً.

ينسخ **جديد** النمط المحدد. لا يحذف **حذف** النمط `Standard` أو الحالي. يؤثر **تعيين كحالي** في النصوص المستقبلية فقط. الأسماء الفارغة أو المكررة أو غير الصالحة في DXF تعطل **OK**. الأنماط التوضيحية المستوردة مخفية حالياً لكن سجلاتها محفوظة.

## الحفظ وDXF

يحفظ **OK** التغييرات، بينما يتجاهلها **إغلاق** أو `Escape`. يتنقل `↑` و`↓` في القائمة. الاسم وملفات الخط والارتفاع والعريض والمائل وعلامة التوضيح جزء من نمط DXF. الإطار وتباعد الأسطر والمحاذاة قيم افتراضية لكل نص في KulmanLab وليست حقولاً في جدول STYLE.

راجع أيضاً [Text](../text/) و[FontManager](../font-manager/) و[MatchProperties](../match-properties/).
