# LeaderStyle

يفتح الأمر `نمط` مدير أنماط خطوط الإشارة المسماة. ينسخ كل [Leader](../leader/) جديد إعدادات النمط *الحالي* عند إنشائه.

## تحرير النمط

اكتب `نمط` أو انقر على **نمط الخط الرصاصي** في لوحة التعليقات التوضيحية. تشير ✓ إلى النمط الحالي، ويتيح القلم بجانب الاسم إعادة تسميته. تتحدث المعاينة فوراً باستخدام عارض الرسم نفسه.

| الحقل | وظيفته |
|---|---|
| ارتباط النص | أعلى أو الوسط أو أسفل أو تسطير |
| رأس السهم / حجم السهم | الرمز والحجم عند نهاية كل ذراع |
| فجوة الهبوط | المسافة بين خط الهبوط والنص |
| دوران النص | زاوية التسمية بالدرجات |
| نمط النص | ينسخ مرة واحدة الخط والارتفاع والعريض والمائل من [TextStyle](../text-style/) |
| الخط / ارتفاع النص | خط التسمية وارتفاعها |
| عريض / مائل | تنسيق مستقل للنص |
| إطار النص | إطار مستطيل حول التسمية |

ينسخ **جديد** النمط المحدد. لا يمكن إعادة تسمية `Standard` أو حذفه، ولا يمكن حذف النمط الحالي. يؤثر **تعيين كحالي** في خطوط الإشارة التي تُنشأ لاحقاً فقط، ولا يغيّر العناصر الموجودة. يعطّل الاسم الفارغ أو المكرر أو غير الصالح في DXF زر **موافق**. تُخفى الأنماط التعليقية المستوردة مع الاحتفاظ ببياناتها.

## الحفظ وDXF

يطبق **موافق** كل التغييرات، بينما يتجاهلها **إغلاق** أو `Escape`. يقرأ KulmanLab سجلات `MLEADERSTYLE` ويكتبها. تُحفظ حقول الاسم ورأس السهم وحجمه والفجوة والارتفاع والارتباط والإطار والعلامة التعليقية ضمن النمط. أما الدوران والخط والعريض والمائل فهي قيم افتراضية في KulmanLab تُنسخ إلى خط الإشارة عند إنشائه.

راجع أيضاً [Leader](../leader/) و[LeaderAdd](../leader-add/) و[LeaderRemove](../leader-remove/).
