# Help

Otevře panel nápovědy v aplikaci se shrnutím všech klávesových zkratek, tipů k navigaci a obecného použití.

## Jak používat

Klikněte na tlačítko **Help** v panelu nástrojů nebo napište `help` do terminálu. Panel nápovědy se okamžitě otevře a příkaz se ukončí.

## Co je v panelu nápovědy

### Navigace
| Zkratka | Akce |
|---------|------|
| `Kolečko myši` | Přiblížení / oddálení |
| `Prostřední tlačítko + tažení` | Posun pohledu |
| `Dvojité kliknutí prostředním tlačítkem` | Zobrazit všechny objekty na obrazovce |

### Příkazy
| Zkratka | Akce |
|---------|------|
| Psaní | Začněte psát název příkazu — návrhy se zobrazí na plátně |
| `Delete` | Smaže všechny vybrané objekty |
| `Enter` / `Space` | Potvrdí příkaz nebo vstup |
| `Enter` / `Space` (nečinný stav) | Zopakuje naposledy použitý příkaz |
| `Escape` | Zruší aktuální příkaz nebo výběr |

### Výběr
| Zkratka | Akce |
|---------|------|
| `Levé tlačítko` | Vybere objekt |
| `Tažení →` | Vybere pouze objekty **zcela uvnitř** oblasti tažení |
| `Tažení ←` | Vybere jakýkoli objekt, který se oblasti tažení **dotýká** |
| `Levé tlačítko na úchytu` | Přímo upraví vrchol nebo koncový bod |

### Tipy ke kreslení
- **Body přichycení** — kurzor se automaticky přichytává ke koncovým bodům blízkých objektů.
- **Přilnavý úhel** — přesuňte kurzor dostatečně daleko jedním směrem a zamkne se na násobky 45°.
- **Přesná délka** — při zamknutém úhlu napište číslo a stiskněte `Enter` pro nastavení přesné vzdálenosti.
