หากต้องการวาดรูปหลายเหลี่ยมปกติใน CAD ให้ระบุจำนวนด้าน เลือกจุดศูนย์กลาง แล้วกำหนดรัศมี — หรือเลือกขอบหนึ่งด้านแล้วส่วนที่เหลือจะตามมาเอง หากต้องการวาดวงกลมสลักเกลียว ให้วาดรูหนึ่งรูแล้วทำซ้ำรอบจุดศูนย์กลางด้วยอาร์เรย์เชิงขั้ว คู่มือนี้ทำทั้งสองอย่างด้วยตัวเลขที่แม่นยำ ในเบราว์เซอร์ที่ [app.kulmanlab.com](https://app.kulmanlab.com) — ฟรี ไม่ต้องติดตั้ง และไฟล์จะไม่ออกจากคอมพิวเตอร์ของคุณ

เราพัฒนา [KulmanLab](https://kulmanlab.com) ดังนั้นขั้นตอนด้านล่างใช้คำสั่งของมัน แนวคิด — ระยะระหว่างหน้าเทียบกับระหว่างมุม เส้นผ่านศูนย์กลางวงกลมพิตช์ สำเนาหมุนไปตามรอบหรือไม่ — เหมือนกันในโปรแกรม CAD ทุกตัว

## วาดรูปหลายเหลี่ยมปกติ

รูปหลายเหลี่ยมปกติมีด้านและมุมเท่ากันทั้งหมด: หกเหลี่ยมสำหรับน็อต แปดเหลี่ยมสำหรับป้าย ห้าเหลี่ยมสำหรับลายตัดประดับ ใน KulmanLab คือคำสั่ง **Polygon**

1. พิมพ์ `polygon` ในเทอร์มินัล หรือใช้ปุ่ม Polygon ในแผง Shapes
2. ป้อน**จำนวนด้าน** — จำนวนเต็มใดก็ได้ตั้งแต่ 3 ถึง 1024 — แล้วกด **Enter** พรอมต์จะเติมจำนวนที่คุณใช้ครั้งล่าสุดไว้ให้
3. **คลิกที่จุดศูนย์กลาง** หรือพิมพ์ `X,Y` เพื่อระบุจุดที่แน่นอน
4. **คลิกที่รัศมี** หรือพิมพ์แล้วกด **Enter**

ผลลัพธ์เป็น polyline แบบปิดหนึ่งเส้น ดังนั้นทุกอย่างที่ทำกับ polyline ได้ — ย้าย หมุน offset ปรับขนาด — ใช้ได้

### ระหว่างหน้าหรือระหว่างมุม?

จุดนี้คนมักสะดุด "รัศมี" อาจหมายถึงระยะสองแบบที่ต่างกัน และหกเหลี่ยมจะระบุด้วยแบบใดแบบหนึ่งขึ้นอยู่กับสิ่งที่คุณวาด:

| | วัดถึง | การใช้งานทั่วไป |
|---|---|---|
| **Inside เปิด** (ค่าเริ่มต้น) | มุมทั้งหลาย | รูปทรงที่ต้องอยู่ในวงกลมที่กำหนด |
| **Inside ปิด** | จุดกึ่งกลางของแต่ละขอบ | รูปทรงที่มีความกว้างระหว่างหน้าที่กำหนด — น็อต หัวสลักเกลียว ขนาดประแจ |

กด `I` ที่พรอมต์รัศมีเพื่อสลับ น็อตหกเหลี่ยมขายตามความกว้างระหว่างหน้า ดังนั้นให้ใช้ **Inside ปิด** แล้วพิมพ์ *ครึ่งหนึ่ง* ของค่านั้น สำหรับน็อต M8 ที่กว้าง 13 มม. ระหว่างหน้า:

1. `polygon` แล้ว `6` สำหรับจำนวนด้าน แล้วคลิกหรือพิมพ์จุดศูนย์กลาง
2. กด `I` เพื่อปิด Inside
3. พิมพ์ `6.5` แล้วกด **Enter**

หน้าทั้งสองห่างกัน 13 มม. พอดี มุมอยู่ห่างจากจุดศูนย์กลาง 7.51 มม. หรือประมาณ 15 มม. ระหว่างมุม หากพิมพ์รัศมีแทนการคลิก รูปหลายเหลี่ยมจะวางโดยให้ขอบล่างสุดอยู่ในแนวนอน ราบอยู่ด้านล่าง หากคลิก มันจะรับทิศทางจากตำแหน่งที่คลิก

### จากขอบหนึ่งด้าน

บางครั้งคุณรู้ความยาวด้านแต่ไม่รู้รัศมี — เช่น โต๊ะแปดเหลี่ยมที่มีด้านละ 20 มม. กด `E` ที่พรอมต์จุดแรกเพื่อสลับเป็นโหมด **Edge** แล้วเลือกปลายทั้งสองของขอบหนึ่งด้าน มุมที่เหลือจะถูกสร้างทวนเข็มนาฬิกาทางซ้ายของขอบนั้น การพิมพ์ `0,0` แล้ว `20,0` จะวางขอบยาว 20 มม. ตามแกน X โดยมีรูปหลายเหลี่ยมอยู่ด้านบน

## วาดวงกลมสลักเกลียว

วงกลมสลักเกลียว — "PCD" ในแบบ — คือวงแหวนของรูที่เว้นระยะเท่ากันรอบจุดศูนย์กลาง คุณวาดรูหนึ่งรูแล้วทำซ้ำ ใน KulmanLab คือ **ArrayPolar**

ยกตัวอย่างรู 6.6 มม. หกรูบนวงกลมพิตช์เส้นผ่านศูนย์กลาง 50 มม. โดยมีจุดศูนย์กลางที่จุดกำเนิด:

1. **วาดรูแรก** รัน `circle` พิมพ์จุดศูนย์กลางเป็น `25` `,` `0` — ครึ่งหนึ่งของ PCD ตามแกน X — กด **Enter** แล้วพิมพ์รัศมี `3.3` และกด **Enter**
2. **เลือกมัน**โดยคลิกที่วงกลม
3. **รันอาร์เรย์เชิงขั้ว** พิมพ์ `arraypolar` หรือใช้ปุ่ม ArrayPolar ในแผง Edit
4. **เลือกจุดศูนย์กลางของลวดลาย** — พิมพ์ `0,0`
5. เทอร์มินัลแสดงอาร์เรย์ตามที่เป็นอยู่ — `Change [Items=6] [Angle=60°] [Fill=360°] [Rotate=true]` — และสำเนาอีกห้าชุดแสดงตัวอย่างสด กด **Enter** เพื่อยอมรับ

นั่นคือวงกลมสลักเกลียวทั้งหมด หากต้องการจำนวนอื่น ให้กด `I` ก่อนยืนยันแล้วพิมพ์จำนวนรายการ — ต้นฉบับนับเป็นหนึ่ง และมุมระหว่างกันจะถูกคำนวณให้ หรือกด `A` แล้วพิมพ์ระยะห่างเป็นองศาแทน มุมการเติมจะถูกคำนวณใหม่ให้สอดคล้อง

รายละเอียดสำคัญบางข้อ:

- **Fill** คือมุมจากรายการแรกถึงรายการสุดท้าย ค่าเริ่มต้น 360° กระจายรายการรอบวงกลมเต็ม ตัวเลขที่น้อยกว่ากระจายบนส่วนโค้ง — เช่น แถวของรูบนหนึ่งในสี่ของรอบ มุมลบไปตามเข็มนาฬิกา
- **Rotate** กำหนดว่าแต่ละสำเนาจะหมุนไปตามรอบหรือไม่ สำหรับรูกลมไม่มีผลต่าง สำหรับร่อง ฟัน หรือขายึดมี: เปิด — แต่ละสำเนาหันเข้าหาจุดศูนย์กลางเหมือนต้นฉบับ ปิด — แต่ละสำเนาคงทิศทางของต้นฉบับและถูกย้ายไปยังตำแหน่งเท่านั้น กด `R` เพื่อสลับก่อนยืนยัน
- อาร์เรย์สร้าง**สำเนา** — ต้นฉบับอยู่ที่เดิม และทุกรายการเป็นเอนทิตีธรรมดาที่แก้ไขได้ภายหลัง

## รวมทั้งหมด: หน้าแปลน

วาดหกเหลี่ยมเป็นเส้นรอบรูป วงกลมตรงกลางเป็นรูเจาะ และวงกลมสลักเกลียวสำหรับรูยึด สามคำสั่ง ทุกขนาดพิมพ์อย่างแม่นยำ และไม่ต้องวัดจากหน้าจอ

หากชิ้นงานจะส่งไปตัดเลเซอร์ ให้ลบวงกลมช่วยที่คุณวาดไว้หาวงกลมพิตช์ — มันจะถูกตัดเหมือนทุกอย่างอื่น — และตรวจไฟล์ตามคู่มือ[การเตรียม DXF สำหรับการตัดเลเซอร์](/th/blog/prepare-dxf-for-laser-cutting/)ของเรา รูปหลายเหลี่ยมเป็นเส้นทางปิดโดยโครงสร้าง ซึ่งเป็นสาเหตุที่พบบ่อยที่สุดที่บริการตัดปฏิเสธไฟล์

## สิ่งที่วิธีนี้ทำไม่ได้

- **รูปหลายเหลี่ยมปกติเท่านั้น** ทุกด้านเท่ากัน เส้นรอบรูปไม่สม่ำเสมอ — รูปทรงที่มีบางด้านยาวกว่า — คือ [polyline](/th/docs/commands/polyline/) ที่คุณวาดทีละจุด
- **2D เท่านั้น** วาดเส้นรอบรูปแบบแบน ไม่ได้ให้น็อตที่สร้างแบบจำลองหรือสลักเกลียวที่มีเกลียว
- **เบราว์เซอร์บนเดสก์ท็อปเท่านั้น** — Chrome, Firefox, Safari และ Edge ไม่มีเวอร์ชันมือถือ
