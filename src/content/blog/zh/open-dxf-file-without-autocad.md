不用 AutoCAD 打开 DXF 文件，把它拖进一个浏览器端的 CAD 编辑器即可——无需安装，也不用注册账户。LibreCAD、QCAD 这类免费桌面软件同样能打开 DXF。本文两条路都讲，并说明图纸打开后空白、极小或缺字时该怎么办。

下面其中一个工具是我们做的——[KulmanLab](https://kulmanlab.com/zh/)——所以请把那一节当作有立场的一节，而其中列出的限制，则是我们不得不诚实交代的部分。

## DXF 文件到底是什么

DXF 是 *Drawing Exchange Format*（图形交换格式）的缩写。Autodesk 创建它，是为了让各种 CAD 程序之间能互相传递图纸，它刻意做成开放的纯文本格式——你完全可以用文本编辑器打开一个 `.dxf` 并读懂它。

正因为开放，你才有多种选择。DXF 不绑定任何一款程序，能读它的工具有几十种。

也正因如此，DXF 不是图片。它保存的是几何信息——直线、圆弧、圆、图层、标注——而不是像素。把后缀改成 `.jpg` 并不会让它在看图软件里打开。

## 方案一：在浏览器里打开

最快的路径，因为没有任何东西要下载，也不需要注册。

1. 打开 [app.kulmanlab.com](https://app.kulmanlab.com)。
2. 把 `.dxf` 文件直接拖到画布上——或使用文件面板中的 **Import** 按钮（文件夹图标）。
3. 图纸随即载入，视图会自动缩放到图纸范围。

文件始终不会离开你的电脑。KulmanLab 完全在浏览器中运行，图纸在本地解析，不会上传到服务器。

之后你可以平移缩放、开关图层、测量距离和角度、编辑几何图形，如果只是需要一份能打印、能转发的东西，还可以导出为 PDF、PNG、JPEG 或 WebP。

**它能从 DXF 中读取：**直线、圆、圆弧、椭圆、多段线、样条曲线、文字、标注、多重引线和填充，以及文件自带的图层表和线型表。

**它的不足——在依赖它之前请先看这一段：**

- **仅限二维。**包含三维实体或网格的 DXF，用这个工具是找错了对象。
- **不支持图块。**块参照（`INSERT`）不会被解析，因此由重复块符号搭建的图纸会读得不完整。
- **只支持 DXF，不支持 DWG。**见下文 DWG 一节。
- **仅限桌面浏览器**——Chrome、Firefox、Safari 和 Edge。没有移动版。
- **导出 DXF 只含几何图形。**如果你编辑后再导出为 DXF，填充、标注、引线和文字都不会写入。需要完整保留请导出为原生 JSON 格式，只是要分享则导出 PDF。

如果其中任何一条对你是硬性障碍，下面的桌面软件会更合适。

## 方案二：免费桌面软件

如果你要经常做这件事，或者你的文件用到了浏览器工具处理不了的功能，那就值得装一个。

**LibreCAD** — 免费开源，纯二维，可在 Windows、macOS 和 Linux 上运行。最接近传统二维制图的一款，也是可靠的 DXF 编辑器。

**QCAD** — LibreCAD 由它衍生而来。有免费的社区版，另有功能更多的付费 Pro 版。

**FreeCAD** — 免费开源，主攻三维参数化建模，但可以导入 DXF。如果你只想看一张二维图纸就太重了，而且学习曲线陡峭。

**Autodesk Viewer** — Autodesk 自家的免费网页查看器。只能查看，且需要用 Autodesk 账户登录。

**Inkscape** — 不是 CAD，但能导入 DXF；如果你只需要看看形状或转成 SVG，它是个合理的选择。

## “其实这是个 DWG 吧？”

很多时候确实是。DXF 和 DWG 都是 Autodesk 的格式，两个名字常被混用，但它们并不是一回事：

| | DXF | DWG |
|---|---|---|
| 格式 | 开放、基于文本 | 专有、二进制 |
| 用途 | 程序之间交换 | AutoCAD 的原生格式 |
| 其他软件的支持 | 广泛 | 有限，且常不完善 |

在到处找查看器之前，先确认文件的真实后缀。如果是 `.dwg`，上面这些工具大多帮不上忙——包括只支持 DXF 的 KulmanLab。

可靠的办法是改要一份 DXF：发文件给你的人可以在自己的 CAD 程序里打开，然后导出或*另存为* DXF。几乎所有桌面 CAD 软件都能做到，前后大概十秒钟。自己用第三方转换器转 DWG 也可以，但损失更大，而且等于把别人的图纸交给了一个来路不明的工具。

## 图纸能打开，但看着不对劲

**画布一片空白。**通常是几何图形离原点很远，视图正对着空白区域。用*充满视图*或*范围缩放*一类的命令跳到图纸位置。也检查一下图层是否被关闭——图纸可能是带着大量冻结图层送过来的。

**一切要么小如微尘，要么大得离谱。**DXF 并不可靠地记录单位。同一张图纸可能是按毫米、厘米、英寸或英尺绘制的，而文件里常常没写明是哪一种。量一个你知道真实尺寸的对象，再据此换算比例。

**文字丢失或被替换。**DXF 不会内嵌字体。如果图纸用了你机器上没有的字体，文字就会退回到别的字体或者干脆消失。装上原字体即可解决。

**图纸有一部分没进来。**文件里有你的工具读不了的实体类型——常见的是图块、三维实体，或生成该文件的程序写入的专有扩展。在断定文件损坏之前，先换第二个工具试试。

**根本打不开。**确认它真的是 DXF：用纯文本编辑器打开看看。真正的 DXF 开头是可读的 ASCII 组码，以及 `SECTION`、`HEADER` 这样的段名。如果看到的是二进制乱码，那它是 DWG 或二进制格式的 DXF。

## 该选哪个

**只是想看一眼，就这一次？**用浏览器打开。为了读别人发来的一个文件而装一整套 CAD，划不来。

**需要测量、标注或打印？**浏览器工具完全够用，而按真实比例打印成 PDF，通常正是大家真正想要的。

**要反复做正经的制图工作？**装 LibreCAD 或 QCAD。专门的桌面软件长期来看更顶用。

**拿到的是 DWG？**找发件人要一份 DXF。这比任何转换路径都更快、更稳妥。
