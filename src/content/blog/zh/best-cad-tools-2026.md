## 功能完整的 DWG 与 DXF 主力工具

这些是为生产制图打造的工具：标题栏、图纸集、外部参照、几十个图层，以及在各家单位之间流转的文件。

### AutoCAD

其他一切都以它为基准。四十年积累的功能、无人能及的脚本与插件生态，以及最关键的一点 — DWG 作为原生格式，而这正是行业实际流通的「货币」。

**优点：** DWG 为原生格式，转换过程中不会丢失任何东西。庞大的插件、LISP 与样板生态。行业专用工具集（Architecture、Mechanical、Electrical、Plant 3D）随完整授权附送。提供网页与移动端配套应用，可查看和做少量编辑。

**缺点：** 价格昂贵，且仅限订阅 — 永久授权早已取消。安装体积庞大，学习曲线确实陡峭。AutoCAD LT 便宜得多，但去掉了三维、LISP 和工具集，因此「实惠」的档位同时也是最难扩展的档位。

**最适合：** 本来就要与客户和承包商交换 DWG 的单位，兼容性值回授权费用。

### BricsCAD

最有说服力的 AutoCAD 直接替代品。原生读写 DWG，保留熟悉的命令行，而且 — 这正是多数人转投它的原因 — 至今仍出售永久授权。

**优点：** 原生 DWG。永久授权，花费有终点。可运行 LISP，因此大量 AutoCAD 工具能直接迁移。分档（Lite / Pro / BIM / Mechanical），用多少付多少。处理大图纸确实快。

**缺点：** 并非像素级的 AutoCAD 克隆 — 复杂的定制流程需要返工。第三方生态较小。部分 Autodesk 专有对象类型会以代理形式载入。

**最适合：** 厌倦订阅、能承受短期迁移成本的资深 AutoCAD 用户。

### DraftSight

Dassault Systèmes 的二维制图软件，定位为成本更低的 DWG 编辑器。它曾以 2019 年前完全免费而闻名；免费档已取消，但付费档按行业标准仍属便宜。

**优点：** 原生 DWG，界面熟悉，相对 AutoCAD 价格低。更高档位增加三维和 API 访问。背后有一家不会消失的公司。

**缺点：** 取消免费版损耗了口碑，且未完全恢复。功能深度落后于 AutoCAD 和 BricsCAD。授权档位令人困惑，便宜的那一档相当受限。

**最适合：** 预算有限、无需高阶功能的常规二维 DWG 工作。

### nanoCAD

一款精简的 DWG 兼容制图工具，采用经典功能区界面。它的免费档同样已经取消，但仍是功能完整的选项中较便宜的一个。

**优点：** 成本低。快速轻量。支持 DWG 和脚本 API。对有 AutoCAD 肌肉记忆的人来说很熟悉。

**缺点：** 仅限 Windows。社区较小，英文文档比竞争对手单薄。高级模块需另行付费。

**最适合：** Windows 平台上预算敏感的二维制图。

## 免费开源的二维工具

没有授权、没有账户、没有厂商。你放弃的是打磨程度和技术支持。

### LibreCAD

一款由社区维护的二维制图软件，在 GPL 下完全免费。它只做一件事：基于 DXF 的二维制图。

**优点：** 真正永久免费，没有档位也没有增购。跨平台（Windows、macOS、Linux）。下载体积小，几乎在任何机器上都能跑。图层、捕捉和标注都很扎实。

**缺点：** 仅支持 DXF — 不支持 DWG。界面显出年头。开发缓慢且不规律。没有三维。处理超大或复杂图纸时不太顺手。

**最适合：** 业余爱好者、学生，以及需要免费桌面二维制图且能忍受老旧界面的人。

### QCAD

LibreCAD 最初从中分支出来的项目，至今仍在积极开发。社区版免费；QCAD Professional 是一次性付费，增加 DWG 导入、更完善的标注工具和脚本功能。

**优点：** 维护活跃，界面比 LibreCAD 更整洁、响应更快。升级到 Pro 花费确实很少，而且只需一次。ECMAScript 插件 API。文档质量好。

**缺点：** 仅二维。DWG 支持需付费档才有。无法替代完整的生产制图套件 — 没有图纸集，也不适合大量使用外部参照的流程。

**最适合：** 预算不多但要认真做二维制图的人，尤其是宁愿一次买断也不愿订阅的人。

在浏览器标签页中运行的完整参数化三维 CAD，具备真正的版本控制和多人同时编辑，这些能力内建于数据模型本身，而非事后附加。

**最适合：** 做三维产品设计、希望无需自建 PDM 服务器即可协作的分布式团队。

## 三维与参数化建模

这是完全不同的问题：你在构建模型，图纸则从模型中派生出来。

### FreeCAD

开源参数化三维建模软件的领头羊。1.x 版本解决了长期存在的拓扑命名问题 — 正是这个问题让早期版本令人沮丧 — 因此它现在是一款明显更严肃的工具。

**优点：** 免费开源，商业使用不受限制。真正的参数化，具备完整的特征历史。提供机械、建筑（BIM）、CAM、有限元和二维制图工作台。全程可用 Python 编写脚本。开发活跃。

**缺点：** 即便以 CAD 的标准衡量，学习曲线也很陡，工作台的概念一开始令人困惑。界面精细程度不及商业工具。大型装配可能会变慢。装配工作流仍在成熟中。

**最适合：** 创客、工程师，以及任何想要免授权参数化三维、并愿意投入学习时间的人。

### Fusion 360

Autodesk 的云端互联 CAD/CAM/CAE 套件。它真正的强项是集成：建模、仿真和刀具路径生成都在一个应用中完成。

**优点：** 集成 CAM 表现出色。云端协作与版本历史。同一工具中兼具强大的直接建模和参数化建模。面向个人非商业用途的免费档。社区规模很大，学习资源丰富。

**缺点：** 免费档被逐步收窄，还可能进一步收窄。需要云账户，离线时功能会降级。仅限订阅。功能可用性在版本之间会变动，一些专业用户对此感到不安。

**最适合：** 希望用一份订阅同时获得建模与 CAM 的产品设计师和机加工人员。

### SolidWorks

制造业机械设计的标准。深入的装配建模、仿真与工程图生成，并有厂商提供零件库构成的生态。

**优点：** 装配与工程图工具能力极强。仿真功能成熟。庞大的库生态 — 多数元器件厂商都会发布 SolidWorks 模型。教学普及，因此招人容易。

**缺点：** 非常昂贵，还要加上维护费。仅限 Windows。硬件要求高。文件格式专有且与版本绑定 — 较新的文件无法在旧版席位上打开。

**最适合：** 设计机械装配的制造企业，相对模具成本而言授权费微不足道。

### SketchUp

为快速、直观的三维体块推敲而生 — 建筑、室内、木工、景观。它的推/拉建模是主流 CAD 中最简单的三维交互方式。

**优点：** 把三维想法呈现到屏幕上，这是本文中最快的工具。3D Warehouse 是一个庞大的免费模型库。扩展生态庞大且成熟。存在免费的浏览器版本。

**缺点：** 是曲面建模器而非实体建模器 — 没有参数化，几何体可能变成非流形，从而破坏后续环节。二维施工图需要配套的 LayOut，而且弱于任何专用制图工具。免费网页档相当受限。

**最适合：** 需要快速出效果的建筑师、室内设计师和木工从业者。

## 如何选择

几个能迅速缩小范围的问题：

**你需要三维吗？** 如果不需要，整个参数化家族都可以跳过 — 否则你要为永远用不到的能力付费并花时间学习。纯二维工具更便宜、更快、更简单。

**别人会发 DWG 给你吗？** 那你需要 DWG 原生的工具：AutoCAD、BricsCAD、DraftSight 或 nanoCAD。基于 DXF 的工具每次都要转换一道，而转换会丢东西。

**工作是偶尔才有吗？** 一个月只用两次的订阅并不划算。QCAD Professional 的一次性付费或免费工具，比按年计费的席位更合理。

**你能安装软件吗？** 在受管控的办公电脑、共用电脑或 Chromebook 上，浏览器工具是唯一真正可行的选择。

**文件必须存放在哪里？** 有些工具默认要求云存储。如果你的图纸涉密，这一约束的分量高于任何功能清单 — 这也正是本地优先工具存在的理由。
