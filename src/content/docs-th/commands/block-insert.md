# Block Insert

คำสั่ง `blockinsert` เปิดพาเลตตัวอย่างของทุกบล็อกในแบบ และวางบล็อกที่คุณเลือก สร้างบล็อกด้วย [Block Create](../block-create/) หรือเปิดไฟล์ DXF ที่มีบล็อก

## การวางบล็อก

1. พิมพ์ `blockinsert` หรือคลิก **แทรกบล็อก** ในแผง **บล็อก** พาเลตจะยึดติดด้านซ้ายพร้อมไทล์ตัวอย่างหนึ่งอันต่อบล็อก หน้าละสิบสองอัน ลูกศรใต้ไทล์ใช้พลิกหน้า
2. พิมพ์ใน **ค้นหาบล็อก** เพื่อกรองไทล์ตามชื่อ
3. ตั้ง **มาตราส่วน** (ต้องมากกว่า 0) และ **การหมุน** เป็นองศา **วางซ้ำ** เปิดอยู่โดยค่าเริ่มต้น
4. คลิกไทล์ของบล็อก บล็อกจะตามเคอร์เซอร์: คลิกเพื่อวางตามจุดฐาน หรือพิมพ์ X,Y เพื่อกำหนดตำแหน่งแน่นอน เมื่อเคอร์เซอร์ล็อกกับมุม คุณพิมพ์ความยาวได้
5. เมื่อ **วางซ้ำ** เปิดอยู่ บล็อกจะตามเคอร์เซอร์ต่อสำหรับสำเนาถัดไปจนกว่าคุณจะกด **Escape** เมื่อปิด คำสั่งจบหลังวางหนึ่งสำเนา

## ควรรู้

- หากต้องการลบบล็อก ให้คลิกถังขยะบนไทล์ของมันแล้วยืนยัน บล็อกที่มีการอ้างอิงในแบบลบไม่ได้: ไทล์ของมันแสดง **กำลังใช้งาน ลบไม่ได้**
- แบบที่ไม่มีบล็อกจะแสดง **ภาพวาดนี้ไม่มีบล็อก** ในพาเลต
- **Escape** ปิดพาเลตเมื่อไม่มีอะไรกำลังถูกวาง พาเลตเป็นหนึ่งในแผงที่ยึดติด ซึ่งแสดงทีละแผงที่ด้านซ้าย
