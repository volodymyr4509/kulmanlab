# Extend

คำสั่ง `extend` ยืดจุดสิ้นสุดที่ใกล้ที่สุดของ [Line](../line/), [Arc](../arc/), [Ellipse](../ellipse/) หรือ Polyline แบบเปิดที่วางเมาส์ไปยังจุดตัดที่ใกล้ที่สุดที่จะเกิดกับวัตถุอื่นในภาพวาด วางเมาส์ใกล้จุดสิ้นสุดที่ต้องการยืด — ตัวอย่างแสดงวัตถุที่ยืดแล้ว — แล้วคลิกเพื่อใช้งาน

เฉพาะวัตถุที่มีจุดสิ้นสุดจริงเท่านั้นที่สามารถยืดได้ [Circle](../circle/) และ Ellipse ที่สมบูรณ์ (360°) เป็นรูปทรงปิดที่ไม่มีจุดสิ้นสุดเสมอ จึงไม่สามารถยืดได้เลย — เช่นเดียวกับ Polyline แบบปิดหรือ Rectangle ส่วน Ellipse บางส่วน (ส่วนโค้งวงรี) และ Arc มีจุดสิ้นสุดและยืดได้เช่นเดียวกับ Line

## การยืดวัตถุ

1. พิมพ์ `extend` ในเทอร์มินัลหรือคลิกปุ่ม **Extend** บนแถบเครื่องมือ
2. **วางเมาส์ใกล้ปลายด้านหนึ่ง** ของวัตถุที่ต้องการยืด — ตัวอย่างแสดงวัตถุที่ยืดไปยังขอบเขตที่ใกล้ที่สุดในทิศทางนั้น
3. **คลิก** เพื่อใช้งานการยืด

คำสั่งยังคงทำงานหลังจากการยืดแต่ละครั้ง ดังนั้นคุณสามารถ hover และคลิกต่อไปเพื่อยืดวัตถุเพิ่มเติม กด **Enter**, **Space** หรือ **Escape** เพื่อออก

```
  ก่อน:                      หลัง:

  ──────           |           ──────────────|
  (เส้นสั้น)     (ขอบเขต)  (ยืดไปยังขอบเขต)
```

## วิธีเลือกจุดสิ้นสุด

คำสั่งดูว่าเคอร์เซอร์อยู่ใกล้ปลายด้านใดมากกว่า:

- **Line และ Polyline แบบเปิด** — เคอร์เซอร์ใกล้จุดสิ้นสุดยืดปลายไปข้างหน้า; เคอร์เซอร์ใกล้จุดเริ่มต้นยืดจุดเริ่มต้นไปข้างหลัง
- **Arc และ Ellipse บางส่วน** — เคอร์เซอร์ใกล้ปลายเชิงมุมด้านใดด้านหนึ่งทำให้ส่วนโค้งเติบโตไปในทิศทางนั้น รอบจุดศูนย์กลางและรัศมีเดียวกัน (หรือรูปทรงวงรีเดียวกัน) จนถึงขอบเขตถัดไป

รังสี — หรือสำหรับ Arc และ Ellipse คือวงกลมหรือเส้นโค้งพื้นฐานของวัตถุเอง — ถูกฉายออกจากปลายที่เลือก และ **จุดตัดที่ใกล้ที่สุด** กับวัตถุอื่น (ยกเว้นตัววัตถุเองและประเภทที่ถูกเพิกเฉย) กลายเป็นจุดสิ้นสุดใหม่

หากไม่พบจุดตัดในทิศทางนั้น ไม่มีตัวอย่างปรากฏและการคลิกไม่มีผล

## การยกเว้นขอบเขต

ประเภทวัตถุต่อไปนี้ถูกเพิกเฉยเป็นขอบเขต — วัตถุไม่ยืดไปพบพวกมัน:

- Text / Mtext
- Multileader

ประเภทอื่นทั้งหมด (Line, Arc, Circle, Ellipse, Polyline, Spline, Dimension) ทำหน้าที่เป็นขอบเขตที่ถูกต้อง

หากส่วนแรกหรือส่วนสุดท้ายของ Polyline เป็นส่วนโค้งเอง (วาดด้วยตัวสลับ Arc) การยืดส่วนนั้นจะทำให้ส่วนโค้งขยายไปตามวงกลมของมันเอง — เหมือนกับการยืด Arc แบบเดี่ยว — แทนที่จะปฏิบัติกับมันเป็นส่วนตรง

## อ้างอิงแป้นพิมพ์

| ปุ่ม | การกระทำ |
|-----|----------|
| `Enter` / `Space` | ออกจากโหมด extend |
| `Escape` | ออกจากโหมด extend |

## วัตถุที่รองรับ

| วัตถุ | สามารถยืดได้? |
|-------|-------------|
| Line | ใช่ |
| Arc | ใช่ |
| Ellipse | ใช่ — เฉพาะถ้าเป็นส่วนโค้งบางส่วนอยู่แล้ว; วงรีที่สมบูรณ์ไม่มีจุดสิ้นสุด |
| Circle | ไม่ — เป็นรูปทรงปิดที่ไม่มีจุดสิ้นสุดเสมอ |
| Polyline (เปิด) | ใช่ |
| Polyline (ปิด) / Rectangle | ไม่ — เป็นรูปทรงปิดที่ไม่มีจุดสิ้นสุดเสมอ |
| Text, Spline, Dimension, Leader | ไม่ |

## Extend vs Trim

| | Extend | Trim |
|---|--------|------|
| สิ่งที่ทำ | ยืดจุดสิ้นสุดของวัตถุไปยังขอบเขต | ลบส่วนของวัตถุ |
| ทริกเกอร์ | วางเมาส์ใกล้จุดสิ้นสุดที่จะยืด | วางเมาส์เหนือส่วนที่จะตัด |
| ผลลัพธ์ | จุดสิ้นสุดย้ายออก | วัตถุแยกหรือสั้นลง |
| วัตถุที่รองรับ | Line, Arc, Ellipse, Polyline | Line, Arc, Circle, Ellipse, Polyline |
