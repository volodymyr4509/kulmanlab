# Measure

คำสั่ง `measure` อ่านแบบวาดรอบเคอร์เซอร์ขณะที่คุณเลื่อน โดยไม่ต้องเลือกจุด: รูปทรงที่ใกล้ที่สุดอยู่ไกลแค่ไหน ยาวหรือกลมเท่าใด และมุมที่เส้นมาบรรจบกัน การคลิกภายในบริเวณปิดจะให้พื้นที่และเส้นรอบรูปของมัน ไม่มีอะไรในแบบวาดเปลี่ยนแปลง

## การวัด

1. พิมพ์ `measure` ในเทอร์มินัล หรือคลิก **Measure** ปุ่มแรกในแผง Measure
2. **เลื่อนเคอร์เซอร์** จากตรงนั้นคำสั่งจะมองไปทางขวา ขึ้น ซ้าย และลงเพื่อหารูปทรงที่ใกล้ที่สุด แล้วแสดงสิ่งที่พบ
3. **คลิกภายในบริเวณปิด** เพื่อเติมและอ่านพื้นที่กับเส้นรอบรูป — ดูด้านล่าง
4. กด **Enter**, **Space** หรือ **Escape** เพื่อจบ

## สิ่งที่แสดง

- **ระยะข้าม** — จากสิ่งที่เคอร์เซอร์พบด้านหนึ่งไปยังสิ่งที่พบอีกด้านหนึ่ง ทั้งแนวนอนและแนวตั้ง หากมีของเพียงด้านเดียว ระยะจะเริ่มจากเคอร์เซอร์ ปลายแต่ละด้านที่พบสิ่งใดจะมีจุดทึบเล็ก ๆ ส่วนปลายที่เคอร์เซอร์ไม่มี
- **ความยาวหรือรัศมี** — วัตถุแต่ละชิ้นที่คำสั่งไปถึงจะถูกเน้นพร้อมความยาว หรือรัศมีหากเป็นส่วนของวงกลม
- **มุม** — ตรงที่เส้นตรงสองเส้นที่ไปถึงมาบรรจบกัน จะเขียนมุมระหว่างทั้งสอง มุมฉากมีสี่เหลี่ยมเล็ก ๆ กำกับ

ความยาวและมุมเขียนตามที่ [DimensionStyle](../dimension-style/) ปัจจุบันเขียน ด้วยรูปแบบหน่วยและความแม่นยำของมัน

## พื้นที่และเส้นรอบรูป

การคลิกภายในบริเวณปิดจะเติมบริเวณนั้นและแสดงพื้นที่กับเส้นรอบรูปในพรอมต์และประวัติ บริเวณถูกค้นหาแบบเดียวกับ [Hatch](../hatch/): เส้นแยกที่ต่อกันปลายต่อปลายปิดบริเวณได้เหมือน polyline และสิ่งปิดภายในจะถูกข้ามเป็นเกาะ — ขอบของมันนับรวมในเส้นรอบรูป และพื้นที่ของมันถูกหักออก

พื้นที่เป็นตัวเลขธรรมดาในหน่วยแบบวาดกำลังสอง — ฟุตและนิ้วไม่มีวิธีเขียนพื้นที่ — ส่วนเส้นรอบรูปเป็นไปตามรูปแบบหน่วย คลิกภายในบริเวณอื่นเพื่อวัด หากไม่มีสิ่งปิดล้อมจุดนั้น เทอร์มินัลจะบอกเหตุผลด้วยข้อความเดียวกับ Hatch: no boundary found, point is not enclosed หรือ boundary is open

## ควรรู้

- วัดเทียบกับเส้น ส่วนโค้ง วงกลม วงรี polyline และสไปลน์ ความยาวและพื้นที่แม่นยำ รวมถึงวงรีและสไปลน์
- วัตถุบนเลเยอร์ที่ถูกตรึงจะถูกละเลย วัตถุบนเลเยอร์ที่ล็อกจะถูกวัด
- ในแบบวาดขนาดใหญ่ มันดูเฉพาะสิ่งที่อยู่ใกล้เคอร์เซอร์ จึงตอบสนองได้เร็ว
