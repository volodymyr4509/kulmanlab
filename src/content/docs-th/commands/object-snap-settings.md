# Object Snap Settings

คำสั่ง `objectsnapsettings` เปิดหน้าต่างที่รวมการตั้งค่าทั้งหมดของแถบควบคุมไว้ที่เดียว แต่ละการตั้งค่าอธิบายไว้ข้างรายการพร้อมภาพวาดเล็ก ๆ เปิดด้วยปุ่มรูปเฟืองในแถบควบคุม หรือพิมพ์ `objectsnapsettings` การเปลี่ยนค่าที่นี่เหมือนกับการสลับปุ่มของมันในแถบ

## การตั้งค่า

### ตำแหน่งที่เคอร์เซอร์ลง

| แถบควบคุม | ทำอะไร |
|---|---|
| `Snap` | เคอร์เซอร์กระโดดไปยังจุดกริดที่ใกล้ที่สุด ทำให้จุดที่เลือกตกบนพิกัดลงตัว การสแนปไปยังวัตถุใกล้เคอร์เซอร์ยังคงมาก่อน ระยะกริดเปลี่ยนตามการซูม |
| `TANG` | ขณะวาดเส้นจากจุดหนึ่ง ให้นำเคอร์เซอร์ไปใกล้ตำแหน่งที่เส้นจะแตะวงกลม ส่วนโค้ง วงรี หรือสไปลน์พอดี แล้วมันจะสแนปตรงนั้น ใช้ได้ในคำสั่งเส้น พอลิไลน์ และคำสั่งอื่น รวมถึงตอนลากปลายของเส้นหรือพอลิไลน์ |

### เส้นนำขณะวาด

| แถบควบคุม | ทำอะไร |
|---|---|
| `ANGL` | เมื่อเคอร์เซอร์เข้าใกล้มุมใดมุมหนึ่งเหล่านี้จากจุดล่าสุด มันจะล็อกไปในทิศนั้น แสดงเป็นรังสีเส้นประ ขณะล็อก ให้พิมพ์ความยาวแล้วกด Enter เพื่อวางจุดที่ระยะนั้น |
| `Pins` | พักเคอร์เซอร์ไว้บนจุดสแนปครู่หนึ่งเพื่อปักหมุด จุดที่ปักหมุดจะส่งเส้นนำแนวนอนและแนวตั้งออกมา และเคอร์เซอร์จะสแนปไปบนเส้นเหล่านั้นและจุดที่ตัดกัน |
| `Dist` | จุดที่ปักหมุดล่าสุดใช้เป็นจุดเริ่ม: เมื่อเคอร์เซอร์ล็อกที่มุมหนึ่งจากหมุด ให้พิมพ์ความยาวแล้วกด Enter เพื่อวางจุดห่างจากหมุดเท่านั้น ต้องเปิดหมุดเวกเตอร์ |

### การป้อนข้อมูลและการเลือก

| แถบควบคุม | ทำอะไร |
|---|---|
| `Rel` | จุด X,Y ที่พิมพ์จะวัดจากจุดที่เลือกล่าสุด เหมือนขึ้นต้นด้วย @ กด Backspace เพื่อลบ @ ให้เป็นจุดในพิกัดของแบบเอง เมื่อปิด ให้พิมพ์ @ เองสำหรับระยะเลื่อน |
| `Lasso` | กดค้างแล้วลากบนพื้นที่ว่างเพื่อวาดบ่วงอิสระรอบสิ่งที่ต้องการแทนสี่เหลี่ยม สิ่งที่บ่วงล้อมไว้จะถูกเลือก |

### การแสดงผล

| แถบควบคุม | ทำอะไร |
|---|---|
| `Grid` | แสดงกริดพื้นหลัง ระยะห่างจะเปลี่ยนตามการซูม การปิดไม่ได้หยุดการสแนปไปยังกริด |
| `LWT` | วาดเส้นตามความหนาของเส้น เส้นที่หนักกว่าจึงดูหนากว่า เมื่อปิด ทุกเส้นจะบาง ซึ่งอาจทำให้แบบที่หนาแน่นอ่านง่ายขึ้น |

**ANGL** มีแถวของตัวเองสำหรับขั้นมุม: เลือก 10°, 20°, 30°, 45° หรือ 90° หรือเลือก **กำหนดเอง** แล้วพิมพ์มุมใดก็ได้ตั้งแต่ 1° ถึง 180°

สแนปเส้นสัมผัส การป้อนแบบสัมพัทธ์ และบ่วงบาศปิดอยู่โดยค่าเริ่มต้น **คืนค่าเริ่มต้น** คืนทุกการตั้งค่ากลับสู่สถานะเริ่มต้น
