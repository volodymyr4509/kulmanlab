# Export Manager

คำสั่ง `exportmanager` ดาวน์โหลดแบบปัจจุบันลงในระบบไฟล์ของคุณ สองรูปแบบวางเคียงกัน — **DXF** สำหรับความเข้ากันได้กับเครื่องมือ CAD อื่น และ **JSON** สำหรับการบันทึกครบถ้วนภายใน KulmanLab CAD — และแต่ละอันมีรายการติ๊กของตัวเองว่าจะใส่อะไรลงไฟล์

## วิธีส่งออก

1. คลิกปุ่ม **Export** บนแถบเครื่องมือ (ไอคอนดาวน์โหลด) ในแผงไฟล์ หรือพิมพ์ `exportmanager` ในเทอร์มินัล
2. หน้าต่าง **Export Manager** เปิดขึ้นเป็นสองคอลัมน์ **JSON** และ **DXF** แต่ละคอลัมน์แสดงชนิดเอนทิตีในแบบพร้อมช่องติ๊กและจำนวน
3. เอาติ๊กออกจากสิ่งที่ไม่ต้องการ ตอนเริ่มต้นทุกอย่างถูกติ๊กไว้
4. คลิก **Export JSON** หรือ **Export DXF** ไฟล์จะดาวน์โหลดลงโฟลเดอร์ดาวน์โหลดเริ่มต้นและหน้าต่างจะปิด

กด `Escape` เพื่อปิดป๊อปอัปโดยไม่ส่งออก

## เลือกสิ่งที่จะส่งออก

ทั้งสองคอลัมน์แสดงชนิดเอนทิตีชุดเดียวกัน แต่ละชนิดมีจำนวนที่อยู่ในแบบกำกับ

Lines · Circles · Arcs · Ellipses · Polylines · Splines · Text · Radius Dimensions · Diameter Dimensions · Angular Dimensions · Linear Dimensions · Leaders · Hatches

ทุกอย่างถูกติ๊กไว้เมื่อเปิดหน้าต่าง ส่งออกทันทีจึงได้แบบทั้งหมด เอาติ๊กของชนิดใดออกเพื่อกันไม่ให้เข้าไฟล์นั้นเพียงไฟล์เดียว

- **สองคอลัมน์เป็นอิสระต่อกัน** การเอาติ๊ก Hatches ออกฝั่ง DXF ไม่กระทบสิ่งที่ **Export JSON** สร้าง แต่ละรูปแบบเก็บการเลือกของตัวเอง
- **ชนิดที่คุณไม่มีจะเป็นสีจาง** แถวที่จำนวนเป็น `0` ติ๊กไม่ได้ รายการนี้จึงเป็นบัญชีตรวจนับแบบอย่างรวดเร็วไปด้วย
- **จำนวนเป็นภาพนิ่ง ณ ขณะนั้น** นับตอนเปิดหน้าต่างและไม่อัปเดตถ้าแบบเปลี่ยนอยู่ข้างหลัง ปิดแล้วเปิดใหม่เพื่อนับใหม่
- **ไม่มีอะไรถูกลบ** การเอาติ๊กออกกำหนดเฉพาะไฟล์ที่ส่งออก ตัวแบบยังคงเดิม

**Linear Dimensions** ครอบคลุมเส้นบอกขนาดแบบเส้นตรง แบบจัดแนว และแบบต่อเนื่อง เป็นเอนทิตีชนิดเดียวที่สร้างจากสามคำสั่งต่างกัน ส่วนรัศมี เส้นผ่านศูนย์กลาง และมุม มีแถวของตัวเอง

สำหรับไฟล์ตัด ให้เอาติ๊ก Text สี่แถวของเส้นบอกขนาด Leaders และ Hatches ออก แล้วคลิก **Export DXF** — ดู [การเตรียม DXF สำหรับตัดเลเซอร์](/th/blog/prepare-dxf-for-laser-cutting/)

## การเลือกรูปแบบ

| รูปแบบ | นามสกุล | เหมาะที่สุดสำหรับ | ข้อจำกัด |
|--------|---------|-------------------|----------|
| **JSON** *(เนทีฟ)* | `.json` | บันทึกงานเพื่อเปิดใหม่ใน KulmanLab CAD | ไม่เข้ากันได้กับเครื่องมือ CAD อื่น |
| **DXF** | `.dxf` | แชร์กับ FreeCAD, LibreCAD ฯลฯ | จะเหลือรอดมากแค่ไหนขึ้นกับโปรแกรมที่เปิด |

**เมื่อใดควรใช้ JSON:** เมื่อใดก็ตามที่คุณต้องการบันทึกสำเนาผลงานที่สมบูรณ์ JSON คือรูปแบบเนทีฟของ KulmanLab และรักษาทุกเอนทิตีไว้อย่างแม่นยำ — รวมถึงมิติ ตัวชี้นำ hatch และข้อมูลเลเยอร์ทั้งหมด

**เมื่อใดควรใช้ DXF:** เมื่อคุณต้องการส่งมอบภาพวาดให้กับผู้ที่ใช้แอปพลิเคชัน CAD อื่น ไฟล์ที่ส่งออกใช้รูปแบบ DXF AC1032 และสามารถเปิดได้ในเครื่องมือที่รองรับ DXF ส่วนใหญ่

## สิ่งที่ถูกส่งออกในแต่ละรูปแบบ

### การส่งออก JSON

รวมทุกชนิดของเอนทิตี:

- Lines, Circles, Arcs, Ellipses, Polylines, Splines
- Text
- มิติ (linear, aligned, continued, radius, diameter, มุม)
- Leaders (multileaders)
- Hatches รวมถึงลวดลาย มาตราส่วน มุม และจุดกำเนิด
- Layers และ Linetypes

### การส่งออก DXF

รวมทุกชนิดของเอนทิตี:

- Lines, Circles, Arcs, Ellipses, Polylines (ส่งออกเป็น `LWPOLYLINE`), Splines
- Text
- มิติ (linear, aligned, continued, radius, diameter, มุม)
- Leaders (multileaders)
- Hatches รวมถึงลวดลาย มาตราส่วน มุม และจุดกำเนิด
- Layers และ Linetypes

ไฟล์ถูกเขียนเป็น DXF แบบ AC1032 แบบที่ส่งออกจาก KulmanLab จึงเปิดในเครื่องมืออื่นที่รองรับ DXF ได้โดยคำอธิบายประกอบยังอยู่ครบ ไม่ได้มาถึงเป็นเพียงรูปทรงเปล่า

ส่วนที่ว่าโปรแกรมปลายทางแต่ละตัวจะจัดการกับมันอย่างไรนั้นยังต่างกันอยู่ การรองรับ DXF ไม่เท่ากันในแต่ละเครื่องมือ และตัวที่เก่ากว่าอาจมองข้ามเอนทิตีที่ตัวใหม่อ่านได้ ถ้าแบบต้องดูเหมือนกันทุกที่ ให้ใช้ [Print Manager](../print-manager/) เก็บเป็น PDF หรือรูปภาพแทน

## ชื่อไฟล์ที่ส่งออก

ไฟล์ที่ดาวน์โหลดจะตั้งชื่อตามไฟล์ภาพวาดปัจจุบัน (เช่น `myplan.json`) นามสกุลจะเปลี่ยนไปตามรูปแบบที่เลือก แบบที่ไม่เคยตั้งชื่อจะส่งออกเป็น `drawing.dxf` หรือ `drawing.json`

## ความแตกต่างระหว่าง Export Manager และ Print Manager

| คุณสมบัติ | Export Manager | Print Manager |
|-----------|-----------------|-----------------|
| ผลลัพธ์ | ไฟล์ต้นฉบับแบบเวกเตอร์ (.dxf / .json) | ภาพแบบราสเตอร์ (.png / .jpeg / .webp / .pdf) |
| แก้ไขได้ในเครื่องมืออื่น | ใช่ (DXF) | ไม่ |
| รักษา layers และ linetypes | ใช่ | ไม่ (เรนเดอร์แบบแบน) |
| เก็บมิติและตัวชี้นำ | ใช่ | ใช่ |

ใช้ **Export Manager** เมื่อคุณต้องการไฟล์ที่แก้ไขได้ ใช้ [Print Manager](../print-manager/) เมื่อคุณต้องการภาพสแนปช็อต

## คำสั่งที่เกี่ยวข้อง

- [Import](../import/) — เปิดไฟล์ DXF หรือ JSON
- [Print Manager](../print-manager/) — ส่งออกแคนวาสเป็นภาพ PNG, JPEG, WebP หรือ PDF
- [File Manager](../file-manager/) — เรียกดูภาพวาดที่บันทึกไว้ในที่เก็บข้อมูลของเบราว์เซอร์
