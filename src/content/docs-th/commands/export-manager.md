# Export Manager

คำสั่ง `exportmanager` ดาวน์โหลดภาพวาดปัจจุบันไปยังระบบไฟล์ของคุณ มีสองรูปแบบให้เลือก แสดงเป็นการ์ดเคียงข้างกัน: **DXF** สำหรับความเข้ากันได้กับเครื่องมือ CAD อื่น ๆ และ **JSON** สำหรับการบันทึกที่มีความแม่นยำสมบูรณ์ภายใน KulmanLab CAD — แต่ละการ์ดแสดงรายการชนิดของเอนทิตีที่รูปแบบนั้นบรรจุไว้อย่างชัดเจน

## วิธีส่งออก

1. คลิกปุ่ม **Export** บนแถบเครื่องมือ (ไอคอนดาวน์โหลด) ในแผงไฟล์ หรือพิมพ์ `exportmanager` ในเทอร์มินัล
2. ป๊อปอัป **Export Manager** จะเปิดขึ้นแสดงการ์ด JSON และ DXF เคียงข้างกัน แต่ละการ์ดแสดงรายการสิ่งที่ถูกส่งออก
3. คลิกการ์ดเพื่อเลือกรูปแบบ — **JSON** หรือ **DXF**
4. คลิกปุ่ม **Export \<FORMAT\>** ไฟล์จะถูกดาวน์โหลดไปยังโฟลเดอร์ดาวน์โหลดเริ่มต้นของคุณโดยอัตโนมัติ

กด `Escape` เพื่อปิดป๊อปอัปโดยไม่ส่งออก

## การเลือกรูปแบบ

| รูปแบบ | นามสกุล | เหมาะที่สุดสำหรับ | ข้อจำกัด |
|--------|---------|-------------------|----------|
| **JSON** *(เนทีฟ)* | `.json` | บันทึกงานเพื่อเปิดใหม่ใน KulmanLab CAD | ไม่เข้ากันได้กับเครื่องมือ CAD อื่น |
| **DXF** | `.dxf` | แชร์กับ FreeCAD, LibreCAD ฯลฯ | จะเหลือรอดมากแค่ไหนขึ้นกับโปรแกรมที่เปิด |

**เมื่อใดควรใช้ JSON:** เมื่อใดก็ตามที่คุณต้องการบันทึกสำเนาผลงานที่สมบูรณ์ JSON คือรูปแบบเนทีฟของ KulmanLab และรักษาทุกเอนทิตีไว้อย่างแม่นยำ — รวมถึงมิติ ตัวชี้นำ hatch และข้อมูลเลเยอร์ทั้งหมด

**เมื่อใดควรใช้ DXF:** เมื่อคุณต้องการส่งมอบภาพวาดให้กับผู้ที่ใช้แอปพลิเคชัน CAD อื่น ไฟล์ที่ส่งออกใช้รูปแบบ DXF AC1032 และสามารถเปิดได้ในเครื่องมือที่รองรับ DXF ส่วนใหญ่

## สิ่งที่ถูกส่งออกในแต่ละรูปแบบ

### การส่งออก JSON

รวมทุกชนิดของเอนทิตี:

- Lines, Circles, Arcs, Ellipses, Polylines, Splines
- Text
- มิติ (linear, aligned, continued, radius, diameter)
- Leaders (multileaders)
- Hatches รวมถึงลวดลาย มาตราส่วน มุม และจุดกำเนิด
- Layers และ Linetypes

### การส่งออก DXF

รวมทุกชนิดของเอนทิตี:

- Lines, Circles, Arcs, Ellipses, Polylines (ส่งออกเป็น `LWPOLYLINE`), Splines
- Text
- มิติ (linear, aligned, continued, radius, diameter)
- Leaders (multileaders)
- Hatches รวมถึงลวดลาย มาตราส่วน มุม และจุดกำเนิด
- Layers และ Linetypes

ไฟล์ถูกเขียนเป็น DXF แบบ AC1032 แบบที่ส่งออกจาก KulmanLab จึงเปิดในเครื่องมืออื่นที่รองรับ DXF ได้โดยคำอธิบายประกอบยังอยู่ครบ ไม่ได้มาถึงเป็นเพียงรูปทรงเปล่า

ส่วนที่ว่าโปรแกรมปลายทางแต่ละตัวจะจัดการกับมันอย่างไรนั้นยังต่างกันอยู่ การรองรับ DXF ไม่เท่ากันในแต่ละเครื่องมือ และตัวที่เก่ากว่าอาจมองข้ามเอนทิตีที่ตัวใหม่อ่านได้ ถ้าแบบต้องดูเหมือนกันทุกที่ ให้ใช้ [Print Manager](../print-manager/) เก็บเป็น PDF หรือรูปภาพแทน

## ชื่อไฟล์ที่ส่งออก

ไฟล์ที่ดาวน์โหลดจะตั้งชื่อตามไฟล์ภาพวาดปัจจุบัน (เช่น `myplan.json`) นามสกุลจะเปลี่ยนไปตามรูปแบบที่เลือก

## ความแตกต่างระหว่าง Export Manager และ Print Manager

| คุณสมบัติ | Export Manager | Print Manager |
|-----------|-----------------|-----------------|
| ผลลัพธ์ | ไฟล์ต้นฉบับแบบเวกเตอร์ (.dxf / .json) | ภาพแบบราสเตอร์ (.png / .jpeg / .webp / .pdf) |
| แก้ไขได้ในเครื่องมืออื่น | ใช่ (DXF) | ไม่ |
| รักษา layers และ linetypes | ใช่ | ไม่ (เรนเดอร์แบบแบน) |
| เก็บมิติและตัวชี้นำ | ใช่ | ใช่ |

ใช้ **Export Manager** เมื่อคุณต้องการไฟล์ที่แก้ไขได้ ใช้ [Print Manager](../print-manager/) เมื่อคุณต้องการภาพสแนปช็อต

## คำสั่งที่เกี่ยวข้อง

- [Import](../import/) — เปิดไฟล์ DXF หรือ JSON
- [Print Manager](../print-manager/) — ส่งออกแคนวาสเป็นภาพ PNG, JPEG, WebP หรือ PDF
- [File Manager](../file-manager/) — เรียกดูภาพวาดที่บันทึกไว้ในที่เก็บข้อมูลของเบราว์เซอร์
