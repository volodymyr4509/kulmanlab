# ChangePrintArea

คำสั่ง `ChangePrintArea` กำหนดบริเวณสี่เหลี่ยมที่ [Print Manager](../print-manager/) ส่งออก คำสั่งทำงานบนพื้นที่วาดขณะที่ Print Manager ถูกซ่อน และรับมุมตรงข้ามสองมุม — คลิกสองครั้งแบบเดียวกับ [Rectangle](../rectangle/) ดังนั้นการพิมพ์พิกัดและการสแนปจึงทำงานเหมือนกันทุกประการ

## การเลือกพื้นที่

1. พิมพ์ `ChangePrintArea` ในเทอร์มินัล หรือคลิก **Change Area** ในแถบด้านข้างของ Print Manager แล้ว Print Manager จะซ่อนตัวและพื้นที่วาดจะโต้ตอบได้
2. **คลิกมุมแรก** หรือพิมพ์ `X,Y` แล้วกด **Enter** เพื่อระบุพิกัดที่แม่นยำ
3. **คลิกมุมตรงข้าม** หรือพิมพ์ `X,Y` อีกครั้ง

Print Manager จะเปิดขึ้นใหม่พร้อมพื้นที่ใหม่ในตัวอย่าง ซึ่งจะปรับขนาดตามอัตราส่วนที่แน่นอนของพื้นที่นั้น

มุมจะสแนปเข้ากับกริปและจุดตัดเช่นเดียวกับการเลือกจุดอื่น ๆ จึงครอบตัดตามเรขาคณิตที่วาดไว้ได้แทนการกะด้วยสายตา ลำดับของสองมุมไม่สำคัญ เพราะมุมตรงข้ามให้สี่เหลี่ยมเดียวกัน

กด `Escape` เพื่อยกเลิก ไม่มีการบันทึกสิ่งใด Print Manager จึงเปิดขึ้นใหม่ด้วยพื้นที่เดิมที่มีอยู่แล้ว

## พื้นที่ถูกจดจำไว้ที่ใด

การเลือกถูกเก็บแยกตามบริบท ไม่ใช่ใช้ร่วมกันทั้งหมด:

| บริบท | ช่องเก็บ |
|---|---|
| พื้นที่ Model | ช่องเก็บร่วมหนึ่งช่อง |
| แต่ละเลย์เอาต์ | ช่องเก็บของตัวเอง แยกกัน |

การเปิด Print Manager ใหม่ในเลย์เอาต์เดิม — หรือใน Model — จะคืนค่าการครอบตัดล่าสุดของบริบทนั้นแทนการรีเซ็ต และการสลับไปมาระหว่างเลย์เอาต์จะไม่กระทบพื้นที่ของแต่ละอัน

ข้อมูลนี้เก็บไว้ในหน่วยความจำเท่านั้น การโหลดหน้าใหม่จะล้างพื้นที่ที่เก็บไว้ทั้งหมด และ Print Manager จะกลับไปใช้ค่าเริ่มต้นด้านล่าง

## พื้นที่เริ่มต้น

หากยังไม่มีข้อมูลเก็บไว้สำหรับบริบทปัจจุบัน Print Manager จะเปิดที่:

| บริบท | ค่าเริ่มต้น |
|---|---|
| พื้นที่ Model | กรอบขอบเขตของทุกเอนทิตี — ขอบเขตเดียวกับที่ [Fit](../fit/) ซูมไป |
| แต่ละเลย์เอาต์ | ทั้งแผ่นงาน |
