# Point Divide

คำสั่ง `pointdivide` วาง[จุด](../point/)ที่แบ่งวัตถุออกเป็นช่วงยาวเท่ากัน ตัววัตถุไม่เปลี่ยนแปลง จุดเป็นเอนทิตีใหม่บนเลเยอร์และสีปัจจุบัน สะดวกสำหรับการสแนป

## การแบ่งวัตถุ

1. พิมพ์ `pointdivide` ในเทอร์มินัล หรือเลือก **Point Divide** จากเมนูแบบเลื่อนลงของอาร์เรย์ในแผง Edit
2. **คลิกที่วัตถุ** — เส้น polyline ส่วนโค้ง วงกลม วงรี หรือสไปลน์ สิ่งอื่นจะถูกปฏิเสธ และเลือกใหม่ได้
3. **พิมพ์จำนวนช่วง** เป็นจำนวนเต็มตั้งแต่ 2 ถึง 32767 จุดจะแสดงตัวอย่างบนวัตถุขณะพิมพ์
4. กด **Enter** หรือ **Space** เพื่อวางจุด คำสั่งจบลง

## จุดอยู่ตรงไหน

- ระยะห่างวัดเป็นความยาวตามวัตถุ ไม่ใช่มุม วงรีหรือสไปลน์จึงถูกแบ่งเป็นชิ้นยาวเท่ากัน ส่วนโค้งของ polyline จะถูกตามไปตามความโค้งของมัน
- บนวัตถุเปิด — เส้น polyline เปิด ส่วนโค้ง วงรีบางส่วน หรือสไปลน์เปิด — จุดอยู่ระหว่างช่วง ไม่อยู่ที่ปลาย: 5 ช่วงได้ 4 จุด
- บนวัตถุปิด — วงกลม polyline ปิด วงรีเต็ม หรือสไปลน์ปิด — จุดวนรอบตั้งแต่จุดเริ่มซึ่งมีจุดด้วย: วงกลมเริ่มที่มุม 0 polyline ปิดเริ่มที่จุดยอดแรก 5 ช่วงได้ 5 จุด
- ตัวเลขนอกช่วง 2–32767 จะถูกปฏิเสธ: เทอร์มินัลบอกเหตุผลและล้างค่าเพื่อให้พิมพ์ใหม่

Backspace ลบตัวเลขสุดท้าย Escape เริ่มใหม่เพื่อเลือกวัตถุอื่น Enter หรือ Space ก่อนเลือกวัตถุจะจบคำสั่ง
