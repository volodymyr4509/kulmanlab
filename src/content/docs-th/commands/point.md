# Point

คำสั่ง `point` วางจุดทุกครั้งที่เลือกและยังทำงานอยู่จนกว่าคุณจะกด Enter, Space หรือ Escape จุดคือตำแหน่งที่ไม่มีขนาด: วาดเป็นจุดเล็ก ๆ และมีเลเยอร์กับสีปัจจุบัน จัดเก็บเป็นเอนทิตี `POINT`

## การวางจุด

1. พิมพ์ `point` ในเทอร์มินัล หรือคลิก **Point** ปุ่มสุดท้ายในแผง Shapes
2. **คลิก** ตรงที่จะวางจุด หรือพิมพ์ `X,Y` แล้วกด **Enter** เพื่อตำแหน่งที่แน่นอน การเลือกแต่ละครั้งวางหนึ่งจุดและเทอร์มินัลบันทึกพิกัดของมัน คำสั่งยังทำงานอยู่สำหรับจุดถัดไป
3. หรือล็อกทิศทางจาก[เข็มหมุดเวกเตอร์](../../interface/vector-pins/)แล้วพิมพ์ระยะ — จุดจะตกลงในระยะนั้นตามทิศทางพอดี
4. กด **Enter**, **Space** หรือ **Escape** เพื่อจบ Enter และ Space จบเฉพาะเมื่อไม่ได้พิมพ์อะไรอยู่

## จุดมีลักษณะอย่างไร

จุดถูกวาดเป็นจุดรัศมี 1.5 px ในทุกระดับการซูม จึงยังมองเห็นเมื่อซูมออกและไม่ใหญ่ขึ้นเมื่อซูมเข้า สไตล์จุดของแบบวาด (`$PDMODE` และ `$PDSIZE`) ยังไม่ถูกอ่าน ดังนั้นทุกจุดเป็นจุดเล็ก ๆ ไม่ว่า DXF จะระบุอะไร

## การแก้ไขจุด

จุดที่เลือกมีกริปหนึ่งอันที่ใช้ย้ายมัน การเลือกด้วยกรอบจะเลือกจุดเมื่ออยู่ภายในกรอบ ไม่ว่าจะลากทิศทางใด

[Move](../move/), [Copy](../copy/), [Rotate](../rotate/), [Mirror](../mirror/) และ [Scale](../scale/) ใช้กับจุดได้เหมือนเอนทิตีอื่น หน้าต่างคุณสมบัติแสดง Position X และ Position Y รวมถึงสีและเลเยอร์

## DXF — เอนทิตี POINT

จุดถูกอ่านจากและเขียนลง DXF เป็นเอนทิตี `POINT` พร้อมตำแหน่ง สี และเลเยอร์ (รหัสกลุ่ม 10/20, 62 และ 8) และเดินทางผ่าน JSON ที่บันทึกด้วย เดิมจะถูกข้ามตอนนำเข้า [Export Manager](../export-manager/) แสดง Points เป็นแถวของตัวเอง คุณจึงเว้นมันจากการส่งออกได้
