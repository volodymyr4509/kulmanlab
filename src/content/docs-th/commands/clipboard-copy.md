# ClipboardCopy

คำสั่ง `ClipboardCopy` เขียนวัตถุที่เลือกลงใน **คลิปบอร์ดของระบบ** เป็นข้อความ JSON เนื่องจากใช้คลิปบอร์ดจริงแทนบัฟเฟอร์ในหน่วยความจำ เรขาคณิตที่คัดลอกไว้จึงอยู่รอดนอกแบบได้ นำไปวางในไฟล์อื่น แท็บเบราว์เซอร์ที่สอง หรือหน้าต่างที่คุณเปิดในภายหลังด้วย [ClipboardPaste](../clipboard-paste/)

นี่คือความต่างจาก [Copy](../copy/): Copy ทำสำเนาวัตถุภายในแบบปัจจุบันในการกระทำเดียว ส่วน ClipboardCopy วางวัตถุไว้ในที่ที่สามารถดึงกลับมาจากแบบอื่นได้อย่างสิ้นเชิง

## เริ่มได้สองวิธี

**เลือกก่อนแล้วคัดลอก** — เส้นทางที่เร็ว:

1. เลือกวัตถุหนึ่งชิ้นหรือมากกว่านั้นบนพื้นที่วาด
2. กด `Ctrl+C` (บน macOS คือ `Cmd+C`) หรือพิมพ์ `ClipboardCopy` ในเทอร์มินัล
3. วัตถุถูกเขียนลงคลิปบอร์ดทันทีและคำสั่งจบลง

**เรียกใช้ก่อนแล้วค่อยเลือก** — เริ่มโดยยังไม่ได้เลือกอะไร:

1. กด `Ctrl+C` หรือพิมพ์ `ClipboardCopy` ขณะที่ยังไม่ได้เลือกอะไร
2. ข้อความแจ้งจะแสดง **pick objects to copy — Enter or Space to confirm**
3. **เลือกวัตถุ** — คลิกเพื่อสลับเอาวัตถุเข้าหรือออกจากการเลือก หรือลากเพื่อเลือกเป็นพื้นที่
4. กด **Enter** หรือ **Space** เพื่อคัดลอกสิ่งที่เลือกแล้วออกจากคำสั่ง

การกด **Enter** หรือ **Space** ขณะที่ไม่ได้เลือกอะไรจะเป็นเพียงการจบคำสั่งโดยไม่แตะต้องคลิปบอร์ด

## สิ่งที่ถูกคัดลอก

ข้อมูลในคลิปบอร์ดบรรจุมากกว่าเรขาคณิตเปล่า ๆ เพื่อให้การวางลงในแบบที่ไม่เกี่ยวข้องกันยังคงแสดงผลถูกต้อง:

| ส่วนประกอบ | หน้าที่ |
|-----------|--------|
| **วัตถุ** | รูปแบบที่ถูกทำให้เป็นอนุกรมอย่างครบถ้วนของวัตถุที่เลือกแต่ละชิ้น |
| **จุดอ้างอิง** | มุมล่างซ้ายของขอบเขตรวมของสิ่งที่เลือก — จุดที่ ClipboardPaste ยึดไว้กับเคอร์เซอร์ |
| **เลเยอร์** | เฉพาะเลเยอร์ที่วัตถุซึ่งคัดลอกอ้างถึงจริง โดยอ้างตามชื่อ |
| **ชนิดเส้น** | เฉพาะชนิดเส้นที่วัตถุซึ่งคัดลอกอ้างถึงจริง โดยอ้างตามชื่อ |

เฉพาะรายการในตารางที่*ถูกอ้างถึง*เท่านั้นที่เดินทางไปพร้อมสำเนา ไม่ใช่ตารางเลเยอร์และชนิดเส้นทั้งหมดของแบบต้นทาง ลวดลายแรเงาไม่ถูกรวมมาด้วยเลยและก็ไม่จำเป็น เพราะตารางลวดลายของแบบคือชุดค่าเริ่มต้นที่ติดมากับโปรแกรม ส่วนไฟล์ `.pat` ที่คุณอัปโหลดจะอยู่ในที่เก็บระดับผู้ใช้ซึ่งใช้ร่วมกันระหว่างแท็บอยู่แล้ว การแรเงาที่วางลงไปจึงหาลวดลายของตัวเองได้

## การยืนยัน

เมื่อสำเร็จ เทอร์มินัลจะรายงานจำนวนวัตถุที่เขียนไป:

```
3 entities copied to clipboard
```

หากเบราว์เซอร์ปฏิเสธการเข้าถึงคลิปบอร์ด เทอร์มินัลจะแสดง **Copy failed: clipboard access denied** และไม่มีอะไรถูกเขียน นี่คือการตัดสินใจเรื่องสิทธิ์ของเบราว์เซอร์ ไม่ใช่ข้อผิดพลาดของแบบ — ดู [สิทธิ์การใช้คลิปบอร์ด](#สิทธิ์การใช้คลิปบอร์ด) ด้านล่าง

## การเลือกระหว่างใช้คำสั่ง

| วิธี | พฤติกรรม |
|------|----------|
| **คลิก** | สลับวัตถุใต้เคอร์เซอร์เข้าหรือออกจากการเลือก |
| **ลากไปทางขวา** (เข้มงวด) | เพิ่มวัตถุที่อยู่ภายในกรอบทั้งชิ้น |
| **ลากไปทางซ้าย** (ตัดผ่าน) | เพิ่มวัตถุที่ตัดผ่านขอบกรอบ |
| **Enter** / **Space** | ยืนยันการเลือกและคัดลอก |

## ปุ่มลัดที่ใช้ได้

| ปุ่ม | การทำงาน |
|------|----------|
| `Ctrl+C` / `Cmd+C` | เรียกใช้ ClipboardCopy |
| `Enter` / `Space` | คัดลอกสิ่งที่เลือกอยู่ หรือออกหากไม่ได้เลือกอะไร |
| `Escape` | ยกเลิกโดยไม่คัดลอก |

## สิทธิ์การใช้คลิปบอร์ด

การเขียนลงคลิปบอร์ดของระบบต้องได้รับอนุญาตจากเบราว์เซอร์ ในทางปฏิบัติ การคัดลอกที่เกิดจากการกดปุ่มจะได้รับอนุญาตโดยไม่ถามในเบราว์เซอร์เดสก์ท็อปปัจจุบัน แต่หน้าเว็บที่เสียโฟกัสไปแล้ว หรือเบราว์เซอร์ที่ตั้งค่าคลิปบอร์ดไว้เข้มงวด อาจปฏิเสธได้ หากเห็นข้อความปฏิเสธการเข้าถึง ให้คลิกที่พื้นที่วาดหนึ่งครั้งเพื่อคืนโฟกัสให้หน้าเว็บแล้วลองใหม่

เนื่องจากข้อมูลเป็นข้อความ JSON ธรรมดา สิ่งอื่นที่คุณคัดลอกหลังจากนั้นจะเข้าไปแทนที่ — ไม่ว่าจะเป็นข้อความหนึ่งบรรทัดหรือลิงก์ ให้คัดลอกใหม่อีกครั้งก่อนวางหากระหว่างนั้นคุณใช้คลิปบอร์ดทำอย่างอื่น

## วัตถุที่รองรับ

ClipboardCopy ใช้ได้กับวัตถุทุกชนิด วัตถุถูกทำให้เป็นอนุกรมด้วยกลไกเดียวกับที่การส่งออก `.json` ของโปรแกรมใช้ จึงไม่มีอะไรตกหล่นระหว่างทาง
