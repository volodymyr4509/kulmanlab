# LeaderStyle

คำสั่ง `LeaderStyle` เปิดตัวจัดการรูปแบบเส้นชี้ที่มีชื่อ [Leader](../leader/) ใหม่ทุกเส้นจะคัดลอกการตั้งค่าของรูปแบบ *ปัจจุบัน* เมื่อสร้าง

## การแก้ไขรูปแบบ

พิมพ์ `LeaderStyle` หรือคลิก **รูปแบบเส้นชี้** ในแผงคำอธิบายประกอบ เครื่องหมาย ✓ แสดงรูปแบบปัจจุบัน และใช้ดินสอข้างชื่อเพื่อเปลี่ยนชื่อ ตัวอย่างจะแสดงผลทันทีด้วยตัวเรนเดอร์เดียวกับแบบร่าง

| ช่อง | หน้าที่ |
|---|---|
| จุดยึดข้อความ | บน กลาง ล่าง หรือขีดเส้นใต้ |
| หัวลูกศร / ขนาดลูกศร | สัญลักษณ์และขนาดที่ปลายแต่ละแขน |
| ช่องว่างแลนดิง | ระยะระหว่างแลนดิงกับข้อความ |
| การหมุนข้อความ | มุมของป้ายเป็นองศา |
| รูปแบบข้อความ | คัดลอกฟอนต์ ความสูง ตัวหนา และตัวเอียงจาก [TextStyle](../text-style/) หนึ่งครั้ง |
| ฟอนต์ / ความสูงข้อความ | แบบอักษรและความสูงของป้าย |
| ตัวหนา / ตัวเอียง | รูปแบบข้อความที่ตั้งค่าแยกกัน |
| กรอบข้อความ | กรอบสี่เหลี่ยมรอบป้าย |

**ใหม่** จะทำสำเนารูปแบบที่เลือก เปลี่ยนชื่อหรือลบ `Standard` ไม่ได้ และลบรูปแบบปัจจุบันไม่ได้เช่นกัน **ตั้งเป็นปัจจุบัน** มีผลเฉพาะเส้นชี้ที่สร้างภายหลัง วัตถุเดิมไม่เปลี่ยน ชื่อที่ว่าง ซ้ำ หรือไม่ถูกต้องสำหรับ DXF จะทำให้ **ตกลง** ใช้งานไม่ได้ รูปแบบคำอธิบายประกอบที่นำเข้าจะถูกซ่อนแต่ยังเก็บรักษาไว้

## การบันทึกและ DXF

KulmanLab นำเข้าและส่งออกระเบียน `MLEADERSTYLE` ชื่อ หัวลูกศรและขนาด ช่องว่างแนวพัก ความสูง จุดยึดข้อความ กรอบ และแฟล็กคำอธิบายประกอบจะคงอยู่เป็นฟิลด์รูปแบบ เมื่อส่งออก กลุ่ม `342` จะชี้ไปยังรูปแบบข้อความที่ฟอนต์ ตัวหนา ตัวเอียง และความสูงตรงกัน หากไม่พบจะใช้ `Standard` การอ้างอิง DXF นี้ไม่ทำให้การคัดลอกครั้งเดียวในแอปเป็นลิงก์สด ค่าจุดยึดค่าเดียวจะเขียนลงทั้งฟิลด์ DXF ซ้ายและขวา
