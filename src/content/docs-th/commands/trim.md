# Trim

คำสั่ง `trim` ลบส่วนของ [Line](../line/), [Arc](../arc/), [Circle](../circle/), [Ellipse](../ellipse/) หรือ [Polyline](../polyline/) ที่อยู่ระหว่างจุดตัดสองจุดที่อยู่ติดกัน โดยแบ่งวัตถุออกเป็นหนึ่งส่วนหรือมากกว่าที่เหลืออยู่ ส่วนที่จะตัดถูกกำหนดโดยตำแหน่งเคอร์เซอร์ — วาง cursor บนส่วนที่ต้องการลบแล้วคลิกเพื่อตัด

## การตัดวัตถุ

1. พิมพ์ `trim` ในเทอร์มินัลหรือคลิกปุ่ม **Trim** บนแถบเครื่องมือ
2. **วาง cursor บนส่วน** ที่ต้องการลบ — ตัวอย่างจะไฮไลต์ส่วนที่จะถูกตัดพอดี
3. **คลิก** เพื่อลบส่วนนั้น

คำสั่งยังคงทำงานหลังจากแต่ละการตัด ดังนั้นคุณสามารถ hover และคลิกต่อไปเพื่อตัดส่วนเพิ่มเติม — บนวัตถุเดิมหรือวัตถุอื่น กด **Enter**, **Space** หรือ **Escape** เพื่อออก

```
  ก่อน:                         หลังตัดส่วนกลาง:

  ──────●──────●──────          ──────●          ●──────
      ตัดกัน   ตัดกัน          (ส่วนซ้าย)    (ส่วนขวา)
                                            (ส่วนกลางถูกลบ)
```

## วิธีกำหนดส่วนที่ตัด

คำสั่งฉายตำแหน่งเคอร์เซอร์ลงบนวัตถุที่ hover และหาจุดตัดทั้งหมดที่วัตถุนั้นมีกับวัตถุอื่น จุดตัดเหล่านี้แบ่งวัตถุออกเป็นส่วนต่างๆ — สำหรับ Line, Arc หรือ Polyline แบบเปิด จุดปลายของวัตถุเองทำหน้าที่เป็นขอบเขตคงที่เพิ่มเติม ส่วน Circle หรือ Ellipse ที่สมบูรณ์ หรือ Polyline แบบปิด (รวมถึง Rectangle) ไม่มีจุดปลายของตัวเอง จึงต้องมีจุดตัดอย่างน้อยสองจุดก่อนที่จะสามารถตัดได้ ส่วนที่ช่วงของมันมีการฉาย cursor จะถูกไฮไลต์และจะถูกลบเมื่อคลิก

- **Line, Arc และ Polyline แบบเปิด** — ส่วนที่ถูกลบอาจเป็นส่วนนำ (ก่อนจุดตัดแรก) ส่วนกลาง (ระหว่างจุดตัดสองจุด แบ่งวัตถุออกเป็นสอง) หรือส่วนท้าย (หลังจุดตัดสุดท้าย)
- **Circle, Ellipse และ Polyline แบบปิด/Rectangle** — เนื่องจากไม่มีจุดเริ่มต้นหรือจุดสิ้นสุดคงที่ จึงลบได้เฉพาะส่วนโค้งระหว่าง *จุดตัด* สองจุดเท่านั้น หากมีจุดตัดน้อยกว่าสองจุด จะไม่มีตัวอย่างปรากฏและการคลิกจะไม่ทำอะไร ส่วนที่เหลือของรูปทรงจะกลายเป็นส่วนเดียวที่เหลืออยู่

## ผลลัพธ์ของการตัด

| วัตถุ | ผลลัพธ์หลังตัด |
|--------|------------------------|
| Line | สูงสุดสองวัตถุ Line ที่สั้นลง |
| Arc | สูงสุดสองวัตถุ Arc ที่สั้นลง |
| Circle | วัตถุ [Arc](../arc/) หนึ่งชิ้น — รูปทรงปิดของวงกลมหายไป ส่วนที่เหลือจึงถูกเก็บเป็นส่วนโค้ง |
| Ellipse | วัตถุ Ellipse หนึ่งชิ้นที่มีมุมเริ่มต้นและมุมสิ้นสุด — ส่วนที่เหลือยังคงเป็น Ellipse แต่ตอนนี้เป็นบางส่วน |
| Polyline (เปิด) | สูงสุดสองวัตถุ Polyline ที่สั้นลง |
| Polyline (ปิด) / Rectangle | วัตถุ Polyline แบบเปิดหนึ่งชิ้น — รูปทรงปิดหายไป ส่วนที่เหลือจึงถูกเก็บในรูปแบบเปิด |
| Spline | Spline ที่สั้นลงไม่เกินสองรายการ — แต่ละชิ้นคือเส้นโค้งเดิมในช่วงที่เล็กลง เก็บด้วยจุดยอดควบคุม (จุด fit ของสไปลน์แบบ Fit จะถูกทิ้ง) สไปลน์ปิดจะเหลือชิ้นเปิดหนึ่งชิ้น |

## อ้างอิงแป้นพิมพ์

| ปุ่ม | การกระทำ |
|-----|----------|
| `Enter` / `Space` | ออกจากโหมด trim |
| `Escape` | ออกจากโหมด trim |

## วัตถุที่รองรับ

| วัตถุ | ตัดได้หรือไม่ |
|-------|--------------|
| Line | ใช่ |
| Arc | ใช่ |
| Circle | ใช่ — ต้องมีจุดตัด 2 จุดขึ้นไป |
| Ellipse | ใช่ — ต้องมีจุดตัด 2 จุดขึ้นไป |
| Polyline (เปิด) | ใช่ |
| Polyline (ปิด) / Rectangle | ใช่ — ต้องมีจุดตัด 2 จุดขึ้นไป |
| Spline | ได้ — สไปลน์ปิดต้องมีจุดตัดตั้งแต่ 2 จุดขึ้นไป; สไปลน์จะถูกตัดตรงที่ตัดกับตัวเองด้วย |
| Text, Dimension, Leader | ไม่ |

ออบเจกต์ที่ใช้เป็น**ขอบเขตการตัด**ได้แก่ Line, Arc, Circle, Ellipse, Polyline หรือ Spline ออบเจกต์ Text, Dimension และ Leader ไม่เคยลงทะเบียนจุดตัด จึงไม่สามารถเป็นขอบเขตได้เช่นกัน

**ส่วนโค้ง** ของ Polyline (วาดด้วยตัวสลับ Arc หรือนำเข้ามา) จะถูกตัดเหมือนกับส่วนตรงทุกประการ — วางเมาส์เหนือส่วนโค้งระหว่างจุดตัดสองจุดแล้วคลิก ขอบที่ถูกตัดจะคงความโค้งไว้ มีเพียงความยาวเท่านั้นที่เปลี่ยนไป

## Trim vs Extend

| | Trim | Extend |
|---|------|--------|
| สิ่งที่ทำ | ลบส่วนของวัตถุ | ยืดจุดสิ้นสุดของเส้นไปถึงขอบ |
| ตัวกระตุ้น | วาง cursor บนส่วนที่จะตัด | วาง cursor ใกล้จุดสิ้นสุดที่จะยืด |
| ผลลัพธ์ | วัตถุแบ่งหรือสั้นลง | จุดสิ้นสุดของเส้นย้ายไปที่ขอบ |
| วัตถุที่รองรับ | Line, Arc, Circle, Ellipse, Polyline, Spline | Line, Arc, Ellipse, Polyline |
