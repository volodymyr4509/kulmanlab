# Hatch

คำสั่ง `hatch` จะเติมพื้นที่ที่ล้อมรอบจุดที่คลิกด้วยลวดลาย ขอบเขตไม่ได้ถูกวาดก่อน — มันมาจากสิ่งที่มีอยู่แล้วบนแคนวาส ดังนั้น [Line](../line/) ที่แยกจากกันสี่เส้นที่มาบรรจบกันที่ปลายจึงล้อมรอบพื้นที่ได้เหมือนกับที่ [Polyline](../polyline/) แบบปิดทำ และรูปทรงปิดใดๆ ที่อยู่ข้างในจะกลายเป็นเกาะที่การเติมจะปล่อยไว้ไม่แตะต้อง

## การเติมพื้นที่

1. พิมพ์ `hatch` ในเทอร์มินัลหรือคลิกปุ่ม **Hatch** บนแถบเครื่องมือ (ไอคอนตัวอย่างสี)
2. **คลิกจุด** ภายในพื้นที่ที่คุณต้องการเติม
3. คำสั่งยังคงทำงานอยู่ ดังนั้นให้คลิกต่อไปเพื่อเติมพื้นที่เพิ่มเติม — แต่ละคลิกจะสร้างวัตถุ `Hatch` ของตัวเอง
4. กด **Enter**, **Space** หรือ **Escape** เมื่อเสร็จสิ้น

```
  ┌─────────────┐        ┌─────────────┐
  │             │        │▓▓▓▓▓▓▓▓▓▓▓▓▓│
  │   ○         │  --->  │▓▓▓( )▓▓▓▓▓▓▓│   คลิกภายในขอบเขต
  │             │        │▓▓▓▓▓▓▓▓▓▓▓▓▓│   ด้านนอก; วงกลมยังคง
  └─────────────┘        └─────────────┘   เป็นเกาะ
```

## อ้างอิงแป้นพิมพ์

| ปุ่ม | การกระทำ |
|-----|--------|
| `Enter` / `Space` | จบคำสั่ง Hatch |
| `Escape` | จบคำสั่ง Hatch (เหมือนกับ Enter/Space) |

## สิ่งที่สามารถสร้างขอบเขตได้

การรวมกันใดๆ ของประเภทวัตถุเหล่านี้สามารถสร้างขอบเขตได้ ในการรวมกันแบบใดก็ได้ ตราบใดที่เชื่อมต่อกันที่ปลายโดยไม่มีช่องว่าง:

- [Line](../line/)
- [Arc](../arc/)
- [Circle](../circle/) (ขอบเขตปิดของตัวเอง)
- [Ellipse](../ellipse/) (แบบปิด หรืออาร์กวงรีแบบเปิดที่เป็นส่วนหนึ่งของวงที่ใหญ่กว่า)
- [Polyline](../polyline/) (แบบเปิดหรือปิด) และ [Rectangle](../rectangle/)
- [Spline CV / Spline Fit](../spline-cv/)

วัตถุ Text, Multileader และ Dimension จะไม่ถูกพิจารณาเป็นขอบเขตเลย

## เกาะ

สิ่งใดก็ตามที่ปิดสนิทอยู่ภายในพื้นที่ที่คุณคลิก — วงกลม, โพลีไลน์แบบปิด, ขอบเขตของ hatch อื่น — จะกลายเป็น **เกาะ**: การเติมจะหยุดที่ขอบของมันและตัวเกาะเองจะยังคงว่างเปล่า วางรูปทรงปิดไว้ภายในรูปทรงปิดอื่น แล้วการเติมจะสลับกัน รูโหว่ในการเติมในรูโหว่ ตามกฎภายใน/ภายนอกเดียวกันในทุกระดับ

## เมื่อการเลือกล้มเหลว

หากจุดที่คุณคลิกไม่ได้ถูกล้อมรอบ หรือขอบเขตมีช่องว่าง เทอร์มินัลจะอธิบายเหตุผลแทนที่จะไม่ทำอะไรเลยอย่างเงียบๆ:

| ข้อความ | ความหมาย |
|---------|----------|
| "no boundary found" | ไม่พบสิ่งใดในทิศทางใดๆ จากจุดที่คลิก — ไม่มีขอบเขตอยู่ใกล้เคียงเลย |
| "point is not enclosed" | มีขอบเขตอยู่ใกล้เคียง แต่รูปทรงที่มันสร้างขึ้นไม่มีจุดที่คุณคลิกอยู่ |
| "boundary is open" | ขอบเขตที่ใกล้ที่สุดมีช่องว่างอยู่ที่ไหนสักแห่ง — ติดตามและตรวจสอบว่าทุกจุดเชื่อมต่อแม่นยำ |
| "boundary too complex" | ไม่สามารถปิดวงขอบเขตได้ภายในขีดจำกัดการเดิน — มักเป็นความยุ่งเหยิงของวัตถุที่ทับซ้อนกัน |

คำสั่งยังคงทำงานอยู่หลังจากการเลือกล้มเหลว — อ่านข้อความ แก้ไขภาพวาดหรือคลิกที่อื่น แล้วลองอีกครั้ง

## การเลือกลวดลาย

hatch ใหม่ทุกอันเริ่มต้นด้วยการเติม `ANSI31` (หรือลวดลายใดก็ตามที่ hatch *ล่าสุด* ที่คุณแก้ไขใช้) — ไม่มีตัวเลือกลวดลายก่อนที่จะวาด หากต้องการใช้ลวดลายอื่น:

1. เลือก hatch ที่มีอยู่และเปิดฟิลด์ **Pattern** ในแผงคุณสมบัติ — วิธีนี้จะเปิดตัวเลือกลวดลาย ซึ่งเป็นตารางตัวอย่างสีที่มีชื่อจัดกลุ่มตามที่มาของแต่ละลวดลาย
2. คลิกลวดลายเพื่อนำไปใช้ — การเติมจะอัปเดตทันที

การเลือกนั้นยังกลายเป็นค่าเริ่มต้นสำหรับ hatch *ถัดไป* ที่คุณสร้างด้วยคำสั่ง `hatch` ด้วยวิธีเดียวกับที่การเลือกเลเยอร์หรือสีจะถูกส่งต่อไป ดังนั้นในการทำ hatch หลายพื้นที่ใหม่ด้วยลวดลายเฉพาะ: เติมพื้นที่หนึ่ง กำหนดลวดลายของมันครั้งเดียว จากนั้นทำ hatch ต่อไป — การเติมทุกครั้งหลังจากนั้นจะเริ่มต้นด้วยลวดลายนั้นที่นำไปใช้แล้ว

ดู [Hatch Manager](../hatch-manager/) เพื่ออัปโหลดไฟล์ลวดลาย `.pat` ของคุณเองและเรียกดูไลบรารีทั้งหมด

**SOLID** เป็นรายการปกติในรายการลวดลาย ไม่ใช่ช่องทำเครื่องหมายหรือโหมดแยกต่างหาก — เลือกมันด้วยวิธีเดียวกับที่คุณจะเลือก ANSI31 หรือลวดลายที่มีชื่ออื่นๆ

## คุณสมบัติ

| คุณสมบัติ | ความหมาย |
|-----------|----------|
| Pattern | ชื่อของลวดลาย จากคำศัพท์ลวดลายที่ใช้ร่วมกัน (ดู [Hatch Manager](../hatch-manager/)) |
| Pattern Scale | ปรับขนาดระยะห่างของเส้นลวดลาย — ค่าที่มากขึ้นจะทำให้เส้นลวดลายห่างกันมากขึ้น |
| Pattern Angle | หมุนลวดลายโดยไม่ขึ้นกับขอบเขต |
| Origin X / Origin Y | ตำแหน่งที่การทำซ้ำของลวดลายเองถูกยึดไว้ ในพิกัดภาพวาด |

การย้าย หมุน สะท้อน หรือปรับขนาด hatch จะนำตำแหน่งลวดลายของมันไปด้วย ดังนั้นการเติมจะยังคงเรียงตัวตรงกับขอบเขต — คุณไม่จำเป็นต้องตั้งค่าสเกลหรือมุมใหม่หลังการแปลง

## การแก้ไขจุดจับของขอบเขต

hatch ที่เลือกจะจับขอบเขตของมันในลักษณะเดียวกับที่ Polyline จับจุดยอดของมัน — จุดจับหนึ่งจุดที่ทุกมุมที่ขอบสองเส้นมาบรรจบกัน และหนึ่งจุดที่กึ่งกลางของแต่ละขอบ (วงปิด เช่น hatch ของวงกลมหรือวงรี จะจับที่จุดแกนทั้งสี่แทน)

| จุดจับ | สิ่งที่ทำ |
|--------|-----------|
| **มุม** | ย้ายมุมนั้น ขอบตรงจะตามไปอย่างแม่นยำ; อาร์กจะปรับให้พอดีใหม่เพื่อให้ยังคงผ่านทั้งสองข้างที่อยู่ติดกัน; ขอบวงรีหรือสไปลน์สามารถลงจอดได้เพียงที่ใดที่หนึ่งบนเส้นโค้งของตัวเองเท่านั้น ดังนั้นมุมจะยึดติดกับจุดที่ใกล้ที่สุดบนเส้นนั้น |
| **กึ่งกลางขอบ — ขอบเส้น วงรี หรือสไปลน์** | เลื่อนขอบทั้งหมด; ขอบทั้งสองด้านจะถูกตัดหรือขยายเพื่อให้ยังคงเชื่อมต่อกับมัน |
| **กึ่งกลางขอบ — ขอบอาร์ก** | **โค้ง** อาร์กผ่านเคอร์เซอร์แทนที่จะเลื่อนมัน — ปลายทั้งสองข้างยังคงอยู่ตรงตำแหน่งเดิมทุกประการ และไม่มีสิ่งอื่นใดในขอบเขตเคลื่อนไหว |
| **จุดศูนย์กลาง** (hatch ทั้งหมด) | เปิดใช้งาน [Move](../move/) สำหรับ hatch ทั้งหมด |

ตัวอย่างการลากจะแสดงขอบเขตเป็นเส้นประแทนที่จะเป็นการเติมทึบขณะที่คุณลาก — การเติมเดิมจะยังคงมองเห็นได้ด้านล่างจนกว่าคุณจะปล่อย เนื่องจากตัวอย่างสามารถวาดทับสิ่งที่มีอยู่แล้วเท่านั้น ไม่สามารถลบสิ่งใดออกจากมันได้

## DXF — วัตถุ HATCH

Hatch จะถูก **นำเข้า** จากวัตถุ `HATCH`: KulmanLab จะอ่านเรขาคณิตของขอบเขตพร้อมกับชื่อ สเกล และมุมของลวดลาย (รหัสกลุ่ม DXF 70/41/52) — แต่จะ **ไม่** อ่านคำจำกัดความเส้นของลวดลายเองที่ถูกฝังไว้ในไฟล์ แทนที่จะเป็นเช่นนั้น ชื่อลวดลายจะถูกค้นหาในไลบรารีลวดลายของ KulmanLab เอง (ค่าเริ่มต้นในตัวบวกกับสิ่งที่คุณอัปโหลดไว้ใน [Hatch Manager](../hatch-manager/)) ชื่อที่ไม่มีอยู่ในไลบรารีของคุณจะย้อนกลับไปเป็น ANSI31 เพื่อให้ภาพวาดยังคงอ่านได้ว่าถูก hatch และจะมีการบันทึกหมายเหตุหนึ่งครั้ง

วงที่ถูกจำกัดด้วยสไปลน์ที่เขียนโดยแอปพลิเคชันอื่น (ประเภทขอบขอบเขต DXF 4) ยังไม่ถูกอ่าน

การแฮตช์ **ส่งออก** ไปยัง DXF เป็นเอนทิตี `HATCH` วงขอบเขตออกไปพร้อมชื่อลาย (รหัสกลุ่ม 2) แฟล็กเติมทึบ (70) และมุมกับมาตราส่วนของการแฮตช์นั้นเอง (52/41) — และต่างจากทางนำเข้า นิยามเส้นของลายที่คลี่แล้วก็ถูกเขียนลงในไฟล์ด้วย (78 พร้อม 53/43/44/45/46/79/49) ความไม่สมมาตรนี้ตั้งใจ เพราะ KulmanLab หาชื่อจากคลังของตัวเองได้ แต่โปรแกรมที่รับไฟล์อาจไม่มีลายนั้น เส้นจึงเดินทางไปด้วย
