# LayerManager

คำสั่ง `LayerManager` เปิดตารางที่แสดงทุกเลเยอร์ในแบบ โดยการตั้งค่า **Freeze**, **Lock**, **Plot**, **สี**, **ความหนาเส้น** และ **ชนิดเส้น** แก้ไขได้โดยตรงในแถว นี่คือจุดศูนย์กลางสำหรับเพิ่มเลเยอร์ ลบเลเยอร์ที่ไม่ได้ใช้ และปรับพฤติกรรมของเลเยอร์ที่มีอยู่ — คำสั่งเลเยอร์อื่น ๆ ([LayerMakeCurrent](../layer-make-current/), [LayerMatch](../layer-match/), [LayerIsolate](../layer-isolate/), [LayerUnfreezeAll](../layer-unfreeze-all/)) ทำหน้าที่เฉพาะอย่างละหนึ่งอย่างโดยไม่ต้องเปิดตารางนี้

## การเปิด Layer Manager

- พิมพ์ `LayerManager` ในเทอร์มินัล **หรือ**
- คลิกปุ่ม **Layer Manager** บนแผงเลเยอร์

หน้าต่างจะเปิดเป็นแผงลอย; ไม่จำเป็นต้องเลือกอะไรไว้ก่อน

## ตารางเลเยอร์

| คอลัมน์ | ควบคุมอะไร |
|--------|--------------|
| Name | ชื่อเลเยอร์ แสดงแบบอ่านอย่างเดียวในตาราง (ตั้งค่าครั้งเดียวตอนสร้าง) |
| Freeze | ซ่อนวัตถุของเลเยอร์และไม่รวมในการเลือกจนกว่าจะยกเลิกการซ่อน |
| Lock | ป้องกันการแก้ไขวัตถุบนเลเยอร์ โดยไม่ซ่อนวัตถุนั้น |
| Plot | วัตถุของเลเยอร์จะถูกรวมเมื่อพิมพ์หรือส่งออกเป็น PDF หรือไม่ |
| Color | สี ACI ของเลเยอร์ — คลิกตัวอย่างสีเพื่อเปิดตัวเลือกสี |
| Lineweight | ความหนาเส้นของเลเยอร์ — คลิกชิปเพื่อเปิดตัวเลือกความหนา |
| Linetype | ลวดลายเส้นของเลเยอร์ — คลิกชิปเพื่อเปิดตัวเลือกชนิดเส้น |
| ✕ | ลบเลเยอร์เมื่อไม่มีสิ่งใดใช้งานอยู่ — ดู [การลบเลเยอร์](#การลบเลเยอร์) |

การสลับ Freeze, Lock หรือ Plot มีผลทันที — ไม่มีขั้นตอนบันทึกแยกต่างหาก วัตถุที่ตั้งค่าสี ความหนาเส้น หรือชนิดเส้นเป็น **ByLayer** (ค่าเริ่มต้น) จะรับค่าที่คุณตั้งที่นี่; วัตถุที่มีการกำหนดค่าเฉพาะของตัวเองจะไม่ได้รับผลกระทบ

## การเพิ่มเลเยอร์

1. คลิก **+ Add Layer** ที่ด้านล่างของตาราง
2. พิมพ์ชื่อและกด **Enter** เพื่อยืนยัน หรือ **Escape** เพื่อยกเลิก

ชื่อเลเยอร์สามารถมีตัวอักษร ตัวเลข ช่องว่าง และ `_`, `-`, `$` ชื่อที่ว่างเปล่า ใช้ไปแล้ว หรือมีอักขระอื่นจะถูกปฏิเสธพร้อมข้อผิดพลาดในแถว และแถวจะยังเปิดอยู่เพื่อลองใหม่

เลเยอร์ใหม่เริ่มต้นด้วย **ไม่ซ่อน ไม่ล็อก พล็อตได้** สี 7 (ขาว/ดำ) ความหนาเส้น Default และชนิดเส้น Continuous — ค่าเริ่มต้นเดียวกับที่ [Import](../import/) กำหนดให้เลเยอร์ `0` ในภาพวาดเปล่า

## การลบเลเยอร์

ทุกแถวลงท้ายด้วยปุ่ม **✕** ที่นำเลเยอร์ออกจากแบบ การลบเกิดขึ้นทันที — ไม่มีขั้นตอนยืนยัน — แต่จะเปิดให้ทำได้เฉพาะเลเยอร์ที่ไม่มีสิ่งใดพึ่งพาอยู่:

| สถานการณ์ | สถานะปุ่ม |
|-----------|-----------|
| เลเยอร์ว่างเปล่า | ใช้งานได้ — *Delete layer* |
| เลเยอร์ถูกกำหนดให้วัตถุอย่างน้อยหนึ่งชิ้น | ถูกปิด — *Cannot delete: assigned to at least one entity* |
| เลเยอร์ `0` | ไม่มีปุ่มเลย |

**"กำลังใช้งาน" ครอบคลุมทั้งแบบ** ไม่ใช่เฉพาะส่วนที่คุณกำลังมองอยู่ วัตถุที่วางอยู่บนเลย์เอาต์ (พื้นที่กระดาษ) นับเท่ากับวัตถุในพื้นที่โมเดลทุกประการ ดังนั้นเลเยอร์อาจดูว่างเปล่าบนหน้าจอแต่ยังคงปฏิเสธการลบ เลเยอร์ที่แช่แข็งก็ไม่ต่างกัน การแช่แข็งเพียงซ่อนวัตถุแต่ไม่ได้ยกเลิกการกำหนดเลเยอร์ ดังนั้นเลเยอร์ที่แช่แข็งไว้และยังมีวัตถุอยู่จึงยังลบไม่ได้

เลเยอร์ `0` ลบไม่ได้เลย มันคือเลเยอร์สำรองที่ทุกแบบรับประกันว่ามี จึงไม่มีการวาดปุ่มให้มันตั้งแต่แรก แทนที่จะแสดงเป็นปุ่มที่ถูกปิด

### "…is now in use and can't be deleted"

บางครั้ง ✕ ดูเหมือนใช้ได้ แต่การคลิกกลับถูกปฏิเสธด้วยแถบข้อความที่ด้านบนของแผง:

```
"WALLS" is now in use and can't be deleted
```

นี่ไม่ใช่ความขัดแย้ง การหาว่าเลเยอร์ใดกำลังถูกใช้ต้องไล่ดูทุกวัตถุในแบบ ผลลัพธ์จึงถูกเก็บแคชไว้และสร้างใหม่เฉพาะเมื่อจำนวนวัตถุเปลี่ยน — ถูกเมื่อมีวัตถุหลักร้อย แต่ไม่ถูกเมื่อมีหลักแสน การย้ายวัตถุที่มีอยู่แล้วไปยังเลเยอร์หนึ่งไม่ทำให้จำนวนเปลี่ยน สถานะปิดของแถวจึงอาจล้าสมัยไปชั่วครู่ การคลิกจะตรวจสอบใหม่ทั้งหมดก่อนลบสิ่งใด นี่คือเหตุผลที่การปฏิเสธเกิดขึ้นตอนคลิก แทนที่จะปล่อยให้เลเยอร์หายไปทั้งที่ยังมีสิ่งอ้างอิงถึงอยู่

ปิดแถบข้อความด้วยปุ่ม **✕** ของมันเอง เลเยอร์ยังคงอยู่เหมือนเดิม

## สิ่งที่ทำที่นี่ไม่ได้

ตารางไม่แสดงว่าเลเยอร์ใดเป็นเลเยอร์ *ปัจจุบัน* สิ่งนั้นกำหนดจากรายการแบบเลื่อนลงในแผงเลเยอร์หรือด้วย [LayerMakeCurrent](../layer-make-current/) ไม่ใช่จากกล่องโต้ตอบนี้ ชื่อเลเยอร์ก็ถูกกำหนดตายตัวตั้งแต่ตอนสร้าง — ลบแล้วสร้างใหม่ได้ แต่เปลี่ยนชื่อไม่ได้

## อ้างอิงแป้นพิมพ์

| ปุ่ม | การกระทำ |
|-----|----------|
| `Enter` | ยืนยันชื่อเลเยอร์ใหม่ (ระหว่างการเพิ่ม) |
| `Escape` | ยกเลิกการเพิ่มเลเยอร์ หรือปิดหน้าต่าง |

## คำสั่งที่เกี่ยวข้อง

| คำสั่ง | สิ่งที่ทำ |
|---------|-----------|
| [LayerMakeCurrent](../layer-make-current/) | ตั้งค่าเลเยอร์ปัจจุบันให้ตรงกับเลเยอร์ของวัตถุที่คลิก |
| [LayerMatch](../layer-match/) | กำหนดวัตถุที่เลือกใหม่ให้ตรงกับเลเยอร์ของวัตถุต้นทาง |
| [LayerIsolate](../layer-isolate/) | ซ่อนเลเยอร์ทั้งหมดยกเว้นเลเยอร์ของวัตถุที่เลือก |
| [LayerUnfreezeAll](../layer-unfreeze-all/) | ยกเลิกการซ่อนเลเยอร์ทั้งหมดในขั้นตอนเดียว |
