# Point Interval

คำสั่ง `pointinterval` วาง[จุด](../point/)เป็นระยะคงที่ตามวัตถุ เหมือนการปักหมุดสถานีตามแนวเส้นทาง ตัววัตถุไม่เปลี่ยนแปลง จุดเป็นเอนทิตีใหม่บนเลเยอร์และสีปัจจุบัน สะดวกสำหรับการสแนป

## การวางจุดเป็นระยะ

1. พิมพ์ `pointinterval` ในเทอร์มินัล หรือเลือก **Point Interval** จากเมนูแบบเลื่อนลงของอาร์เรย์ในแผง Edit
2. **คลิกที่วัตถุใกล้ปลายที่จะเริ่ม** — เส้น polyline ส่วนโค้ง วงกลม วงรี หรือสไปลน์ สิ่งอื่นจะถูกปฏิเสธ และเลือกใหม่ได้
3. **พิมพ์ความยาวช่วง** จุดจะแสดงตัวอย่างบนวัตถุขณะพิมพ์
4. กด **Enter** หรือ **Space** เพื่อวางจุด คำสั่งจบลง

## จุดอยู่ตรงไหน

- จุดแรกอยู่ห่างจากจุดเริ่มหนึ่งช่วง และจุดที่เหลือตามมาทีละช่วง วัดตามวัตถุรวมทั้งส่วนโค้ง ไม่มีจุดที่ตัวจุดเริ่มเอง
- บนวัตถุเปิด — เส้น polyline เปิด ส่วนโค้ง วงรีบางส่วน หรือสไปลน์เปิด — การวัดเริ่มจากปลายที่คลิกใกล้กว่า ส่วนที่เหลือที่ปลายไกลจะไม่มีเครื่องหมาย: ปลายไกลได้จุดก็ต่อเมื่อช่วงลงตัวพอดี
- บนวัตถุปิด — วงกลม polyline ปิด วงรีเต็ม หรือสไปลน์ปิด — การวัดเริ่มจากจุดเริ่มของวัตถุเองไม่ว่าคลิกตรงไหน: วงกลมเริ่มที่มุม 0 ทวนเข็มนาฬิกา polyline ปิดเริ่มที่จุดยอดแรก จุดหยุดก่อนถึงจุดเริ่ม
- ความยาว 0 หรือน้อยกว่า ยาวกว่าวัตถุ หรือที่ได้จุดเกิน 32767 จุดจะถูกปฏิเสธ: เทอร์มินัลบอกเหตุผลและล้างค่าเพื่อให้พิมพ์ใหม่

Backspace ลบอักขระสุดท้าย Escape เริ่มใหม่เพื่อเลือกวัตถุอื่น Enter หรือ Space ก่อนเลือกวัตถุจะจบคำสั่ง
