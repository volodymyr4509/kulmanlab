# Explode

คำสั่ง `explode` แยก [Polyline](../polyline/) ออกเป็นวัตถุ [Line](../line/) และ [Arc](../arc/) แต่ละชิ้น — ทีละส่วน ตรงตำแหน่งจุดยอดเดิมของ polyline พอดี ชิ้นส่วนเหล่านี้จะแทนที่ polyline ในตำแหน่งเดิม และคงความหนาเส้น สี เลเยอร์ และชนิดเส้นของมันไว้

Explode ใช้ได้กับเอนทิตี **Polyline** และ**การอ้างอิงบล็อก**

## การใช้ explode

มีสองวิธีในการรัน แบบเดียวกับ [Delete](../delete/):

**เลือกก่อน แล้วค่อย explode** — วิธีที่เร็วที่สุด:

1. เลือก polyline หนึ่งชิ้นขึ้นไปบนแคนวาส
2. พิมพ์ `explode` ในเทอร์มินัล หรือเลือก **Explode** จากเมนูดรอปดาวน์ในแผง Edit

polyline ที่เลือกไว้จะถูก explode ทันที — ไม่มีขั้นตอนยืนยันแยกต่างหาก เพราะมีการเลือกไว้แล้ว

**เปิดใช้งานคำสั่งก่อน แล้วค่อยเลือก**:

1. พิมพ์ `explode` หรือเลือก **Explode** จากเมนูดรอปดาวน์โดยไม่ได้เลือกอะไรไว้
2. **เลือก polyline หรือการอ้างอิงบล็อก** — คลิกเพื่อสลับ หรือลากเพื่อเลือกตามพื้นที่
3. กด **Enter** หรือ **Space** เพื่อยืนยันและ explode polyline ที่เลือกไว้

ระหว่างการเลือกจะหยิบเฉพาะ polyline และการอ้างอิงบล็อก — การคลิก Line, Circle หรือเอนทิตีอื่นไม่มีผล และการลากพื้นที่จะข้ามทุกอย่างอื่นที่อยู่ข้างในหรือตัดผ่าน

## ผลลัพธ์ที่ได้

แต่ละส่วนของ polyline จะกลายเป็นวัตถุของตัวเอง:

- **ส่วนที่เป็นเส้นตรง** จะกลายเป็น **Line**
- **ส่วนที่เป็นส่วนโค้ง** (จาก[ตัวเลือก Arc](../polyline/) ของ Polyline) จะกลายเป็น **Arc** ที่ตรงกับจุดศูนย์กลาง รัศมี และมุมกวาดของเส้นโค้งเดิมทุกประการ

Line และ Arc แต่ละชิ้นที่ได้จะสืบทอด **ความหนาเส้น สี เลเยอร์ ชนิดเส้น และมาตราส่วนชนิดเส้น** จาก polyline ต้นทาง — รูปลักษณ์ของรูปทรงเรขาคณิตไม่เปลี่ยนแปลงเลย เพียงแต่ตอนนี้กลายเป็นวัตถุอิสระหลายชิ้นแทนที่จะเป็น polyline ที่เชื่อมต่อกันชิ้นเดียว

**การอ้างอิงบล็อก**จะกลายเป็นเอนทิตีที่บล็อกวาด วางไว้ตรงที่การอ้างอิงเคยแสดง เอนทิตีที่บล็อกซ่อนไว้ — สถานะอื่นของบล็อกไดนามิก — จะถูกตัดออก แอตทริบิวต์แต่ละตัวกลายเป็น Text ธรรมดาพร้อมค่า ชิ้นที่วาดแบบ ByBlock ใช้สีของการอ้างอิง และชิ้นบนเลเยอร์ 0 ใช้เลเยอร์ของมัน บล็อกที่ซ้อนอยู่จะออกมาเป็นการอ้างอิงบล็อกของตัวเอง ซึ่งแยกต่อได้ การอ้างอิงที่ปรับมาตราส่วน X และ Y ต่างกันจะไม่ถูกเลือก เพราะวงกลมจะต้องกลายเป็นวงรี

การ explode สามารถยกเลิกได้ในขั้นตอนเดียวด้วย [Undo](../undo/) เช่นเดียวกับการแก้ไขอื่น ๆ

## การเลือกระหว่างใช้คำสั่ง

| วิธี | พฤติกรรม |
|------|-----------|
| **คลิก** | เพิ่มหรือนำ polyline หรือการอ้างอิงบล็อกใต้เคอร์เซอร์ออกจากการเลือก คลิกเอนทิตีอื่นไม่มีผล |
| **ลากไปทางขวา** (เข้มงวด) | เลือกเฉพาะ polyline และการอ้างอิงบล็อกที่อยู่ในกรอบทั้งหมด |
| **ลากไปทางซ้าย** (ตัดผ่าน) | เลือก polyline และการอ้างอิงบล็อกที่ตัดขอบกรอบ |
| **Enter** / **Space** | ยืนยันและแยกสิ่งที่เลือก |

## วัตถุที่รองรับ

| วัตถุ | รองรับ |
|-------|--------|
| Polyline / Rectangle | ใช่ |
| การอ้างอิงบล็อก | ได้ ยกเว้นเมื่อมาตราส่วน X และ Y ต่างกัน |
| Line, Arc, Circle, Ellipse | ไม่ — ไม่มีอะไรให้ explode |
| Text, Spline, Dimension, Leader, Hatch | ไม่ |
