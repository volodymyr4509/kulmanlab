# Block Create

คำสั่ง `blockcreate` สร้าง**บล็อก**: กลุ่มวัตถุที่มีชื่อ เก็บไว้ครั้งเดียวในแบบ และวางได้กี่ครั้งก็ได้ด้วย [Block Insert](../block-insert/) วัตถุที่คุณเลือกกลายเป็นบล็อก และในแบบจะถูกแทนที่ด้วยการอ้างอิงถึงบล็อกนั้นหนึ่งรายการ จึงไม่มีอะไรดูเปลี่ยนไป

## การสร้างบล็อก

1. เลือกวัตถุก่อนก็ได้ แล้วพิมพ์ `blockcreate` หรือคลิก **สร้างบล็อก** ในแผง **บล็อก** ป๊อปอัปจะเปิดขึ้นพร้อมสิ่งที่เลือกไว้แล้ว
2. พิมพ์ **ชื่อ** ห้ามว่าง ห้ามมีอักขระใดใน `< > / \ " : ; ? * | , =` หรือเครื่องหมายแบ็กทิก และห้ามซ้ำกับชื่อบล็อกอื่น
3. คลิก **เลือกวัตถุ** เพื่อเพิ่มหรือเอาวัตถุออก: ป๊อปอัปจะซ่อน แล้วคุณคลิกวัตถุหรือลากเป็นพื้นที่ กด **Enter** หรือ **Space** เพื่อกลับไปที่ป๊อปอัป ซึ่ง **วัตถุ** แสดงจำนวน
4. ตั้ง **จุดฐาน** ซึ่งเป็นจุดที่ใช้วางบล็อก: พิมพ์ X และ Y หรือคลิก **เลือกจุด** แล้วคลิกบนผืนผ้าใบ (หรือพิมพ์ X,Y ที่นั่น) ค่าเริ่มต้นคือ 0,0
5. คลิก **OK** บล็อกถูกเก็บไว้ วัตถุหลีกทางให้การอ้างอิงถึงบล็อกหนึ่งรายการที่จุดฐาน และเทอร์มินัลบันทึกชื่อบล็อกกับจำนวนวัตถุในนั้น

## ควรรู้

- **OK** ยังคงใช้ไม่ได้ขณะที่มีบางอย่างผิด และข้อความใต้ช่องบอกว่าอะไร: ชื่อว่างหรือใช้ไม่ได้ ชื่อที่ใช้อยู่แล้ว หรือไม่มีวัตถุ
- **Escape** ขณะเลือกวัตถุหรือจุดฐานจะกลับไปที่ป๊อปอัปโดยบล็อกคงเดิม **Escape** ในป๊อปอัปยกเลิกคำสั่ง
- บล็อกถูกบันทึกพร้อมแบบและเขียนลง DXF พร้อมการอ้างอิงของมัน
