# Array Polar

คำสั่ง `ArrayPolar` สร้างสำเนาของวัตถุที่เลือกรอบจุดศูนย์กลาง กระจายเท่า ๆ กันในรอบเต็มหรือบางส่วนของรอบ ต้นฉบับเป็นรายการแรก รายการอื่นทุกรายการเป็นสำเนาที่หมุนรอบจุดศูนย์กลาง — หรือเพียงย้ายรอบจุดนั้นหากปิด Rotate

## การสร้างอาร์เรย์เชิงขั้ว

1. เลือกวัตถุ แล้วพิมพ์ `arraypolar` ในเทอร์มินัลหรือคลิกปุ่ม **Array Polar** บนแถบเครื่องมือ หากเริ่มโดยไม่มีการเลือก คำสั่งจะให้คุณเลือกก่อน — กด **Enter** หรือ **Space** เพื่อยืนยัน
2. **คลิกที่จุดศูนย์กลาง** ที่สำเนาจะวนรอบ หรือพิมพ์ `X,Y` แล้วกด **Enter** เพื่อระบุพิกัดที่แน่นอน
3. ตรวจสอบอาร์เรย์ สำเนาทั้งหมดแสดงตัวอย่างสด และเทอร์มินัลแสดง `Change [Items=6] [Angle=60°] [Fill=360°] [Rotate=true]` — กดตัวอักษรของตัวเลือกเพื่อเปลี่ยน
4. กด **Enter** หรือ **Space** เพื่อสร้างสำเนา ต้นฉบับอยู่ที่เดิมและการเลือกถูกล้าง

## ตัวเลือก

| ตัวเลือก | ปุ่ม | ผล |
|---|---|---|
| Items | `I` | จำนวนรายการทั้งหมดรวมต้นฉบับ — จำนวนเต็มตั้งแต่ 2 ถึง 1024 เริ่มที่ 6 |
| Angle | `A` | องศาจากรายการหนึ่งไปรายการถัดไป ทวนเข็มนาฬิกา มุมลบไปตามเข็มนาฬิกา สูงสุด 180° |
| Fill | `F` | องศาจากรายการแรกไปรายการสุดท้าย 360 (ค่าเริ่มต้น) คือรอบเต็ม ตัวเลขที่น้อยกว่ากระจายรายการในบางส่วนของรอบ ค่าลบไปตามเข็มนาฬิกา สูงสุด 360° |
| Rotate | `R` | เปิด (ค่าเริ่มต้น): แต่ละสำเนาหมุนไปตามรอบ ปิด: แต่ละสำเนาถูกย้ายไปยังตำแหน่งและหันไปทางเดียวกับต้นฉบับ สลับทันที — ไม่มีตัวเลขให้พิมพ์ |

- Angle และ Fill เป็นสองวิธีบอกสิ่งเดียวกัน การเปลี่ยนอย่างหนึ่งจึงคำนวณอีกอย่างใหม่ ในรอบเต็ม รายการสุดท้ายหยุดก่อนรายการแรกหนึ่งก้าว ส่วนในบางส่วนของรอบ จะลงที่มุมการเติมพอดี
- หากต้องการเปลี่ยนตัวเลข ให้กดตัวอักษรของตัวเลือกนั้น พรอมต์จะเติมค่าปัจจุบันไว้ให้ — พิมพ์เพื่อแทนที่ แล้วกด **Enter** หรือ **Space** การยืนยันโดยไม่เปลี่ยนจะคงอาร์เรย์ไว้ตามเดิม
- Items รับเฉพาะจำนวนเต็ม ส่วน Angle และ Fill รับทศนิยมและ `-` นำหน้าสำหรับตามเข็มนาฬิกา มุมหรือการเติม 0 จะถูกปฏิเสธ เช่นเดียวกับมุมเกิน 180° หรือการเติมเกิน 360° — เทอร์มินัลจะบอกเหตุผล
- Angle ที่เล็กเกินกว่าจะใส่ทุกรายการได้จะตัดรายการที่ไม่มีที่ออก และเทอร์มินัลจะรายงานจำนวนใหม่
- ใช้ได้กับทุกชนิดเอนทิตี: แต่ละสำเนาคือต้นฉบับที่หมุนรอบจุดศูนย์กลางหรือย้ายที่ เหมือนที่ [Rotate](../rotate/) และ [Move](../move/) ทำ

## ปุ่มลัด

| ปุ่ม | การกระทำ |
|---|---|
| `Enter` / `Space` | ยืนยันการเลือก อาร์เรย์ หรือตัวเลขที่พิมพ์ |
| `I` `A` `F` `R` | เปลี่ยน Items, Angle หรือ Fill โดยพิมพ์ตัวเลข สลับ Rotate |
| `0`–`9`, `.`, `-` | พิมพ์ตัวเลข (`.` และ `-` ใช้กับ Angle และ Fill เท่านั้น โดย `-` อยู่หน้าสุด) |
| `Backspace` | ลบอักขระที่พิมพ์ล่าสุด |
| `Escape` | ยกเลิก |
