# Polygon

คำสั่ง `polygon` วาดรูปหลายเหลี่ยมปกติ — ทุกด้านและทุกมุมเท่ากัน — ที่มี 3 ถึง 1024 ด้าน พิมพ์ `polygon` ในเทอร์มินัล ผลลัพธ์เป็น **`LWPOLYLINE` แบบปิด** ดังนั้นเมื่อวางแล้วจะทำงานเหมือน [Polyline](../polyline/) อื่น ๆ และการแก้ไข polyline ทั้งหมดใช้ได้

## การวาดรูปหลายเหลี่ยม

1. พิมพ์ `polygon` ในเทอร์มินัลและป้อน**จำนวนด้าน** — จำนวนเต็มตั้งแต่ 3 ถึง 1024 — แล้วกด **Enter** หรือ **Space** พรอมต์จะเติมจำนวนที่ใช้ครั้งล่าสุดไว้ให้ก่อน (ครั้งแรกคือ 4) เริ่มพิมพ์เพื่อแทนที่ ค่าอื่นจะถูกปฏิเสธและค้างอยู่ในพรอมต์เพื่อแก้ไข
2. **คลิกที่จุดศูนย์กลาง** หรือพิมพ์ `X,Y` แล้วกด **Enter** เพื่อระบุพิกัดที่แน่นอน กด `E` ก่อนหากต้องการเริ่มจากขอบแทน (ดูด้านล่าง)
3. **คลิกที่รัศมี** — รูปหลายเหลี่ยมจะแสดงตัวอย่างสด — หรือพิมพ์รัศมีแล้วกด **Enter** หรือ **Space**
4. รูปหลายเหลี่ยมถูกวางและคำสั่งจบลง

## ตัวเลือก

| ตัวเลือก | ปุ่ม | ผล |
|---|---|---|
| Edge | `E` | จุดแรกจะเป็นปลายด้านหนึ่งของขอบแทนที่จะเป็นจุดศูนย์กลาง เลือกปลายที่สอง มุมที่เหลือจะถูกสร้างทวนเข็มนาฬิกา ทางซ้ายของขอบจากปลายแรกไปปลายที่สอง กด `E` อีกครั้งเพื่อกลับไปที่จุดศูนย์กลาง |
| Inside | `I` | เปิดเป็นค่าเริ่มต้นและคงไว้จากรูปหลายเหลี่ยมหนึ่งไปอีกรูป เปิด: มุมอยู่บนวงกลมรัศมีที่กำหนด ปิด: รูปหลายเหลี่ยมอยู่นอกวงกลมนั้น โดยจุดกึ่งกลางของแต่ละขอบอยู่บนวงกลม |

- การคลิกวางมุม (Inside เปิด) หรือจุดกึ่งกลางของขอบ (Inside ปิด) ตรงตำแหน่งเคอร์เซอร์พอดี ดังนั้นเคอร์เซอร์จึงกำหนดทิศทางด้วย
- รัศมีที่พิมพ์ไม่มีทิศทางให้เล็ง รูปหลายเหลี่ยมจึงวางโดยให้ขอบล่างสุดอยู่ในแนวนอน — เว้นแต่เปิดการล็อกมุมไว้ ซึ่งจะเป็นไปตามมุมที่ล็อก
- แต่ละตัวเลือกจะปรากฏในขั้นตอนของตัวเอง และสลับได้แม้ขณะกำลังพิมพ์ตัวเลข

## ปุ่มลัด

| ปุ่ม | การกระทำ |
|---|---|
| `0`–`9`, `.` | พิมพ์จำนวนด้าน รัศมี พิกัด หรือความยาว |
| `E` | เปิดหรือปิด Edge (ขั้นตอนจุดแรก) |
| `I` | เปิดหรือปิด Inside (ขั้นตอนรัศมี) |
| `Enter` / `Space` | ยืนยันจำนวนด้านหรือรัศมี |
| `Escape` | ยกเลิก |

## DXF — เอนทิตี LWPOLYLINE

รูปหลายเหลี่ยมถูกบันทึกเป็น `LWPOLYLINE` แบบปิดที่มีจุดยอดหนึ่งจุดต่อหนึ่งมุม DXF ไม่มีชนิดรูปหลายเหลี่ยมโดยเฉพาะ คุณสมบัติทั้งหมด — พิกัดจุดยอด สี เลเยอร์ ชนิดเส้น มาตราส่วนชนิดเส้น และความหนา — ถูกเก็บไว้โดยไม่สูญเสีย และโปรแกรมดู DXF ทุกตัวอ่านเป็น polyline แบบปิด
