# TextStyle

คำสั่ง `TextStyle` เปิดตัวจัดการรูปแบบข้อความ คุณสามารถสร้างรูปแบบที่มีชื่อ แก้ไขค่าเริ่มต้น และเลือกรูปแบบ *ปัจจุบัน* ได้ [Text](../text/) ใหม่ทุกชิ้นจะคัดลอกการตั้งค่าของรูปแบบปัจจุบันเมื่อสร้าง

## การใช้ตัวจัดการ

พิมพ์ `TextStyle` หรือคลิก **รูปแบบข้อความ** ในแผงคำอธิบายประกอบ เครื่องหมาย ✓ แสดงรูปแบบปัจจุบัน และการดับเบิลคลิกแถวจะตั้งรูปแบบนั้นเป็นรูปแบบปัจจุบัน

| ช่อง | หน้าที่ |
|---|---|
| ชื่อ | ชื่อที่ไม่ซ้ำ โดยเปลี่ยนชื่อ `Standard` ไม่ได้ |
| ฟอนต์ / ความสูง | แบบอักษรและความสูงคงที่; `0` = กำหนดตามข้อความ |
| ตัวหนา / ตัวเอียง | เปิดหรือปิดได้แยกกัน |
| ระยะห่างระหว่างบรรทัด | ช่องว่างระหว่างบรรทัดข้อความ |
| การจัดแนวนอน | ซ้าย กึ่งกลาง ขวา หรือเต็มแนว |
| กรอบ | กรอบสี่เหลี่ยมรอบข้อความใหม่ |

**ใหม่** จะทำสำเนารูปแบบที่เลือก **ลบ** ไม่สามารถลบ `Standard` หรือรูปแบบปัจจุบันได้ **ตั้งเป็นปัจจุบัน** มีผลเฉพาะข้อความที่สร้างภายหลัง ข้อความเดิมไม่เปลี่ยน ชื่อที่ว่าง ซ้ำ หรือไม่ถูกต้องสำหรับ DXF จะทำให้ **ตกลง** ใช้งานไม่ได้ รูปแบบคำอธิบายประกอบที่นำเข้าจะถูกซ่อน แต่ข้อมูลยังคงอยู่

## การบันทึกและ DXF

**ตกลง** บันทึกการเปลี่ยนแปลง ส่วน **ปิด** หรือ `Escape` จะยกเลิก ใช้ `↑` และ `↓` เพื่อเลื่อนในรายการ ชื่อ ไฟล์ฟอนต์ ความสูง ตัวหนา ตัวเอียง และแฟล็กคำอธิบายประกอบเป็นส่วนหนึ่งของรูปแบบข้อความ DXF ส่วนกรอบ ระยะห่างบรรทัด และการจัดแนวนอนเป็นค่าเริ่มต้นต่อข้อความของ KulmanLab ไม่ใช่ช่องในตาราง STYLE
