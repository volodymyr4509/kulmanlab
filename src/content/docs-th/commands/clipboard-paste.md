# ClipboardPaste

คำสั่ง `ClipboardPaste` อ่านวัตถุที่ [ClipboardCopy](../clipboard-copy/) เขียนไว้ใน **คลิปบอร์ดของระบบ** แล้ววางลงในแบบปัจจุบัน ณ จุดที่คุณเลือก เนื่องจากเป็นคลิปบอร์ดของระบบจริง ต้นทางจึงอาจเป็นแบบอื่น แท็บเบราว์เซอร์อื่น หรือเซสชันจากช่วงต้นของวันก็ได้

## วิธีวาง

1. กด `Ctrl+V` (บน macOS คือ `Cmd+V`) หรือพิมพ์ `ClipboardPaste` ในเทอร์มินัล
2. ข้อความแจ้งจะแสดง **reading clipboard…** ขณะที่เบราว์เซอร์ส่งมอบข้อความจากคลิปบอร์ด
3. เมื่อโหลดเสร็จ ข้อความแจ้งจะเปลี่ยนเป็น **pick insertion point** และภาพตัวอย่างของเรขาคณิตจะตามเคอร์เซอร์ไป
4. **คลิก** เพื่อวางวัตถุ วัตถุจะถูกเพิ่มเข้าไปในแบบและยังคงถูกเลือกอยู่

ภาพตัวอย่างถูกยึดไว้ด้วย **จุดอ้างอิง** ของสำเนา — มุมล่างซ้ายของขอบเขตรวมของสิ่งที่เลือกไว้เดิม มุมนั้นจะอยู่ใต้เคอร์เซอร์ของคุณ การจัดวางสัมพัทธ์ระหว่างวัตถุที่คัดลอกมาจึงคงไว้อย่างแม่นยำ

## สิ่งที่เกิดขึ้นเมื่อวาง

| ขั้นตอน | พฤติกรรม |
|---------|----------|
| **รหัสประจำตัวใหม่** | วัตถุที่วางแต่ละชิ้นได้รับ id ใหม่ การวางสองครั้งจึงได้ชุดที่เป็นอิสระต่อกันสองชุด |
| **การเลื่อน** | วัตถุถูกเลื่อนไปเป็นระยะ เคอร์เซอร์ − จุดอ้างอิง |
| **การรวมเลเยอร์** | เลเยอร์ที่ถูกอ้างถึงแต่แบบปลายทางยังไม่มี จะถูกเพิ่มตามชื่อ |
| **การรวมชนิดเส้น** | ชนิดเส้นที่ถูกอ้างถึงแต่แบบปลายทางยังไม่มี จะถูกเพิ่มตามชื่อ |
| **การเลือก** | การเลือกเดิมถูกล้าง และวัตถุที่วางจะกลายเป็นสิ่งที่ถูกเลือก |

### การรวมเลเยอร์และชนิดเส้น

รายการที่ขาดไปจะถูกเพิ่มเข้ามา ส่วน **รายการที่มีอยู่แล้วจะไม่ถูกแตะต้อง** หากคลิปบอร์ดพาเลเยอร์ชื่อ `WALLS` สีแดงมา และแบบปลายทางมีเลเยอร์ `WALLS` สีน้ำเงินอยู่แล้ว นิยามของแบบปลายทางจะชนะและวัตถุที่วางจะเข้าไปอยู่ในเลเยอร์นั้น — จึงกลายเป็นสีน้ำเงิน การวางไม่ได้นิยามสิ่งใดในแบบปลายทางใหม่

เรื่องนี้สำคัญเมื่อคัดลอกระหว่างแบบที่ใช้ข้อตกลงเรื่องเลเยอร์ต่างกัน หากสีไม่เป็นอย่างที่คาดไว้หลังวางข้ามแบบ ให้ตรวจดูที่ [Layer Manager](../layer-manager/)

## เมื่อคลิปบอร์ดไม่มีอะไรให้วาง

ClipboardPaste รับเฉพาะข้อมูลที่ ClipboardCopy สร้างขึ้นเท่านั้น สิ่งอื่นใดในคลิปบอร์ด — ข้อความธรรมดา ลิงก์ รูปภาพ หรือ JSON จากโปรแกรมอื่น — จะถูกปฏิเสธ และเทอร์มินัลจะรายงานว่า:

```
Clipboard has no copied entities
```

หากเบราว์เซอร์ปฏิเสธการเข้าถึงคลิปบอร์ดโดยสิ้นเชิง ข้อความจะเป็น **Blocked by the browser: allow clipboard in site settings, by the address bar** แทน ทั้งสองกรณีจบคำสั่งโดยไม่เปลี่ยนแปลงแบบ

## ปุ่มลัดที่ใช้ได้

| ปุ่ม | การทำงาน |
|------|----------|
| `Ctrl+V` / `Cmd+V` | เรียกใช้ ClipboardPaste |
| `Escape` | ยกเลิก — วัตถุถูกทิ้งไปและไม่มีอะไรถูกเพิ่มเข้ามา |

การยกเลิกระหว่างช่วงอ่านนั้นปลอดภัย หากคลิปบอร์ดตอบกลับมาหลังจากที่คุณยกเลิกไปแล้วหรือเริ่มคำสั่งอื่นไปแล้ว ผลลัพธ์ที่มาช้าจะถูกทิ้งไป แทนที่จะไปขัดจังหวะสิ่งที่กำลังทำงานอยู่ในตอนนั้น

## การคัดลอกข้ามแท็บ

ขั้นตอนทั่วไปเมื่อทำงานข้ามแบบ:

1. เปิดแบบต้นทาง เลือกเรขาคณิต แล้วกด `Ctrl+C`
2. สลับไปยังอีกแท็บหนึ่ง — หรือเปิดแท็บที่สองของแอปแล้วโหลดไฟล์อื่น
3. กด `Ctrl+V` แล้วคลิกจุดแทรก

ทั้งสองแท็บมีต้นทางเดียวกันและใช้คลิปบอร์ดของระบบร่วมกัน จึงไม่มีการอัปโหลดใด ๆ และไม่มีเซิร์ฟเวอร์เข้ามาเกี่ยวข้อง ข้อมูลยังคงเป็นข้อความ JSON อยู่ในคลิปบอร์ดของคุณเองตลอดเวลา

## วัตถุที่รองรับ

วัตถุทุกชนิดที่ ClipboardCopy เขียนได้ ClipboardPaste ก็อ่านกลับได้ — ด้วยการทำให้เป็นอนุกรมแบบเดียวกับที่รูปแบบ `.json` ของโปรแกรมใช้
