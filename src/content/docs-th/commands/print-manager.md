# Print Manager

คำสั่ง `PrintManager` เปิด **Print Manager** — หน้าต่างส่งออกพร้อมแคนวาสตัวอย่างแบบสด ตัวเลือกรูปแบบ (PNG / JPEG / WebP / PDF) ตัวเลือก Style (Default / Monochrome / Blueprint) และการครอบพื้นที่ตามต้องการ ไม่มีการส่งงานไปยังเครื่องพิมพ์จริง ผลลัพธ์จะถูกดาวน์โหลดเป็นไฟล์

## การเปิด Print Manager

คลิกปุ่ม **Print** บนแถบเครื่องมือหรือพิมพ์ `PrintManager` ในเทอร์มินัล Print Manager จะเปิดขึ้นทันทีพร้อมแสดงตัวอย่างของวิวพอร์ตปัจจุบัน

ตัวอย่างถูกเรนเดอร์ผ่านโค้ดพาธเดียวกันทุกประการ ที่ความละเอียดพิกเซลเดียวกันทุกประการ กับไฟล์ที่คุณจะส่งออกในที่สุด — การเปลี่ยน Quality, Style หรือพื้นที่ส่งออก จะเรนเดอร์ตัวอย่างใหม่ทันที ดังนั้นสิ่งที่คุณเห็นคือสิ่งที่จะถูกดาวน์โหลด ไม่ใช่ค่าประมาณ

## เค้าโครง Print Manager

หน้าต่างมีสองแผง:
- **แถบด้านซ้าย** — ตัวควบคุมการส่งออกทั้งหมด
- **แผงด้านขวา** — แคนวาสตัวอย่างแบบสดที่อัปเดตตามการเปลี่ยนการตั้งค่า

### ตัวควบคุมในแถบด้านซ้าย

| ตัวควบคุม | คำอธิบาย |
|-----------|-----------|
| **Change Area** | ครอบพื้นที่สี่เหลี่ยมที่กำหนดเองบนแคนวาส (ดูด้านล่าง) — ครอบภาพที่ส่งออกจริง ๆ รวมถึงบนเลย์เอาต์ที่มีพื้นที่กระดาษด้วย ไม่ใช่แค่ตัวอย่างบนหน้าจอ |
| ดรอปดาวน์ **Quality** | กำหนดความละเอียดในการส่งออก (ดูด้านล่าง) |
| ดรอปดาวน์ **Style** | Default, Monochrome หรือ Blueprint — ดู *สไตล์การพิมพ์* ด้านล่าง Monochrome เป็นค่าเริ่มต้นเพื่อผลลัพธ์การพิมพ์ที่สะอาด |
| ดรอปดาวน์ **Format** | PNG, JPEG, WebP หรือ PDF |
| ปุ่ม **Export** | สร้างและดาวน์โหลดไฟล์ |

## สไตล์การพิมพ์

ดรอปดาวน์ **Style** ควบคุมทั้งสีหมึกที่ใช้วาดเอนทิตีและพื้นหลังของหน้ากระดาษ:

| Style | หมึก | พื้นหลังหน้ากระดาษ |
|-------|------|----------------------|
| **Default** | สีของแต่ละเอนทิตีเอง | ขาว |
| **Monochrome** *(ค่าเริ่มต้น)* | ดำล้วน ไม่ว่าสีของเอนทิตี/เลเยอร์จะเป็นอะไร | ขาว |
| **Blueprint** | ขาวล้วน ไม่ว่าสีของเอนทิตี/เลเยอร์จะเป็นอะไร | น้ำเงินปรัสเซียนเข้ม พร้อมตารางอ้างอิงจาง ๆ |

Blueprint จำลองรูปลักษณ์ของภาพพิมพ์สถาปัตยกรรมไซยาโนไทป์แบบดั้งเดิม — เส้นสีขาวบนแผ่นสีน้ำเงินเข้ม ตารางอ้างอิงมีขนาดสัมพันธ์กับขนาดหน้ากระดาษ ไม่ใช่ DPI จึงดูมีความหนาแน่นเท่ากันในทุกการตั้งค่า Quality แทนที่จะหนาแน่นขึ้นเมื่อความละเอียดเพิ่มขึ้น

## คุณภาพและความละเอียด

เมนูดรอปดาวน์ **Quality** กำหนด DPI ที่ใช้เรนเดอร์การส่งออก:

| Quality | DPI |
|---------|-----|
| Draft | 72 |
| Normal *(ค่าเริ่มต้น)* | 150 |
| Presentation | 300 |
| Max | 600 |

คุณภาพที่สูงขึ้นจะสร้างภาพที่ใหญ่และคมชัดขึ้นในขนาดจริงเท่าเดิม — ความหนาของเส้นจะปรับตามความละเอียด ดังนั้นเส้นจะคงความหนา*จริง*บนกระดาษเท่าเดิมไม่ว่าจะตั้งค่า Quality แบบใด แทนที่จะดูบางลงเมื่อ DPI เพิ่มขึ้น ข้อยกเว้นเดียวคือเส้นบาง (ความหนาเส้น `0`) ซึ่งตามธรรมเนียมนิยามว่าเป็น "เส้นที่บางที่สุดที่อุปกรณ์เอาต์พุตสามารถวาดได้" — จะคงความกว้าง 1 พิกเซลคงที่ในทุกระดับ Quality เช่นเดียวกับที่แสดงบนแคนวาสแบบสด

การเปลี่ยน Quality จะเรนเดอร์ตัวอย่างใหม่ทันที ทำให้คุณเห็นความคมชัดจริง (และการแลกเปลี่ยนขนาดไฟล์) ก่อนส่งออก

## การเลือกพื้นที่ส่งออกแบบกำหนดเอง

โดยค่าเริ่มต้น ตัวอย่างจะแสดงกรอบขอบเขตของทุกเอนทิตีในพื้นที่ Model — ขอบเขตเดียวกับที่ [Fit](../fit/) ซูมไป — หรือทั้งแผ่นงานในเลย์เอาต์ หากต้องการส่งออกบริเวณที่ต้องการ:

1. คลิก **Change Area** — Print Manager จะซ่อนตัวและแคนวาสจะโต้ตอบได้
2. **คลิกมุมแรก** ของสี่เหลี่ยมส่งออก
3. **คลิกมุมตรงข้าม** — Print Manager จะเปิดขึ้นใหม่พร้อมพื้นที่ที่เลือกในตัวอย่าง

กด `Escape` ระหว่างการเลือกพื้นที่เพื่อยกเลิกและกู้คืนพื้นที่ก่อนหน้า

แคนวาสตัวอย่างปรับขนาดแบบไดนามิกเพื่อให้ตรงกับ **อัตราส่วนภาพที่แน่นอน** ของพื้นที่ที่เลือก ดังนั้นตัวอย่างจึงแม่นยำระดับพิกเซล

พื้นที่ที่เลือกจะถูกจดจำแยกกันสำหรับพื้นที่ Model และแต่ละเลย์เอาต์จนกว่าคุณจะโหลดหน้าใหม่ — ดู [ChangePrintArea](../change-print-area/)

## รูปแบบการส่งออก

| รูปแบบ | เหมาะสำหรับ | หมายเหตุ |
|--------|------------|---------|
| **PNG** | ไม่สูญเสียข้อมูล เส้นคมชัด | ฝังพื้นหลังหน้ากระดาษของ Style ไว้ ไม่มีความโปร่งใส |
| **JPEG** | ไฟล์ขนาดเล็กสำหรับแชร์ | คุณภาพ 95% มีการบีบอัดเล็กน้อย |
| **WebP** | ไฟล์ขนาดเล็กที่สุดสำหรับเว็บ | คุณภาพ 95% เหมือนกัน บีบอัดดีกว่า JPEG |
| **PDF** | เอกสารพร้อมพิมพ์ | ฝังรูปภาพในคอนเทนเนอร์ PDF ที่ DPI ของ Quality ที่เลือก ในขนาดที่ทำให้หน้ากระดาษพิมพ์ออกมาตามมาตราส่วนจริงทางกายภาพ |

ไฟล์ที่ส่งออกจะตั้งชื่อว่า `kulman-<timestamp>.<ext>` และดาวน์โหลดอัตโนมัติ

## ความละเอียดและพื้นหลังการส่งออก

- **การส่งออก model space / viewport**: จำกัดที่ 2000 × 2000 พิกเซลที่ Quality Normal เริ่มต้น (150 DPI) ปรับสัดส่วนตามพื้นที่ที่เลือก ขีดจำกัดนี้ยังปรับตาม Quality ด้วย — Draft ต่ำกว่า ส่วน Presentation และ Max สูงกว่า (สูงสุด 8000 × 8000 ที่ Max/600 DPI)
- **การส่งออก layout (พื้นที่กระดาษ)**: กำหนดขนาดโดยตรงจากขนาดกระดาษของ layout ที่ DPI ที่เลือก — เช่น กระดาษ A4 (210 × 297 มม.) ที่ Quality Normal จะส่งออกที่ประมาณ 1240 × 1754 px — จึงไม่อยู่ภายใต้ขีดจำกัด 2000 px ของ viewport
- พื้นหลังเป็นไปตาม **Style** การพิมพ์ที่เลือก — สีขาวสำหรับ Default และ Monochrome สีน้ำเงินปรัสเซียนเข้มสำหรับ Blueprint (ดู *สไตล์การพิมพ์* ด้านบน)
- เลเยอร์ที่ทำเครื่องหมายว่า **non-plotting** จะถูกยกเว้นจากการส่งออก

## อ้างอิงแป้นพิมพ์

| ปุ่ม | การกระทำ |
|-----|----------|
| `Escape` (ระหว่างการเลือกพื้นที่) | ยกเลิกการเลือกพื้นที่ กู้คืนพื้นที่ก่อนหน้า |
| `Escape` (ใน Print Manager) | ปิด Print Manager |
