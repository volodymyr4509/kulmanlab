# ตัวกรองการเลือก

การเลือกวัตถุจำนวนมากพร้อมกันจะเปิดแผงคุณสมบัติในมุมมองการเลือกหลายชิ้น ("Selection (N)") **ไอคอนตัวกรอง** ที่อยู่ข้างปุ่มปิดช่วยให้คุณจำกัดสิ่งที่เลือกนั้นตามคุณสมบัติก่อนจะแก้ไขทีละหลายชิ้น

## การเปิดตัวกรอง

1. เลือกวัตถุหลายชิ้น — ลากกรอบเลือก คลิกพร้อมกด Shift หรือกด Ctrl+A
2. คลิก **ไอคอนตัวกรอง** (รูปกรวย) บนหัวแผงคุณสมบัติ
3. หน้าต่างจะเปิดขึ้นใต้ปุ่มนั้น พร้อมรายการติ๊กสำหรับทุกคุณสมบัติที่มีค่าต่างกันจริงภายในสิ่งที่เลือก

## แง่มุม

หน้าต่างแสดงได้สูงสุดห้าแง่มุม แต่ละแง่มุมสร้างขึ้นสดจากสิ่งที่เลือกอยู่ในขณะนั้น:

| แง่มุม | ค่าที่แสดง |
|--------|-----------|
| **ชนิด** | ชื่อชนิดของวัตถุ (Line, Circle, Hatch, …) |
| **เลเยอร์** | ชื่อเลเยอร์ พร้อมตัวอย่างสีที่ตรงกับเลเยอร์นั้น |
| **สี** | ดัชนีสี ACI |
| **ความหนาเส้น** | ค่าความหนาเส้น |
| **ชนิดเส้น** | ชื่อชนิดเส้น |

แง่มุมจะปรากฏก็ต่อเมื่อสิ่งที่เลือกมีค่าที่ต่างกันมากกว่าหนึ่งค่าสำหรับแง่มุมนั้นจริง ๆ — การเลือกเส้นสิบเส้นที่อยู่บนเลเยอร์เดียวกันทั้งหมดจะไม่แสดงแง่มุมเลเยอร์ เพราะการติ๊กที่นั่นก็ไม่ได้จำกัดอะไรลง วัตถุที่ไม่มีคุณสมบัตินั้นเลย (เช่น Hatch และ Text ไม่มีทั้งความหนาเส้นและชนิดเส้น) จะไม่ถูกนับรวมในแง่มุมนั้น — และก็ไม่เคยถูกคัดออกด้วยแง่มุมนั้นเช่นกัน

## การจำกัดสิ่งที่เลือก

ติ๊กค่าหนึ่งค่าหรือมากกว่าในแง่มุมใดก็ได้ เพื่อจำกัดสิ่งที่เลือกให้เหลือเฉพาะวัตถุที่ตรงกับ **ทุกแง่มุม** ที่ติ๊กไว้ (วัตถุต้องตรงกับค่าที่ติ๊กอย่างน้อยหนึ่งค่าใน *ทุก* แง่มุมที่คุณแตะ ไม่ใช่แค่แง่มุมเดียว) ช่องติ๊กและจำนวนของแต่ละแง่มุมสะท้อนสิ่งที่แง่มุม *อื่น ๆ* ที่ติ๊กไว้ได้จำกัดลงแล้ว ดังนั้นแง่มุมหนึ่งจะไม่ซ่อนตัวเลือกที่ตัวเองติ๊กไว้แล้ว — เป็นพฤติกรรมมาตรฐานของการค้นหาแบบแง่มุม

จำนวนผลลัพธ์อัปเดตทันทีขณะคุณติ๊กและเอาติ๊กออก และสิ่งที่เลือกบนพื้นที่วาดก็ถูกจำกัดตามไปด้วย — นี่ไม่ใช่แค่ตัวกรองสำหรับแสดงผล วัตถุที่ไม่ตรงเงื่อนไขอีกต่อไปจะถูกยกเลิกการเลือกจริง ๆ พร้อมให้คุณแก้ไขทีละหลายชิ้นกับชุดย่อยที่คุณกรองไว้พอดี

## การล้างตัวกรอง

ใช้ปุ่มรีเซ็ตในหน้าต่างเพื่อล้างช่องติ๊กทั้งหมดและกลับไปยังสิ่งที่เลือกดั้งเดิมทั้งชุด หรือปิดหน้าต่างไป (ครั้งถัดไปที่คุณคลิกไอคอนตัวกรองบนการเลือกชุดใหม่ มันจะเปิดขึ้นด้วยจุดตั้งต้นใหม่)

## ที่เกี่ยวข้อง

- [Match Properties](../../commands/match-properties/) — คัดลอกคุณสมบัติจากวัตถุหนึ่งไปยังวัตถุอื่น เมื่อคุณจำกัดได้แล้วว่าเป็นชิ้นไหน
- [LayerIsolate](../../commands/layer-isolate/) — ทางเลือกในระดับเลเยอร์เมื่อคุณต้องการแยกตามเลเยอร์เพียงอย่างเดียว โดยไม่ขึ้นกับสิ่งที่เลือกอยู่
