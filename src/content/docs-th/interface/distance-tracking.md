# การติดตามระยะ

**การติดตามระยะ** ให้คุณวางจุดด้วยการพิมพ์ความยาวที่แม่นยำแทนการคลิก ควบคุมด้วยปุ่ม **Dist** บนแถบควบคุม ถัดจาก [Pins](../vector-pins/) และ ANGL โดย **เปิดใช้งานไว้เป็นค่าเริ่มต้น** และการตั้งค่านี้คงอยู่ข้ามรอบการใช้งาน

สิ่งที่มันเพิ่มเข้ามานั้นแคบแต่มีประโยชน์: มันให้ **หมุดเวกเตอร์ล่าสุด** ทำหน้าที่เป็นจุดยึดที่การติดตามมุมใช้วัดออกไป หากไม่มีมัน คำสั่งจะวัดได้จากจุดที่ตัวมันเองเก็บมาแล้วเท่านั้น — นั่นหมายความว่าจุด *แรก* ของรูปทรงไม่มีอะไรให้วัดออกไปเลย

## ปุ่มทั้งสามทำงานร่วมกัน

การติดตามระยะไม่ได้ทำงานลำพัง ปุ่มอีกสองปุ่มต้องอยู่ในสถานะที่ถูกต้องก่อนที่คุณจะพิมพ์ความยาวได้:

| ปุ่ม | หน้าที่ |
|------|--------|
| **Pins** | ให้จุดอ้างอิง วางเคอร์เซอร์ค้างบนจุดสแนป 500 มิลลิวินาทีเพื่อปักหมุด — ดู [Vector Pins](../vector-pins/) |
| **ANGL** | ให้มุม การติดตามระยะจะใช้ได้ต่อเมื่อเคอร์เซอร์ล็อกเข้ากับมุมแล้ว ดังนั้น ANGL ต้องตั้งเป็นขั้น (10°, 20°, 30°, 45°, 90°) ไม่ใช่ Off |
| **Dist** | อนุญาตให้ใช้หมุดเป็นจุดยึด แทนที่จะใช้เพียงจุดของคำสั่งเอง |

หาก Pins และ Dist เปิดอยู่แต่ ANGL ตั้งเป็น **Off** จะไม่มีอะไรเกิดขึ้น เพราะไม่มีทิศทางที่ล็อกไว้ให้วัดความยาวไปตามนั้น

## Pins กับ Dist ผูกกันอย่างไร

การติดตามระยะไม่มีความหมายเมื่อปิดหมุด ปุ่มทั้งสองจึงเดินไปด้วยกัน:

- **เปิด Pins** จะ **เปิด Dist** ด้วย
- **ปิด Pins** จะ **ปิด Dist** ด้วย
- **เปิด Dist** จะ **เปิด Pins** ถ้ายังไม่ได้เปิด
- **ปิด Dist** จะ **ปล่อยให้ Pins เปิดอยู่**

ดังนั้น Dist จะไม่มีทางทำงานขณะที่ Pins ปิดอยู่ แต่คุณสามารถคงการติดตามหมุดไว้เพื่อจัดแนว แล้วปิดการติดตามระยะได้ — มีประโยชน์เมื่อคุณอยากได้เส้นอ้างอิงโดยไม่ให้เคอร์เซอร์ล็อกเข้ากับหมุด ทั้งที่คุณตั้งใจจะล็อกกับจุดล่าสุดของตัวเอง

## การวางจุดที่ระยะแม่นยำ

1. เปิด **Pins** และ **Dist** แล้วตั้ง **ANGL** เป็นขั้นของมุม
2. เริ่มคำสั่งที่ขอจุด — [Line](../../commands/line/), [Circle](../../commands/circle/), [Rectangle](../../commands/rectangle/) และอื่น ๆ
3. **ปักหมุดจุดอ้างอิง**: วางเคอร์เซอร์บนจุดสแนปที่มีอยู่จนกระทั่งเครื่องหมายกลายเป็นสี่เหลี่ยมทึบ
4. เลื่อนเคอร์เซอร์ออกจากหมุดไปในทิศทางมุมที่ต้องการโดยประมาณ เมื่อเข้าใกล้ขั้นใดขั้นหนึ่งของ ANGL ทิศทางจะ **ล็อก** — จะปรากฏตัวชี้การติดตามจากหมุด
5. **พิมพ์ความยาว** แล้วกด **Enter** หรือ **Space** จุดจะถูกวางห่างจากหมุดเท่านั้นพอดี ไปตามมุมที่ล็อกไว้

ข้อความแจ้งในเทอร์มินัลจะบอกว่าเมื่อใดพิมพ์ได้ ขณะล็อกอยู่จะอ่านว่า:

```
pick start point or enter length: [ ]
```

และค่าที่คุณพิมพ์จะปรากฏในวงเล็บเหลี่ยม

## ทำไมจุดแรกจึงสำคัญ

นี่คือกรณีที่ถ้าไม่มีความสามารถนี้ก็ทำไม่ได้เลย สมมติว่าเส้นต้องเริ่มห่างจากมุมที่มีอยู่ไปทางขวาพอดี 250 หน่วย:

1. เริ่มคำสั่ง [Line](../../commands/line/)
2. ปักหมุดที่มุมเดิมนั้น
3. เลื่อนไปทางขวาจนทิศทางล็อกที่ 0°
4. พิมพ์ `250` แล้วกด **Enter**

ตอนนี้เส้นเริ่มที่จุดซึ่งห่างจากมุมนั้น 250 หน่วย โดยไม่ต้องใช้เส้นช่วยและไม่ต้องคำนวณ หากไม่มี Dist คำสั่ง Line ยังไม่ได้เก็บจุดใดเลย จึงไม่มีอะไรให้ *วัดออกไป* สำหรับความยาวที่พิมพ์ — คุณทำได้แค่คลิกโดยประมาณ หรือลากเส้นช่วยแล้วลบทิ้งภายหลัง

สำหรับจุด **ที่สองเป็นต้นไป** คำสั่งมีจุดยึดของตัวเองอยู่แล้ว (จุดก่อนหน้า) และจะใช้จุดนั้นก่อน หมุดจะถูกนำมาใช้เป็นทางเลือกก็ต่อเมื่อจุดยึดของคุณเองยังไม่ล็อก ดังนั้นการปักหมุดจึงไม่ไปแย่งการล็อกที่คุณมีอยู่แล้ว

## การพิมพ์จะตรึงการล็อกไว้

ทันทีที่คุณเริ่มพิมพ์ตัวเลข จุดยึดจะหยุดเปลี่ยน จุดใดก็ตามที่ล็อกอยู่ตอนตัวเลขตัวแรกถูกป้อนเข้าไป จะยังคงเป็นจุดยึดจนกว่าคุณจะยืนยันหรือล้างช่องนั้น — การขยับเมาส์ระหว่างพิมพ์จะไม่ย้ายการวัดไปยังหมุดอื่นหรือไปยังจุดของคำสั่งเองอย่างเงียบ ๆ

## ปุ่มลัดที่ใช้ได้

| ปุ่ม | การทำงาน |
|------|----------|
| `0`–`9`, `.` | เพิ่มเข้าไปในความยาว |
| `-` | ความยาวติดลบ — กลับทิศไปตามมุมที่ล็อกไว้ (เฉพาะอักขระตัวแรก) |
| `Backspace` | ลบอักขระตัวสุดท้าย |
| `Enter` / `Space` | วางจุดที่ความยาวซึ่งพิมพ์ไว้ |
| `Escape` | ยกเลิกคำสั่ง การล็อกและค่าที่พิมพ์จะถูกล้าง |

การพิมพ์ความยาวเป็นทางเลือก เมื่อทิศทางล็อกอยู่คุณยังคลิกได้ และจุดจะถูกฉายลงบนมุมที่ล็อกไว้

## ใช้ได้ที่ไหนบ้าง

การติดตามระยะใช้ได้ในทุกคำสั่งที่ขอให้คุณเลือกจุด:

[Line](../../commands/line/), [Polyline](../../commands/polyline/), [Arc](../../commands/arc/), [Circle](../../commands/circle/), [Ellipse](../../commands/ellipse/), [Rectangle](../../commands/rectangle/), [Spline Cv](../../commands/spline-cv/), [Spline Fit](../../commands/spline-fit/), [Leader](../../commands/leader/), [Area](../../commands/area/), [Move](../../commands/move/), [Copy](../../commands/copy/) และ [ViewportCopy](../../commands/viewport-copy/)

## ดูเพิ่มเติม

- [Vector Pins](../vector-pins/) — การปักหมุดจุดและการติดตามไปตามเส้นอ้างอิงของหมุด
- [Grid & Snap](../grid-snap/) — เครื่องมือช่วยความแม่นยำอื่น ๆ บนแถบควบคุม
- [Distance](../../commands/distance/) — การวัดระยะที่มีอยู่แล้ว แทนการพิมพ์ระยะใหม่
