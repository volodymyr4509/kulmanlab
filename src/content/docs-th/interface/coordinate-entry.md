# การป้อนพิกัด

เมื่อคำสั่งขอจุด — จุดเริ่มของ [Line](../../commands/line/) มุมของ [Rectangle](../../commands/rectangle/) จุดฐานของ [Move](../../commands/move/) หรือกริปที่กำลังลาก — คุณพิมพ์แทนการคลิกได้ เริ่มพิมพ์ตัวเลขแล้วเทอร์มินัลจะแสดงสิ่งที่พิมพ์ กด **Enter** หรือ **Space** เพื่อวางจุด

## สี่วิธีเขียนจุด

| คุณพิมพ์ | จุดอยู่ที่ |
|---|---|
| `100,50` | ที่ X 100, Y 50 |
| `@100,50` | ห่างจากจุดล่าสุด 100 ตาม X และ 50 ตาม Y |
| `100<45` | ห่างจากจุดกำเนิด 100 ที่มุม 45° |
| `@100<45` | ห่างจากจุดล่าสุด 100 ที่มุม 45° |

มุมเป็นองศา ทวนเข็มนาฬิกาจากแกน X ดังนั้น `@50<90` คือขึ้นตรงไป 50 และ `@50<180` คือไปทางซ้าย 50 ค่าใดค่าหนึ่งเป็นลบได้

## จุดล่าสุด

`@` วัดจากจุดล่าสุดที่คลิกหรือพิมพ์ในคำสั่งใดก็ได้ — การคลิกครั้งสุดท้ายของคำสั่งก่อนหน้านับด้วย และกริปที่เพิ่งลากก็นับ ถ้ายังไม่มีจุดล่าสุด `@100,50` จะอ่านเป็น `100,50` จุดล่าสุดจะถูกลืมเมื่อสลับระหว่าง model space กับเลย์เอาต์ และเมื่อเปิดแบบ

## Rel: สัมพัทธ์โดยค่าเริ่มต้น

ปุ่ม **Rel** ในแถบควบคุมทำให้ทุกจุดที่พิมพ์เริ่มเป็นแบบสัมพัทธ์: ทันทีที่พิมพ์ตัวเลขแรก จะมี `@` ใส่ไว้ข้างหน้า `100,50` จึงกลายเป็น `@100,50` กด **Backspace** ที่ `@` เพื่อให้จุดนั้นเป็นแบบแน่นอน ถ้ายังไม่มีจุดล่าสุดจะไม่ใส่ `@` Rel ปิดโดยค่าเริ่มต้นและถูกจดจำไว้กับปุ่มอื่นในแถบควบคุม

## ปุ่มขณะพิมพ์

| ปุ่ม | ผล |
|---|---|
| `0`–`9`, `.`, `-` | พิมพ์ตัวเลข `-` ได้เฉพาะต้นค่า |
| `@` | ทำให้จุดเป็นแบบสัมพัทธ์ ที่ต้น X |
| `,` หรือ **Space** | จบ X แล้วไปที่ Y |
| `<` | จบ X เป็นระยะแล้วไปที่มุม |
| **Enter** หรือ **Space** | วางจุดเมื่อ Y มีค่าแล้ว |
| **←** **→** **Home** **End** | เลื่อนเคอร์เซอร์ภายในค่าที่กำลังพิมพ์ |
| **Backspace** | ลบหน้าเคอร์เซอร์ ที่ต้น Y ที่ว่างจะกลับไปที่ X |

จุดที่อ่านเป็นตัวเลขไม่ได้จะค้างอยู่ในเทอร์มินัลให้แก้ไข ทุกจุดที่พิมพ์จะทิ้งบรรทัดในประวัติเทอร์มินัลตามที่พิมพ์ — `พิมพ์ @100<45` — ก่อนบรรทัดของคำสั่งที่บอกว่าจุดไปอยู่ที่ใด

## จุดที่พิมพ์และการติดตามมุม

เมื่อเคอร์เซอร์ล็อกอยู่บนรังสีติดตามมุม การพิมพ์ตัวเลขจะให้ระยะตามรังสีนั้นแทน X การพิมพ์ `@` ก่อนจะเริ่มจุดแบบเต็ม `@100,50` จึงใช้ได้บนรังสีที่ล็อกเช่นกัน
