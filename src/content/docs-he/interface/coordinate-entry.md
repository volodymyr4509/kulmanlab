# הזנת קואורדינטות

בכל מקום שפקודה מבקשת נקודה — תחילת [Line](../../commands/line/), פינה של [Rectangle](../../commands/rectangle/), נקודת הבסיס של [Move](../../commands/move/) או ידית שאתם גוררים — אפשר להקליד אותה במקום ללחוץ. התחילו להקליד מספר והמסוף יציג את מה שהקלדתם; לחצו **Enter** או **Space** כדי להציב את הנקודה.

## ארבע דרכים לכתוב נקודה

| אתם מקלידים | הנקודה נמצאת |
|---|---|
| `100,50` | ב-X 100, Y 50 |
| `@100,50` | 100 ב-X ו-50 ב-Y מהנקודה האחרונה |
| `100<45` | 100 מהראשית, בזווית 45° |
| `@100<45` | 100 מהנקודה האחרונה, בזווית 45° |

הזוויות במעלות, נגד כיוון השעון מציר X, כך ש-`@50<90` הוא 50 ישר למעלה ו-`@50<180` הוא 50 שמאלה. כל אחד מהערכים יכול להיות שלילי.

## הנקודה האחרונה

`@` מודד מהנקודה האחרונה שנבחרה או הוקלדה בכל פקודה — הלחיצה האחרונה של הפקודה הקודמת נחשבת, וכך גם ידית שגררתם זה עתה. כשאין עדיין נקודה אחרונה, `@100,50` נקרא כ-`100,50`. הנקודה האחרונה נשכחת כשעוברים בין מרחב המודל לפריסה, וכשנפתח שרטוט.

## Rel: יחסי כברירת מחדל

המתג **Rel** בסרגל הבקרה גורם לכל נקודה מוקלדת להתחיל כיחסית: ברגע שמקלידים את הספרה הראשונה, נוסף לפניה `@`, כך ש-`100,50` הופך ל-`@100,50`. לחצו **Backspace** מעל ה-`@` כדי להפוך את הנקודה הזו למוחלטת. כשאין עדיין נקודה אחרונה, לא נוסף `@`. Rel כבוי כברירת מחדל ונשמר יחד עם שאר המתגים בסרגל הבקרה.

## מקשים בזמן ההקלדה

| מקש | פעולה |
|---|---|
| `0`–`9`, `.`, `-` | הקלידו את המספר; `-` רק בתחילתו |
| `@` | הפכו את הנקודה ליחסית, בתחילת X |
| `,` או **Space** | סיימו את X ועברו ל-Y |
| `<` | סיימו את X כמרחק ועברו לזווית שלו |
| **Enter** או **Space** | הציבו את הנקודה כשיש ל-Y ערך |
| **←** **→** **Home** **End** | הזיזו את הסמן בתוך הערך המוקלד |
| **Backspace** | מחיקה לפני הסמן; בתחילת Y ריק, חזרה ל-X |

נקודה שאי אפשר לקרוא כמספרים נשארת במסוף כדי שתתקנו אותה. כל נקודה מוקלדת משאירה שורה בהיסטוריית המסוף כפי שהקלדתם — `הוקלד @100<45` — לפני השורה של הפקודה שמציינת היכן היא נחתה.

## נקודות מוקלדות ומעקב זווית

כשהסמן נעול לקרן של מעקב זווית, הקלדת מספר נותנת מרחק לאורך הקרן ולא X. הקלדת `@` קודם מתחילה נקודה מלאה, כך ש-`@100,50` עובד גם על קרן נעולה.
