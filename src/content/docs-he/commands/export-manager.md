# Export Manager

הפקודה `exportmanager` מורידה את השרטוט הנוכחי למערכת הקבצים שלכם. שני פורמטים זמינים, מוצגים ככרטיסים זה לצד זה: **DXF** לתאימות עם כלי CAD אחרים ו-**JSON** לשמירה באמינות מלאה בתוך KulmanLab CAD — כל כרטיס מפרט בדיוק אילו סוגי ישויות אותו פורמט נושא.

## איך לייצא

1. לחצו על כפתור **Export** בסרגל הכלים (סמל הורדה) בפאנל הקבצים, או הקלידו `exportmanager` במסוף.
2. החלון הקופץ **Export Manager** נפתח ומציג את כרטיסי JSON ו-DXF זה לצד זה, כל אחד מפרט מה מיוצא (ועבור DXF, מה מושמט).
3. לחצו על כרטיס כדי לבחור את הפורמט — **JSON** או **DXF**.
4. לחצו על כפתור **Export \<FORMAT\>**. הקובץ מורד אוטומטית לתיקיית ההורדות המוגדרת כברירת מחדל.

לחצו `Escape` כדי לסגור את החלון הקופץ מבלי לייצא.

## בחירת פורמט

| פורמט | סיומת | הכי מתאים ל | מגבלות |
|--------|-------|--------------|--------|
| **JSON** *(מקורי)* | `.json` | שמירת עבודה לפתיחה מחדש ב-KulmanLab CAD | לא תואם לכלי CAD אחרים |
| **DXF** | `.dxf` | שיתוף עם FreeCAD, LibreCAD וכו' | Hatches, מידות, מובילים וטקסט אינם מיוצאים |

**מתי להשתמש ב-JSON:** בכל פעם שתרצו לשמור עותק מלא של העבודה שלכם. JSON הוא הפורמט המקורי של KulmanLab ושומר כל ישות בדיוק — כולל מידות, מובילים, hatches וכל נתוני השכבות.

**מתי להשתמש ב-DXF:** כשאתם צריכים למסור את השרטוט למישהו שמשתמש ביישום CAD אחר. הקובץ המיוצא משתמש בפורמט DXF מסוג AC1032 וניתן לפתוח אותו ברוב הכלים התואמים ל-DXF.

## מה מיוצא לכל פורמט

### ייצוא JSON

כל סוג ישות נכלל:

- Lines, Circles, Arcs, Ellipses, Polylines, Splines
- Text
- מידות (ליניארית, מיושרת, רציפה, רדיוס, קוטר)
- Leaders (מובילים מרובים)
- Hatches, כולל הדוגמה, קנה המידה, הזווית ונקודת המוצא שלהם
- Layers ו-Linetypes

### ייצוא DXF

רק ישויות גיאומטריות נכללות:

- Lines, Circles, Arcs, Ellipses, Polylines (מיוצאות כ-`LWPOLYLINE`), Splines
- Layers ו-Linetypes

**לא מיוצא ל-DXF:** hatches, מידות, מובילים וטקסט. מידות ומובילים משתמשים במבני נתונים ייחודיים ל-KulmanLab שלא ניתן לייצג נאמנה ב-DXF סטנדרטי; hatches עדיין לא מיוצאים ל-DXF כלל, למרות שהם כן מיובאים ממנו; גם ייצוא טקסט טרם מומש. אם בשרטוט שלכם יש משהו מאלה, השתמשו ב-JSON או ב-[Print Manager](../print-manager/) כדי ללכוד אותם.

## שם הקובץ המיוצא

הקובץ שהורד נקרא על שם קובץ השרטוט הנוכחי (למשל `myplan.json`). הסיומת משתנה בהתאם לפורמט שנבחר.

## ההבדל בין Export Manager ל-Print Manager

| תכונה | Export Manager | Print Manager |
|--------|-----------------|-----------------|
| פלט | קובץ מקור וקטורי (.dxf / .json) | תמונה רסטרית (.png / .jpeg / .webp / .pdf) |
| ניתן לעריכה בכלים אחרים | כן (DXF) | לא |
| שומר על layers ו-linetypes | כן | לא (מעובד שטוח) |
| לוכד מידות ומובילים | JSON בלבד | כן |

השתמשו ב-**Export Manager** כשאתם צריכים קובץ הניתן לעריכה. השתמשו ב-[Print Manager](../print-manager/) כשאתם צריכים תמונת מצב ויזואלית.
