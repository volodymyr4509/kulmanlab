# Export Manager

הפקודה `exportmanager` מורידה את השרטוט הנוכחי אל מערכת הקבצים שלכם. שני פורמטים זה לצד זה — **DXF** לתאימות עם כלי CAD אחרים ו-**JSON** לשמירה מלאה בתוך KulmanLab CAD — ולכל אחד רשימת סימון משלו למה שייכנס לקובץ.

## איך לייצא

1. לחצו על כפתור **Export** בסרגל הכלים (סמל הורדה) בפאנל הקבצים, או הקלידו `exportmanager` במסוף.
2. חלון **Export Manager** נפתח בשתי עמודות, **JSON** ו-**DXF**, שכל אחת מונה את סוגי הישויות בשרטוט עם תיבת סימון ומספר.
3. הסירו סימון ממה שברצונכם להשאיר בחוץ. בהתחלה הכול מסומן.
4. לחצו **Export JSON** או **Export DXF**. הקובץ יורד לתיקיית ההורדות והחלון נסגר.

לחצו `Escape` כדי לסגור את החלון הקופץ מבלי לייצא.

## בחירת מה לייצא

שתי העמודות מונות את אותם סוגי ישויות, כל אחד עם מספר המופעים בשרטוט:

Lines · Circles · Arcs · Ellipses · Polylines · Splines · Text · Radius Dimensions · Diameter Dimensions · Angular Dimensions · Linear Dimensions · Leaders · Hatches

עם פתיחת החלון הכול מסומן, כך שייצוא מיידי נותן את השרטוט כולו. הסירו סימון מסוג כדי להשאיר אותו מחוץ לאותו קובץ בלבד.

- **שתי העמודות עצמאיות.** הסרת הסימון מ-Hatches תחת DXF אינה משנה את מה ש-**Export JSON** מפיק — לכל פורמט הבחירה שלו.
- **סוג שאין לכם מוצג עמום.** שורה שמספרה `0` אינה ניתנת לסימון, ולכן הרשימה משמשת גם ספירת מלאי מהירה של השרטוט.
- **המספרים הם תצלום רגע.** הם נלקחים בפתיחת החלון ואינם מתעדכנים אם השרטוט משתנה מאחור. סגרו ופתחו שוב לרענון.
- **שום דבר לא נמחק.** הסרת הסימון מעצבת רק את הקובץ המיוצא; השרטוט עצמו נשאר כשהיה.

**Linear Dimensions** מכסה מידות ליניאריות, מיושרות ורציפות: סוג ישות אחד שנוצר בשלוש פקודות שונות. רדיוס, קוטר וזווית — לכל אחד שורה משלו.

לקובץ חיתוך, הסירו סימון מ-Text, מארבע שורות המידות, מ-Leaders ומ-Hatches ולחצו **Export DXF** — ראו [הכנת DXF לחיתוך לייזר](/he/blog/prepare-dxf-for-laser-cutting/).

## בחירת פורמט

| פורמט | סיומת | הכי מתאים ל | מגבלות |
|--------|-------|--------------|--------|
| **JSON** *(מקורי)* | `.json` | שמירת עבודה לפתיחה מחדש ב-KulmanLab CAD | לא תואם לכלי CAD אחרים |
| **DXF** | `.dxf` | שיתוף עם FreeCAD, LibreCAD וכו' | כמה שורד תלוי בתוכנה שמקבלת |

**מתי להשתמש ב-JSON:** בכל פעם שתרצו לשמור עותק מלא של העבודה שלכם. JSON הוא הפורמט המקורי של KulmanLab ושומר כל ישות בדיוק — כולל מידות, מובילים, hatches וכל נתוני השכבות.

**מתי להשתמש ב-DXF:** כשאתם צריכים למסור את השרטוט למישהו שמשתמש ביישום CAD אחר. הקובץ המיוצא משתמש בפורמט DXF מסוג AC1032 וניתן לפתוח אותו ברוב הכלים התואמים ל-DXF.

## מה מיוצא לכל פורמט

### ייצוא JSON

כל סוג ישות נכלל:

- Lines, Circles, Arcs, Ellipses, Polylines, Splines
- Text
- מידות (ליניארית, מיושרת, רציפה, רדיוס, קוטר, זווית)
- Leaders (מובילים מרובים)
- Hatches, כולל הדוגמה, קנה המידה, הזווית ונקודת המוצא שלהם
- Layers ו-Linetypes

### ייצוא DXF

כל סוג ישות נכלל:

- Lines, Circles, Arcs, Ellipses, Polylines (מיוצאות כ-`LWPOLYLINE`), Splines
- Text
- מידות (ליניארית, מיושרת, רציפה, רדיוס, קוטר, זווית)
- Leaders (מובילים מרובים)
- Hatches, כולל הדוגמה, קנה המידה, הזווית ונקודת המוצא שלהם
- Layers ו-Linetypes

הקובץ נכתב כ-DXF מסוג AC1032, כך ששרטוט המיוצא מ-KulmanLab נפתח בכלים אחרים התומכים ב-DXF עם הסימונים שלו שלמים, ולא מגיע כגיאומטריה חשופה.

מה שכל תוכנה מקבלת עושה איתו בהמשך עדיין משתנה — התמיכה ב-DXF שונה מכלי לכלי, וכלי ישן עלול להתעלם מישויות שכלי חדש קורא. אם שרטוט חייב להיראות זהה בכל מקום, [Print Manager](../print-manager/) לוכד אותו כ-PDF או כתמונה במקום.

## שם הקובץ המיוצא

הקובץ שהורד נקרא על שם קובץ השרטוט הנוכחי (למשל `myplan.json`). הסיומת משתנה בהתאם לפורמט שנבחר. שרטוט שמעולם לא נקרא בשם מיוצא בשם `drawing.dxf` או `drawing.json`.

## ההבדל בין Export Manager ל-Print Manager

| תכונה | Export Manager | Print Manager |
|--------|-----------------|-----------------|
| פלט | קובץ מקור וקטורי (.dxf / .json) | תמונה רסטרית (.png / .jpeg / .webp / .pdf) |
| ניתן לעריכה בכלים אחרים | כן (DXF) | לא |
| שומר על layers ו-linetypes | כן | לא (מעובד שטוח) |
| לוכד מידות ומובילים | כן | כן |

השתמשו ב-**Export Manager** כשאתם צריכים קובץ הניתן לעריכה. השתמשו ב-[Print Manager](../print-manager/) כשאתם צריכים תמונת מצב ויזואלית.
