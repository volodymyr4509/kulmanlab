# Print Manager

הפקודה `PrintManager` פותחת את **Print Manager** — חלון ייצוא ייעודי עם קנבס תצוגה מקדימה חי, בורר פורמט (PNG / JPEG / WebP / PDF), בורר Style (Default / Monochrome / Blueprint) וחיתוך אזור אופציונלי. שום דבר לא נשלח למדפסת פיזית; הפלט מורד כקובץ.

## פתיחת Print Manager

לחצו על כפתור סרגל הכלים **Print** או הקלידו `PrintManager` במסוף. Print Manager נפתח מיידית ומציג תצוגה מקדימה של חלון התצוגה הנוכחי.

התצוגה המקדימה מעובדת בדיוק באותו נתיב קוד, ובדיוק באותה רזולוציית פיקסלים, כמו הקובץ שתייצאו בסופו של דבר — שינוי Quality, Style, או אזור הייצוא מעבד מחדש את התצוגה המקדימה מיד, כך שמה שאתם רואים הוא מה שיורד, לא קירוב שלו.

## פריסת Print Manager

לחלון יש שני פאנלים:
- **סרגל צד שמאלי** — כל בקרות הייצוא.
- **פאנל ימני** — קנבס תצוגה מקדימה חי המתעדכן בזמן שאתם משנים הגדרות.

### בקרות סרגל הצד

| בקרה | תיאור |
|---------|-------------|
| **Change Area** | חיתוך למלבן מותאם אישית על הקנבס (ראו למטה) — חותך בפועל את התמונה המיוצאת, גם בפריסה עם שטח נייר, לא רק את התצוגה המקדימה על המסך |
| תפריט נפתח **Quality** | קובע את רזולוציית הייצוא (ראו למטה) |
| תפריט נפתח **Style** | Default, Monochrome, או Blueprint — ראו *סגנונות הדפסה* למטה. Monochrome כברירת מחדל לפלט הדפסה נקי |
| תפריט נפתח **Format** | PNG, JPEG, WebP או PDF |
| כפתור **Export** | יצירת הקובץ והורדתו |

## סגנונות הדפסה

תפריט **Style** שולט הן בצבע הדיו שבו מציירים את הישויות והן ברקע העמוד:

| סגנון | דיו | רקע עמוד |
|--------|-----|-----------|
| **Default** | הצבע העצמי של כל ישות | לבן |
| **Monochrome** *(ברירת מחדל)* | שחור אחיד, ללא קשר לצבע הישות/השכבה | לבן |
| **Blueprint** | לבן אחיד, ללא קשר לצבע הישות/השכבה | כחול פרוסי עמוק, עם רשת ייחוס עדינה |

Blueprint משחזר את המראה של הדפסה אדריכלית מסורתית בסגנון ציאנוטייפ — קווים לבנים על גיליון כחול כהה. גודל רשת הייחוס שלו יחסי לגודל העמוד ולא ל-DPI, כך שהיא נראית באותה צפיפות בכל הגדרת Quality במקום להתעבות עם עליית הרזולוציה.

## איכות ורזולוציה

התפריט הנפתח **Quality** קובע את ה-DPI שבו הייצוא מעובד:

| Quality | DPI |
|---------|-----|
| Draft | 72 |
| Normal *(ברירת מחדל)* | 150 |
| Presentation | 300 |
| Max | 600 |

איכות גבוהה יותר מייצרת תמונה גדולה וחדה יותר באותו גודל פיזי — עובי הקווים משתנה יחד עם הרזולוציה, כך שקו שומר על אותו עובי *פיזי* על הנייר בכל הגדרת Quality, במקום להיראות דק יותר כשה-DPI עולה. היוצא מן הכלל היחיד הוא קו שערה (עובי קו `0`), המוגדר באופן מקובל כ"הקו הדק ביותר שמכשיר הפלט יכול לצייר" — הוא נשאר ברוחב קבוע של פיקסל אחד בכל רמת Quality, בדיוק כפי שהוא מתנהג על הקנבס החי.

שינוי Quality מעבד מחדש את התצוגה המקדימה מיד, כך שאתם רואים את החדות האמיתית (ואת הפשרה בגודל הקובץ) לפני הייצוא.

## בחירת אזור ייצוא מותאם אישית

כברירת מחדל, התצוגה המקדימה מציגה בדיוק את מה שהיה גלוי על הקנבס כאשר פתחתם את Print Manager. כדי לייצא אזור ספציפי:

1. לחצו **Change Area** — Print Manager מוסתר והקנבס הופך לאינטראקטיבי.
2. **לחצו על הפינה הראשונה** של מלבן הייצוא.
3. **לחצו על הפינה הנגדית** — Print Manager נפתח מחדש עם האזור הנבחר בתצוגה המקדימה.

לחצו `Escape` במהלך בחירת האזור כדי לבטל ולשחזר את האזור הקודם.

קנבס התצוגה המקדימה משנה גודל באופן דינמי כדי להתאים ל**יחס הרוחב-גובה המדויק** של האזור הנבחר, כך שהתצוגה המקדימה מדויקת לפיקסל.

## פורמטי ייצוא

| פורמט | אידיאלי עבור | הערות |
|--------|----------|-------|
| **PNG** | ללא אובדן, קווים חדים | רקע העמוד של ה-Style משולב, ללא שקיפות |
| **JPEG** | קובץ קטן יותר לשיתוף | איכות 95%, דחיסה קלה |
| **WebP** | הקובץ הקטן ביותר לאינטרנט | אותה איכות 95%, דחיסה טובה יותר מ-JPEG |
| **PDF** | מסמכים מוכנים להדפסה | תמונה מוטמעת בתוך מכולת PDF ב-DPI של ה-Quality שנבחרה, בגודל שגורם לעמוד להדפס בקנה מידה פיזי אמיתי |

הקובץ המיוצא נקרא `kulman-<timestamp>.<ext>` ומורד אוטומטית.

## רזולוציית ייצוא ורקע

- **ייצוא model space / viewport**: מוגבל ל-2000 × 2000 פיקסלים באיכות ברירת המחדל Normal (150 DPI), בקנה מידה פרופורציונלי לאזור הנבחר; הגבול גם הוא משתנה עם Quality — ל-Draft גבול נמוך יותר, ל-Presentation ול-Max גבול גבוה יותר (עד 8000 × 8000 ב-Max/600 DPI).
- **ייצוא layout (שטח נייר)**: בגודל שנקבע ישירות ממידות הנייר של ה-layout ב-DPI שנבחר — לדוגמה גיליון A4 (210 × 297 מ"מ) באיכות Normal מיוצא בכ-1240 × 1754 פיקסלים — ולכן אינו כפוף למגבלת ה-2000 פיקסלים של ה-viewport.
- הרקע עוקב אחר ה-**Style** של ההדפסה שנבחר — לבן עבור Default ו-Monochrome, כחול פרוסי עמוק עבור Blueprint (ראו *סגנונות הדפסה* למעלה).
- שכבות המסומנות כ**לא-מודפסות** מוחרגות מהייצוא.
