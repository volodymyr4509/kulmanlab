# TextStyle

הפקודה `סגנון` פותחת את מנהל סגנונות הטקסט. ניתן ליצור סגנונות בעלי שם, לערוך את ברירות המחדל שלהם ולבחור את הסגנון *הנוכחי*. כל [Text](../text/) חדש מעתיק את הגדרות הסגנון הנוכחי בעת יצירתו.

## שימוש במנהל

הקלידו `סגנון` או לחצו על **סגנון טקסט** בלוח ההערות. הסימן ✓ מציין את הסגנון הנוכחי; לחיצה כפולה על שורה הופכת את הסגנון הזה לנוכחי.

| שדה | פעולה |
|---|---|
| שם | שם ייחודי; אי אפשר לשנות את השם `Standard` |
| גופן / גובה | גופן וגובה קבוע; `0` = נקבע לכל טקסט |
| מודגש / נטוי | אפשרויות עיצוב עצמאיות |
| מרווח שורות | המרחק בין שורות הטקסט |
| יישור אופקי | שמאל, מרכז, ימין או יישור לשני הצדדים |
| מסגרת | מסגרת מלבנית סביב טקסט חדש |

**חדש** משכפל את הסגנון שנבחר. **מחיקה** אינה יכולה להסיר את `Standard` או את הסגנון הנוכחי. **הגדרה כנוכחי** משפיעה רק על טקסט שייווצר לאחר מכן; טקסט קיים אינו משתנה. שם ריק, כפול או לא חוקי ב־DXF משבית את **אישור**. סגנונות אנוטטיביים שיובאו מוסתרים, אך הנתונים שלהם נשמרים.

## שמירה ו־DXF

**אישור** שומר את השינויים; **סגירה** או `Escape` מבטלים אותם. השתמשו ב־`↑` וב־`↓` כדי לנוע ברשימה. שם, קובצי גופן, גובה, הדגשה, נטייה ודגל אנוטטיבי הם חלק מסגנון הטקסט של DXF. מסגרת, מרווח שורות ויישור הם ברירות מחדל לכל טקסט ב־KulmanLab, ולא שדות בטבלת STYLE.

ראו גם [Text](../text/), [FontManager](../font-manager/) ו־[MatchProperties](../match-properties/).
