# Fillet

פקודת `עיגולפינה` מעגלת פינה בין שני קטעי [Line](../line/), [Arc](../arc/) או [Polyline](../polyline/) על ידי הכנסת קשת משיקה ברדיוס נתון, וגוזרת (או ממזגת) את הישויות הנבחרות עד לאותה נקודה.

Fillet פועלת על ישויות **Line, Arc ו-Polyline** — כולל קטעים ישרים או קטעי קשת של פוליליין עצמו.

## שימוש ב-Fillet

1. הקלידו `עיגולפינה` במסוף או לחצו על כפתור סרגל הכלים **Fillet**.
2. **הקלידו את רדיוס ה-fillet** ולחצו **Enter**.
3. **לחצו על הקו, הקשת או קטע הפוליליין הראשון** — החלק שאתם לוחצים עליו קובע איזה צד של כל חיתוך נשמר.
4. **רחפו מעל הישות השנייה** — תצוגה מקדימה של קשת מקווקוות מציגה את ה-fillet שינבע. הזיזו את הסמן לצד שברצונכם לשמור.
5. **לחצו** כדי להחיל.

```
  לפני:                        אחרי fillet (רדיוס r):

  ──────────────              ──────────╮
                │                        ╰────
                │
```

## בחירת צד לישויות מצטלבות

כאשר שתי ישויות חוצות זו את זו, ה-fillet מוחל על הפינה המוגדרת על ידי מיקומי הלחיצה — החלק של כל ישות ב**אותו צד כמו הסמן** נשמר.

- לחצו קרוב לאחד הקצוות של הישות הראשונה כדי לבחור את החצי ההוא.
- הזיזו את הסמן לחצי הרצוי של הישות השנייה — התצוגה המקדימה המקווקוות מתעדכנת בזמן אמת.

## מה הפקודה יוצרת

התוצאה תלויה במה שבחרתם:

- **שתי ישויות Line/Arc עצמאיות**, או כל זוג שלא כולל פוליליין פתוח: שתיהן נגזרות בחזרה לנקודות ההשקה **T1**/**T2**, וישות Arc חדשה מוכנסת ביניהן.
- **שני קטעים של אותו פוליליין החולקים קודקוד פינה**: אין ישות חדשה — ה-fillet הופך לחלק מהפוליליין עצמו. קודקוד הפינה מוחלף בשתי נקודות ההשקה, והקשת ביניהן נשמרת כ-bulge של אותה צלע — בדיוק כפי שפינת פוליליין מעוגלת עוברת הלוך ושוב דרך DXF.
- **כל השאר שכולל פוליליין פתוח** — שני פוליליינים פתוחים שונים, או פוליליין פתוח וישות Line/Arc עצמאית: שניהם ממוזגים ל**פוליליין חדש יחיד**, כשכל צד נשמר עד לנקודת ההשקה שלו ומחובר בקשת ה-fillet כקטע bulge נוסף, במקום הישויות המקוריות.

הקשת שהוכנסה או הוארכה יורשת את הגדרות עובי הקו, הצבע, השכבה וסוג הקו הנוכחיים (או אלה של הפוליליין עצמו, כשהיא מצטרפת אליו).

## פינות ללא זווית אמיתית לעיגול

אם שני הקטעים הנבחרים כבר נפגשים באופן משיק בקודקוד משותף — פינת פוליליין ישרה, או קו שעובר בחלקות לקטע קשת של המשכיות משיקה — אין פינה אמיתית שמעגל יכול לעגל. Fillet מזהה זאת ומסרבת עם ההודעה `cannot fillet: no tangent circle fits there` במקום לצייר לולאה לא רצויה.

## מרגע לוח המקשים

| מקש | פעולה |
|-----|--------|
| `0`–`9`, `.` | הוספת ספרה לערך הרדיוס |
| `Backspace` | מחיקת התו האחרון שהוקלד |
| `Enter` / `Space` | אישור הרדיוס שהוקלד ומעבר לבחירת ישות |
| `Escape` | ביטול ואיפוס |

## ישויות נתמכות

| ישות | נתמך |
|--------|-----------|
| Line | כן |
| Arc | כן |
| Polyline (קטע ישר או קשת) | כן |
| Circle, Ellipse | לא |
| Text, Spline, Dimension, Leader | לא |
