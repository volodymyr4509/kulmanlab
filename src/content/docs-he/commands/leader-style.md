# LeaderStyle

הפקודה `סגנון` פותחת את מנהל סגנונות הקו המוביל בעלי השם. כל [Leader](../leader/) חדש מעתיק בעת יצירתו את הגדרות הסגנון *הנוכחי*.

## עריכת סגנון

הקלידו `סגנון` או לחצו על **סגנון קו מוביל** בלוח ההערות. הסימן ✓ מציין את הסגנון הנוכחי; השתמשו בעיפרון שליד השם כדי לשנותו. התצוגה המקדימה מתעדכנת מיד באמצעות אותו מנגנון ציור של השרטוט.

| שדה | פעולה |
|---|---|
| חיבור טקסט | עליון, אמצעי, תחתון או קו תחתון |
| ראש חץ / גודל חץ | הסמל והגודל בקצה כל זרוע |
| מרווח חיבור | המרחק בין החיבור לטקסט |
| סיבוב טקסט | זווית התווית במעלות |
| סגנון טקסט | העתקה חד־פעמית של גופן, גובה, הדגשה ונטייה מתוך [TextStyle](../text-style/) |
| גופן / גובה טקסט | הגופן והגובה של התווית |
| מודגש / נטוי | עיצוב טקסט עצמאי |
| מסגרת טקסט | מסגרת מלבנית סביב התווית |

**חדש** משכפל את הסגנון שנבחר. אי אפשר לשנות את השם `Standard` או למחוק אותו; גם את הסגנון הנוכחי אי אפשר למחוק. **הגדר כנוכחי** משפיע רק על קווים שייווצרו לאחר מכן — עצמים קיימים אינם משתנים. שם ריק, כפול או לא חוקי ב־DXF משבית את **אישור**. סגנונות אנוטטיביים שיובאו מוסתרים אך נשמרים.

## שמירה ו־DXF

**אישור** מחיל את כל השינויים; **סגירה** או `Escape` מבטלים אותם. KulmanLab קורא וכותב רשומות `MLEADERSTYLE`. שם, ראש וגודל חץ, מרווח, גובה, חיבור, מסגרת ודגל אנוטטיבי נשמרים כשדות סגנון. סיבוב, גופן, הדגשה ונטייה הם ברירות מחדל של KulmanLab שמועתקות לקו בעת יצירתו.

ראו גם [Leader](../leader/), [LeaderAdd](../leader-add/) ו־[LeaderRemove](../leader-remove/).
