# Array Polar

הפקודה `ArrayPolar` יוצרת עותקים של האובייקטים הנבחרים סביב נקודת מרכז, מפוזרים באופן שווה על סיבוב מלא או חלק ממנו. המקור הוא הפריט הראשון; כל פריט אחר הוא עותק שסובב סביב המרכז — או רק הוזז סביבו, אם כיבית את Rotate.

## יצירת מערך קוטבי

1. בחרו את האובייקטים ואז הקלידו `arraypolar` במסוף או לחצו על הכפתור **Array Polar** בסרגל הכלים. אם הופעלה ללא בחירה, היא מבקשת קודם לבחור אותם — אשרו ב-**Enter** או **Space**.
2. **לחצו על המרכז** שסביבו העותקים מקיפים, או הקלידו `X,Y` ולחצו **Enter** לקואורדינטה מדויקת.
3. בדקו את המערך. כל העותקים מוצגים בתצוגה מקדימה חיה והמסוף מציג `Change [Items=6] [Angle=60°] [Fill=360°] [Rotate=true]` — לחצו על אות האפשרות כדי לשנות אותה.
4. לחצו **Enter** או **Space** כדי ליצור את העותקים. המקורות נשארים במקומם והבחירה מתבטלת.

## אפשרויות

| אפשרות | מקש | השפעה |
|---|---|---|
| Items | `I` | כמה פריטים יש, כולל המקור — מספר שלם מ-2 עד 1024. מתחיל ב-6. |
| Angle | `A` | מעלות מפריט אחד לבא אחריו, נגד כיוון השעון; זווית שלילית נעה עם כיוון השעון. עד 180°. |
| Fill | `F` | מעלות מהפריט הראשון לאחרון. 360 (ברירת מחדל) הוא סיבוב מלא; מספר קטן יותר מפזר את הפריטים על חלק ממנו. שלילי נע עם כיוון השעון. עד 360°. |
| Rotate | `R` | מופעל (ברירת מחדל): כל עותק מסתובב תוך כדי הקפה. כבוי: כל עותק מוזז למקומו ופונה לאותו כיוון כמו המקור. מתחלף במקום — אין מספר להקליד. |

- Angle ו-Fill הן שתי דרכים לומר אותו דבר, ולכן שינוי אחת מנסח מחדש את השנייה. על סיבוב מלא הפריט האחרון נעצר צעד אחד לפני הראשון; על חלק מסיבוב הוא נוחת בדיוק בזווית המילוי.
- כדי לשנות מספר, לחצו על אות האפשרות שלו. ההנחיה ממולאת מראש בערך הנוכחי — הקלידו כדי להחליפו ולחצו **Enter** או **Space**; אישור ללא שינוי משאיר את המערך כפי שהיה.
- Items מקבל מספרים שלמים בלבד; Angle ו-Fill מקבלים עשרוניים ו-`-` בתחילה לכיוון השעון. זווית או מילוי של 0 נדחים, וכך גם זווית מעל 180° או מילוי מעל 360° — המסוף מסביר מדוע.
- Angle קטן מדי מכדי להכיל את כל הפריטים משמיט את אלה שאין להם מקום, והמסוף מדווח על המספר החדש.
- פועלת על כל סוגי הישויות: כל עותק הוא המקור מסובב סביב המרכז, או מוזז, בדיוק כפי ש-[Rotate](../rotate/) ו-[Move](../move/) היו עושים.

## מקשי קיצור

| מקש | פעולה |
|---|---|
| `Enter` / `Space` | אישור הבחירה, המערך או מספר שהוקלד |
| `I` `A` `F` `R` | שינוי Items, Angle או Fill בהקלדת מספר; החלפת Rotate |
| `0`–`9`, `.`, `-` | הקלדת המספר (`.` ו-`-` רק עבור Angle ו-Fill, כש-`-` ראשון) |
| `Backspace` | מחיקת התו האחרון שהוקלד |
| `Escape` | ביטול |
