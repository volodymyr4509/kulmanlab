# ClipboardCopy

הפקודה `ClipboardCopy` כותבת את הישויות הנבחרות **ללוח של המערכת** שלכם כטקסט JSON. מכיוון שהיא משתמשת בלוח האמיתי ולא במאגר בזיכרון, הגאומטריה המועתקת שורדת מחוץ לשרטוט: הדביקו אותה לקובץ אחר, ללשונית דפדפן שנייה או לחלון שתפתחו מאוחר יותר, בעזרת [ClipboardPaste](../clipboard-paste/).

זה ההבדל מ-[Copy](../copy/): Copy משכפלת ישויות בתוך השרטוט הנוכחי בתנועה אחת, ואילו ClipboardCopy מניחה אותן במקום שממנו אפשר לאחזר אותן משרטוט אחר לגמרי.

## שתי דרכים להתחיל

**בחירה תחילה, ואז העתקה** — המסלול המהיר:

1. בחרו ישות אחת או יותר על משטח השרטוט.
2. הקישו `Ctrl+C` (או `Cmd+C` ב-macOS), או הקלידו `ClipboardCopy` בטרמינל.
3. הישויות נכתבות ללוח מיד והפקודה מסתיימת.

**הפעלה תחילה, ואז בחירה** — התחלה בלי שנבחר דבר:

1. הקישו `Ctrl+C` או הקלידו `ClipboardCopy` כשהבחירה ריקה.
2. השורה מציגה **pick objects to copy — Enter or Space to confirm**.
3. **בחרו אובייקטים** — לחצו כדי להכניס ישות בודדת לבחירה או להוציא אותה, או גררו כדי לבחור לפי אזור.
4. הקישו **Enter** או **Space** כדי להעתיק את הבחירה ולצאת.

הקשה על **Enter** או **Space** כשלא נבחר דבר פשוט מסיימת את הפקודה בלי לגעת בלוח.

## מה מועתק

תוכן הלוח נושא יותר מגאומטריה בלבד, כדי שהדבקה לשרטוט זר עדיין תיראה נכון:

| רכיב | תפקיד |
|------|-------|
| **ישויות** | הצורה המסודרת המלאה של כל ישות נבחרת |
| **נקודת ייחוס** | הפינה השמאלית התחתונה של התוחם המשולב של הבחירה — מה ש-ClipboardPaste מעגן לסמן |
| **שכבות** | רק השכבות שהישויות המועתקות באמת מפנות אליהן, לפי שם |
| **סוגי קו** | רק סוגי הקו שהישויות המועתקות באמת מפנות אליהם, לפי שם |

עם ההעתק נוסעות רק רשומות טבלה *שיש אליהן הפניה* — לא טבלאות השכבות וסוגי הקו המלאות של שרטוט המקור. תבניות מילוי אינן נארזות כלל ואין בכך צורך: טבלת התבניות של שרטוט היא ערכת ברירת המחדל המובנית, וקובצי `.pat` שהעליתם שוכנים במאגר לכל משתמש שכבר משותף בין לשוניות, כך שמילוי שהודבק מוצא את התבנית שלו בעצמו.

## אישור

בהצלחה, הטרמינל מדווח כמה ישויות נכתבו:

```
3 entities copied to clipboard
```

אם הדפדפן מסרב לגישה ללוח, הטרמינל מציג **Copy failed: clipboard access denied** ודבר אינו נכתב. זו החלטת הרשאות של הדפדפן, לא שגיאה בשרטוט — ראו [הרשאות הלוח](#הרשאות-הלוח) בהמשך.

## בחירה במהלך הפקודה

| שיטה | התנהגות |
|------|---------|
| **לחיצה** | מכניסה את הישות שמתחת לסמן לבחירה או מוציאה אותה |
| **גרירה ימינה** (מחמירה) | מוסיפה ישויות שנמצאות כולן בתוך המסגרת |
| **גרירה שמאלה** (חוצה) | מוסיפה ישויות שחוצות את גבול המסגרת |
| **Enter** / **Space** | מאשרת את הבחירה ומעתיקה |

## מקשים

| מקש | פעולה |
|-----|-------|
| `Ctrl+C` / `Cmd+C` | הפעלת ClipboardCopy |
| `Enter` / `Space` | העתקת הבחירה הנוכחית, או יציאה אם לא נבחר דבר |
| `Escape` | ביטול בלי להעתיק |

## הרשאות הלוח

כתיבה ללוח של המערכת מחייבת הרשאה מהדפדפן. בפועל, העתקה שהופעלה בהקשת מקש מאושרת ללא שאלה בדפדפני שולחן עבודה עדכניים, אבל דף שאיבד מיקוד, או דפדפן עם הגדרות לוח מחמירות, עלול לסרב. אם מופיעה הודעת הגישה שנדחתה, לחצו פעם אחת על משטח השרטוט כדי להחזיר מיקוד לדף ונסו שוב.

מכיוון שהתוכן הוא טקסט JSON רגיל, כל דבר אחר שתעתיקו אחריו יחליף אותו — שורת טקסט או קישור. העתיקו שוב לפני ההדבקה אם השתמשתם בלוח למשהו אחר בינתיים.

## ישויות נתמכות

ClipboardCopy עובדת עם כל סוגי הישויות. הישויות מסודרות באותו מנגנון שבו משתמש הייצוא המובנה `.json`, כך שדבר אינו אובד בדרך.
