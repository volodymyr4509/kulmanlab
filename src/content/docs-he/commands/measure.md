# Measure

הפקודה `מדידה` קוראת את השרטוט סביב הסמן בזמן שמזיזים אותו, בלי נקודות לבחור: כמה רחוק הגיאומטריה הקרובה ביותר, כמה ארוכה או עגולה היא, ובאיזו זווית קווים נפגשים. לחיצה בתוך אזור סגור נותנת את שטחו והיקפו. דבר בשרטוט לא משתנה.

## מדידה

1. הקלידו `מדידה` במסוף או לחצו על **Measure**, הכפתור הראשון בחלונית Measure.
2. **הזיזו את הסמן.** ממנו הפקודה מביטה ימינה, למעלה, שמאלה ולמטה אחר הגיאומטריה הקרובה ומציגה מה שמצאה.
3. **לחצו בתוך אזור סגור** כדי למלא אותו ולקרוא את שטחו והיקפו — ראו להלן.
4. לחצו **Enter**, **Space** או **Escape** לסיום.

## מה היא מציגה

- **מרחק לרוחב** — ממה שהסמן פוגש בצד אחד אל מה שהוא פוגש בצד השני, אופקית ואנכית. אם רק בצד אחד יש משהו, המרחק נמשך מהסמן. לכל קצה שפוגש משהו יש נקודה קטנה מלאה; לקצה בסמן אין.
- **אורך או רדיוס** — כל אובייקט שהפקודה מגיעה אליו מודגש עם אורכו, או רדיוסו כשהוא חלק ממעגל.
- **זווית** — היכן ששני קווים ישרים שהושגו נפגשים, נכתבת הזווית ביניהם; זווית ישרה מסומנת בריבוע קטן.

אורכים וזוויות נכתבים כפי שה-[DimensionStyle](../dimension-style/) הנוכחי כותב אותם, בפורמט היחידות והדיוק שלו.

## שטח והיקף

לחיצה בתוך אזור סגור ממלאת אותו ומציבה את שטחו והיקפו בהנחיה ובהיסטוריה. האזור נמצא כפי ש-[Hatch](../hatch/) מוצא אזור: קווים נפרדים הנפגשים קצה בקצה סוגרים אזור בדיוק כמו polyline, וכל מה שסגור בתוכו מושמט כאי — שפתו נספרת בהיקף ושטחו מופחת.

השטח הוא מספר פשוט ביחידות שרטוט רבועות — רגל ואינץ' אינם יכולים לכתוב שטח — בעוד ההיקף עוקב אחר פורמט היחידות. לחצו בתוך אזור אחר כדי למדוד אותו. אם שום דבר סגור אינו מקיף את הנקודה, המסוף מסביר מדוע באותן הודעות של Hatch: no boundary found, point is not enclosed או boundary is open.

## טוב לדעת

- היא מודדת ביחס לקווים, קשתות, מעגלים, אליפסות, polylines וספליינים; אורכים ושטחים מדויקים, גם לאליפסות ולספליינים.
- אובייקטים בשכבות קפואות מתעלמים מהם; אובייקטים בשכבות נעולות נמדדים.
- בשרטוט גדול היא מביטה רק במה שקרוב לסמן, ולכן נשארת מגיבה.
