# FontAdd

הפקודה `הוספתגופן` פותחת את בורר הקבצים של המערכת להעלאת גופן `.ttf` מותאם אישית, מבלי לפתוח קודם את דיאלוג [Font Manager](../font-manager/). זו אותה העלאה שכפתור **Add Font** ב-Font Manager מפעיל — FontAdd היא פשוט דרך ישירה אליה מהמסוף.

## העלאת גופן

1. הקלידו `הוספתגופן` במסוף, או לחצו על **Add Font** בכותרת התחתונה של דיאלוג [Font Manager](../font-manager/).
2. בחרו קובץ `.ttf` בבורר המערכת. רק גופני TrueType נתמכים — `.otf` ו-`.woff`/`.woff2` אינם נתמכים.

הפקודה מסתיימת ברגע שבורר הקבצים נפתח — לא נדרשת לחיצה נוספת או הקלדה במסוף. הגופן נרשם ומופיע בקבוצת **User** ברגע שהקובץ נבחר.

## מה קורה בעת ההעלאה

- שם הקובץ (ללא הסיומת) הופך לשם הגופן. העלאת `MyFont.ttf` מוסיפה גופן בשם `MyFont`.
- העלאת קובץ ששמו תואם לגופן מותאם אישית קיים **מחליפה** אותו.
- הגופן נשמר לצמיתות בדפדפן (IndexedDB) ונטען מחדש אוטומטית בפעם הבאה שתפתחו את KulmanLab CAD — הוא אינו קשור לשרטוט הנוכחי.

## מרגע לוח המקשים

ל-FontAdd אין אינטראקציית מקלדת משלה — כל הפקודה מורכבת מדיאלוג בורר הקבצים הטבעי של הדפדפן. ביטול אותו דיאלוג (או אי-בחירת קובץ) משאיר את רשימת הגופנים ללא שינוי.
