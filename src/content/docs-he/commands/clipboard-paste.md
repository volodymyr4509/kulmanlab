# ClipboardPaste

הפקודה `הדבקהמהלוח` קוראת את הישויות ש-[ClipboardCopy](../clipboard-copy/) כתבה **ללוח של המערכת** ומניחה אותן בשרטוט הנוכחי בנקודה שאתם בוחרים. מכיוון שהלוח הוא הלוח האמיתי של המערכת, המקור יכול להיות שרטוט אחר, לשונית דפדפן אחרת או הפעלה מוקדם יותר באותו יום.

## איך מדביקים

1. הקישו `Ctrl+V` (או `Cmd+V` ב-macOS), או הקלידו `הדבקהמהלוח` בטרמינל.
2. השורה מציגה **reading clipboard…** בזמן שהדפדפן מוסר את טקסט הלוח.
3. עם סיום הטעינה השורה משתנה ל-**pick insertion point**, ותצוגה מקדימה של הגאומטריה עוקבת אחר הסמן.
4. **לחצו** כדי להניח את הישויות. הן נוספות לשרטוט ונשארות מסומנות.

התצוגה המקדימה מעוגנת ב**נקודת הייחוס** של ההעתק — הפינה השמאלית התחתונה של התוחם המשולב של הבחירה המקורית. אותה פינה נמצאת מתחת לסמן, ולכן הסידור היחסי בין הישויות המועתקות נשמר במדויק.

## מה קורה בהדבקה

| שלב | התנהגות |
|-----|---------|
| **זהויות חדשות** | כל ישות שהודבקה מקבלת מזהה חדש, כך ששתי הדבקות מניבות שתי קבוצות בלתי תלויות |
| **הזזה** | הישויות מוזזות במידה של סמן − נקודת ייחוס |
| **מיזוג שכבות** | כל שכבה שיש אליה הפניה וחסרה בשרטוט היעד מתווספת לפי שם |
| **מיזוג סוגי קו** | כל סוג קו שיש אליו הפניה וחסר בשרטוט היעד מתווסף לפי שם |
| **בחירה** | הבחירה הקודמת מתנקה והישויות שהודבקו הופכות לבחירה |

### מיזוג שכבות וסוגי קו

רשומות טבלה חסרות מתווספות; **הקיימות נשארות כשהיו**. אם הלוח נושא שכבה בשם `WALLS` באדום ובשרטוט היעד כבר יש `WALLS` בכחול, ההגדרה של היעד גוברת והישויות שהודבקו מצטרפות אליה — כלומר יהיו כחולות. הדבקה אינה מגדירה מחדש דבר בשרטוט היעד.

זה משנה כשמעתיקים בין שרטוטים עם מוסכמות שכבות שונות: בדקו את [Layer Manager](../layer-manager/) אחרי הדבקה בין שרטוטים אם הצבעים אינם כפי שציפיתם.

## כשאין בלוח מה להדביק

ClipboardPaste מקבלת רק תוכן ש-ClipboardCopy יצרה. כל דבר אחר בלוח — טקסט רגיל, קישור, תמונה, JSON מיישום אחר — נדחה והטרמינל מדווח:

```
Clipboard has no copied entities
```

אם הדפדפן מסרב לגישה ללוח לחלוטין, ההודעה היא **Clipboard access denied**. שתיהן מסיימות את הפקודה בלי לשנות את השרטוט.

## מקשים

| מקש | פעולה |
|-----|-------|
| `Ctrl+V` / `Cmd+V` | הפעלת ClipboardPaste |
| `Escape` | ביטול — הישויות נזרקות ודבר אינו נוסף |

ביטול בשלב הקריאה בטוח: אם הלוח משיב רק אחרי שכבר ביטלתם או התחלתם פקודה אחרת, התוצאה המאחרת נזרקת במקום להפריע למה שפעיל אז.

## העתקה בין לשוניות

זרימת העבודה הרגילה בין שרטוטים:

1. פתחו את שרטוט המקור, סמנו את הגאומטריה, הקישו `Ctrl+C`.
2. עברו ללשונית האחרת — או פתחו לשונית שנייה של היישום וטענו קובץ אחר.
3. הקישו `Ctrl+V` ולחצו על נקודת הוספה.

לשתי הלשוניות מקור זהה והן חולקות את לוח המערכת, ולכן דבר אינו מועלה ואף שרת אינו מעורב. התוכן נשאר טקסט JSON בלוח שלכם לאורך כל הדרך.

## ישויות נתמכות

כל סוג ישות ש-ClipboardCopy יכולה לכתוב, ClipboardPaste יכולה לקרוא בחזרה — באותו סידור שבו משתמש הפורמט המובנה `.json`.
