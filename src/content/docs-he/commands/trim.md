# Trim

פקודת `קיטום` מסירה את החלק של [Line](../line/), [Arc](../arc/), [Circle](../circle/), [Ellipse](../ellipse/) או [Polyline](../polyline/) הנמצא בין שתי נקודות חיתוך סמוכות, ומפצלת את הישות לחלק אחד או יותר שנותרים. הקטע שייגזר נקבע על ידי מיקום הסמן — רחפו מעל החלק שברצונכם להסיר ולחצו כדי לגזור אותו.

## גיזום ישות

1. הקלידו `קיטום` במסוף או לחצו על כפתור סרגל הכלים **Trim**.
2. **רחפו מעל הקטע** שברצונכם להסיר — תצוגה מקדימה מדגישה בדיוק את החלק שייגזר.
3. **לחצו** כדי להסיר את הקטע הזה.

הפקודה נשארת פעילה לאחר כל גיזום, כך שתוכלו להמשיך לרחף וללחוץ כדי לגזור עוד קטעים — על אותה ישות או על ישות אחרת. לחצו **Enter**, **Space** או **Escape** ליציאה.

```
  לפני:                       אחרי גיזום הקטע האמצעי:

  ──────●──────●──────        ──────●          ●──────
      חיתוך     חיתוך          (חלק שמאלי)  (חלק ימני)
                                 (הקטע האמצעי הוסר)
```

## איך נקבע קטע הגיזום

הפקודה מקרינה את מיקום הסמן על הישות שרחפתם מעליה ומוצאת את כל נקודות החיתוך שלישות זו יש עם ישויות אחרות. חיתוכים אלה מחלקים את הישות לקטעים — עבור Line, Arc או Polyline פתוחה, נקודות הקצה של הישות עצמה משמשות כגבולות קבועים נוספים. ל-Circle או Ellipse מלאים, או ל-Polyline סגורה (כולל Rectangle), אין נקודות קצה משלהם, כך שנדרשות לפחות שתי נקודות חיתוך לפני שניתן בכלל לגזור אותם. הקטע שהמרווח שלו מכיל את ההקרנה של הסמן מודגש ויוסר בלחיצה.

- **Line, Arc ו-Polyline פתוחה** — הקטע המוסר יכול להיות החלק המוביל (לפני נקודת החיתוך הראשונה), חלק אמצעי (בין שתי נקודות חיתוך, מפצל את הישות לשניים), או החלק הנגרר (אחרי נקודת החיתוך האחרונה).
- **Circle, Ellipse ו-Polyline סגורה/Rectangle** — מכיוון שאין התחלה או סוף קבועים, ניתן להסיר רק את הקשת שבין שתי *נקודות חיתוך*. עם פחות משתי נקודות חיתוך, לא מוצגת תצוגה מקדימה ולחיצה לא עושה דבר. שאר הצורה הופכת לחלק היחיד שנותר.

## מה גיזום מייצר

| ישות | תוצאה אחרי גיזום |
|--------|------------------------|
| Line | עד שתי ישויות Line קצרות יותר |
| Arc | עד שתי ישויות Arc קצרות יותר |
| Circle | ישות [Arc](../arc/) אחת — הצורה הסגורה של המעגל נעלמת, כך שהחלק שנותר נשמר כקשת |
| Ellipse | ישות Ellipse אחת עם זווית התחלה וסיום — החלק שנותר נשאר Ellipse, כעת חלקי |
| Polyline (פתוחה) | עד שתי ישויות Polyline קצרות יותר |
| Polyline (סגורה) / Rectangle | ישות Polyline פתוחה אחת — הצורה הסגורה נעלמת, כך שהחלק שנותר נשמר פתוח |
| Spline | עד שני אובייקטי Spline קצרים יותר — כל חלק הוא אותה עקומה על קטע קטן יותר ממנה, הנשמרת באמצעות קודקודי בקרה (נקודות ההתאמה של ספליין Fit נזרקות); ספליין סגור משאיר חלק פתוח אחד |

## ישויות נתמכות

| ישות | ניתן לגזור? |
|--------|----------------|
| Line | כן |
| Arc | כן |
| Circle | כן — דורש 2 נקודות חיתוך או יותר |
| Ellipse | כן — דורש 2 נקודות חיתוך או יותר |
| Polyline (פתוחה) | כן |
| Polyline (סגורה) / Rectangle | כן — דורש 2 נקודות חיתוך או יותר |
| Spline | כן — ספליין סגור דורש 2 נקודות חיתוך או יותר |
| Text, Dimension, Leader | לא |

האובייקטים המשמשים כ**גבולות חיתוך** יכולים להיות Line,‏ Arc,‏ Circle,‏ Ellipse,‏ Polyline או Spline. אובייקטי Text,‏ Dimension ו-Leader אינם רושמים חיתוכים, ולכן אינם יכולים לשמש גבולות.

**קטעי הקשת** של Polyline (מצוירים באמצעות מתג Arc, או מיובאים) נגזמים בדיוק כמו הקטעים הישרים שלה — רחפו מעל חלק הקשת בין שתי חיתוכים ולחצו. הקצה שנגזם שומר על העקמומיות שלו; רק האורך שלו משתנה.
