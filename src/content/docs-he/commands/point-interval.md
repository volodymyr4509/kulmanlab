# Point Interval

הפקודה `נקודותבמרווח` מציבה [נקודות](../point/) במרווח קבוע לאורך אובייקט, כמו סימון תחנות לאורך מסלול. האובייקט עצמו אינו משתנה: הנקודות הן ישויות חדשות בשכבה ובצבע הנוכחיים, נוחות להצמדה.

## הצבת נקודות במרווחים

1. הקלידו `נקודותבמרווח` במסוף או בחרו **Point Interval** מהתפריט הנפתח של המערכים בחלונית Edit.
2. **לחצו על האובייקט ליד הקצה שממנו מתחילים** — קו, polyline, קשת, מעגל, אליפסה או ספליין. כל דבר אחר נדחה, ואפשר לבחור שוב.
3. **הקלידו את אורך המרווח.** הנקודות מוצגות על האובייקט בזמן ההקלדה.
4. לחצו **Enter** או **Space** כדי להציב אותן. הפקודה מסתיימת.

## היכן הנקודות נופלות

- הנקודה הראשונה נופלת מרווח אחד מההתחלה והשאר באות במרווח אחד זו מזו, נמדדות לאורך האובייקט כולל עקומות. על ההתחלה עצמה לא מוצבת נקודה.
- באובייקט פתוח — קו, polyline פתוח, קשת, אליפסה חלקית או ספליין פתוח — המדידה מתחילה מהקצה שלידו לחצתם. מה שנשאר בקצה הרחוק אינו מסומן: הקצה הרחוק מקבל נקודה רק כשהמרווח מתחלק בדיוק.
- באובייקט סגור — מעגל, polyline סגור, אליפסה שלמה או ספליין סגור — המדידה מתחילה מההתחלה של האובייקט עצמו, היכן שלא תלחצו: מעגל מזווית 0 נגד כיוון השעון, polyline סגור מהקודקוד הראשון שלו. הנקודות נעצרות לפני ההתחלה.
- אורך של 0 או פחות, ארוך מהאובייקט, או כזה שייתן יותר מ-32767 נקודות נדחה: המסוף מסביר מדוע ומוחק אותו כדי שתקלידו שוב.

Backspace מוחק את התו האחרון. Escape מתחיל מחדש, כדי לבחור אובייקט אחר. Enter או Space לפני בחירת אובייקט מסיימים את הפקודה.
