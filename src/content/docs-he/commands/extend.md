# Extend

פקודת `הארכה` מארכת את נקודת הקצה הקרובה ביותר של [Line](../line/), [Arc](../arc/), [Ellipse](../ellipse/) או Polyline פתוחה שרחפתם מעליה לחיתוך הקרוב ביותר שהיא הייתה יוצרת עם ישות אחרת בשרטוט. רחפו קרוב לנקודת הקצה שברצונכם להאריך — תצוגה מקדימה מציגה את הישות המוארכת — ואז לחצו כדי להחיל.

רק ישויות עם נקודת קצה אמיתית ניתנות להארכה. [Circle](../circle/) ו-Ellipse מלאה (360°) הן תמיד צורות סגורות ללא נקודת קצה, ולכן לעולם אי אפשר להאריך אותן — כך גם Polyline סגורה או Rectangle. Ellipse חלקית (קשת אליפטית) ו-Arc יש להן נקודות קצה והן מתארכות באותו אופן כמו Line.

## הארכת ישות

1. הקלידו `הארכה` במסוף או לחצו על כפתור סרגל הכלים **Extend**.
2. **רחפו קרוב לאחד מקצוות** הישות שברצונכם להאריך — התצוגה המקדימה מציגה אותה מוארכת לגבול הקרוב ביותר בכיוון זה.
3. **לחצו** להחלת ההארכה.

הפקודה נשארת פעילה לאחר כל הארכה, כך שתוכלו להמשיך לרחף וללחוץ כדי להאריך עוד ישויות. לחצו **Enter**, **Space** או **Escape** ליציאה.

```
  לפני:                         אחרי:

  ──────           |           ──────────────|
  (קו קצר)         (גבול)       (מוארך לגבול)
```

## איך נבחרת נקודת הקצה

הפקודה בוחנת לאיזה קצה הסמן קרוב יותר:

- **Line ו-Polyline פתוחה** — הסמן קרוב יותר לנקודת הסיום מאריך את הסיום קדימה; הסמן קרוב יותר לנקודת ההתחלה מאריך את ההתחלה אחורה.
- **Arc ו-Ellipse חלקית** — הסמן קרוב יותר לאחד מהקצוות הזוויתיים גורם לקשת לגדול בכיוון זה, סביב אותו מרכז ורדיוס (או אותה צורת אליפסה), עד שהיא מגיעה לגבול הבא.

קרן — או, עבור Arc ו-Ellipse, המעגל או העקומה הבסיסית של הישות עצמה — נורית מהקצה שנבחר, וה**חיתוך הקרוב ביותר** עם ישות אחרת כלשהי (למעט הישות עצמה והסוגים המוחרגים) הופך לנקודת הקצה החדשה.

אם לא נמצא חיתוך בכיוון זה, לא מופיעה תצוגה מקדימה ולחיצה לא עושה דבר.

## החרגות גבול

סוגי הישויות הבאים מוחרגים כגבולות — ישות לא מתארכת כדי לפגוש אותם:

- Text / Mtext
- Multileader
- Spline

כל שאר הסוגים (Line, Arc, Circle, Ellipse, Polyline, Dimension) משמשים כגבולות תקפים.

אם הקטע הראשון או האחרון של Polyline הוא עצמו קטע קשת (מצויר באמצעות מתג Arc), הארכתו מגדילה את הקשת לאורך המעגל שלה — בדיוק כמו הארכת Arc עצמאי — במקום להתייחס אליו כקטע ישר.

## ישויות נתמכות

| ישות | ניתן להאריך? |
|--------|----------------|
| Line | כן |
| Arc | כן |
| Ellipse | כן — רק אם היא כבר קשת חלקית; לאליפסה מלאה אין נקודת קצה |
| Circle | לא — תמיד צורה סגורה ללא נקודת קצה |
| Polyline (פתוחה) | כן |
| Polyline (סגורה) / Rectangle | לא — תמיד צורה סגורה ללא נקודת קצה |
| Text, Spline, Dimension, Leader | לא |
