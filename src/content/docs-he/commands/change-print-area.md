# ChangePrintArea

פקודת `ChangePrintArea` קובעת את האזור המלבני ש-[Print Manager](../print-manager/) מייצא. היא פועלת על הבד החשוף כאשר Print Manager מוסתר, ומקבלת שתי פינות נגדיות — אותן שתי לחיצות כמו [Rectangle](../rectangle/), כך שקואורדינטות מוקלדות והצמדה מתנהגות בדיוק אותו הדבר.

## בחירת אזור

1. הקלידו `ChangePrintArea` בטרמינל, או לחצו על **Change Area** בסרגל הצד של Print Manager. Print Manager מוסתר והבד הופך אינטראקטיבי.
2. **לחצו על הפינה הראשונה**, או הקלידו `X,Y` והקישו **Enter** לקואורדינטה מדויקת.
3. **לחצו על הפינה הנגדית**, או הקלידו `X,Y` שוב.

Print Manager נפתח מחדש עם האזור החדש בתצוגה המקדימה, שגודלה מותאם ליחס הגובה-רוחב המדויק של אותו אזור.

הפינות נצמדות לידיות ולנקודות חיתוך כמו כל בחירת נקודה אחרת, כך שאפשר לחתוך לפי גיאומטריה משורטטת במקום באומדן. סדר שתי הפינות אינו משנה: פינות נגדיות מגדירות את אותו מלבן.

הקישו `Escape` לביטול. שום דבר לא נכתב, ולכן Print Manager נפתח מחדש עם האזור שכבר היה לו.

## היכן האזור נזכר

הבחירה נשמרת לפי הקשר, לא באופן גלובלי:

| הקשר | משבצת |
|---|---|
| מרחב Model | משבצת משותפת אחת |
| כל פריסה | משבצת משלה, נשמרת בנפרד |

פתיחה מחדש של Print Manager באותה פריסה — או ב-Model — משחזרת את החיתוך האחרון של אותו הקשר במקום לאפס אותו, ומעבר בין פריסות משאיר את האזור של כל אחת על כנו.

זה נשמר בזיכרון בלבד. רענון הדף מנקה את כל האזורים השמורים, ו-Print Manager חוזר לברירות המחדל שלהלן.

## אזור ברירת מחדל

כאשר לא נשמר דבר עבור ההקשר הנוכחי, Print Manager נפתח על:

| הקשר | ברירת מחדל |
|---|---|
| מרחב Model | התיבה התוחמת של כל הישויות — אותו טווח ש-[Fit](../fit/) מתקרב אליו |
| כל פריסה | הגיליון כולו |
