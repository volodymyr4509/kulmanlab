# Block Create

`blockcreate` 명령은 **블록**을 만듭니다. 블록은 이름이 있는 객체 묶음으로, 도면에 한 번만 저장되고 [Block Insert](../block-insert/)로 원하는 만큼 배치됩니다. 고른 객체가 블록이 되고 도면에서는 그 블록에 대한 참조 하나로 바뀌므로 겉모습은 달라지지 않습니다.

## 블록 만들기

1. 원하면 먼저 객체를 선택한 뒤 `blockcreate`를 입력하거나 **블록** 패널에서 **블록 생성**을 클릭하세요. 선택이 이미 들어 있는 팝업이 열립니다.
2. **이름**을 입력하세요. 비워 둘 수 없고, `< > / \ " : ; ? * | , =` 중 어느 문자나 백틱도 포함할 수 없으며, 다른 블록의 이름과 같을 수 없습니다.
3. **객체 선택**를 클릭해 객체를 추가하거나 뺍니다. 팝업이 숨겨지면 객체를 클릭하거나 영역을 드래그하세요. **Enter** 또는 **Space**를 누르면 팝업으로 돌아가며, **객체**에 개수가 표시됩니다.
4. 블록을 배치할 기준점인 **기준점**를 설정하세요. X와 Y를 입력하거나 **점 선택**을 클릭한 뒤 캔버스를 클릭합니다(거기서 X,Y를 입력해도 됩니다). 처음 값은 0,0입니다.
5. **OK**를 클릭하세요. 블록이 저장되고, 객체는 기준점에 있는 그 블록의 참조 하나에 자리를 내주며, 터미널에 블록 이름과 담긴 객체 수가 기록됩니다.

## 알아 두기

- 문제가 있는 동안 **OK**는 비활성 상태로 남고, 필드 아래의 메시지가 이유를 알려 줍니다. 이름이 비었거나 쓸 수 없음, 이미 쓰는 이름, 객체 없음 중 하나입니다.
- 객체나 기준점을 고르는 중에 **Escape**를 누르면 블록은 그대로인 채 팝업으로 돌아갑니다. 팝업에서 **Escape**를 누르면 명령이 취소됩니다.
- 블록은 도면과 함께 저장되고 참조와 함께 DXF에 기록됩니다.
