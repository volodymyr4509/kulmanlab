# Polygon

`polygon` 명령은 변과 각이 모두 같은 정다각형을 3~1024개 변으로 그립니다. 터미널에 `polygon`을 입력하세요. 결과는 **닫힌 `LWPOLYLINE`**이므로 배치한 뒤에는 다른 [Polyline](../polyline/)과 똑같이 동작하며 모든 폴리라인 편집이 적용됩니다.

## 다각형 그리기

1. 터미널에 `polygon`을 입력하고 **변의 수**(3~1024의 정수)를 입력한 뒤 **Enter** 또는 **Space**를 누르세요. 프롬프트에는 지난번에 쓴 수가 미리 채워져 있으며(처음에는 4), 입력을 시작하면 바뀝니다. 그 밖의 값은 거부되고 수정할 수 있도록 프롬프트에 남습니다.
2. **중심을 클릭**하거나 `X,Y`를 입력하고 **Enter**를 눌러 정확한 좌표를 지정하세요. 대신 변에서 시작하려면 먼저 `E`를 누르세요(아래 참조).
3. **반지름을 클릭**하거나(다각형이 실시간으로 미리 보입니다) 반지름을 입력하고 **Enter** 또는 **Space**를 누르세요.
4. 다각형이 배치되고 명령이 끝납니다.

## 옵션

| 옵션 | 키 | 효과 |
|---|---|---|
| Edge | `E` | 첫 점이 중심이 아니라 변의 한쪽 끝이 됩니다. 다른 쪽 끝을 지정하면 나머지 꼭짓점은 첫 끝에서 둘째 끝으로 가는 변의 왼쪽에 반시계 방향으로 만들어집니다. `E`를 다시 누르면 중심 모드로 돌아갑니다. |
| Inside | `I` | 기본적으로 켜져 있으며 다각형 사이에 유지됩니다. 켜짐: 꼭짓점이 지정한 반지름의 원 위에 놓입니다. 꺼짐: 다각형이 그 원 바깥에 놓이고 각 변의 중점이 원 위에 놓입니다. |

- 클릭하면 커서가 있는 바로 그 자리에 꼭짓점(Inside 켜짐) 또는 변의 중점(Inside 꺼짐)이 놓이므로, 커서가 방향도 정합니다.
- 입력한 반지름에는 겨냥할 방향이 없으므로 다각형은 가장 아래쪽 변이 수평이 되도록 놓입니다. 각도 잠금이 켜져 있으면 잠긴 각도를 따릅니다.
- 각 옵션은 해당 단계에서 제공되며 숫자를 입력하는 도중에도 전환할 수 있습니다.

## 키보드 참조

| 키 | 동작 |
|---|---|
| `0`–`9`, `.` | 변의 수, 반지름, 좌표 또는 길이 입력 |
| `E` | Edge 켜기/끄기(첫 점 단계) |
| `I` | Inside 켜기/끄기(반지름 단계) |
| `Enter` / `Space` | 변의 수 또는 반지름 확정 |
| `Escape` | 취소 |

## DXF — LWPOLYLINE 객체

다각형은 모서리마다 꼭짓점 하나를 가진 닫힌 `LWPOLYLINE`으로 저장됩니다. DXF에는 전용 다각형 유형이 없습니다. 꼭짓점 좌표, 색, 레이어, 선종류, 선종류 축척, 두께 등 모든 속성이 손실 없이 유지되며, 어떤 DXF 뷰어에서도 닫힌 폴리라인으로 읽힙니다.
