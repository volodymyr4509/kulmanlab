# LeaderStyle

`LeaderStyle` 명령은 이름이 있는 지시선 스타일 관리자를 엽니다. 새 [Leader](../leader/)는 생성될 때 *현재* 스타일의 설정을 복사합니다.

## 스타일 편집

`LeaderStyle`을 입력하거나 주석 패널에서 **지시선 스타일**을 클릭합니다. ✓ 표시는 현재 스타일이며 이름 옆의 연필로 이름을 바꿀 수 있습니다. 미리보기는 도면과 같은 렌더러를 사용하여 즉시 갱신됩니다.

| 필드 | 기능 |
|---|---|
| 문자 부착 위치 | 위, 중간, 아래 또는 밑줄 |
| 화살촉 / 화살표 크기 | 각 지시선 끝의 기호와 크기 |
| 지시선 연결부 간격 | 연결부와 문자 사이의 간격 |
| 문자 회전 | 레이블 각도(도) |
| 문자 스타일 | [TextStyle](../text-style/)에서 글꼴, 높이, 굵게, 기울임꼴을 한 번 복사 |
| 글꼴 / 문자 높이 | 레이블의 글꼴과 높이 |
| 굵게 / 기울임꼴 | 독립적인 문자 서식 |
| 문자 프레임 | 레이블 둘레의 사각형 |

**새로 만들기**는 선택한 스타일을 복제합니다. `Standard`는 이름을 바꾸거나 삭제할 수 없고 현재 스타일도 삭제할 수 없습니다. **현재로 설정**은 이후에 만드는 지시선에만 적용되며 기존 객체는 바뀌지 않습니다. 비어 있거나 중복되었거나 DXF에서 허용되지 않는 이름이 있으면 **확인**이 비활성화됩니다. 가져온 주석 스타일은 숨겨지지만 유지됩니다.

## 저장 및 DXF

KulmanLab은 `MLEADERSTYLE` 레코드를 가져오고 내보냅니다. 이름, 화살촉과 크기, 랜딩 간격, 텍스트 높이, 부착, 프레임 및 주석 플래그가 스타일 필드로 유지됩니다. 내보낼 때 그룹 `342`는 글꼴, 굵게, 기울임꼴 및 높이가 지시선 스타일과 일치하는 텍스트 스타일을 가리키며, 일치 항목이 없으면 `Standard`를 사용합니다. 이 DXF 참조는 앱의 일회성 복사를 실시간 링크로 만들지 않습니다. 하나의 부착 값은 DXF의 왼쪽과 오른쪽 필드 모두에 기록됩니다.

관련 명령: [Leader](../leader/), [LeaderAdd](../leader-add/), [LeaderRemove](../leader-remove/).
