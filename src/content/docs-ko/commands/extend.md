# Extend

`extend` 명령어는 호버된 [Line](../line/), [Arc](../arc/), [Ellipse](../ellipse/) 또는 열린 [Polyline](../polyline/)의 가장 가까운 끝점을 도면의 다른 객체와 형성할 가장 가까운 교차점까지 늘립니다. 연장하려는 끝점 근처에 커서를 올리면 미리보기가 연장된 객체를 보여줍니다 — 그런 다음 클릭하여 적용합니다.

실제 끝점이 있는 객체만 연장할 수 있습니다. [Circle](../circle/)과 완전한(360°) Ellipse는 항상 끝점이 없는 닫힌 도형이므로 절대 연장할 수 없습니다 — 닫힌 Polyline이나 Rectangle도 마찬가지입니다. 부분적인 Ellipse(타원호)와 Arc는 끝점을 가지고 있으며 Line과 동일한 방식으로 연장됩니다.

## 객체 연장

1. 터미널에 `extend`를 입력하거나 **Extend** 도구 모음 버튼을 클릭합니다.
2. 연장하려는 객체의 **한쪽 끝 근처에 커서를 올립니다** — 미리보기가 그 방향에서 가장 가까운 경계까지 연장된 모습을 보여줍니다.
3. **클릭**하여 연장을 적용합니다.

각 연장 후 명령어가 활성 상태를 유지하므로 계속 호버하고 클릭하여 더 많은 객체를 연장할 수 있습니다. **Enter**, **Space**, 또는 **Escape**를 눌러 종료합니다.

```
  이전:                      이후:

  ──────           |           ──────────────|
  (짧은 선)     (경계)  (경계까지 연장됨)
```

## 끝점이 선택되는 방법

명령어는 커서가 어느 끝에 더 가까운지 확인합니다:

- **Line과 열린 Polyline** — 커서가 끝점에 더 가까우면 끝이 앞으로 연장됩니다; 커서가 시작점에 더 가까우면 시작점이 뒤로 연장됩니다.
- **Arc와 부분적인 Ellipse** — 커서가 각도상의 끝 중 하나에 더 가까우면, 같은 중심과 반지름(또는 같은 타원 형태)을 유지한 채 그 방향으로 호가 자라 다음 경계에 도달할 때까지 이어집니다.

선택된 끝에서 광선 — Arc와 Ellipse의 경우 객체 자체의 기본 원 또는 곡선 — 이 투사되고, 다른 모든 객체(객체 자체 및 무시된 유형 제외)와의 **가장 가까운 교차점**이 새 끝점이 됩니다.

그 방향에서 교차점이 없으면 미리보기가 나타나지 않고 클릭해도 아무 일도 일어나지 않습니다.

## 경계 제외

다음 객체 유형은 경계로 무시됩니다 — 객체가 만나도록 연장되지 않습니다:

- 텍스트 / Mtext
- 다중 지시선

다른 모든 유형(Line, Arc, Circle, Ellipse, Polyline, 스플라인, Dimension)은 유효한 경계 역할을 합니다.

Polyline의 첫 번째 또는 마지막 세그먼트가 그 자체로 호 세그먼트(Arc 토글로 그려진 것)인 경우, 연장하면 독립된 Arc를 연장할 때와 같은 방식으로 호가 자신의 원을 따라 자라납니다 — 직선 세그먼트로 취급되지 않습니다.

## 지원되는 객체

| 객체 | 연장할 수 있나요? |
|------|----------------|
| Line | 예 |
| Arc | 예 |
| Ellipse | 예 — 이미 부분 호인 경우에만; 완전한 타원은 끝점이 없습니다 |
| Circle | 아니오 — 항상 끝점이 없는 닫힌 도형 |
| Polyline (열린) | 예 |
| Polyline (닫힌) / Rectangle | 아니오 — 항상 끝점이 없는 닫힌 도형 |
| 텍스트, 스플라인, 치수, 지시선 | 아니오 |

## Extend vs Trim

| | Extend | Trim |
|--|------|--------|
| 하는 일 | 객체의 끝점을 경계까지 늘리기 | 객체의 세그먼트 제거 |
| 트리거 | 늘릴 끝점 근처에 커서 올리기 | 자를 세그먼트 위에 커서 올리기 |
| 결과 | 끝점이 바깥쪽으로 이동 | 객체가 분할되거나 짧아짐 |
| 지원되는 객체 | Line, Arc, Ellipse, Polyline | Line, Arc, Circle, Ellipse, Polyline |
