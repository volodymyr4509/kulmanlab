# TextStyle

`TextStyle` 명령은 텍스트 스타일 관리자를 엽니다. 이름이 있는 스타일을 만들고 기본값을 편집하며 *현재 스타일*을 선택할 수 있습니다. 새 [Text](../text/)는 생성될 때 현재 스타일의 설정을 복사합니다.

## 관리자 사용하기

`TextStyle`을 입력하거나 주석 패널에서 **텍스트 스타일**을 클릭합니다. ✓ 표시는 현재 스타일이며, 행을 두 번 클릭하면 해당 스타일이 현재 스타일로 지정됩니다.

| 필드 | 기능 |
|---|---|
| 이름 바꾸기 | 이름 옆의 연필로 목록에서 편집합니다. `Standard`의 이름은 바꿀 수 없습니다. |
| 글꼴 / 높이 | 글꼴과 필수 양수 높이입니다. 0 또는 음수 값은 `1`이 되며 관리자는 `0`보다 큰 값만 받습니다. |
| 굵게 / 기울임꼴 | 각각 독립적으로 적용하는 서식 |
| 줄 간격 | 텍스트 줄 사이의 간격 |
| 수평 정렬 | 왼쪽, 가운데, 오른쪽 또는 양쪽 맞춤 |
| 프레임 | 새 텍스트를 둘러싸는 사각형 |

미리보기는 캔버스와 같은 렌더러로 두 줄을 표시합니다. 글꼴, 높이, 굵게, 기울임꼴, 프레임, 줄 간격 및 정렬이 즉시 갱신되며 표시값은 맞춤 확대/축소 배율입니다. 새 스타일은 기본적으로 **왼쪽** 정렬입니다.

**새로 만들기**는 선택한 스타일을 복제합니다. **삭제**로 `Standard`나 현재 스타일은 삭제할 수 없습니다. **현재로 설정**은 이후에 만드는 텍스트에만 적용되며 기존 텍스트는 바뀌지 않습니다. 비어 있거나 중복되었거나 DXF에서 허용되지 않는 이름이 있으면 **확인**이 비활성화됩니다. 가져온 주석 스타일은 숨겨지지만 데이터는 유지됩니다.

## 저장 및 DXF

이름, 글꼴 파일, 굵게, 기울임꼴과 주석 플래그는 DXF 텍스트 스타일에 보존됩니다. KulmanLab은 STYLE 그룹 `40`을 `0`(가변 높이), 마지막 사용 높이를 그룹 `42`에 기록하므로 고정 STYLE 높이가 치수 스타일 자체의 텍스트 높이를 덮어쓰지 않습니다. 프레임, 줄 간격, 가로 정렬은 KulmanLab의 텍스트별 기본값이며 DXF STYLE 테이블 필드가 아닙니다.
