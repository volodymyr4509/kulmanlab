# ClipboardCopy

`ClipboardCopy` 명령은 선택한 개체를 **시스템 클립보드**에 JSON 텍스트로 씁니다. 메모리 버퍼가 아니라 실제 클립보드를 쓰기 때문에 복사한 형상은 도면 밖에서도 살아남습니다. [ClipboardPaste](../clipboard-paste/)로 다른 파일, 두 번째 브라우저 탭, 또는 나중에 여는 창에 붙여 넣으세요.

이것이 [Copy](../copy/)와의 차이입니다. Copy는 한 동작으로 현재 도면 안에서 개체를 복제하지만, ClipboardCopy는 완전히 다른 도면에서도 꺼내 쓸 수 있는 곳에 개체를 놓아 둡니다.

## 시작하는 두 가지 방법

**먼저 선택하고 복사** — 빠른 경로:

1. 캔버스에서 개체를 하나 이상 선택합니다.
2. `Ctrl+C`(macOS에서는 `Cmd+C`)를 누르거나 터미널에 `ClipboardCopy`를 입력합니다.
3. 개체가 즉시 클립보드에 기록되고 명령이 끝납니다.

**먼저 실행하고 선택** — 아무것도 선택하지 않은 상태에서 시작:

1. 선택이 비어 있을 때 `Ctrl+C`를 누르거나 `ClipboardCopy`를 입력합니다.
2. 프롬프트에 **pick objects to copy — Enter or Space to confirm**이 나타납니다.
3. **개체를 선택합니다** — 클릭하면 개별 개체가 선택에 들어가거나 빠지고, 드래그하면 영역으로 선택합니다.
4. **Enter** 또는 **Space**를 눌러 선택을 복사하고 종료합니다.

아무것도 선택하지 않은 상태에서 **Enter**나 **Space**를 누르면 클립보드를 건드리지 않고 명령만 끝납니다.

## 복사되는 내용

클립보드 데이터는 형상만 담지 않습니다. 낯선 도면에 붙여 넣어도 제대로 보이게 하기 위해서입니다.

| 구성 요소 | 역할 |
|-----------|------|
| **개체** | 선택한 각 개체의 완전한 직렬화 형태 |
| **참조점** | 선택 영역 전체 경계의 왼쪽 아래 모서리 — ClipboardPaste가 커서에 맞추는 기준 |
| **도면층** | 복사한 개체가 실제로 참조하는 도면층만, 이름으로 |
| **선종류** | 복사한 개체가 실제로 참조하는 선종류만, 이름으로 |

함께 이동하는 것은 *참조된* 테이블 항목뿐이며, 원본 도면의 도면층·선종류 테이블 전체가 아닙니다. 해치 패턴은 아예 포함되지 않고 그럴 필요도 없습니다. 도면의 패턴 테이블은 기본 내장 세트이고, 업로드한 `.pat` 파일은 이미 탭 사이에서 공유되는 사용자별 저장소에 있으므로 붙여 넣은 해치가 스스로 패턴을 찾아냅니다.

## 확인 메시지

성공하면 터미널이 기록된 개체 수를 알려 줍니다:

```
3 entities copied to clipboard
```

브라우저가 클립보드 접근을 거부하면 터미널에 **Copy failed: clipboard access denied**가 표시되고 아무것도 기록되지 않습니다. 이는 도면 오류가 아니라 브라우저의 권한 판단입니다 — 아래 [클립보드 권한](#클립보드-권한)을 참고하세요.

## 명령 중의 선택

| 방법 | 동작 |
|------|------|
| **클릭** | 커서 아래 개체를 선택에 넣거나 뺍니다 |
| **오른쪽으로 드래그**(엄격) | 상자 안에 완전히 들어온 개체를 추가합니다 |
| **왼쪽으로 드래그**(걸침) | 상자 경계와 교차하는 개체를 추가합니다 |
| **Enter** / **Space** | 선택을 확정하고 복사합니다 |

## 키보드 참조

| 키 | 동작 |
|----|------|
| `Ctrl+C` / `Cmd+C` | ClipboardCopy 실행 |
| `Enter` / `Space` | 현재 선택을 복사, 선택이 없으면 종료 |
| `Escape` | 복사하지 않고 취소 |

## 클립보드 권한

시스템 클립보드에 쓰려면 브라우저 권한이 필요합니다. 실제로는 키 입력으로 시작한 복사는 최신 데스크톱 브라우저에서 묻지 않고 허용되지만, 포커스를 잃은 페이지나 클립보드 설정이 엄격한 브라우저는 거부할 수 있습니다. 접근 거부 메시지가 보이면 캔버스를 한 번 클릭해 페이지에 포커스를 준 뒤 다시 시도하세요.

데이터가 평범한 JSON 텍스트이므로, 이후에 복사한 것 — 한 줄의 글, 주소 — 이 그것을 대체합니다. 중간에 클립보드를 다른 용도로 썼다면 붙여 넣기 전에 다시 복사하세요.

## 지원하는 개체

ClipboardCopy는 모든 개체 유형에서 동작합니다. 개체는 자체 `.json` 내보내기와 같은 방식으로 직렬화되므로 도중에 빠지는 것이 없습니다.
