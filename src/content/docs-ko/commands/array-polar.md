# Array Polar

`ArrayPolar` 명령은 선택한 객체의 복사본을 중심점 둘레에 한 바퀴 또는 그 일부에 고르게 배치합니다. 원본이 첫 번째 항목이고 나머지는 모두 중심을 기준으로 회전한 복사본입니다. Rotate를 끄면 회전하지 않고 이동만 합니다.

## 원형 배열 만들기

1. 객체를 선택한 뒤 터미널에 `arraypolar`를 입력하거나 도구 모음의 **Array Polar** 버튼을 클릭하세요. 선택 없이 시작하면 먼저 객체를 선택하라고 요청합니다. **Enter** 또는 **Space**로 확정하세요.
2. 복사본이 둘레를 도는 **중심을 클릭**하거나, `X,Y`를 입력하고 **Enter**를 눌러 정확한 좌표를 지정하세요.
3. 배열을 확인하세요. 모든 복사본이 실시간으로 미리 보이며 터미널에 `Change [Items=6] [Angle=60°] [Fill=360°] [Rotate=true]`가 표시됩니다. 바꾸려는 옵션의 문자를 누르세요.
4. **Enter** 또는 **Space**를 누르면 복사본이 만들어집니다. 원본은 그대로 있고 선택은 해제됩니다.

## 옵션

| 옵션 | 키 | 효과 |
|---|---|---|
| Items | `I` | 원본을 포함한 항목 수. 2~1024의 정수. 초기값은 6입니다. |
| Angle | `A` | 한 항목에서 다음 항목까지의 각도(도). 반시계 방향이며 음수 각도는 시계 방향입니다. 최대 180°. |
| Fill | `F` | 첫 항목에서 마지막 항목까지의 각도(도). 360(기본값)은 한 바퀴이고, 더 작은 값은 항목을 그 일부에만 배치합니다. 음수는 시계 방향. 최대 360°. |
| Rotate | `R` | 켜짐(기본값): 각 복사본이 돌면서 회전합니다. 꺼짐: 각 복사본이 제자리로 이동만 하고 원본과 같은 방향을 유지합니다. 즉시 전환되며 입력할 숫자는 없습니다. |

- Angle과 Fill은 같은 것을 다르게 표현한 것이므로 한쪽을 바꾸면 다른 쪽이 다시 계산됩니다. 한 바퀴일 때는 마지막 항목이 첫 항목 한 칸 앞에서 멈추고, 일부일 때는 정확히 Fill 각도에 놓입니다.
- 숫자를 바꾸려면 해당 옵션의 문자를 누르세요. 프롬프트에는 현재 값이 미리 채워져 있으니 입력해서 바꾼 뒤 **Enter** 또는 **Space**를 누르세요. 바꾸지 않고 확정하면 배열은 그대로입니다.
- Items는 정수만 받고, Angle과 Fill은 소수와 시계 방향을 뜻하는 앞의 `-`를 받습니다. 0인 각도나 Fill, 180°를 넘는 Angle, 360°를 넘는 Fill은 거부되며 터미널이 이유를 알려 줍니다.
- 모든 항목이 들어가기엔 너무 작은 Angle은 자리가 없는 항목을 빼고, 터미널이 새 개수를 알려 줍니다.
- 모든 객체 유형에서 동작합니다. 각 복사본은 [Rotate](../rotate/)와 [Move](../move/)가 하는 것과 똑같이 원본을 중심 둘레로 회전하거나 이동한 것입니다.

## 키보드 참조

| 키 | 동작 |
|---|---|
| `Enter` / `Space` | 선택, 배열 또는 입력한 숫자 확정 |
| `I` `A` `F` `R` | 숫자를 입력해 Items, Angle, Fill 변경, Rotate 전환 |
| `0`–`9`, `.`, `-` | 숫자 입력(`.`과 `-`는 Angle과 Fill에만, `-`는 맨 앞) |
| `Backspace` | 마지막으로 입력한 문자 삭제 |
| `Escape` | 취소 |
