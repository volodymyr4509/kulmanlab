# Point Divide

`pointdivide` 명령은 객체를 같은 길이의 구간으로 나누는 [점](../point/)을 배치합니다. 객체 자체는 바뀌지 않으며, 점은 현재 레이어와 색의 새 객체로 스냅에 유용합니다.

## 객체 나누기

1. 터미널에 `pointdivide`를 입력하거나 Edit 패널의 배열 드롭다운에서 **Point Divide**를 선택합니다.
2. **객체를 클릭**합니다 — 선, 폴리라인, 호, 원, 타원 또는 스플라인. 그 밖의 것은 거부되며 다시 고를 수 있습니다.
3. **구간 수를 입력**합니다(2~32767의 정수). 입력하는 동안 객체 위에 점이 미리 보입니다.
4. **Enter** 또는 **Space**를 눌러 배치합니다. 명령이 끝납니다.

## 점이 놓이는 위치

- 간격은 각도가 아니라 객체를 따른 길이로 정해지므로 타원이나 스플라인도 같은 길이의 조각으로 나뉩니다. 폴리라인의 호 구간은 곡선을 따라 갑니다.
- 열린 객체(선, 열린 폴리라인, 호, 부분 타원, 열린 스플라인)에서는 점이 구간 사이에 놓이며 끝에는 놓이지 않습니다. 5구간이면 점 4개입니다.
- 닫힌 객체(원, 닫힌 폴리라인, 전체 타원, 닫힌 스플라인)에서는 시작점부터 한 바퀴 돌며 점이 놓이고 시작점에도 점이 놓입니다. 원은 각도 0, 닫힌 폴리라인은 첫 꼭짓점에서 시작합니다. 5구간이면 점 5개입니다.
- 2~32767 밖의 숫자는 거부됩니다. 터미널이 이유를 알려 주고 입력을 지우므로 다시 입력할 수 있습니다.

Backspace는 마지막 숫자를 지웁니다. Escape는 처음부터 다시 시작하므로 다른 객체를 고를 수 있습니다. 객체를 고르기 전에 Enter나 Space를 누르면 명령이 끝납니다.
