# Print Manager

`PrintManager` 명령어는 **인쇄 관리자**를 엽니다 — 실시간 미리보기 캔버스, 형식 선택기(PNG / JPEG / WebP / PDF), 스타일 선택기(Default / Monochrome / Blueprint), 선택적 영역 자르기가 있는 전용 내보내기 창입니다. 실제 프린터로는 아무것도 전송되지 않습니다; 출력은 파일로 다운로드됩니다.

## 인쇄 관리자 여는 방법

**Print** 도구 모음 버튼을 클릭하거나 터미널에 `PrintManager`를 입력합니다. 인쇄 관리자가 현재 뷰포트의 미리보기를 보여주며 즉시 열립니다.

미리보기는 최종적으로 내보낼 파일과 정확히 동일한 코드 경로를 거쳐, 정확히 동일한 픽셀 해상도로 렌더링됩니다 — Quality, Style, 또는 내보내기 영역을 변경하면 미리보기가 즉시 다시 렌더링되므로, 보이는 것이 근사치가 아니라 실제로 다운로드되는 것 그 자체입니다.

## 인쇄 관리자 레이아웃

창에는 두 개의 패널이 있습니다:
- **왼쪽 사이드바** — 모든 내보내기 컨트롤.
- **오른쪽 패널** — 설정을 변경할 때 업데이트되는 실시간 미리보기 캔버스.

### 사이드바 컨트롤

| 컨트롤 | 설명 |
|--------|------|
| **Change Area** | 캔버스에서 사용자 정의 직사각형으로 자르기(아래 참조) — 화면상의 미리보기뿐 아니라 페이퍼 스페이스가 있는 레이아웃에서도 내보내는 이미지 자체를 실제로 자릅니다 |
| **Quality** 드롭다운 | 내보내기 해상도를 설정합니다(아래 참조) |
| **Style** 드롭다운 | Default, Monochrome, 또는 Blueprint — 아래 "인쇄 스타일" 참조. 깔끔한 인쇄 출력을 위해 기본값은 Monochrome |
| **형식** 드롭다운 | PNG, JPEG, WebP 또는 PDF |
| **내보내기** 버튼 | 파일 생성 및 다운로드 |

## 인쇄 스타일

**Style** 드롭다운은 엔티티가 그려지는 잉크 색상과 페이지 배경 모두를 제어합니다:

| 스타일 | 잉크 | 페이지 배경 |
|--------|------|-------------|
| **Default** | 각 엔티티 고유의 색상 | 흰색 |
| **Monochrome**(기본값) | 엔티티/레이어 색상과 무관하게 단색 검정 | 흰색 |
| **Blueprint** | 엔티티/레이어 색상과 무관하게 단색 흰색 | 짙은 프러시안 블루, 은은한 참조 격자 포함 |

Blueprint는 전통적인 사이아노타입 건축 도면의 모습을 재현합니다 — 짙은 파란색 시트 위의 흰색 선화. 참조 격자는 DPI가 아니라 페이지 크기에 비례한 크기로 그려지므로, 해상도가 높아질수록 촘촘해지는 대신 어떤 Quality 설정에서도 동일한 밀도로 보입니다.

## 품질 및 해상도

**Quality** 드롭다운은 내보내기가 렌더링되는 DPI를 설정합니다:

| Quality | DPI |
|---------|-----|
| Draft | 72 |
| Normal(기본값) | 150 |
| Presentation | 300 |
| Max | 600 |

품질이 높을수록 동일한 물리적 크기에서 더 크고 선명한 이미지가 생성됩니다 — 선 굵기는 해상도와 함께 조정되므로, DPI가 높아질수록 얇아 보이는 대신 어떤 품질 설정에서도 종이 위 선의 *물리적* 두께는 동일하게 유지됩니다. 유일한 예외는 헤어라인(선 굵기 `0`)으로, 이는 관례적으로 "출력 장치가 그릴 수 있는 가장 얇은 선"으로 정의됩니다 — 라이브 캔버스에서의 동작과 마찬가지로 어떤 품질 수준에서도 고정된 1픽셀 너비를 유지합니다.

품질을 변경하면 미리보기가 즉시 다시 렌더링되어, 내보내기 전에 실제 선명도(및 파일 크기와의 절충)를 확인할 수 있습니다.

## 사용자 정의 내보내기 영역 선택

기본적으로 미리보기는 모델 공간의 모든 엔티티에 대한 경계 상자 — [Fit](../fit/)이 확대하는 것과 같은 범위 — 또는 레이아웃의 시트 전체를 표시합니다. 특정 영역을 내보내려면:

1. **Change Area**을 클릭합니다 — 인쇄 관리자가 숨겨지고 캔버스가 대화형 상태가 됩니다.
2. 내보내기 직사각형의 **첫 번째 모서리를 클릭**합니다.
3. **반대쪽 모서리를 클릭**합니다 — 인쇄 관리자가 선택한 영역이 미리보기에 표시되며 다시 열립니다.

영역 선택 중에 `Escape`를 눌러 취소하고 이전 영역을 복원합니다.

미리보기 캔버스는 선택한 영역의 **정확한 가로세로 비율**에 맞게 동적으로 크기가 조정되므로 미리보기가 픽셀 단위로 정확합니다.

선택한 영역은 페이지를 새로 고칠 때까지 모델 공간과 각 레이아웃별로 따로 기억됩니다 — [ChangePrintArea](../change-print-area/) 참조.

## 내보내기 형식

| 형식 | 최적 용도 | 비고 |
|------|----------|------|
| **PNG** | 손실 없음, 선명한 선 | Style의 페이지 배경이 포함됨, 투명도 없음 |
| **JPEG** | 공유를 위한 작은 파일 | 95% 품질, 약간의 압축 |
| **WebP** | 웹용 가장 작은 파일 | 동일한 95% 품질, JPEG보다 나은 압축 |
| **PDF** | 인쇄 준비 문서 | 선택한 Quality의 DPI로 PDF 컨테이너 내에 이미지 삽입, 페이지가 실제 물리적 축척으로 인쇄되도록 크기 설정 |

내보낸 파일은 `kulman-<타임스탬프>.<확장자>` 형태로 이름이 지정되며 자동으로 다운로드됩니다.

## 내보내기 해상도 및 배경

- **모델 스페이스 / 뷰포트 내보내기**: 기본 Normal(150 DPI) 품질에서 2000 × 2000 픽셀로 제한되며, 선택한 영역에 비례하여 크기 조정됩니다. 이 한도 역시 Quality에 따라 달라져 Draft는 더 낮고 Presentation과 Max는 더 높습니다(Max/600 DPI에서 최대 8000 × 8000).
- **레이아웃(페이퍼 스페이스) 내보내기**: 선택한 DPI에서 레이아웃의 용지 치수로부터 직접 크기가 결정됩니다 — 예를 들어 A4 용지(210 × 297mm)는 Normal 품질에서 약 1240 × 1754px로 내보내지며, 뷰포트의 2000px 상한 대상이 아닙니다.
- 배경은 선택한 인쇄 **Style**을 따릅니다 — Default와 Monochrome은 흰색, Blueprint는 짙은 프러시안 블루입니다(위 "인쇄 스타일" 참조).
- **비인쇄** 표시된 레이어는 내보내기에서 제외됩니다.

## 인쇄 vs 내보내기

| 기능 | 인쇄 | 내보내기 |
|------|------|---------|
| 출력 | 래스터 이미지(.png / .jpeg / .webp / .pdf) | 벡터 소스 파일(.dxf / .json) |
| 다른 도구에서 편집 가능 | 아니오 | 예(DXF) |
| 레이어 및 선종류 보존 | 아니오(평면 렌더링) | 예 |
| 치수 및 지시선 캡처 | 예 | JSON만 가능 |

시각적 스냅샷이 필요할 때 **인쇄**를 사용합니다. 편집 가능한 파일이 필요하면 [Export Manager](../export-manager/)를 사용합니다.

## 키보드 참고
