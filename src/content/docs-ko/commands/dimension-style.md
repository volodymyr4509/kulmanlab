# DimensionStyle 치수 스타일

이 명령은 명명된 치수 스타일을 만들고 편집하고 미리 보고 선택하는 대화상자를 엽니다. 새 선형, 정렬, 반지름, 지름, 각도 치수는 생성할 때 현재 스타일을 복사하며 기존 치수는 실시간으로 연결되지 않습니다.

## 대화상자 열기

터미널에 현지화된 명령을 입력하거나 **주석** 패널의 **치수 스타일** 버튼을 클릭합니다. 왼쪽 목록에는 표시 가능한 스타일이 있고, 확인 표시는 현재 스타일, 연필은 이름 바꾸기를 뜻합니다.

## 선 및 화살표

**화살표 1 / 화살표 2 · 화살표 크기 · 치수보조선 원점 간격 · 치수보조선 연장 길이 · 중심 표식 · 중심 표식 크기**

두 화살촉, 화살표 크기, 치수 보조선 간격과 연장, 중심 표식 종류 및 크기(`없음`, `표식`, `선`)를 각각 설정합니다.

## 문자

**텍스트 스타일 · 글꼴 · 문자 높이 · 문자 프레임 · 문자 간격 · 문자 부착 위치 · 문자를 치수선에 정렬 · 정밀도 · 각도 정밀도**

텍스트 영역은 텍스트 스타일 빠른 채우기, 글꼴, 높이, 굵게, 기울임꼴, 프레임, 간격, 9개 부착 위치 중 하나, 치수선 정렬, 선형 및 각도 정밀도를 제어합니다. 텍스트 스타일은 값을 한 번 복사할 뿐 실시간 링크가 아닙니다.

미리보기는 캔버스와 같은 렌더러를 사용합니다. 선형, 반지름, 지름, 각도 샘플을 전환해 화살표, 중심 표식, 텍스트 위치, 정밀도와 프레임을 확인할 수 있습니다.

## 스타일 만들기 및 관리

**새로 만들기**는 선택한 스타일을 복제합니다. `Standard`는 이름을 바꾸거나 삭제할 수 없고 현재 스타일도 삭제할 수 없습니다. 이름은 고유하고 비어 있지 않으며 DXF에 유효해야 합니다. 가져온 주석 스타일은 숨겨지지만 보존됩니다.

## 현재 스타일 설정

**현재로 설정**은 선택한 스타일을 새 치수의 템플릿으로 만듭니다. 주석 패널 목록에서도 같은 선택을 할 수 있습니다. 값은 생성 시 복사되고 Dimension Continue는 기준 치수의 전체 모양을 상속합니다.

## 저장 또는 취소

**확인**은 이름 변경, 추가, 삭제, 속성, 현재 스타일 선택을 함께 적용합니다. **닫기**, 배경 클릭 또는 `Escape`는 변경을 취소합니다.

## DXF 호환성

KulmanLab은 별도 화살표, 치수 보조선, 텍스트, 정밀도, 중심 표식, 프레임, 텍스트 스타일 참조와 주석 플래그가 포함된 명명된 `DIMSTYLE` 레코드를 가져오고 내보냅니다. 가져올 때 엔티티별 `DSTYLE` 재정의가 우선합니다.

내보낼 때 참조 `STYLE`은 가변 높이(`40 = 0`)를 사용하고 마지막 높이를 그룹 `42`에 저장합니다. 고정 텍스트 스타일 높이가 치수 스타일 자체의 텍스트 높이를 덮어쓰지 않습니다.
