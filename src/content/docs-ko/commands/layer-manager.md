# LayerManager

`LayerManager` 명령은 도면의 모든 도면층을 나열하는 표를 열며, **Freeze**, **Lock**, **Plot**, **색상**, **선가중치**, **선종류** 설정을 행 안에서 바로 편집할 수 있습니다. 도면층을 추가하고, 쓰이지 않는 것을 삭제하고, 기존 도면층의 동작을 조정하는 중심 자리입니다 — 나머지 도면층 명령([LayerMakeCurrent](../layer-make-current/), [LayerMatch](../layer-match/), [LayerIsolate](../layer-isolate/), [LayerUnfreezeAll](../layer-unfreeze-all/))은 이 창을 열지 않고 각각 한 가지 일만 합니다.

## Layer Manager 열기

- 터미널에 `LayerManager`를 입력하거나, **또는**
- 레이어 패널의 **Layer Manager** 버튼을 클릭합니다.

대화 상자는 떠 있는 패널로 열립니다. 미리 아무것도 선택할 필요가 없습니다.

## 레이어 표

| 열 | 제어하는 것 |
|----|--------------|
| Name | 레이어 이름, 표에서 읽기 전용으로 표시됨(생성 시 한 번 설정) |
| Freeze | 레이어의 객체를 숨기고 동결이 해제될 때까지 선택에서 제외합니다 |
| Lock | 레이어의 객체를 숨기지 않고 편집을 방지합니다 |
| Plot | 인쇄 또는 PDF 내보내기 시 레이어의 객체를 포함할지 여부 |
| Color | 레이어의 ACI 색상 — 견본을 클릭하여 색상 선택기를 엽니다 |
| Lineweight | 레이어의 선 가중치 — 칩을 클릭하여 선 가중치 선택기를 엽니다 |
| Linetype | 레이어의 파선 패턴 — 칩을 클릭하여 선종류 선택기를 엽니다 |
| ✕ | 아무것도 쓰고 있지 않을 때 도면층을 삭제합니다 — [도면층 삭제](#도면층-삭제) 참고 |

Freeze, Lock, Plot을 전환하면 즉시 적용됩니다 — 별도의 저장 단계가 없습니다. 색상, 선 가중치, 선종류가 **ByLayer**(기본값)로 설정된 객체는 여기서 설정한 값을 따릅니다. 자체 명시적 재정의가 있는 객체는 영향을 받지 않습니다.

## 레이어 추가

1. 표 하단의 **+ Add Layer**를 클릭합니다.
2. 이름을 입력하고 **Enter**를 눌러 확인하거나 **Escape**를 눌러 취소합니다.

레이어 이름에는 문자, 숫자, 공백, `_`, `-`, `$`를 사용할 수 있습니다. 비어 있거나 이미 사용 중이거나 다른 문자를 포함한 이름은 인라인 오류와 함께 거부되며, 행은 다시 시도할 수 있도록 열린 상태로 유지됩니다.

새 레이어는 **동결 해제, 잠금 해제, 플롯 가능** 상태로 시작하며, 색상은 7(흰색/검정), 선 가중치는 Default, 선종류는 Continuous입니다 — [Import](../import/)가 빈 도면의 레이어 `0`에 지정하는 것과 동일한 기본값입니다.

## 도면층 삭제

각 행 끝에는 도면층을 도면에서 제거하는 **✕** 버튼이 있습니다. 삭제는 즉시 이뤄지며 확인 단계는 없습니다. 다만 아무것도 의존하지 않는 도면층에만 제공됩니다.

| 상황 | 버튼 상태 |
|------|-----------|
| 도면층이 비어 있음 | 활성 — *Delete layer* |
| 도면층이 개체 하나 이상에 지정되어 있음 | 비활성 — *Cannot delete: assigned to at least one entity* |
| 도면층 `0` | 버튼 자체가 없음 |

**"사용 중"은 도면 전체를 가리킵니다.** 지금 보고 있는 부분만이 아닙니다. 배치(도면 공간)에 놓인 개체도 모형 공간의 개체와 똑같이 계산되므로, 화면상 비어 보이는 도면층이 삭제를 거부할 수 있습니다. 동결된 도면층도 다르지 않습니다. 동결은 개체를 숨길 뿐 지정을 해제하지 않으므로, 개체를 품은 동결 도면층은 여전히 삭제되지 않습니다.

도면층 `0`은 결코 삭제할 수 없습니다. 모든 도면이 반드시 갖는 대체 도면층이기 때문에, 버튼을 비활성으로 보여 주는 대신 아예 그리지 않습니다.

### "…is now in use and can't be deleted"

가끔 ✕ 가 눌릴 것처럼 보여도 클릭이 패널 위쪽 배너로 거부됩니다.

```
"WALLS" is now in use and can't be deleted
```

모순이 아닙니다. 어떤 도면층이 쓰이는지 알아내려면 도면의 모든 개체를 훑어야 하므로 결과를 캐시해 두고 개체 수가 바뀔 때만 다시 만듭니다 — 개체가 수백 개면 값싸지만 수십만 개면 그렇지 않습니다. 기존 개체를 다른 도면층으로 옮겨도 개체 수는 그대로여서, 행의 비활성 상태가 한순간 옛것일 수 있습니다. 클릭하면 무엇을 지우기 전에 처음부터 다시 확인하므로, 아직 참조가 남아 있는데 도면층이 사라지는 대신 클릭 시점에 거부가 일어납니다.

배너는 자체 **✕** 로 닫습니다. 도면층은 그대로입니다.

## 여기서 할 수 없는 일

어떤 도면층이 *현재* 도면층인지는 표에 표시되지 않습니다. 그것은 도면층 패널의 드롭다운이나 [LayerMakeCurrent](../layer-make-current/)로 정하며, 이 대화 상자에서는 정하지 않습니다. 도면층 이름도 만들 때 고정됩니다 — 삭제하고 다시 만들 수는 있어도 이름을 바꿀 수는 없습니다.

## 관련 명령어

| 명령어 | 기능 |

| [LayerMatch](../layer-match/) | 선택한 객체의 레이어를 원본 객체의 레이어에 맞게 재지정 |

| [LayerUnfreezeAll](../layer-unfreeze-all/) | 한 번에 모든 레이어 동결 해제 |
