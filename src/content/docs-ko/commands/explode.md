# Explode

`explode` 명령어는 [폴리선](../polyline/)을 개별 [선](../line/) 및 [호](../arc/) 객체로 분해합니다 — 세그먼트당 하나씩, 정확히 폴리선 자체의 정점이 있던 위치에서요. 분해된 조각은 폴리선을 그 자리에서 대체하며 선 굵기, 색상, 레이어, 선종류를 그대로 유지합니다.

Explode는 **Polyline** 객체와 **블록 참조**에 사용할 수 있습니다.

## explode 사용하기

실행하는 두 가지 방법은 [Delete](../delete/)와 동일한 패턴입니다:

**먼저 선택한 후 explode** — 가장 빠른 방법:

1. 캔버스에서 하나 이상의 폴리선을 선택합니다.
2. 터미널에 `explode`를 입력하거나 Edit 패널의 드롭다운에서 **Explode**를 선택합니다.

선택한 폴리선이 즉시 분해됩니다 — 이미 무언가가 선택되어 있으므로 별도의 확인 단계는 없습니다.

**명령어를 활성화한 후 선택**:

1. 아무것도 선택하지 않은 상태에서 `explode`를 입력하거나 드롭다운에서 **Explode**를 선택합니다.
2. **폴리라인이나 블록 참조를 선택**합니다 — 클릭으로 전환하거나 드래그로 영역을 선택합니다.
3. **Enter** 또는 **스페이스**를 눌러 선택한 폴리선을 확정하고 분해합니다.

선택 중에는 폴리라인과 블록 참조만 잡힙니다. Line, Circle 등 다른 객체를 클릭해도 아무 일도 일어나지 않으며, 영역 드래그도 안에 있거나 걸치는 다른 것은 모두 무시합니다.

## 결과로 나오는 것

폴리선의 각 세그먼트는 자체 객체가 됩니다:

- **직선 세그먼트**는 **Line**이 됩니다.
- **호 세그먼트**(Polyline의 [Arc 옵션](../polyline/)에서 비롯된)는 원래 곡선의 중심, 반지름, 스윕과 정확히 일치하는 **Arc**가 됩니다.

결과로 생성된 각 Line과 Arc는 원본 폴리선의 **선 굵기, 색상, 레이어, 선종류, 선종류 축척**을 그대로 이어받습니다 — 지오메트리의 겉모습은 전혀 변하지 않으며, 단지 하나의 연결된 폴리선 대신 여러 개의 독립적인 객체가 되었을 뿐입니다.

**블록 참조**는 그 블록이 그리는 객체가 되어, 참조가 보여 주던 자리에 놓입니다. 블록이 숨겨 둔 객체(동적 블록의 다른 상태)는 빠지고, 각 속성은 값을 가진 일반 Text가 됩니다. ByBlock으로 그린 부분은 참조의 색을, 레이어 0에 있는 부분은 참조의 레이어를 따릅니다. 중첩된 블록은 별도의 블록 참조로 나오며 다시 분해할 수 있습니다. X와 Y의 축척이 다른 참조는 선택되지 않습니다. 원이 타원이 되어야 하기 때문입니다.

분해는 다른 편집과 마찬가지로 [Undo](../undo/)로 한 번에 실행 취소할 수 있습니다.

## 명령어 실행 중 선택

| 방법 | 동작 |
|------|------|
| **클릭** | 커서 아래의 폴리라인이나 블록 참조를 선택에 넣거나 뺍니다. 다른 객체를 클릭하면 아무 일도 없습니다 |
| **오른쪽으로 드래그**(윈도우) | 상자 안에 완전히 들어간 폴리라인과 블록 참조만 선택 |
| **왼쪽으로 드래그**(교차) | 상자 경계와 만나는 폴리라인과 블록 참조를 선택 |
| **Enter** / **Space** | 확인하고 선택을 분해 |

## 지원되는 객체

| 객체 | 지원 여부 |
|------|----------|
| Polyline / Rectangle | 예 |
| 블록 참조 | 예(X와 Y 축척이 다르면 제외) |
| Line, Arc, Circle, Ellipse | 아니오 — 분해할 것이 없음 |
| Text, Spline, Dimension, Leader, Hatch | 아니오 |
