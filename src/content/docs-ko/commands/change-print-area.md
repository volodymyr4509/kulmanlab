# ChangePrintArea

`ChangePrintArea` 명령은 [인쇄 관리자](../print-manager/)가 내보내는 사각형 영역을 지정합니다. 인쇄 관리자가 숨겨진 상태에서 빈 캔버스 위에서 실행되며 마주 보는 두 모서리를 받습니다 — [Rectangle](../rectangle/)과 동일한 두 번의 클릭이므로 좌표 입력과 스냅도 똑같이 동작합니다.

## 영역 선택

1. 터미널에 `ChangePrintArea`를 입력하거나 인쇄 관리자 사이드바에서 **Change Area**를 클릭합니다. 인쇄 관리자가 숨겨지고 캔버스가 조작 가능해집니다.
2. **첫 번째 모서리를 클릭**하거나, 정확한 좌표를 원하면 `X,Y`를 입력하고 **Enter**를 누릅니다.
3. **맞은편 모서리를 클릭**하거나 `X,Y`를 다시 입력합니다.

인쇄 관리자가 새 영역을 미리보기에 표시하며 다시 열리고, 미리보기는 해당 영역의 정확한 종횡비에 맞게 크기가 조정됩니다.

모서리는 다른 점 지정과 마찬가지로 그립과 교차점에 스냅되므로, 눈대중이 아니라 그려진 형상에 맞춰 자를 수 있습니다. 두 모서리의 순서는 상관없으며, 마주 보는 모서리는 같은 사각형을 정의합니다.

`Escape`를 누르면 취소됩니다. 아무것도 기록되지 않으므로 인쇄 관리자는 기존 영역 그대로 다시 열립니다.

## 영역이 기억되는 위치

선택은 전역이 아니라 컨텍스트별로 저장됩니다:

| 컨텍스트 | 슬롯 |
|---|---|
| 모델 공간 | 공유 슬롯 하나 |
| 각 레이아웃 | 따로 유지되는 자체 슬롯 |

같은 레이아웃(또는 모델 공간)에서 인쇄 관리자를 다시 열면 초기화되지 않고 해당 컨텍스트의 마지막 자르기가 복원되며, 레이아웃을 전환해도 각각의 영역은 그대로 유지됩니다.

이는 메모리에만 저장됩니다. 페이지를 새로 고치면 저장된 모든 영역이 지워지고 인쇄 관리자는 아래 기본값으로 돌아갑니다.

## 기본 영역

현재 컨텍스트에 저장된 값이 없으면 인쇄 관리자는 다음으로 열립니다:

| 컨텍스트 | 기본값 |
|---|---|
| 모델 공간 | 모든 엔티티의 경계 상자 — [Fit](../fit/)이 확대하는 것과 같은 범위 |
| 각 레이아웃 | 시트 전체 |

## 관련 명령

| 명령 | 기능 |
|---|---|
| [Print Manager](../print-manager/) | 이 영역이 적용되는 내보내기 창 |
| [Rectangle](../rectangle/) | 동일한 두 모서리 지정이지만 폴리라인을 그립니다 |
| [Fit](../fit/) | 모델 공간이 기본으로 사용하는 범위로 확대합니다 |
