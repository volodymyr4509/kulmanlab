# HatchAdd

`HatchAdd` 명령은 [Hatch Manager](../hatch-manager/) 대화 상자를 먼저 열지 않고 `.pat` 해치 패턴 파일을 업로드하기 위해 시스템 파일 선택 창을 엽니다. Hatch Manager의 **Add .pat File** 버튼이 실행하는 것과 같은 업로드이며, HatchAdd는 터미널에서 그곳으로 곧장 가는 길일 뿐입니다.

## 패턴 파일 업로드하기

1. 터미널에 `HatchAdd`를 입력하거나, [Hatch Manager](../hatch-manager/) 대화 상자 아래쪽의 **Add .pat File**을 클릭하십시오.
2. 시스템 선택 창에서 `.pat` 파일을 고르십시오. 표준 해치 패턴 형식만 받습니다.

파일 선택 창이 열리는 즉시 명령이 끝납니다 — 이후의 프롬프트나 클릭, 터미널 입력은 없습니다. 파일을 고르는 즉시 패턴이 등록되어 **User** 그룹에 나타납니다.

## 업로드 시 일어나는 일

- **`.pat` 파일은 담는 그릇이지 패턴 하나가 아닙니다.** 파일 하나가 이름 붙은 패턴을 여럿 정의하는 것이 보통이고, 그것들이 함께 추가됩니다. `.ttf` 하나가 글꼴 하나인 [FontAdd](../font-add/)와 갈라지는 지점입니다.
- **파일 자체는 보관하지 않습니다.** 한 번 읽어 패턴으로 나눈 뒤, 각 패턴을 자기 이름으로 따로 저장합니다. 그래서 나중에 한 패턴만 지워도 함께 들어온 나머지는 그대로 남고, 그래서 **User** 그룹은 어느 파일에서 왔는지가 아니라 이름의 가나다순으로 나열합니다.
- **이름이 기존 패턴과 같으면 그것을 대체합니다.** KulmanLab 자체의 근사치 위에 공인된 정의를 얹는 지원되는 방법입니다. 실제 `acad.pat`를 올리면 그 `ANSI31`과 다른 표준 이름의 정의가 넘겨받습니다.
- **패턴은 도면이 아니라 사용자 단위로 저장됩니다.** 브라우저(IndexedDB)에 남아 다음에 KulmanLab CAD를 열 때 자동으로 다시 불러오며, 모든 도면에서 쓸 수 있습니다.
- **유효한 패턴 정의가 없는 파일은 아무것도 추가하지 않습니다.** 라이브러리는 그대로 유지됩니다.

## 키보드 참고

HatchAdd에는 자체 키보드 조작이 없습니다 — 명령 전체가 브라우저의 기본 파일 선택 대화 상자입니다. 그 대화 상자를 취소하거나 파일을 고르지 않으면 패턴 라이브러리는 그대로 남습니다.

## 관련 명령어

| 명령어 | 기능 |
|--------|------|
| [Hatch Manager](../hatch-manager/) | 실시간 견본 미리보기로 패턴 라이브러리를 둘러보고, 업로드한 패턴을 제거 |
| [Hatch](../hatch/) | 닫힌 영역을 라이브러리의 패턴으로 채움 |
| [FontAdd](../font-add/) | `.ttf` 글꼴을 위한 같은 직접 업로드 단축 명령 |
