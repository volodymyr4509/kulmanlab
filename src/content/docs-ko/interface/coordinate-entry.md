# 좌표 입력

명령이 점을 요구할 때 — [Line](../../commands/line/)의 시작점, [Rectangle](../../commands/rectangle/)의 모서리, [Move](../../commands/move/)의 기준점, 드래그 중인 그립 등 — 클릭하는 대신 입력할 수 있습니다. 숫자를 입력하기 시작하면 터미널에 입력 내용이 표시되고, **Enter** 또는 **Space**를 누르면 점이 놓입니다.

## 점을 쓰는 네 가지 방법

| 입력 | 점의 위치 |
|---|---|
| `100,50` | X 100, Y 50 |
| `@100,50` | 마지막 점에서 X로 100, Y로 50 |
| `100<45` | 원점에서 100, 45° 방향 |
| `@100<45` | 마지막 점에서 100, 45° 방향 |

각도는 도 단위이며 X축에서 반시계 방향입니다. 따라서 `@50<90`은 위로 50, `@50<180`은 왼쪽으로 50입니다. 두 값 모두 음수일 수 있습니다.

## 마지막 점

`@`는 어떤 명령에서든 마지막으로 클릭하거나 입력한 점에서 잽니다. 이전 명령의 마지막 클릭도, 방금 드래그한 그립도 포함됩니다. 아직 마지막 점이 없으면 `@100,50`은 `100,50`으로 읽힙니다. 모델 공간과 레이아웃을 오가거나 도면을 열면 마지막 점은 잊힙니다.

## Rel: 기본적으로 상대 좌표

컨트롤 바의 **Rel** 토글을 켜면 입력하는 모든 점이 상대 좌표로 시작합니다. 첫 숫자를 입력하자마자 앞에 `@`가 붙어 `100,50`은 `@100,50`이 됩니다. `@` 위에서 **Backspace**를 누르면 그 점만 절대 좌표가 됩니다. 아직 마지막 점이 없으면 `@`는 붙지 않습니다. Rel은 기본적으로 꺼져 있으며 다른 컨트롤 바 토글과 함께 기억됩니다.

## 입력 중 키

| 키 | 동작 |
|---|---|
| `0`–`9`, `.`, `-` | 숫자 입력. `-`는 맨 앞에서만 |
| `@` | 점을 상대 좌표로, X의 맨 앞에서 |
| `,` 또는 **Space** | X를 마치고 Y로 |
| `<` | X를 거리로 마치고 그 각도로 |
| **Enter** 또는 **Space** | Y에 값이 있으면 점을 놓음 |
| **←** **→** **Home** **End** | 입력 중인 값 안에서 커서 이동 |
| **Backspace** | 커서 앞을 지움. 빈 Y의 맨 앞에서는 X로 돌아감 |

숫자로 읽을 수 없는 점은 고칠 수 있도록 터미널에 남습니다. 입력한 점은 입력한 그대로 터미널 기록에 한 줄을 남기며 — `입력: @100<45` — 그 뒤에 명령이 점이 놓인 위치를 적은 줄이 이어집니다.

## 입력한 점과 각도 추적

커서가 각도 추적 광선에 잠겨 있을 때 숫자를 입력하면 X가 아니라 그 광선을 따른 거리가 됩니다. 먼저 `@`를 입력하면 완전한 점 입력이 시작되므로, 잠긴 광선에서도 `@100,50`이 동작합니다.
