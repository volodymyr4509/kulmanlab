# 선택 필터

한 번에 여러 개체를 선택하면 속성 패널이 다중 선택 보기("Selection (N)")로 열립니다. 닫기 버튼 옆의 **필터 아이콘**을 쓰면 일괄 편집에 앞서 그 선택을 속성으로 좁힐 수 있습니다.

## 필터 열기

1. 개체를 여러 개 선택합니다 — 선택 상자를 끌거나, Shift 클릭하거나, Ctrl+A를 누릅니다.
2. 속성 패널 머리글의 **필터 아이콘**(깔때기)을 클릭합니다.
3. 버튼 아래에 팝업이 열리고, 선택 안에서 실제로 값이 갈리는 속성마다 체크리스트가 나타납니다.

## 패싯

팝업은 최대 다섯 개의 패싯을 보여 주며, 각각은 현재 선택에서 실시간으로 만들어집니다.

| 패싯 | 표시되는 값 |
|------|-------------|
| **유형** | 개체 유형 이름(Line, Circle, Hatch, …) |
| **도면층** | 도면층 이름과 그 도면층에 맞는 색상 견본 |
| **색상** | ACI 색상 번호 |
| **선가중치** | 선가중치 값 |
| **선종류** | 선종류 이름 |

패싯은 선택 안에 그 속성의 서로 다른 값이 실제로 둘 이상 있을 때만 나타납니다 — 같은 도면층에 있는 선 열 개를 골라도 도면층 패싯은 뜨지 않습니다. 체크해 봐야 아무것도 좁혀지지 않기 때문입니다. 해당 속성을 아예 갖지 않는 개체(예를 들어 Hatch와 Text에는 선가중치도 선종류도 없습니다)는 그 패싯 집계에 그냥 포함되지 않으며, 그 패싯 때문에 제외되지도 않습니다.

## 선택 좁히기

아무 패싯에서나 값을 하나 이상 체크하면 선택이 **체크된 모든 패싯**을 만족하는 개체로 좁혀집니다(개체는 여러분이 건드린 *모든* 패싯에서 체크된 값 가운데 최소 하나와 일치해야 합니다. 어느 한 패싯만으로는 부족합니다). 각 패싯의 체크박스와 개수는 *다른* 체크된 패싯이 이미 좁혀 놓은 결과를 반영하므로, 패싯이 자기 자신의 이미 체크된 항목을 감추는 일은 없습니다 — 패싯 검색의 일반적인 동작입니다.

결과 개수는 체크하고 해제할 때마다 즉시 갱신되고, 캔버스의 선택 자체도 함께 좁혀집니다. 이것은 단순한 표시용 필터가 아닙니다. 더 이상 조건에 맞지 않는 개체는 실제로 선택이 해제되어, 걸러 낸 부분집합을 그대로 일괄 편집할 수 있습니다.

## 필터 지우기

팝업의 초기화 컨트롤로 체크를 모두 지우고 원래 선택 전체로 돌아가거나, 팝업을 닫으면 됩니다(다음에 다른 선택에서 필터 아이콘을 누르면 새 기준으로 다시 열립니다).

## 관련

- [Match Properties](../../commands/match-properties/) — 대상을 좁힌 뒤 한 개체의 속성을 다른 개체로 복사
- [LayerIsolate](../../commands/layer-isolate/) — 현재 선택과 무관하게 도면층만으로 분리하고 싶을 때의 도면층 단위 대안
