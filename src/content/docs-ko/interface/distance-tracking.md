# 거리 추적

**거리 추적**은 클릭하는 대신 정확한 길이를 입력해 점을 놓게 해 줍니다. 제어 막대의 **Dist** 토글([Pins](../vector-pins/)와 ANGL 옆)로 제어하며, **기본으로 켜져 있고** 설정은 세션이 바뀌어도 유지됩니다.

더해 주는 것은 좁지만 쓸모가 있습니다. **가장 최근의 벡터 핀**이 각도 추적의 측정 기준점이 되게 합니다. 이것이 없으면 명령은 자기가 이미 모아 둔 점에서만 측정할 수 있습니다 — 즉 도형의 *첫* 점은 측정할 기준 자체가 없습니다.

## 세 토글이 함께 작동합니다

거리 추적은 혼자서는 성립하지 않습니다. 길이를 입력하려면 다른 두 토글이 올바른 상태여야 합니다.

| 토글 | 역할 |
|------|------|
| **Pins** | 기준점을 제공합니다. 스냅점 위에 500ms 머무르면 고정됩니다 — [Vector Pins](../vector-pins/) 참고. |
| **ANGL** | 각도를 제공합니다. 거리 추적은 커서가 각도에 잠긴 뒤에야 쓸 수 있으므로, ANGL은 Off가 아니라 단계(10°, 20°, 30°, 45°, 90°)로 설정되어 있어야 합니다. |
| **Dist** | 명령 자신의 점뿐 아니라 핀을 기준점으로 쓰도록 허용합니다. |

Pins와 Dist가 켜져 있어도 ANGL이 **Off**면 아무 일도 일어나지 않습니다. 길이를 잴 잠긴 방향이 없기 때문입니다.

## Pins와 Dist가 묶이는 방식

핀이 꺼진 상태에서 거리 추적은 의미가 없으므로 두 토글은 발을 맞춥니다.

- **Pins를 켜면** **Dist도 켜집니다**.
- **Pins를 끄면** **Dist도 꺼집니다**.
- **Dist를 켜면** 아직 꺼져 있던 **Pins가 켜집니다**.
- **Dist를 끄면** **Pins는 켜진 채로** 남습니다.

따라서 Pins가 꺼진 동안 Dist가 활성일 수는 없습니다. 다만 정렬용으로 핀 추적은 남겨 두고 거리 추적만 끌 수 있습니다 — 내 마지막 점에 잠기려 했는데 커서가 핀에 잠기는 일 없이 기준선만 쓰고 싶을 때 유용합니다.

## 정확한 거리에 점 놓기

1. **Pins**와 **Dist**를 켜고 **ANGL**을 각도 단계로 설정합니다.
2. 점을 요구하는 명령을 시작합니다 — [Line](../../commands/line/), [Circle](../../commands/circle/), [Rectangle](../../commands/rectangle/) 등.
3. **기준점을 고정합니다**: 기존 스냅점 위에 커서를 올려 표시가 채워진 사각형으로 바뀔 때까지 기다립니다.
4. 원하는 각도 방향으로 커서를 핀에서 멀어지게 움직입니다. ANGL 단계 중 하나에 가까워지면 방향이 **잠기고** 핀에서 추적 표시가 나타납니다.
5. **길이를 입력하고** **Enter** 또는 **Space**를 누릅니다. 점은 잠긴 각도를 따라 핀에서 정확히 그만큼 떨어진 자리에 놓입니다.

터미널 프롬프트가 입력 가능한 시점을 알려 줍니다. 잠긴 동안에는 이렇게 표시됩니다:

```
pick start point or enter length: [ ]
```

입력한 값은 대괄호 안에 나타납니다.

## 첫 점이 중요한 이유

이것이 없으면 불가능한 경우가 바로 이것입니다. 기존 모서리에서 오른쪽으로 정확히 250단위 떨어진 곳에서 선을 시작한다고 해 봅시다.

1. [Line](../../commands/line/)을 시작합니다.
2. 기존 모서리를 고정합니다.
3. 방향이 0°에서 잠길 때까지 오른쪽으로 움직입니다.
4. `250`을 입력하고 **Enter**를 누릅니다.

이제 선은 모서리에서 250단위 떨어진 점에서 시작합니다 — 보조 도형도, 암산도 필요 없습니다. Dist가 없으면 Line 명령은 아직 점을 하나도 모으지 못한 상태라 입력한 길이를 *잴 기준*이 없습니다. 대충 클릭하거나, 보조선을 그린 뒤 나중에 지우는 수밖에 없었습니다.

**두 번째 이후** 점에서는 명령이 이미 자기 기준점(직전 점)을 가지고 있고 그쪽이 먼저 쓰입니다. 핀은 내 기준점이 잠기지 않았을 때만 대안으로 참조되므로, 무언가를 고정한다고 해서 이미 걸린 잠금을 가로채지 않습니다.

## 입력하면 잠금이 고정됩니다

숫자를 입력하기 시작하면 기준점은 더 이상 바뀌지 않습니다. 첫 숫자가 들어온 순간 잠겨 있던 점이, 확정하거나 입력란을 비울 때까지 기준점으로 남습니다 — 입력 도중 마우스를 움직여도 측정이 다른 핀이나 명령 자신의 점으로 슬그머니 옮겨 가지 않습니다.

## 키보드 참조

| 키 | 동작 |
|----|------|
| `0`–`9`, `.` | 길이에 덧붙이기 |
| `-` | 음수 길이 — 잠긴 각도를 따라 방향을 뒤집습니다(첫 문자일 때만) |
| `Backspace` | 마지막 문자 삭제 |
| `Enter` / `Space` | 입력한 길이에 점 놓기 |
| `Escape` | 명령 취소. 잠금과 입력값이 지워집니다 |

길이 입력은 선택 사항입니다. 방향이 잠긴 상태에서도 클릭할 수 있고, 그 점은 잠긴 각도 위로 투영됩니다.
