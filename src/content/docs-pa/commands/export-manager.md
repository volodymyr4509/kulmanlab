# Export Manager

`exportmanager` ਕਮਾਂਡ ਮੌਜੂਦਾ ਡਰਾਇੰਗ ਨੂੰ ਤੁਹਾਡੇ ਫਾਈਲ ਸਿਸਟਮ ਵਿੱਚ ਡਾਊਨਲੋਡ ਕਰਦੀ ਹੈ। ਦੋ ਫਾਰਮੈਟ ਉਪਲਬਧ ਹਨ, ਨਾਲ-ਨਾਲ ਕਾਰਡਾਂ ਵਜੋਂ ਦਿਖਾਏ ਗਏ: ਹੋਰ CAD ਟੂਲਾਂ ਨਾਲ ਅਨੁਕੂਲਤਾ ਲਈ **DXF** ਅਤੇ KulmanLab CAD ਦੇ ਅੰਦਰ ਪੂਰੀ-ਵਫ਼ਾਦਾਰੀ ਸੇਵ ਲਈ **JSON** — ਹਰ ਕਾਰਡ ਬਿਲਕੁਲ ਦੱਸਦਾ ਹੈ ਕਿ ਉਹ ਫਾਰਮੈਟ ਕਿਹੜੀਆਂ ਐਂਟਿਟੀ ਕਿਸਮਾਂ ਲੈ ਕੇ ਜਾਂਦਾ ਹੈ।

## ਐਕਸਪੋਰਟ ਕਿਵੇਂ ਕਰੀਏ

1. ਫਾਈਲ ਪੈਨਲ ਵਿੱਚ ਟੂਲਬਾਰ ਦੇ **Export** ਬਟਨ (ਡਾਊਨਲੋਡ ਆਈਕਨ) 'ਤੇ ਕਲਿੱਕ ਕਰੋ, ਜਾਂ ਟਰਮੀਨਲ ਵਿੱਚ `exportmanager` ਟਾਈਪ ਕਰੋ।
2. **Export Manager** ਪੌਪਅੱਪ ਖੁੱਲ੍ਹਦਾ ਹੈ ਜੋ JSON ਅਤੇ DXF ਕਾਰਡ ਨਾਲ-ਨਾਲ ਦਿਖਾਉਂਦਾ ਹੈ, ਹਰ ਇੱਕ ਦੱਸਦਾ ਹੈ ਕਿ ਕੀ ਐਕਸਪੋਰਟ ਹੁੰਦਾ ਹੈ।
3. ਫਾਰਮੈਟ ਚੁਣਨ ਲਈ ਕਿਸੇ ਕਾਰਡ 'ਤੇ ਕਲਿੱਕ ਕਰੋ — **JSON** ਜਾਂ **DXF**।
4. **Export \<FORMAT\>** ਬਟਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ। ਫਾਈਲ ਤੁਹਾਡੇ ਡਿਫਾਲਟ ਡਾਊਨਲੋਡ ਫੋਲਡਰ ਵਿੱਚ ਆਪਣੇ ਆਪ ਡਾਊਨਲੋਡ ਹੋ ਜਾਂਦੀ ਹੈ।

ਐਕਸਪੋਰਟ ਕੀਤੇ ਬਿਨਾਂ ਪੌਪਅੱਪ ਬੰਦ ਕਰਨ ਲਈ `Escape` ਦਬਾਓ।

## ਇੱਕ ਫਾਰਮੈਟ ਚੁਣਨਾ

| ਫਾਰਮੈਟ | ਐਕਸਟੈਂਸ਼ਨ | ਸਭ ਤੋਂ ਵਧੀਆ ਕਿਸ ਲਈ | ਸੀਮਾਵਾਂ |
|--------|-----------|---------------------|---------|
| **JSON** *(ਨੇਟਿਵ)* | `.json` | KulmanLab CAD ਵਿੱਚ ਦੁਬਾਰਾ ਖੋਲ੍ਹਣ ਲਈ ਕੰਮ ਸੇਵ ਕਰਨਾ | ਹੋਰ CAD ਟੂਲਾਂ ਨਾਲ ਅਨੁਕੂਲ ਨਹੀਂ |
| **DXF** | `.dxf` | FreeCAD, LibreCAD ਆਦਿ ਨਾਲ ਸਾਂਝਾ ਕਰਨਾ | ਕਿੰਨਾ ਬਚੇਗਾ ਇਹ ਲੈਣ ਵਾਲੇ ਐਪਲੀਕੇਸ਼ਨ ਉੱਤੇ ਨਿਰਭਰ ਹੈ |

**JSON ਕਦੋਂ ਵਰਤਣਾ ਹੈ:** ਜਦੋਂ ਵੀ ਤੁਸੀਂ ਆਪਣੇ ਕੰਮ ਦੀ ਇੱਕ ਪੂਰੀ ਕਾਪੀ ਸੇਵ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ। JSON KulmanLab ਦਾ ਨੇਟਿਵ ਫਾਰਮੈਟ ਹੈ ਅਤੇ ਹਰ ਐਂਟਿਟੀ ਨੂੰ ਬਿਲਕੁਲ ਸੁਰੱਖਿਅਤ ਰੱਖਦਾ ਹੈ — Dimensions, Leaders, Hatches, ਅਤੇ ਸਾਰੇ ਲੇਅਰ ਡੇਟਾ ਸਮੇਤ।

**DXF ਕਦੋਂ ਵਰਤਣਾ ਹੈ:** ਜਦੋਂ ਤੁਹਾਨੂੰ ਡਰਾਇੰਗ ਕਿਸੇ ਅਜਿਹੇ ਵਿਅਕਤੀ ਨੂੰ ਸੌਂਪਣੀ ਹੋਵੇ ਜੋ ਕੋਈ ਹੋਰ CAD ਐਪਲੀਕੇਸ਼ਨ ਵਰਤਦਾ ਹੈ। ਐਕਸਪੋਰਟ ਕੀਤੀ ਫਾਈਲ AC1032 DXF ਫਾਰਮੈਟ ਵਰਤਦੀ ਹੈ ਅਤੇ ਜ਼ਿਆਦਾਤਰ DXF-ਅਨੁਕੂਲ ਟੂਲਾਂ ਵਿੱਚ ਖੋਲ੍ਹੀ ਜਾ ਸਕਦੀ ਹੈ।

## ਹਰ ਫਾਰਮੈਟ ਵਿੱਚ ਕੀ ਐਕਸਪੋਰਟ ਹੁੰਦਾ ਹੈ

### JSON ਐਕਸਪੋਰਟ

ਹਰ ਐਂਟਿਟੀ ਕਿਸਮ ਸ਼ਾਮਲ ਹੈ:

- Lines, Circles, Arcs, Ellipses, Polylines, Splines
- Text
- Dimensions (linear, aligned, continued, radius, diameter)
- Leaders (multileaders)
- Hatches, ਉਹਨਾਂ ਦੇ ਪੈਟਰਨ, ਸਕੇਲ, ਕੋਣ, ਅਤੇ origin ਸਮੇਤ
- Layers ਅਤੇ Linetypes

### DXF ਐਕਸਪੋਰਟ

ਹਰ ਐਂਟਿਟੀ ਕਿਸਮ ਸ਼ਾਮਲ ਹੈ:

- Lines, Circles, Arcs, Ellipses, Polylines (`LWPOLYLINE` ਵਜੋਂ ਐਕਸਪੋਰਟ), Splines
- Text
- Dimensions (linear, aligned, continued, radius, diameter)
- Leaders (multileaders)
- Hatches, ਉਹਨਾਂ ਦੇ ਪੈਟਰਨ, ਸਕੇਲ, ਕੋਣ, ਅਤੇ origin ਸਮੇਤ
- Layers ਅਤੇ Linetypes

ਫ਼ਾਈਲ AC1032 DXF ਵਜੋਂ ਲਿਖੀ ਜਾਂਦੀ ਹੈ, ਸੋ KulmanLab ਤੋਂ ਬਰਾਮਦ ਕੀਤੀ ਡਰਾਇੰਗ ਹੋਰ DXF-ਸਮਰੱਥ ਸੰਦਾਂ ਵਿੱਚ ਆਪਣੇ ਨਿਸ਼ਾਨਾਂ ਸਮੇਤ ਖੁੱਲ੍ਹਦੀ ਹੈ, ਨਿਰੀ ਰੇਖਾ-ਗਣਿਤ ਬਣ ਕੇ ਨਹੀਂ ਪਹੁੰਚਦੀ।

ਅੱਗੇ ਹਰ ਲੈਣ ਵਾਲਾ ਐਪਲੀਕੇਸ਼ਨ ਉਸ ਨਾਲ ਕੀ ਕਰਦਾ ਹੈ, ਇਹ ਹਾਲੇ ਵੀ ਵੱਖੋ-ਵੱਖ ਹੈ — DXF ਦੀ ਸਹਾਇਤਾ ਸੰਦ ਦਰ ਸੰਦ ਵੱਖਰੀ ਹੈ, ਤੇ ਕੋਈ ਪੁਰਾਣਾ ਉਹ ਇਕਾਈਆਂ ਅਣਗੌਲੀਆਂ ਕਰ ਸਕਦਾ ਹੈ ਜੋ ਨਵਾਂ ਪੜ੍ਹ ਲੈਂਦਾ ਹੈ। ਜੇ ਡਰਾਇੰਗ ਨੂੰ ਹਰ ਥਾਂ ਇੱਕੋ ਜਿਹੀ ਦਿਸਣਾ ਜ਼ਰੂਰੀ ਹੈ, ਤਾਂ [Print Manager](../print-manager/) ਉਸ ਨੂੰ PDF ਜਾਂ ਤਸਵੀਰ ਵਜੋਂ ਸਾਂਭ ਲੈਂਦਾ ਹੈ।

## ਐਕਸਪੋਰਟ ਕੀਤੀ ਫਾਈਲ ਦਾ ਨਾਮ

ਡਾਊਨਲੋਡ ਕੀਤੀ ਫਾਈਲ ਦਾ ਨਾਮ ਮੌਜੂਦਾ ਡਰਾਇੰਗ ਫਾਈਲ ਦੇ ਨਾਮ 'ਤੇ ਰੱਖਿਆ ਜਾਂਦਾ ਹੈ (ਜਿਵੇਂ `myplan.json`)। ਐਕਸਟੈਂਸ਼ਨ ਚੁਣੇ ਗਏ ਫਾਰਮੈਟ ਨਾਲ ਮੇਲ ਖਾਣ ਲਈ ਬਦਲ ਜਾਂਦਾ ਹੈ।

## Export Manager ਅਤੇ Print Manager ਵਿੱਚ ਅੰਤਰ

| ਫੀਚਰ | Export Manager | Print Manager |
|-------|-----------------|-----------------|
| ਆਉਟਪੁੱਟ | ਵੈਕਟਰ ਸੋਰਸ ਫਾਈਲ (.dxf / .json) | ਰਾਸਟਰ ਚਿੱਤਰ (.png / .jpeg / .webp / .pdf) |
| ਹੋਰ ਟੂਲਾਂ ਵਿੱਚ ਸੰਪਾਦਨਯੋਗ | ਹਾਂ (DXF) | ਨਹੀਂ |
| Layers ਅਤੇ Linetypes ਸੁਰੱਖਿਅਤ ਰੱਖਦਾ ਹੈ | ਹਾਂ | ਨਹੀਂ (ਫਲੈਟ ਰੈਂਡਰ ਹੁੰਦਾ ਹੈ) |
| Dimensions ਅਤੇ Leaders ਕੈਪਚਰ ਕਰਦਾ ਹੈ | ਹਾਂ | ਹਾਂ |

ਜਦੋਂ ਤੁਹਾਨੂੰ ਸੰਪਾਦਨਯੋਗ ਫਾਈਲ ਚਾਹੀਦੀ ਹੋਵੇ ਤਾਂ **Export Manager** ਵਰਤੋ। ਜਦੋਂ ਤੁਹਾਨੂੰ ਵਿਜ਼ੁਅਲ ਸਨੈਪਸ਼ਾਟ ਚਾਹੀਦਾ ਹੋਵੇ ਤਾਂ [Print Manager](../print-manager/) ਵਰਤੋ।
