# ChangePrintArea

`ChangePrintArea` ਕਮਾਂਡ ਉਹ ਆਇਤਾਕਾਰ ਖੇਤਰ ਤੈਅ ਕਰਦੀ ਹੈ ਜੋ [Print Manager](../print-manager/) ਨਿਰਯਾਤ ਕਰਦਾ ਹੈ। ਇਹ Print Manager ਦੇ ਲੁਕੇ ਹੋਏ ਹੁੰਦਿਆਂ ਖਾਲੀ ਕੈਨਵਸ ਉੱਤੇ ਚੱਲਦੀ ਹੈ ਅਤੇ ਦੋ ਵਿਰੋਧੀ ਕੋਨੇ ਲੈਂਦੀ ਹੈ — [Rectangle](../rectangle/) ਵਾਂਗ ਹੀ ਦੋ ਕਲਿੱਕ, ਇਸ ਲਈ ਟਾਈਪ ਕੀਤੇ ਧੁਰੇ ਤੇ ਸਨੈਪਿੰਗ ਬਿਲਕੁਲ ਉਵੇਂ ਹੀ ਕੰਮ ਕਰਦੇ ਹਨ।

## ਖੇਤਰ ਚੁਣਨਾ

1. ਟਰਮੀਨਲ ਵਿੱਚ `ChangePrintArea` ਟਾਈਪ ਕਰੋ, ਜਾਂ Print Manager ਦੇ ਸਾਈਡਬਾਰ ਵਿੱਚ **Change Area** ਦਬਾਓ। Print Manager ਲੁਕ ਜਾਂਦਾ ਹੈ ਅਤੇ ਕੈਨਵਸ ਇੰਟਰਐਕਟਿਵ ਹੋ ਜਾਂਦਾ ਹੈ।
2. **ਪਹਿਲੇ ਕੋਨੇ 'ਤੇ ਕਲਿੱਕ ਕਰੋ**, ਜਾਂ ਸਹੀ ਧੁਰੇ ਲਈ `X,Y` ਟਾਈਪ ਕਰਕੇ **Enter** ਦਬਾਓ।
3. **ਵਿਰੋਧੀ ਕੋਨੇ 'ਤੇ ਕਲਿੱਕ ਕਰੋ**, ਜਾਂ ਦੁਬਾਰਾ `X,Y` ਟਾਈਪ ਕਰੋ।

Print Manager ਨਵੇਂ ਖੇਤਰ ਨਾਲ ਮੁੜ ਖੁੱਲ੍ਹਦਾ ਹੈ, ਅਤੇ ਪ੍ਰੀਵਿਊ ਉਸ ਖੇਤਰ ਦੇ ਸਹੀ ਆਸਪੈਕਟ ਅਨੁਪਾਤ ਅਨੁਸਾਰ ਆਕਾਰ ਬਦਲ ਲੈਂਦਾ ਹੈ।

ਕੋਨੇ ਕਿਸੇ ਵੀ ਹੋਰ ਬਿੰਦੂ ਚੋਣ ਵਾਂਗ ਗ੍ਰਿਪ ਤੇ ਕਾਟ-ਬਿੰਦੂਆਂ 'ਤੇ ਸਨੈਪ ਹੁੰਦੇ ਹਨ, ਸੋ ਅੰਦਾਜ਼ੇ ਦੀ ਥਾਂ ਖਿੱਚੀ ਹੋਈ ਜਿਓਮੈਟਰੀ ਉੱਤੇ ਕਰੌਪ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ। ਦੋਹਾਂ ਕੋਨਿਆਂ ਦਾ ਕ੍ਰਮ ਮਾਇਨੇ ਨਹੀਂ ਰੱਖਦਾ: ਵਿਰੋਧੀ ਕੋਨੇ ਉਹੀ ਆਇਤ ਬਣਾਉਂਦੇ ਹਨ।

ਰੱਦ ਕਰਨ ਲਈ `Escape` ਦਬਾਓ। ਕੁਝ ਵੀ ਨਹੀਂ ਲਿਖਿਆ ਜਾਂਦਾ, ਸੋ Print Manager ਉਸੇ ਖੇਤਰ ਨਾਲ ਮੁੜ ਖੁੱਲ੍ਹਦਾ ਹੈ ਜੋ ਪਹਿਲਾਂ ਹੀ ਸੀ।

## ਖੇਤਰ ਕਿੱਥੇ ਯਾਦ ਰੱਖਿਆ ਜਾਂਦਾ ਹੈ

ਚੋਣ ਸਾਂਝੇ ਤੌਰ 'ਤੇ ਨਹੀਂ, ਹਰ ਪ੍ਰਸੰਗ ਲਈ ਵੱਖਰੀ ਸੰਭਾਲੀ ਜਾਂਦੀ ਹੈ:

| ਪ੍ਰਸੰਗ | ਸਲਾਟ |
|---|---|
| Model ਸਪੇਸ | ਇੱਕ ਸਾਂਝਾ ਸਲਾਟ |
| ਹਰ ਲੇਆਉਟ | ਆਪਣਾ ਸਲਾਟ, ਵੱਖਰਾ ਰੱਖਿਆ |

ਉਸੇ ਲੇਆਉਟ — ਜਾਂ Model — ਵਿੱਚ Print Manager ਮੁੜ ਖੋਲ੍ਹਣ 'ਤੇ ਰੀਸੈੱਟ ਹੋਣ ਦੀ ਥਾਂ ਉਸ ਪ੍ਰਸੰਗ ਦਾ ਪਿਛਲਾ ਕਰੌਪ ਵਾਪਸ ਆ ਜਾਂਦਾ ਹੈ, ਅਤੇ ਲੇਆਉਟ ਬਦਲਣ 'ਤੇ ਹਰੇਕ ਦਾ ਖੇਤਰ ਸਹੀ-ਸਲਾਮਤ ਰਹਿੰਦਾ ਹੈ।

ਇਹ ਸਿਰਫ਼ ਮੈਮਰੀ ਵਿੱਚ ਰਹਿੰਦਾ ਹੈ। ਪੰਨਾ ਮੁੜ ਲੋਡ ਕਰਨ 'ਤੇ ਸਾਰੇ ਸੰਭਾਲੇ ਖੇਤਰ ਮਿਟ ਜਾਂਦੇ ਹਨ ਅਤੇ Print Manager ਹੇਠਾਂ ਦਿੱਤੇ ਡਿਫਾਲਟ 'ਤੇ ਪਰਤ ਆਉਂਦਾ ਹੈ।

## ਡਿਫਾਲਟ ਖੇਤਰ

ਮੌਜੂਦਾ ਪ੍ਰਸੰਗ ਲਈ ਕੁਝ ਸੰਭਾਲਿਆ ਨਾ ਹੋਵੇ, ਤਾਂ Print Manager ਇਸ ਉੱਤੇ ਖੁੱਲ੍ਹਦਾ ਹੈ:

| ਪ੍ਰਸੰਗ | ਡਿਫਾਲਟ |
|---|---|
| Model ਸਪੇਸ | ਸਾਰੀਆਂ ਐਂਟਿਟੀਆਂ ਦਾ ਬਾਊਂਡਿੰਗ ਬਾਕਸ — ਉਹੀ ਵਿਸਥਾਰ ਜਿਸ 'ਤੇ [Fit](../fit/) ਜ਼ੂਮ ਕਰਦਾ ਹੈ |
| ਹਰ ਲੇਆਉਟ | ਪੂਰੀ ਸ਼ੀਟ |
