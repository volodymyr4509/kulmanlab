# Point Interval

`pointinterval` ਕਮਾਂਡ ਵਸਤੂ ਦੇ ਨਾਲ ਤੈਅ ਫ਼ਾਸਲੇ 'ਤੇ [ਬਿੰਦੂ](../point/) ਰੱਖਦੀ ਹੈ, ਜਿਵੇਂ ਕਿਸੇ ਰਸਤੇ 'ਤੇ ਸਟੇਸ਼ਨ ਨਿਸ਼ਾਨਬੱਧ ਕੀਤੇ ਜਾਂਦੇ ਹਨ। ਵਸਤੂ ਖ਼ੁਦ ਨਹੀਂ ਬਦਲਦੀ: ਬਿੰਦੂ ਮੌਜੂਦਾ ਲੇਅਰ ਅਤੇ ਰੰਗ ਵਿੱਚ ਨਵੀਆਂ ਐਂਟਿਟੀਆਂ ਹਨ, ਸਨੈਪ ਕਰਨ ਲਈ ਕੰਮ ਦੀਆਂ।

## ਅੰਤਰਾਲ 'ਤੇ ਬਿੰਦੂ ਰੱਖਣਾ

1. ਟਰਮੀਨਲ ਵਿੱਚ `pointinterval` ਟਾਈਪ ਕਰੋ ਜਾਂ Edit ਪੈਨਲ ਦੇ ਐਰੇ ਡ੍ਰੌਪਡਾਊਨ ਵਿੱਚੋਂ **Point Interval** ਚੁਣੋ।
2. **ਜਿਸ ਸਿਰੇ ਤੋਂ ਸ਼ੁਰੂ ਕਰਨਾ ਹੈ ਉਸਦੇ ਨੇੜੇ ਵਸਤੂ 'ਤੇ ਕਲਿੱਕ ਕਰੋ** — ਰੇਖਾ, ਪੌਲੀਲਾਈਨ, ਚਾਪ, ਚੱਕਰ, ਅੰਡਾਕਾਰ ਜਾਂ ਸਪਲਾਈਨ। ਹੋਰ ਕੁਝ ਰੱਦ ਹੁੰਦਾ ਹੈ, ਅਤੇ ਤੁਸੀਂ ਦੁਬਾਰਾ ਚੁਣ ਸਕਦੇ ਹੋ।
3. **ਅੰਤਰਾਲ ਦੀ ਲੰਬਾਈ ਟਾਈਪ ਕਰੋ।** ਟਾਈਪ ਕਰਦਿਆਂ ਬਿੰਦੂ ਵਸਤੂ 'ਤੇ ਪੂਰਵ-ਦਰਸ਼ਨ ਵਿੱਚ ਦਿਖਦੇ ਹਨ।
4. ਉਹਨਾਂ ਨੂੰ ਰੱਖਣ ਲਈ **Enter** ਜਾਂ **Space** ਦਬਾਓ। ਕਮਾਂਡ ਖ਼ਤਮ ਹੋ ਜਾਂਦੀ ਹੈ।

## ਬਿੰਦੂ ਕਿੱਥੇ ਆਉਂਦੇ ਹਨ

- ਪਹਿਲਾ ਬਿੰਦੂ ਸ਼ੁਰੂਆਤ ਤੋਂ ਇੱਕ ਅੰਤਰਾਲ 'ਤੇ ਆਉਂਦਾ ਹੈ ਅਤੇ ਬਾਕੀ ਇੱਕ-ਇੱਕ ਅੰਤਰਾਲ 'ਤੇ, ਵਸਤੂ ਦੇ ਨਾਲ ਮਾਪੇ ਗਏ, ਵਕਰਾਂ ਸਮੇਤ। ਸ਼ੁਰੂਆਤ 'ਤੇ ਕੋਈ ਬਿੰਦੂ ਨਹੀਂ ਆਉਂਦਾ।
- ਖੁੱਲ੍ਹੀ ਵਸਤੂ 'ਤੇ — ਰੇਖਾ, ਖੁੱਲ੍ਹੀ ਪੌਲੀਲਾਈਨ, ਚਾਪ, ਅੱਧਾ ਅੰਡਾਕਾਰ ਜਾਂ ਖੁੱਲ੍ਹੀ ਸਪਲਾਈਨ — ਮਾਪ ਉਸ ਸਿਰੇ ਤੋਂ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ ਜਿਸਦੇ ਨੇੜੇ ਤੁਸੀਂ ਕਲਿੱਕ ਕੀਤਾ। ਦੂਰ ਦੇ ਸਿਰੇ 'ਤੇ ਜੋ ਬਚਦਾ ਹੈ ਉਹ ਬਿਨਾਂ ਨਿਸ਼ਾਨ ਰਹਿੰਦਾ ਹੈ: ਅੰਤਰਾਲ ਠੀਕ ਬੈਠਣ 'ਤੇ ਹੀ ਦੂਰ ਦੇ ਸਿਰੇ 'ਤੇ ਬਿੰਦੂ ਆਉਂਦਾ ਹੈ।
- ਬੰਦ ਵਸਤੂ 'ਤੇ — ਚੱਕਰ, ਬੰਦ ਪੌਲੀਲਾਈਨ, ਪੂਰਾ ਅੰਡਾਕਾਰ ਜਾਂ ਬੰਦ ਸਪਲਾਈਨ — ਤੁਸੀਂ ਕਿਤੇ ਵੀ ਕਲਿੱਕ ਕਰੋ, ਮਾਪ ਵਸਤੂ ਦੀ ਆਪਣੀ ਸ਼ੁਰੂਆਤ ਤੋਂ ਹੁੰਦਾ ਹੈ: ਚੱਕਰ ਕੋਣ 0 ਤੋਂ ਘੜੀ ਦੀ ਉਲਟ ਦਿਸ਼ਾ ਵਿੱਚ, ਬੰਦ ਪੌਲੀਲਾਈਨ ਆਪਣੇ ਪਹਿਲੇ ਸਿਖਰ ਤੋਂ। ਬਿੰਦੂ ਸ਼ੁਰੂਆਤ ਤੋਂ ਪਹਿਲਾਂ ਰੁਕ ਜਾਂਦੇ ਹਨ।
- 0 ਜਾਂ ਘੱਟ, ਵਸਤੂ ਤੋਂ ਲੰਮੀ, ਜਾਂ 32767 ਤੋਂ ਵੱਧ ਬਿੰਦੂ ਦੇਣ ਵਾਲੀ ਲੰਬਾਈ ਰੱਦ ਹੁੰਦੀ ਹੈ: ਟਰਮੀਨਲ ਕਾਰਨ ਦੱਸਦਾ ਹੈ ਅਤੇ ਉਸਨੂੰ ਮਿਟਾ ਦਿੰਦਾ ਹੈ ਤਾਂ ਜੋ ਤੁਸੀਂ ਦੁਬਾਰਾ ਟਾਈਪ ਕਰ ਸਕੋ।

Backspace ਆਖਰੀ ਅੱਖਰ ਮਿਟਾਉਂਦਾ ਹੈ। Escape ਮੁੜ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ, ਤਾਂ ਜੋ ਤੁਸੀਂ ਹੋਰ ਵਸਤੂ ਚੁਣ ਸਕੋ। ਵਸਤੂ ਚੁਣਨ ਤੋਂ ਪਹਿਲਾਂ Enter ਜਾਂ Space ਕਮਾਂਡ ਖ਼ਤਮ ਕਰਦਾ ਹੈ।
