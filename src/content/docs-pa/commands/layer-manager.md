# LayerManager

`LayerManager` ਕਮਾਂਡ ਇੱਕ ਟੇਬਲ ਖੋਲ੍ਹਦੀ ਹੈ ਜਿਸ ਵਿੱਚ ਡਰਾਇੰਗ ਦੀ ਹਰ ਲੇਅਰ ਸੂਚੀਬੱਧ ਹੁੰਦੀ ਹੈ, ਅਤੇ ਉਸ ਦੀਆਂ **Freeze**, **Lock**, **Plot**, **Color**, **Lineweight** ਤੇ **Linetype** ਸੈਟਿੰਗਾਂ ਸਿੱਧੀਆਂ ਕਤਾਰ ਵਿੱਚ ਹੀ ਸੋਧੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ। ਨਵੀਆਂ ਲੇਅਰਾਂ ਜੋੜਨ ਅਤੇ ਮੌਜੂਦਾ ਲੇਅਰਾਂ ਦਾ ਵਿਹਾਰ ਬਦਲਣ ਦੀ ਇਹ ਮੁੱਖ ਥਾਂ ਹੈ — ਬਾਕੀ ਲੇਅਰ ਕਮਾਂਡਾਂ ([LayerMakeCurrent](../layer-make-current/), [LayerMatch](../layer-match/), [LayerIsolate](../layer-isolate/), [LayerUnfreezeAll](../layer-unfreeze-all/)) ਹਰੇਕ ਇਸ ਨੂੰ ਖੋਲ੍ਹੇ ਬਿਨਾਂ ਇੱਕ ਖਾਸ ਕੰਮ ਕਰਦੀ ਹੈ।

## Layer Manager ਖੋਲ੍ਹਣਾ

- ਟਰਮੀਨਲ ਵਿੱਚ `LayerManager` ਟਾਈਪ ਕਰੋ, **ਜਾਂ**
- ਲੇਅਰ ਪੈਨਲ ਵਿੱਚ **Layer Manager** ਬਟਨ ਦਬਾਓ।

ਡਾਇਲਾਗ ਇੱਕ ਤੈਰਦੇ ਪੈਨਲ ਵਜੋਂ ਖੁੱਲ੍ਹਦਾ ਹੈ; ਪਹਿਲਾਂ ਕੁਝ ਵੀ ਚੁਣਨ ਦੀ ਲੋੜ ਨਹੀਂ।

## ਲੇਅਰ ਟੇਬਲ

| ਕਾਲਮ | ਕੀ ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ |
|--------|-------------------|
| Name | ਲੇਅਰ ਦਾ ਨਾਂ, ਟੇਬਲ ਵਿੱਚ ਸਿਰਫ਼ ਪੜ੍ਹਨ ਲਈ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ (ਬਣਾਉਣ ਵੇਲੇ ਇੱਕ ਵਾਰ ਤੈਅ ਹੁੰਦਾ ਹੈ) |
| Freeze | ਲੇਅਰ ਦੀਆਂ ਇਕਾਈਆਂ ਲੁਕਾਉਂਦੀ ਹੈ ਅਤੇ ਅਨਫ੍ਰੀਜ਼ ਹੋਣ ਤੱਕ ਚੋਣ ਤੋਂ ਬਾਹਰ ਰੱਖਦੀ ਹੈ |
| Lock | ਲੇਅਰ ਦੀਆਂ ਇਕਾਈਆਂ ਨੂੰ ਲੁਕਾਏ ਬਿਨਾਂ ਸੋਧਣ ਤੋਂ ਰੋਕਦੀ ਹੈ |
| Plot | ਪ੍ਰਿੰਟ ਜਾਂ PDF ਨਿਰਯਾਤ ਵੇਲੇ ਲੇਅਰ ਦੀਆਂ ਇਕਾਈਆਂ ਸ਼ਾਮਲ ਹੋਣ ਜਾਂ ਨਾ |
| Color | ਲੇਅਰ ਦਾ ACI ਰੰਗ — ਰੰਗ ਚੋਣਕਾਰ ਖੋਲ੍ਹਣ ਲਈ ਸਵਾਚ ਦਬਾਓ |
| Lineweight | ਲੇਅਰ ਦੀ ਲਾਈਨ ਮੋਟਾਈ — ਲਾਈਨਵੇਟ ਚੋਣਕਾਰ ਖੋਲ੍ਹਣ ਲਈ ਚਿੱਪ ਦਬਾਓ |
| Linetype | ਲੇਅਰ ਦਾ ਡੈਸ਼ ਪੈਟਰਨ — ਲਾਈਨਟਾਈਪ ਚੋਣਕਾਰ ਖੋਲ੍ਹਣ ਲਈ ਚਿੱਪ ਦਬਾਓ |

Freeze, Lock ਜਾਂ Plot ਬਦਲਣਾ ਤੁਰੰਤ ਲਾਗੂ ਹੁੰਦਾ ਹੈ — ਵੱਖਰਾ ਸੇਵ ਕਦਮ ਨਹੀਂ ਹੈ। ਜਿਹੜੀਆਂ ਇਕਾਈਆਂ ਦਾ ਰੰਗ, ਲਾਈਨਵੇਟ ਜਾਂ ਲਾਈਨਟਾਈਪ **ByLayer** (ਡਿਫਾਲਟ) ਹੈ ਉਹ ਇੱਥੇ ਤੈਅ ਕੀਤਾ ਮੁੱਲ ਲੈ ਲੈਂਦੀਆਂ ਹਨ; ਜਿਨ੍ਹਾਂ ਦਾ ਆਪਣਾ ਵੱਖਰਾ ਮੁੱਲ ਹੈ ਉਹ ਪ੍ਰਭਾਵਿਤ ਨਹੀਂ ਹੁੰਦੀਆਂ।

## ਲੇਅਰ ਜੋੜਨਾ

1. ਟੇਬਲ ਦੇ ਹੇਠਾਂ **+ Add Layer** ਦਬਾਓ।
2. ਨਾਂ ਟਾਈਪ ਕਰਕੇ ਪੁਸ਼ਟੀ ਲਈ **Enter** ਦਬਾਓ, ਜਾਂ ਰੱਦ ਕਰਨ ਲਈ **Escape**।

ਲੇਅਰ ਦੇ ਨਾਂ ਵਿੱਚ ਅੱਖਰ, ਅੰਕ, ਖਾਲੀ ਥਾਂ ਅਤੇ `_`, `-`, `$` ਹੋ ਸਕਦੇ ਹਨ। ਖਾਲੀ ਨਾਂ, ਪਹਿਲਾਂ ਤੋਂ ਵਰਤਿਆ ਨਾਂ, ਜਾਂ ਕਿਸੇ ਹੋਰ ਅੱਖਰ ਵਾਲਾ ਨਾਂ ਮੌਕੇ 'ਤੇ ਹੀ ਗਲਤੀ ਨਾਲ ਰੱਦ ਹੋ ਜਾਂਦਾ ਹੈ, ਅਤੇ ਕਤਾਰ ਦੁਬਾਰਾ ਕੋਸ਼ਿਸ਼ ਲਈ ਖੁੱਲ੍ਹੀ ਰਹਿੰਦੀ ਹੈ।

ਨਵੀਆਂ ਲੇਅਰਾਂ **ਅਨਫ੍ਰੀਜ਼, ਅਨਲਾਕ, ਪਲਾਟ ਹੋਣ ਯੋਗ** ਸ਼ੁਰੂ ਹੁੰਦੀਆਂ ਹਨ, ਰੰਗ 7 (ਚਿੱਟਾ/ਕਾਲਾ), Lineweight Default ਅਤੇ Linetype Continuous ਨਾਲ — ਉਹੀ ਡਿਫਾਲਟ ਜੋ [Import](../import/) ਖਾਲੀ ਡਰਾਇੰਗ ਵਿੱਚ ਲੇਅਰ `0` ਨੂੰ ਦਿੰਦੀ ਹੈ।

## ਇੱਥੇ ਕੀ ਨਹੀਂ ਕਰ ਸਕਦੇ

ਮਿਟਾਉਣ ਦਾ ਕੋਈ ਬਟਨ ਨਹੀਂ ਹੈ — ਲੇਅਰਾਂ ਬਣਨ ਤੋਂ ਬਾਅਦ ਕਦੇ ਹਟਾਈਆਂ ਨਹੀਂ ਜਾਂਦੀਆਂ, ਸਿਰਫ਼ ਫ੍ਰੀਜ਼ ਕੀਤੀਆਂ ਜਾਂ ਬਿਨਾਂ ਵਰਤੋਂ ਛੱਡੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। ਟੇਬਲ ਵਿੱਚ ਇਹ ਵੀ ਨਹੀਂ ਦਿਖਦਾ ਕਿ ਕਿਹੜੀ ਲੇਅਰ *ਮੌਜੂਦਾ* ਹੈ; ਉਹ ਲੇਅਰ ਪੈਨਲ ਦੀ ਡ੍ਰੌਪਡਾਊਨ ਵਿੱਚੋਂ ਚੁਣ ਕੇ ਜਾਂ [LayerMakeCurrent](../layer-make-current/) ਨਾਲ ਤੈਅ ਹੁੰਦੀ ਹੈ, ਇਸ ਡਾਇਲਾਗ ਤੋਂ ਨਹੀਂ।
