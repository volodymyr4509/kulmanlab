# Point Interval

`pointinterval` कमांड किसी ऑब्जेक्ट के साथ तय दूरी पर [बिंदु](../point/) रखती है, जैसे किसी मार्ग पर स्टेशन चिह्नित किए जाते हैं। ऑब्जेक्ट स्वयं नहीं बदलता: बिंदु वर्तमान लेयर और रंग पर नई एंटिटी हैं, स्नैप करने के लिए उपयोगी।

## अंतराल पर बिंदु रखना

1. टर्मिनल में `pointinterval` टाइप करें या Edit पैनल के ऐरे ड्रॉपडाउन से **Point Interval** चुनें।
2. **जिस सिरे से शुरू करना है उसके पास ऑब्जेक्ट पर क्लिक करें** — रेखा, पॉलीलाइन, चाप, वृत्त, दीर्घवृत्त या स्प्लाइन। कुछ और अस्वीकार होता है, और आप फिर चुन सकते हैं।
3. **अंतराल की लंबाई टाइप करें।** टाइप करते समय बिंदु ऑब्जेक्ट पर पूर्वावलोकन में दिखते हैं।
4. उन्हें रखने के लिए **Enter** या **Space** दबाएँ। कमांड समाप्त हो जाती है।

## बिंदु कहाँ आते हैं

- पहला बिंदु शुरुआत से एक अंतराल पर आता है और बाकी एक-एक अंतराल पर, ऑब्जेक्ट के साथ मापे गए, वक्रों सहित। शुरुआत पर कोई बिंदु नहीं आता।
- खुले ऑब्जेक्ट पर — रेखा, खुली पॉलीलाइन, चाप, आंशिक दीर्घवृत्त या खुला स्प्लाइन — माप उस सिरे से शुरू होता है जिसके पास आपने क्लिक किया। दूर के सिरे पर जो बचता है वह बिना निशान रहता है: अंतराल ठीक बैठने पर ही दूर के सिरे पर बिंदु आता है।
- बंद ऑब्जेक्ट पर — वृत्त, बंद पॉलीलाइन, पूरा दीर्घवृत्त या बंद स्प्लाइन — आप कहीं भी क्लिक करें, माप ऑब्जेक्ट की अपनी शुरुआत से होता है: वृत्त कोण 0 से वामावर्त, बंद पॉलीलाइन अपने पहले शीर्ष से। बिंदु शुरुआत से पहले रुक जाते हैं।
- 0 या कम, ऑब्जेक्ट से लंबी, या 32767 से अधिक बिंदु देने वाली लंबाई अस्वीकार होती है: टर्मिनल कारण बताता है और उसे मिटा देता है ताकि आप फिर टाइप कर सकें।

Backspace आख़िरी अक्षर मिटाता है। Escape फिर से शुरू करता है, ताकि आप दूसरा ऑब्जेक्ट चुन सकें। ऑब्जेक्ट चुनने से पहले Enter या Space कमांड समाप्त करता है।
