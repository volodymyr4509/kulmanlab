# Help

Atveria programos pagalbos skydelį su visų sparčiųjų klavišų, naršymo patarimų ir bendro naudojimo santrauka.

## Kaip naudoti

Spustelėkite įrankių juostos mygtuką **Help** arba terminale įveskite `help`. Pagalbos skydelis atsidaro iškart ir komanda išeina.

## Kas yra pagalbos skydelyje

### Naršymas
| Spartusis klavišas | Veiksmas |
|--------------------|----------|
| `Pelės ratukas` | Priartinti / nutolinti |
| `Vidurinis klavišas + tempimas` | Perstumti vaizdą |
| `Dvigubas vidurinio klavišo spustelėjimas` | Parodyti visus objektus ekrane |

### Komandos
| Spartusis klavišas | Veiksmas |
|--------------------|----------|
| Rinkimas | Pradėkite rinkti komandos pavadinimą — pasiūlymai atsiranda drobėje |
| `Delete` | Ištrinti visus pasirinktus objektus |
| `Enter` / `Space` | Patvirtinti komandą ar įvestį |
| `Enter` / `Space` (neveikiant) | Pakartoti paskutinę naudotą komandą |
| `Escape` | Atšaukti dabartinę komandą ar išvalyti pasirinkimą |

### Pasirinkimas
| Spartusis klavišas | Veiksmas |
|--------------------|----------|
| `Kairysis spustelėjimas` | Pasirinkti objektą |
| `Tempimas →` | Pasirinkti tik objektus, **visiškai esančius** tempimo srityje |
| `Tempimas ←` | Pasirinkti bet kurį objektą, kuris **liečia** tempimo sritį |
| `Kairysis spustelėjimas ant rankenėlės` | Tiesiogiai redaguoti viršūnę ar galą |

### Braižymo patarimai
- **Prisitraukimo taškai** — žymeklis automatiškai prisitraukia prie artimų objektų galų.
- **Lipnus kampas** — pakankamai toli perkėlus žymeklį viena kryptimi, jis užsirakina ties 45° žingsniais.
- **Tikslus ilgis** — kai kampas užrakintas, įveskite skaičių ir paspauskite `Enter`, kad nustatytumėte tikslų atstumą.
