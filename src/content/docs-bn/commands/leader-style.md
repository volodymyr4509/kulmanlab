# LeaderStyle

`LeaderStyle` কমান্ড নামযুক্ত লিডার স্টাইল ম্যানেজার খোলে। প্রতিটি নতুন [Leader](../leader/) তৈরির সময় *বর্তমান* স্টাইলের সেটিং কপি করে।

## স্টাইল সম্পাদনা

`LeaderStyle` লিখুন অথবা অ্যানোটেশন প্যানেলে **লিডার শৈলী** ক্লিক করুন। ✓ বর্তমান স্টাইল দেখায়; নামের পাশের পেন্সিল দিয়ে নাম বদলানো যায়। অঙ্কনের একই রেন্ডারার ব্যবহার করে প্রিভিউ সঙ্গে সঙ্গে আপডেট হয়।

| ক্ষেত্র | কাজ |
|---|---|
| টেক্সট সংযুক্তি | উপরে, মাঝে, নিচে অথবা নিম্নরেখা |
| তীরমুখ / তীরের আকার | প্রতিটি বাহুর প্রান্তের চিহ্ন ও আকার |
| ল্যান্ডিং ফাঁক | ল্যান্ডিং ও টেক্সটের মধ্যকার জায়গা |
| টেক্সট ঘূর্ণন | ডিগ্রিতে লেবেলের কোণ |
| টেক্সট স্টাইল | [TextStyle](../text-style/) থেকে ফন্ট, উচ্চতা, বোল্ড ও ইটালিক একবার কপি করে |
| ফন্ট / টেক্সট উচ্চতা | লেবেলের ফন্ট ও উচ্চতা |
| বোল্ড / ইটালিক | আলাদা টেক্সট ফরম্যাটিং |
| ফ্রেম টেক্সট | লেবেলের চারপাশে আয়তাকার ফ্রেম |

**নতুন** নির্বাচিত স্টাইলের অনুলিপি করে। `Standard`-এর নাম বদলানো বা এটি মোছা যায় না; বর্তমান স্টাইলও মোছা যায় না। **বর্তমান করুন** শুধু পরে তৈরি লিডারে প্রভাব ফেলে—বিদ্যমান অবজেক্ট বদলায় না। ফাঁকা, সদৃশ বা DXF-এ অবৈধ নাম থাকলে **ঠিক আছে** নিষ্ক্রিয় থাকে। আমদানি করা অ্যানোটেটিভ স্টাইল লুকানো থাকলেও সংরক্ষিত হয়।

## সংরক্ষণ ও DXF

KulmanLab `MLEADERSTYLE` রেকর্ড আমদানি ও রপ্তানি করে। নাম, তীরের মাথা ও আকার, ল্যান্ডিং ফাঁক, টেক্সট উচ্চতা, সংযুক্তি, ফ্রেম ও অ্যানোটেটিভ ফ্ল্যাগ স্টাইলের ক্ষেত্র হিসেবে থাকে। রপ্তানির সময় গ্রুপ `342` মিল থাকা ফন্ট, বোল্ড, ইটালিক ও উচ্চতার টেক্সট স্টাইল নির্দেশ করে; মিল না থাকলে `Standard` ব্যবহৃত হয়। এই DXF রেফারেন্স অ্যাপের একবারের কপিকে লাইভ লিংক করে না। একটি সংযুক্তি মান বাম ও ডান উভয় DXF ক্ষেত্রে লেখা হয়।
