# ChangePrintArea

`ChangePrintArea` কমান্ড সেই আয়তাকার অঞ্চল নির্ধারণ করে যা [Print Manager](../print-manager/) রপ্তানি করে। Print Manager লুকানো অবস্থায় এটি খালি ক্যানভাসে চলে এবং দুটি বিপরীত কোণ নেয় — [Rectangle](../rectangle/)-এর মতোই দুটি ক্লিক, তাই টাইপ করা স্থানাঙ্ক ও স্ন্যাপিং হুবহু একইভাবে কাজ করে।

## একটি অঞ্চল নির্বাচন

1. টার্মিনালে `ChangePrintArea` টাইপ করুন, বা Print Manager-এর সাইডবারে **Change Area** ক্লিক করুন। Print Manager লুকিয়ে যায় এবং ক্যানভাস ইন্টারঅ্যাক্টিভ হয়।
2. **প্রথম কোণে ক্লিক করুন**, অথবা সঠিক স্থানাঙ্কের জন্য `X,Y` টাইপ করে **Enter** চাপুন।
3. **বিপরীত কোণে ক্লিক করুন**, অথবা আবার `X,Y` টাইপ করুন।

Print Manager নতুন অঞ্চল সহ আবার খোলে, এবং প্রিভিউ সেই অঞ্চলের সঠিক অনুপাত অনুযায়ী আকার নেয়।

অন্য যেকোনো বিন্দু নির্বাচনের মতোই কোণগুলি গ্রিপ ও ছেদবিন্দুতে স্ন্যাপ করে, তাই আন্দাজে নয়, আঁকা জ্যামিতি ধরে ক্রপ করা যায়। দুটি কোণের ক্রম গুরুত্বপূর্ণ নয়: বিপরীত কোণ একই আয়তক্ষেত্র নির্ধারণ করে।

বাতিল করতে `Escape` চাপুন। কিছুই লেখা হয় না, তাই Print Manager আগের অঞ্চল নিয়েই আবার খোলে।

## অঞ্চল কোথায় মনে রাখা হয়

নির্বাচন বিশ্বব্যাপী নয়, প্রতিটি প্রসঙ্গ অনুযায়ী সংরক্ষিত হয়:

| প্রসঙ্গ | স্লট |
|---|---|
| Model স্পেস | একটি ভাগ করা স্লট |
| প্রতিটি লেআউট | নিজস্ব স্লট, আলাদাভাবে রাখা |

একই লেআউটে — বা Model-এ — Print Manager আবার খুললে রিসেট না হয়ে সেই প্রসঙ্গের শেষ ক্রপ ফিরে আসে, আর লেআউটের মধ্যে অদলবদল করলেও প্রত্যেকটির অঞ্চল অক্ষত থাকে।

এটি কেবল মেমরিতে থাকে। পৃষ্ঠা রিলোড করলে সংরক্ষিত সব অঞ্চল মুছে যায় এবং Print Manager নিচের ডিফল্টে ফিরে যায়।

## ডিফল্ট অঞ্চল

বর্তমান প্রসঙ্গের জন্য কিছু সংরক্ষিত না থাকলে Print Manager খোলে:

| প্রসঙ্গ | ডিফল্ট |
|---|---|
| Model স্পেস | সব এনটিটির বাউন্ডিং বক্স — [Fit](../fit/) যে বিস্তারে জুম করে সেটিই |
| প্রতিটি লেআউট | পুরো শিট |

## সম্পর্কিত কমান্ড

| কমান্ড | কী করে |

| [Rectangle](../rectangle/) | একই দুই-কোণ নির্বাচন, তবে পলিলাইন আঁকে |
| [Fit](../fit/) | Model স্পেস ডিফল্টে যে বিস্তার ব্যবহার করে সেখানে জুম করে |
