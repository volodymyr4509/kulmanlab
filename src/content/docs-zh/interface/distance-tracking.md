# 距离追踪

**距离追踪**让你通过键入精确长度来放置点，而不必单击。它由控制栏中的 **Dist** 开关控制，紧邻 [Pins](../vector-pins/) 与 ANGL，**默认开启**，且该设置在会话之间保留。

它带来的能力范围很窄却很有用：让**最近的一个矢量固定点**充当角度追踪的测量基点。没有它，命令只能从自己已经采集到的点开始测量 — 也就意味着图形的*第一个*点根本无从测起。

## 三个开关协同工作

距离追踪并不独立成立。在你能键入长度之前，另外两个开关必须处于正确状态：

| 开关 | 作用 |
|------|------|
| **Pins** | 提供参考点。将光标悬停在某个捕捉点上 500 毫秒即可固定它 — 参见 [Vector Pins](../vector-pins/)。 |
| **ANGL** | 提供角度。只有当光标锁定到角度上时，距离追踪才可用，因此 ANGL 必须设为某个步长（10°、20°、30°、45°、90°），而不是 Off。 |
| **Dist** | 允许把固定点用作基点，而不只是命令自身的点。 |

若 Pins 与 Dist 已开启，但 ANGL 设为 **Off**，则什么也不会发生：没有可供测量长度的锁定方向。

## Pins 与 Dist 如何联动

固定点关闭时距离追踪毫无意义，因此两个开关始终保持同步：

- **开启 Pins** 也会**开启 Dist**。
- **关闭 Pins** 也会**关闭 Dist**。
- **开启 Dist** 会在 **Pins** 尚未开启时将其开启。
- **关闭 Dist** 会**保持 Pins 开启**。

因此 Dist 绝不会在 Pins 关闭时处于激活状态；但你可以保留固定点追踪用于对齐，同时关掉距离追踪 — 当你想要参考线，却不希望在打算锁定自己上一个点时光标却锁到固定点上，这很有用。

## 在精确距离处放置一个点

1. 开启 **Pins** 与 **Dist**，并把 **ANGL** 设为某个角度步长。
2. 启动一个需要指定点的命令 — [Line](../../commands/line/)、[Circle](../../commands/circle/)、[Rectangle](../../commands/rectangle/) 等等。
3. **固定一个参考点**：将光标悬停在已有捕捉点上，直到标记变成实心方块。
4. 沿着大致所需的角度把光标移离固定点。当它接近某个 ANGL 步长时，方向就会**锁定** — 自固定点出现追踪指示线。
5. **键入长度**并按 **Enter** 或 **Space**。该点将沿锁定角度，恰好放置在离固定点这一距离处。

终端提示会告诉你何时可以键入。锁定时它显示为：

```
pick start point or enter length: [ ]
```

你键入的数值会出现在方括号内。

## 为什么第一个点尤为重要

这正是若无此功能便无法做到的情形。假设要让一条线恰好从某个已有角点向右 250 单位处起始：

1. 启动 [Line](../../commands/line/)。
2. 固定那个已有角点。
3. 向右移动，直到方向锁定在 0°。
4. 键入 `250`，按 **Enter**。

这条线现在从距角点 250 单位处开始 — 无需辅助几何，也无需心算。若没有 Dist，Line 命令尚未采集任何点，键入的长度便*无从测起* — 你只能大致单击，或者画一条辅助线再删掉。

对于**第二个及之后**的点，命令已经有了自己的基点（上一个点），并会优先使用它。只有当你自己的基点未锁定时，才会把固定点作为备选 — 所以固定某个东西不会劫持你已经获得的锁定。

## 键入会冻结锁定

一旦你开始输入数字，基点就不再变动。第一个数字落下时锁定的是哪个点，它就一直是基点，直到你确认或清空输入 — 输入过程中移动鼠标不会悄悄把测量切换到另一个固定点或命令自身的点上。

## 键盘参考

| 按键 | 操作 |
|------|------|
| `0`–`9`、`.` | 追加到长度 |
| `-` | 负长度 — 沿锁定角度反向（仅限首字符） |
| `Backspace` | 删除最后一个字符 |
| `Enter` / `Space` | 在键入的长度处放置该点 |
| `Escape` | 取消命令；锁定与已键入的数值都会清除 |

键入长度是可选的。方向锁定后你仍然可以单击，该点会被投影到锁定角度上。
