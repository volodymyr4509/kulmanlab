# 坐标输入

命令要求指定点时——[Line](../../commands/line/) 的起点、[Rectangle](../../commands/rectangle/) 的一角、[Move](../../commands/move/) 的基点，或正在拖动的夹点——都可以输入而不必单击。开始输入数字，命令行会显示所输入的内容；按 **Enter** 或 **Space** 放置该点。

## 书写点的四种方式

| 输入 | 点的位置 |
|---|---|
| `100,50` | X 100、Y 50 处 |
| `@100,50` | 距上一点 X 方向 100、Y 方向 50 |
| `100<45` | 距原点 100、角度 45° |
| `@100<45` | 距上一点 100、角度 45° |

角度以度为单位，从 X 轴起逆时针计算，因此 `@50<90` 是向上 50，`@50<180` 是向左 50。两个值都可以为负数。

## 上一点

`@` 从任一命令中最后一次单击或输入的点开始测量——上一个命令的最后一次单击算数，刚拖动过的夹点也算。还没有上一点时，`@100,50` 按 `100,50` 读取。在模型空间与布局之间切换，或打开图纸时，上一点会被清除。

## Rel：默认使用相对坐标

控制栏中的 **Rel** 开关让每个输入的点都以相对坐标开始：一输入第一个数字，前面就会加上 `@`，于是 `100,50` 变成 `@100,50`。在 `@` 处按 **Backspace** 可使该点变为绝对坐标。还没有上一点时不会添加 `@`。Rel 默认关闭，并与控制栏的其他开关一起被记住。

## 输入时的按键

| 按键 | 作用 |
|---|---|
| `0`–`9`, `.`, `-` | 输入数字；`-` 只能在开头 |
| `@` | 使点成为相对坐标，在 X 的开头 |
| `,` 或 **Space** | 结束 X，转到 Y |
| `<` | 将 X 作为距离结束，转到其角度 |
| **Enter** 或 **Space** | Y 有值后放置该点 |
| **←** **→** **Home** **End** | 在正在输入的值中移动光标 |
| **Backspace** | 删除光标前的字符；在空的 Y 开头时返回 X |

无法读作数字的点会留在命令行中供你修改。每个输入的点都会按你输入的样子在命令行历史中留下一行——`输入：@100<45`——随后是命令记录该点落在何处的那一行。

## 输入的点与角度追踪

光标锁定在角度追踪射线上时，输入数字得到的是沿该射线的距离，而不是 X。先输入 `@` 则开始一个完整的点，因此在锁定的射线上 `@100,50` 依然有效。
