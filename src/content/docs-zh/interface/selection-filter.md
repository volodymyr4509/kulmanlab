# 选择过滤器

一次选中多个实体会让属性面板进入多重选择视图（“Selection (N)”）。关闭按钮旁的**过滤器图标**可让你在批量编辑之前按属性缩小该选择。

## 打开过滤器

1. 选择若干实体 — 拖出选择框、按住 Shift 单击，或按 Ctrl+A。
2. 单击属性面板标题栏中的**过滤器图标**（漏斗）。
3. 按钮下方会打开一个弹窗，为选择集中确实存在差异的每一项属性给出一份勾选列表。

## 分面

弹窗最多可显示五个分面，每一个都根据当前选择实时生成：

| 分面 | 显示的值 |
|------|----------|
| **类型** | 实体类型名称（Line、Circle、Hatch 等） |
| **图层** | 图层名称，并附带与该图层匹配的色块 |
| **颜色** | ACI 颜色索引 |
| **线宽** | 线宽数值 |
| **线型** | 线型名称 |

只有当选择集中该属性确实存在一个以上的不同取值时，分面才会出现 — 选中十条同在一个图层上的直线不会出现“图层”分面，因为勾选它并不能缩小任何范围。完全不具备某项属性的实体（例如 Hatch 和 Text 没有线宽或线型）根本不会计入该分面 — 也永远不会被它排除在外。

## 缩小选择

在任一分面中勾选一个或多个值，即可把选择缩小到符合**所有**已勾选分面的实体（实体必须在你动过的*每一个*分面中都至少匹配一个已勾选的值，而不只是其中之一）。每个分面自身的复选框与计数，反映的是*其他*已勾选分面缩小之后的结果，因此分面绝不会隐藏它自己已勾选的选项 — 这正是分面检索的惯常行为。

结果数量会随着你勾选和取消勾选实时更新，画布上的选择本身也随之缩小 — 这并非仅仅是显示层面的过滤：不再符合条件的实体会被真正取消选中，让你可以对筛选后的那个子集精确地批量编辑。

## 清除过滤条件

使用弹窗中的重置控件清空所有勾选，回到完整的原始选择；或者关闭弹窗（下次你在新的选择上单击过滤器图标时，它会以全新的基准重新打开）。
