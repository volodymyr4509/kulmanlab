# Object Snap Settings

`objectsnapsettings` 命令打开一个汇集控制栏所有设置的窗口。每项设置都在列表旁附有说明和一幅小图。可通过控制栏中的齿轮按钮打开，或输入 `objectsnapsettings`。在这里更改设置，等同于切换控制栏中对应的按钮。

## 各项设置

### 光标落点

| 控制栏 | 作用 |
|---|---|
| `Snap` | 光标跳到最近的栅格点，使你选取的点落在整数坐标上。光标附近的对象捕捉仍然优先。栅格间距随缩放变化。 |
| `TANG` | 从某点画线时，把光标移到线恰好与圆、圆弧、椭圆或样条曲线相切的位置附近，就会捕捉到那里。适用于直线、多段线等命令，以及拖动直线或多段线端点时。 |

### 绘图时的辅助线

| 控制栏 | 作用 |
|---|---|
| `ANGL` | 光标从上一点接近这些角度之一时，会锁定在该方向上，以虚线射线显示。锁定时输入长度并按 Enter，即可把点放在该距离处。 |
| `Pins` | 把光标在捕捉点上停留片刻即可将其钉住。被钉住的点会发出水平和垂直辅助线，光标会捕捉到这些线及其交点。 |
| `Dist` | 让最后钉住的点作为起点：当光标从图钉锁定到某个角度时，输入长度并按 Enter，即可把点放在离它该距离处。需要开启矢量图钉。 |

### 输入与选择

| 控制栏 | 作用 |
|---|---|
| `Rel` | 输入的 X,Y 点从上一次选取的点量起，就像以 @ 开头。按退格键删除 @ 即为图纸自身坐标中的点。关闭时，偏移需自己输入 @。 |
| `Lasso` | 在空白处按住并拖动，可以围绕想要的对象画一个自由环，而不是矩形。环内包含的对象会被选中。 |

### 显示

| 控制栏 | 作用 |
|---|---|
| `Grid` | 显示背景栅格。其间距随缩放变化。关闭它不会停止栅格捕捉。 |
| `LWT` | 按线宽绘制线条，较重的线看起来更粗。关闭时所有线都画得很细，可能使密集的图纸更易读。 |

**ANGL** 的步长有单独一行：可选择 10°、20°、30°、45° 或 90°，也可选择 **自定义** 并输入 1° 到 180° 之间的任意角度。

切点捕捉、相对输入和套索默认关闭。**恢复默认值** 会把所有设置恢复为初始状态。
