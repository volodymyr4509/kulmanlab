# Extend

`extend`（延伸）命令将悬停的 [Line](../line/)、[Arc](../arc/)、[Ellipse](../ellipse/) 或开放 [Polyline](../polyline/) 的最近端点延伸到它与图形中另一个图元的最近交点处。将光标悬停在要延伸的端点附近 — 预览显示延伸后的图元 — 然后单击以应用。

只有具有真正端点的图元才能被延伸。[Circle](../circle/) 和完整（360°）的 Ellipse 始终是没有端点的闭合形状，因此永远无法延伸——闭合的 Polyline 或 Rectangle 也是如此。部分 Ellipse（椭圆弧）和 Arc 都有端点，其延伸方式与 Line 相同。

## 延伸图元

1. 在命令行中输入 `extend`，或单击工具栏中的**Extend**按钮。
2. **将光标悬停在要延伸的图元一端附近** — 预览显示它延伸到该方向最近边界的效果。
3. **单击**以应用延伸。

每次延伸后命令保持激活状态，可以继续悬停并单击以延伸更多图元。按 **Enter**、**Space** 或 **Escape** 键退出。

```
  之前：                      之后：

  ──────           |           ──────────────|
  （短直线）     （边界）  （延伸到边界）
```

## 如何选择端点

命令查看光标距离哪一端更近：

- **Line 和开放 Polyline** — 光标更靠近终点时终点向前延伸；光标更靠近起点时起点向后延伸。
- **Arc 和部分 Ellipse** — 光标更靠近其中一个角度端点时，圆弧沿该方向围绕相同的圆心和半径（或相同的椭圆形状）增长，直到到达下一个边界。

从所选端点投射一条射线——对于 Arc 和 Ellipse，则是图元自身的圆或曲线——与任何其他图元（排除图元本身和被忽略的类型）的**最近交点**成为新端点。

如果在该方向上找不到交点，则不显示预览，单击不会产生任何效果。

## 边界排除

以下图元类型被忽略作为边界 — 图元不会延伸到与它们相交处：

- 文字 / 多行文字
- 多重引线

所有其他类型（Line、Arc、Circle、Ellipse、Polyline、样条线、标注）均作为有效边界。

如果 Polyline 的第一个或最后一个段本身就是弧形段（用 Arc 开关绘制），延伸它会沿着其自身的圆增长弧形——就像延伸独立的 Arc 一样——而不是将其当作直线段处理。

## 支持的图元

| 图元 | 可以延伸？ |
|--------|----------------|
| Line | 是 |
| Arc | 是 |
| Ellipse | 是 — 仅当它已经是部分圆弧时；完整椭圆没有端点 |
| Circle | 否 — 始终是没有端点的闭合形状 |
| Polyline（开放） | 是 |
| Polyline（闭合）/ Rectangle | 否 — 始终是没有端点的闭合形状 |
| 文字、样条线、标注、引线 | 否 |

## Extend vs Trim

| | 延伸 | 修剪 |
|---|--------|------|
| 功能 | 将图元端点延伸到边界 | 删除图元的一段 |
| 触发方式 | 悬停在要延伸的端点附近 | 悬停在要切割的线段上 |
| 结果 | 端点向外移动 | 图元分割或缩短 |
| 支持的图元 | Line、Arc、Ellipse、Polyline | Line、Arc、Circle、Ellipse、Polyline |
