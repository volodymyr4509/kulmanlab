# Print Manager

`PrintManager`(打印)命令打开**打印管理器** — 带实时预览画布、格式选择器(PNG / JPEG / WebP / PDF)、样式选择器(Default / Monochrome / Blueprint)和可选区域裁剪的专用导出窗口。不会向物理打印机发送任何内容;输出以文件形式下载。

## 打开打印管理器

单击工具栏中的**Print**按钮,或在命令行中输入 `PrintManager`。打印管理器立即打开,显示当前视口的预览。

预览通过与最终导出的文件完全相同的代码路径、完全相同的像素分辨率进行渲染 —— 更改 Quality、Style 或导出区域会立即重新渲染预览,因此你看到的就是将要下载的内容,而不是它的近似值。

## 打印管理器布局

窗口有两个面板:
- **左侧边栏** — 所有导出控件。
- **右侧面板** — 随设置更改实时更新的实时预览画布。

### 侧边栏控件

| 控件 | 说明 |
|---------|-------------|
| **更改区域** | 裁剪到画布上的自定义矩形(见下文)—— 即使在带纸张空间的布局中,也会真正裁剪导出的图像本身,而不仅仅是屏幕上的预览 |
| **Quality** 下拉菜单 | 设置导出分辨率(见下文) |
| **Style** 下拉菜单 | Default、Monochrome 或 Blueprint —— 见下文"打印样式"。默认使用 Monochrome 以获得清晰的打印输出 |
| **格式**下拉菜单 | PNG、JPEG、WebP 或 PDF |
| **导出**按钮 | 生成并下载文件 |

## 打印样式

**Style** 下拉菜单同时控制绘制实体所用的墨水颜色和页面背景:

| 样式 | 墨水 | 页面背景 |
|------|------|----------|
| **Default** | 每个实体自身的颜色 | 白色 |
| **Monochrome**(默认) | 纯黑色,与实体/图层颜色无关 | 白色 |
| **Blueprint** | 纯白色,与实体/图层颜色无关 | 深普鲁士蓝,带一层淡淡的参考网格 |

Blueprint 重现了传统蓝图建筑晒图的外观 —— 深蓝色纸面上的白色线条。它的参考网格是相对于页面尺寸而非 DPI 来确定大小的,因此在任何 Quality 设置下密度看起来都相同,而不会随分辨率提高而变得更密。

## 质量与分辨率

**Quality**(质量)下拉菜单设置导出渲染的 DPI:

| Quality | DPI |
|---------|-----|
| Draft | 72 |
| Normal(默认) | 150 |
| Presentation | 300 |
| Max | 600 |

质量越高,在相同物理尺寸下生成的图像越大越清晰 —— 线宽会随分辨率同步缩放,因此无论选择哪种质量设置,线条在纸面上的*物理*粗细都保持不变,而不会随 DPI 提高而显得更细。唯一的例外是细线(线宽 `0`),按惯例被定义为"输出设备能绘制的最细的线"—— 它在任何质量级别下都保持固定的 1 像素宽度,与在实时画布上的表现完全一致。

更改质量会立即重新渲染预览,因此你在导出前就能看到实际的清晰度(以及文件大小的权衡)。

## 选择自定义导出区域

默认情况下,预览显示打开打印管理器时画布上可见的确切内容。要导出特定区域:

1. 单击**更改区域** — 打印管理器隐藏,画布变为交互式。
2. **单击导出矩形的第一个角**。
3. **单击对角** — 打印管理器重新打开,预览中显示选定区域。

区域选择期间按 `Escape` 可取消并恢复之前的区域。

预览画布动态调整大小以匹配选定区域的**精确宽高比**,因此预览像素精确。

## 导出格式

| 格式 | 最适用于 | 备注 |
|--------|----------|-------|
| **PNG** | 无损、清晰线条 | 内嵌 Style 的页面背景,无透明度 |
| **JPEG** | 用于共享的较小文件 | 95% 质量,轻微压缩 |
| **WebP** | 网络最小文件 | 相同 95% 质量,比 JPEG 更好的压缩 |
| **PDF** | 可打印文档 | 图像以所选 Quality 的 DPI 嵌入 PDF 容器,尺寸设定为使页面按真实物理比例打印 |

导出的文件命名为 `kulman-<时间戳>.<扩展名>` 并自动下载。

## 导出分辨率和背景

- **模型空间 / 视口导出**:在默认的 Normal(150 DPI)质量下上限为 2000 × 2000 像素,按选定区域比例缩放;该上限也会随 Quality 变化 —— Draft 较低,Presentation 和 Max 较高(Max/600 DPI 下最高可达 8000 × 8000)。
- **布局(纸张空间)导出**:直接根据布局的纸张尺寸在所选 DPI 下确定大小 —— 例如 A4 纸(210 × 297 毫米)在 Normal 质量下导出约为 1240 × 1754 px —— 因此不受视口 2000 px 上限的限制。
- 背景遵循所选的打印 **Style** —— Default 和 Monochrome 为白色,Blueprint 为深普鲁士蓝(见上文"打印样式")。
- 标记为**不打印**的图层被排除在导出之外。

## 键盘参考

| 按键 | 操作 |
|-----|--------|
| `Escape`(区域选择期间) | 取消区域选择,恢复之前的区域 |
| `Escape`(在打印管理器中) | 关闭打印管理器 |
