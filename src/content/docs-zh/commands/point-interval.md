# Point Interval

`pointinterval` 命令沿对象按固定间距放置[点](../point/)，就像沿路线标注桩号一样。对象本身不会改变：这些点是当前图层和颜色上的新图元，便于捕捉。

## 按间距放置点

1. 在命令行中输入 `pointinterval`，或在 Edit 面板的阵列下拉菜单中选择 **Point Interval**。
2. **在要开始的一端附近单击对象**——直线、多段线、圆弧、圆、椭圆或样条曲线。其他对象会被拒绝，可以重新选择。
3. **输入间距长度。** 输入时点会在对象上预览。
4. 按 **Enter** 或 **Space** 放置这些点，命令随即结束。

## 点的位置

- 第一个点距起点一个间距，其余点依次相隔一个间距，沿对象测量，包括曲线部分。起点本身不放点。
- 在开放对象上（直线、开放多段线、圆弧、部分椭圆或开放样条曲线），从单击位置较近的一端开始测量。远端剩余的部分不做标记：只有间距恰好整除时，远端才会有一个点。
- 在闭合对象上（圆、闭合多段线、完整椭圆或闭合样条曲线），无论在哪里单击，都从对象自身的起点开始测量：圆从角度 0 起逆时针，闭合多段线从第一个顶点起。点在回到起点之前停止。
- 小于或等于 0、比对象更长、或会产生超过 32767 个点的长度会被拒绝：命令行会说明原因并清空输入，以便重新输入。

Backspace 删除最后一个字符。Escape 重新开始，可以选择其他对象。选择对象之前按 Enter 或 Space 会结束命令。
