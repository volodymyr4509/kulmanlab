# Block Create

`blockcreate` 命令创建一个**块**：一组有名称的对象，在图纸中只保存一次，并可用 [Block Insert](../block-insert/) 放置任意多次。你选择的对象成为块，在图纸中被一个指向它的参照取代，因此外观不会有任何变化。

## 创建块

1. 可先选择对象，然后输入 `blockcreate`，或在 **块** 面板中单击 **创建块**。会打开一个已包含所选对象的弹窗。
2. 输入**名称**。名称不能为空，不能包含 `< > / \ " : ; ? * | , =` 中的任何字符或反引号，也不能与其他块同名。
3. 单击 **选择对象** 以添加或移除对象：弹窗会隐藏，然后你单击对象或拖出一个区域。按 **Enter** 或 **Space** 返回弹窗，**对象** 会显示已选数量。
4. 设置**基点**，即放置块所用的点：输入它的 X 和 Y，或单击 **拾取点** 再在画布上单击（也可在那里输入 X,Y）。初始为 0,0。
5. 单击 **OK**。块被保存，对象让位于基点处指向它的一个参照，命令行会记录块的名称及其所含对象数。

## 须知

- 只要有问题，**OK** 就保持禁用，字段下方的提示会说明原因：名称为空或不可用、名称已被使用，或没有对象。
- 选择对象或基点时按 **Escape** 会返回弹窗，块保持原样。在弹窗中按 **Escape** 会取消命令。
- 块随图纸一起保存，并连同其参照一起写入 DXF。
