# TextStyle

`TextStyle` 命令打开文字样式管理器。您可以创建命名样式、编辑默认格式并选择*当前*样式。新建[文字](../text/)时会复制当前样式的设置。

## 使用管理器

在终端输入 `TextStyle`，或单击**注释**面板中的**文字样式**。✓ 表示当前样式；双击可将另一样式设为当前。

| 字段 | 作用 |
|---|---|
| 重命名 | 使用样式名称旁的铅笔在列表中编辑；`Standard` 不能重命名。 |
| 字体 / 高度 | 字体和必需的正数高度。零或负值会改为 `1`；管理器只接受大于 `0` 的值。 |
| 粗体 / 斜体 | 独立格式开关 |
| 行距 | 文字行之间的距离 |
| 水平对齐 | 左、居中、右或两端对齐 |
| 边框 | 为新文字绘制矩形边框 |

预览使用与画布文字相同的渲染器显示两行文字。字体、高度、粗体、斜体、边框、行距和对齐会立即更新；读数显示适配缩放比例。新样式默认**左对齐**。

**新建**复制所选样式。**删除**不能删除 `Standard` 或当前样式。**置为当前**只影响之后创建的文字。空名称、重复名称或 DXF 不允许的名称会禁用 **OK**。导入的注释性样式目前隐藏，但其记录会保留。

## 保存与 DXF

名称、字体文件、粗体、斜体和注释性标志会保留在 DXF 文字样式中。KulmanLab 将 STYLE 组 `40` 写为 `0`（可变高度），并把上次使用的高度写入组 `42`；这可防止固定 STYLE 高度覆盖标注样式自身的文字高度。边框、行距和水平对齐是 KulmanLab 针对每个文字对象的默认值，并非 DXF STYLE 表字段。
