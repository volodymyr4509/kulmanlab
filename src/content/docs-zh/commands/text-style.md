# TextStyle

`TextStyle` 命令打开文字样式管理器。您可以创建命名样式、编辑默认格式并选择*当前*样式。新建[文字](../text/)时会复制当前样式的设置。

## 使用管理器

在终端输入 `TextStyle`，或单击**注释**面板中的**文字样式**。✓ 表示当前样式；双击可将另一样式设为当前。

| 字段 | 作用 |
|---|---|
| 名称 | 唯一名称；`Standard` 不能重命名 |
| 字体 / 高度 | 字体和固定高度；`0` 表示由各文字指定 |
| 粗体 / 斜体 | 独立格式开关 |
| 行距 | 文字行之间的距离 |
| 水平对齐 | 左、居中、右或两端对齐 |
| 边框 | 为新文字绘制矩形边框 |

**新建**复制所选样式。**删除**不能删除 `Standard` 或当前样式。**置为当前**只影响之后创建的文字。空名称、重复名称或 DXF 不允许的名称会禁用 **OK**。导入的注释性样式目前隐藏，但其记录会保留。

## 保存与 DXF

**OK** 保存全部修改；**关闭**或 `Escape` 放弃修改。`↑` 和 `↓` 在列表中移动。名称、字体文件、固定高度、粗体、斜体和注释性标志属于 DXF 样式记录。边框、行距和水平对齐是 KulmanLab 的逐文字默认值，不是 DXF STYLE 表字段。

另请参阅 [Text](../text/)、[FontManager](../font-manager/) 和 [MatchProperties](../match-properties/)。
