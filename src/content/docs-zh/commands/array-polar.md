# Array Polar

`ArrayPolar` 命令围绕中心点创建所选对象的副本，均匀分布在整圈或其一部分上。原件是第一个项目；其余每个项目都是绕中心旋转的副本——关闭 Rotate 则只是围绕中心移动。

## 创建环形阵列

1. 先选择对象，然后在命令行中输入 `arraypolar` 或单击工具栏的 **Array Polar** 按钮。若在未选择时启动，会先要求你选择对象——按 **Enter** 或 **Space** 确认。
2. **单击副本围绕的中心**，或输入 `X,Y` 并按 **Enter** 指定精确坐标。
3. 查看阵列。所有副本实时预览，命令行显示 `Change [Items=6] [Angle=60°] [Fill=360°] [Rotate=true]`——按选项的字母即可更改。
4. 按 **Enter** 或 **Space** 创建副本。原件保持原位，选择被清除。

## 选项

| 选项 | 按键 | 效果 |
|---|---|---|
| Items | `I` | 项目数量，包括原件——2 到 1024 的整数。初始为 6。 |
| Angle | `A` | 从一个项目到下一个的角度（度），逆时针；负角度顺时针。最大 180°。 |
| Fill | `F` | 从第一个项目到最后一个项目的角度（度）。360（默认）为整圈；较小的数值使项目分布在其一部分上。负值顺时针。最大 360°。 |
| Rotate | `R` | 开启（默认）：每个副本随绕行而旋转。关闭：每个副本移动到相应位置，朝向与原件相同。立即切换——无需输入数字。 |

- Angle 与 Fill 是对同一件事的两种表述，因此改变其一会重新推算另一个。整圈时，最后一个项目停在第一个项目前一步；不满一圈时，它恰好落在填充角度上。
- 要更改某个数值，请按其选项的字母。提示中预填了当前值——输入即可替换，然后按 **Enter** 或 **Space**；不作修改直接确认则阵列保持原样。
- Items 只接受整数；Angle 和 Fill 接受小数，以及表示顺时针的前导 `-`。角度或填充为 0 会被拒绝，角度超过 180° 或填充超过 360° 也会被拒绝——命令行会说明原因。
- Angle 小到容不下所有项目时，会舍弃放不下的项目，命令行会报告新的数量。
- 适用于所有图元类型：每个副本都是原件绕中心旋转或移动的结果，与 [Rotate](../rotate/) 和 [Move](../move/) 的做法完全一致。

## 键盘参考

| 按键 | 操作 |
|---|---|
| `Enter` / `Space` | 确认选择、阵列或输入的数字 |
| `I` `A` `F` `R` | 输入数字以更改 Items、Angle 或 Fill；切换 Rotate |
| `0`–`9`, `.`, `-` | 输入数字（`.` 和 `-` 仅用于 Angle 和 Fill，`-` 须在最前） |
| `Backspace` | 删除最后输入的字符 |
| `Escape` | 取消 |
