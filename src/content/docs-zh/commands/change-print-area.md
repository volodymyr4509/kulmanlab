# ChangePrintArea

`ChangePrintArea` 命令设定[打印管理器](../print-manager/)导出的矩形区域。它在打印管理器隐藏时于空白画布上运行，接受两个对角点 — 与 [Rectangle](../rectangle/) 相同的两次点选，因此键入坐标和捕捉的行为完全一致。

## 选择区域

1. 在命令行中输入 `ChangePrintArea`，或点击打印管理器侧边栏中的 **Change Area**。打印管理器隐藏，画布变为可交互。
2. **点击第一个角点**，或输入 `X,Y` 并按 **Enter** 指定精确坐标。
3. **点击对角点**，或再次输入 `X,Y`。

打印管理器重新打开，预览中显示新区域，并按该区域的精确宽高比调整大小。

角点会像其他点选一样捕捉到夹点和交点，因此可以按已绘制的几何图形精确裁剪，而不是凭肉眼。两个角点的顺序无关紧要：对角点定义同一个矩形。

按 `Escape` 取消。不会写入任何内容，打印管理器将以原有区域重新打开。

## 区域记忆的位置

选择按上下文分别存储，而非全局共用：

| 上下文 | 存储位 |
|---|---|
| 模型空间 | 一个共享存储位 |
| 每个布局 | 各自独立保存的存储位 |

在同一布局（或模型空间）中重新打开打印管理器会恢复该上下文上次的裁剪，而不是重置；在布局之间切换不会影响各自的区域。

这仅保存在内存中。重新加载页面会清除所有已存区域，打印管理器将回退到下方的默认值。

## 默认区域

若当前上下文没有存储内容，打印管理器打开时使用：

| 上下文 | 默认值 |
|---|---|
| 模型空间 | 所有实体的边界框 — 与 [Fit](../fit/) 缩放到的范围相同 |
| 每个布局 | 整张图纸 |

## 相关命令

| 命令 | 作用 |
|---|---|
| [Print Manager](../print-manager/) | 此区域所应用的导出窗口 |
| [Rectangle](../rectangle/) | 同样的两角点选，但绘制多段线 |
| [Fit](../fit/) | 缩放到模型空间默认使用的范围 |
