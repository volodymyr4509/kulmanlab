# Measure

`measure` 命令在你移动光标时读取其周围的图形，无需选点：到最近几何体有多远、该几何体有多长或多圆，以及线条相交处的角度。在封闭区域内单击可得到其面积和周长。图形不会有任何改动。

## 测量

1. 在命令行中输入 `measure`，或单击 Measure 面板的第一个按钮 **Measure**。
2. **移动光标。** 命令从光标处向右、向上、向左、向下寻找最近的几何体，并显示所发现的内容。
3. **在封闭区域内单击**，即可填充该区域并读取其面积和周长——见下文。
4. 按 **Enter**、**Space** 或 **Escape** 结束。

## 显示的内容

- **跨越距离** — 从光标在一侧遇到的对象到另一侧遇到的对象，水平和垂直方向各一。如果只有一侧有对象，则距离从光标算起。每个遇到对象的端点处有一个小实心圆点；光标处的端点没有。
- **长度或半径** — 命令到达的每个对象都会突出显示其长度，若属于圆的一部分则显示半径。
- **角度** — 两条到达的直线相交处会写出它们之间的角度；直角用一个小方块标出。

长度和角度按当前 [DimensionStyle](../dimension-style/) 的写法显示，即采用其单位格式和精度。

## 面积和周长

在封闭区域内单击会填充该区域，并把面积和周长放入提示和历史记录。区域的查找方式与 [Hatch](../hatch/) 相同：首尾相接的分离线条会像多段线一样封闭区域，其内部任何封闭的图形都会作为孤岛被排除——其边界计入周长，其面积被扣除。

面积是以图形单位平方表示的普通数字——英尺和英寸无法表示面积——而周长遵循单位格式。要测量另一个区域，请在其内部单击。如果点周围没有封闭图形，命令行会用与 Hatch 相同的消息说明原因：no boundary found、point is not enclosed 或 boundary is open。

## 须知

- 它以直线、圆弧、圆、椭圆、多段线和样条曲线为测量对象；长度和面积是精确的，椭圆和样条曲线也不例外。
- 冻结图层上的对象会被忽略；锁定图层上的对象会被测量。
- 在大型图形中，它只查看光标附近的内容，因此保持流畅。
