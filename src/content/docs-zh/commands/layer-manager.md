# LayerManager

`LayerManager` 命令会打开一张表格，列出图形中的每一个图层，其 **Freeze**、**Lock**、**Plot**、**颜色**、**线宽** 与 **线型** 设置均可直接在行内编辑。这是新增图层、删除未使用图层以及调整既有图层行为的中枢 — 其余图层命令（[LayerMakeCurrent](../layer-make-current/)、[LayerMatch](../layer-match/)、[LayerIsolate](../layer-isolate/)、[LayerUnfreezeAll](../layer-unfreeze-all/)）各自只做一件事，无需打开它。

## 打开图层管理器

- 在命令行中输入 `LayerManager`，**或**
- 单击图层面板中的 **Layer Manager** 按钮。

对话框以浮动面板形式打开；事先不需要选中任何内容。

## 图层表

| 列 | 控制的内容 |
|----|--------------|
| Name | 图层名称，在表中以只读方式显示（创建时设置一次） |
| Freeze | 隐藏图层的图元并将其排除在选择之外，直到解冻 |
| Lock | 阻止编辑图层上的图元，但不隐藏它们 |
| Plot | 打印或导出为 PDF 时是否包含该图层的图元 |
| Color | 图层的 ACI 颜色 — 单击色样打开颜色选择器 |
| Lineweight | 图层的线宽 — 单击色块打开线宽选择器 |
| Linetype | 图层的虚线图案 — 单击色块打开线型选择器 |
| ✕ | 当没有任何东西使用该图层时将其删除 — 参见[删除图层](#删除图层) |

切换 Freeze、Lock 或 Plot 会立即生效 — 没有单独的保存步骤。颜色、线宽或线型设置为 **ByLayer**（默认值）的图元会采用您在此处的设置；拥有自己显式覆盖值的图元不受影响。

## 添加图层

1. 单击表格底部的 **+ Add Layer**。
2. 输入名称并按 **Enter** 确认，或按 **Escape** 取消。

图层名称可以包含字母、数字、空格以及 `_`、`-`、`$`。空白、已被使用或包含其他字符的名称会被拒绝并显示内联错误，该行会保持打开以便再次尝试。

新图层默认**未冻结、未锁定、可打印**，颜色为 7（白/黑），线宽为 Default，线型为 Continuous — 与 [Import](../import/) 在空白图形中赋予图层 `0` 的默认值相同。

## 删除图层

每一行的末尾都有一个 **✕** 按钮，用于把该图层从图形中移除。删除会立即生效 — 没有确认步骤 — 但只对没有任何东西依赖的图层开放：

| 情形 | 按钮状态 |
|------|----------|
| 图层为空 | 可用 — *Delete layer* |
| 图层至少被一个实体使用 | 禁用 — *Cannot delete: assigned to at least one entity* |
| 图层 `0` | 完全不显示按钮 |

**“使用中”涵盖整个图形**，而不只是你当前看到的部分。位于布局（图纸空间）上的实体与模型空间中的实体计入的分量完全相同，因此某个图层在屏幕上看似空白，仍可能拒绝被删除。冻结图层也不例外：冻结只是隐藏实体，并不会解除它们的图层归属，所以含有实体的冻结图层依然无法删除。

图层 `0` 永远无法删除。它是每个图形都必定具备的后备图层，因此其按钮根本不会被绘制出来，而不是显示为禁用状态。

### “…is now in use and can't be deleted”

偶尔 ✕ 看起来可用，但单击会被面板顶部的横幅拒绝：

```
"WALLS" is now in use and can't be deleted
```

这并不矛盾。要判断哪些图层正在使用，必须遍历图形中的每一个实体，因此结果会被缓存，仅在实体数量发生变化时重建 — 在数百个实体时开销低廉，在数十万个时则不然。把已有实体移动到某个图层并不会改变数量，所以该行的禁用状态可能会短暂过时。单击时会从头重新检查再执行删除，这正是拒绝发生在单击那一刻、而不是让图层在仍被引用时消失的原因。

用横幅自带的 **✕** 关闭它。图层不受影响。

## 此处无法完成的操作

表格不会指示哪个图层是*当前*图层；那由图层面板的下拉菜单或 [LayerMakeCurrent](../layer-make-current/) 设定，而非此对话框。图层名称也在创建时即固定 — 图层可以删除后重建，但不能重命名。

## 键盘参考

| 按键 | 操作 |
|-----|------|
| `Enter` | 确认新图层的名称（添加过程中） |
| `Escape` | 取消添加图层，或关闭对话框 |

## 相关命令

| 命令 | 功能 |
|------|------|
| [LayerMakeCurrent](../layer-make-current/) | 将单击图元所在图层设为当前图层 |
| [LayerMatch](../layer-match/) | 将选中图元的图层重新指定为与源图元相同 |
| [LayerIsolate](../layer-isolate/) | 冻结除选中图元所在图层以外的所有图层 |
| [LayerUnfreezeAll](../layer-unfreeze-all/) | 一键解冻所有图层 |
