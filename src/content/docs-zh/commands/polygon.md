# Polygon

`polygon` 命令绘制 3 到 1024 条边的正多边形——所有边和角都相等。在命令行中输入 `polygon`。结果是**闭合的 `LWPOLYLINE`**，放置后与其他 [Polyline](../polyline/) 一样，所有多段线编辑都适用。

## 绘制多边形

1. 在命令行中输入 `polygon`，输入**边数**（3 到 1024 的整数），然后按 **Enter** 或 **Space**。提示中会预填上次使用的边数（首次为 4）；开始输入即可替换。其他输入会被拒绝并留在提示中供修改。
2. **单击中心**，或输入 `X,Y` 并按 **Enter** 指定精确坐标。若要改从一条边开始，请先按 `E`（见下文）。
3. **单击确定半径**——多边形会实时预览——或输入半径并按 **Enter** 或 **Space**。
4. 多边形随即放置，命令结束。

## 选项

| 选项 | 按键 | 效果 |
|---|---|---|
| Edge | `E` | 第一个点成为边的一个端点，而不是中心。再选第二个端点；其余顶点按逆时针方向建立，位于从第一个端点到第二个端点的边的左侧。再次按 `E` 返回中心模式。 |
| Inside | `I` | 默认开启，并在多边形之间保持。开启：顶点位于给定半径的圆上。关闭：多边形位于该圆外侧，每条边的中点在圆上。 |

- 单击会把一个顶点（Inside 开启）或一条边的中点（Inside 关闭）恰好放在光标处，因此光标同时决定方向。
- 输入的半径没有可以瞄准的方向，因此多边形最低的一条边保持水平——除非开启了角度锁定，此时会沿锁定的角度。
- 每个选项在各自的步骤中提供，即使在输入数字时也可以切换。

## 键盘参考

| 按键 | 操作 |
|---|---|
| `0`–`9`, `.` | 输入边数、半径、坐标或长度 |
| `E` | 开启或关闭 Edge（第一点步骤） |
| `I` | 开启或关闭 Inside（半径步骤） |
| `Enter` / `Space` | 确认边数或半径 |
| `Escape` | 取消 |

## DXF — LWPOLYLINE 图元

多边形保存为闭合的 `LWPOLYLINE`，每个角一个顶点；DXF 没有专门的多边形类型。所有属性——顶点坐标、颜色、图层、线型、线型比例和厚度——都无损往返，任何 DXF 查看器都会将其读作闭合多段线。
