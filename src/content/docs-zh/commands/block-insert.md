# Block Insert

`blockinsert` 命令打开一个显示图纸中所有块预览的面板，并放置你选中的块。可用 [Block Create](../block-create/) 创建块，或打开含有块的 DXF 文件。

## 放置块

1. 输入 `blockinsert`，或在 **块** 面板中单击 **插入块**。面板停靠在左侧，每个块一个预览图块，每页十二个；图块下方的箭头用于翻页。
2. 在 **搜索块** 中输入，可按名称缩小图块范围。
3. 设置 **比例**（必须大于 0）和 **旋转**（单位为度）。**重复放置** 默认开启。
4. 单击某个块的图块。块会跟随光标：单击即按其基点放置，或输入 X,Y 指定精确位置。光标锁定到某个角度后，也可以输入长度。
5. **重复放置** 开启时，块会继续跟随光标放置下一个副本，直到你按 **Escape**。关闭时，放置一个副本后命令结束。

## 须知

- 要删除块，单击其图块上的垃圾桶并确认。图纸中有参照的块无法删除：其图块上会显示 **正在使用，无法删除**。
- 没有任何块的图纸会在面板中显示 **此图形中没有块**。
- 没有正在放置的内容时，**Escape** 会关闭面板。它是停靠面板之一，左侧同一时间只显示一个。
