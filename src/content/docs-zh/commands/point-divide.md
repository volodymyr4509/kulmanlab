# Point Divide

`pointdivide` 命令放置把对象分成等长段的[点](../point/)。对象本身不会改变：这些点是当前图层和颜色上的新图元，便于捕捉。

## 等分对象

1. 在命令行中输入 `pointdivide`，或在 Edit 面板的阵列下拉菜单中选择 **Point Divide**。
2. **单击对象**——直线、多段线、圆弧、圆、椭圆或样条曲线。其他对象会被拒绝，可以重新选择。
3. **输入段数**，即 2 到 32767 之间的整数。输入时点会在对象上预览。
4. 按 **Enter** 或 **Space** 放置这些点，命令随即结束。

## 点的位置

- 间距按沿对象的长度计算，而不是按角度，因此椭圆或样条曲线也会被分成等长的段。多段线的圆弧段会沿其曲线计算。
- 在开放对象上（直线、开放多段线、圆弧、部分椭圆或开放样条曲线），点位于各段之间，不会落在端点上：5 段得到 4 个点。
- 在闭合对象上（圆、闭合多段线、完整椭圆或闭合样条曲线），点从起点开始绕一整圈，起点处也有一个点：圆从角度 0 开始，闭合多段线从第一个顶点开始。5 段得到 5 个点。
- 超出 2–32767 的数字会被拒绝：命令行会说明原因并清空输入，以便重新输入。

Backspace 删除最后一位数字。Escape 重新开始，可以选择其他对象。选择对象之前按 Enter 或 Space 会结束命令。
