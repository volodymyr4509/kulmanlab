# LeaderStyle（引线样式）

`LeaderStyle` 命令打开命名引线样式管理器。每条新建的 [Leader](../leader/) 都会在创建时复制*当前*样式的设置。

## 编辑样式

输入 `LeaderStyle`，或单击注释面板中的**引线样式**。✓ 表示当前样式；名称旁的铅笔可用于重命名。预览使用与绘图区相同的渲染器并立即更新。

| 字段 | 作用 |
|---|---|
| 文字附着方式 | 上、中、下或下划线 |
| 箭头 / 箭头大小 | 每个引线端点的符号和大小 |
| 基线间距 | 基线端点与文字之间的距离 |
| 文字旋转角度 | 标签的旋转角度 |
| 文字样式 | 从 [TextStyle](../text-style/) 一次性复制字体、高度、粗体和斜体 |
| 字体 / 文字高度 | 标签的字体和高度 |
| 粗体 / 斜体 | 可独立设置的文字格式 |
| 文字边框 | 标签周围的矩形边框 |

**新建**会复制所选样式。`Standard` 不能重命名或删除，当前样式也不能删除。**置为当前**只影响之后新建的引线，现有对象不会改变。空名称、重复名称或 DXF 不允许的名称会禁用**确定**。导入的注释性样式会隐藏，但其数据仍被保留。

## 保存和 DXF

**确定**应用全部更改；**关闭**或 `Escape` 放弃更改。KulmanLab 可读写 `MLEADERSTYLE` 记录。名称、箭头及其大小、基线间距、文字高度、附着方式、边框和注释性标志作为样式字段保存。旋转、字体、粗体和斜体是 KulmanLab 默认值，在创建引线时复制到实体。

另请参阅 [Leader](../leader/)、[LeaderAdd](../leader-add/) 和 [LeaderRemove](../leader-remove/)。
