# Explode

`explode` 命令将一条[多段线](../polyline/)拆分为独立的[直线](../line/)和[圆弧](../arc/)图元——每段一个，精确地位于多段线自身顶点所在的位置。拆分出的图元会原地替换多段线，并保留其线宽、颜色、图层和线型。

Explode 适用于 **Polyline** 图元和**块参照**。

## 使用 explode

有两种运行方式，与 [Delete](../delete/) 相同：

**先选择，再炸开**——最快的方式：

1. 在画布上选择一条或多条多段线。
2. 在命令行中输入 `explode`，或在 Edit 面板的下拉菜单中选择 **Explode**。

选中的多段线会立即被拆分——无需单独的确认步骤，因为已经有内容被选中。

**先激活，再选择**：

1. 在未选择任何对象时输入 `explode`，或在下拉菜单中选择 **Explode**。
2. **选择多段线或块参照**——单击切换，或拖动按区域选择。
3. 按 **Enter** 或 **空格键** 确认并拆分选中的多段线。

选择过程中只会选取多段线和块参照——单击 Line、Circle 或其他图元不会有任何作用，区域拖动也会忽略框内或与框相交的其他一切。

## 拆分后得到什么

多段线的每一段都会变成自己独立的图元：

- **直线段**变为**直线**。
- **圆弧段**（来自 Polyline 的 [Arc 选项](../polyline/)）变为**圆弧**，与原曲线的圆心、半径和扫掠角度完全一致。

每个生成的直线和圆弧都会继承源多段线的**线宽、颜色、图层、线型和线型比例**——几何外观没有任何变化，只是现在变成了若干独立的图元，而不再是一条相连的多段线。

**块参照**会变成其块所绘制的图元，放在参照显示它们的位置。块中隐藏的图元（动态块的其他状态）不会保留；每个属性变为带有其值的普通 Text；以 ByBlock 绘制的部件取参照的颜色，0 图层上的部件取参照的图层。嵌套的块会成为独立的块参照，可以再次分解。X 和 Y 方向缩放不同的参照不会被选取，因为其中的圆将不得不变成椭圆。

拆分操作可以像其他任何编辑一样，通过 [Undo](../undo/) 一步撤销。

## 命令执行期间的选择

| 方式 | 行为 |
|------|------|
| **单击** | 将光标下的多段线或块参照加入或移出选择集；单击其他图元无作用 |
| **向右拖动**（严格） | 只选择完全位于框内的多段线和块参照 |
| **向左拖动**（交叉） | 选择与框边界相交的多段线和块参照 |
| **Enter** / **Space** | 确认并分解所选对象 |

## 支持的图元

| 图元 | 是否支持 |
|--------|-----------|
| Polyline / Rectangle | 是 |
| 块参照 | 是，X 和 Y 缩放不同时除外 |
| Line, Arc, Circle, Ellipse | 否 — 没有可拆分的内容 |
| Text, Spline, Dimension, Leader, Hatch | 否 |
