# Explode

`explode` 命令将一条[多段线](../polyline/)拆分为独立的[直线](../line/)和[圆弧](../arc/)图元——每段一个，精确地位于多段线自身顶点所在的位置。拆分出的图元会原地替换多段线，并保留其线宽、颜色、图层和线型。

Explode 仅适用于 **Polyline** 图元。

## 使用 explode

有两种运行方式，与 [Delete](../delete/) 相同：

**先选择，再炸开**——最快的方式：

1. 在画布上选择一条或多条多段线。
2. 在命令行中输入 `explode`，或点击 Edit 面板中的 **Explode** 按钮。

选中的多段线会立即被拆分——无需单独的确认步骤，因为已经有内容被选中。

**先激活，再选择**：

1. 在未选中任何内容的情况下输入 `explode` 或点击工具栏按钮。
2. **选择多段线**——点击以切换选中状态，或拖动以按区域选择。
3. 按 **Enter** 或 **空格键** 确认并拆分选中的多段线。

选择过程中只会拾取多段线——点击直线、圆或任何其他图元都不会有任何效果，区域拖选也会忽略框内或与框相交的多段线之外的一切内容。

## 拆分后得到什么

多段线的每一段都会变成自己独立的图元：

- **直线段**变为**直线**。
- **圆弧段**（来自 Polyline 的 [Arc 选项](../polyline/)）变为**圆弧**，与原曲线的圆心、半径和扫掠角度完全一致。

每个生成的直线和圆弧都会继承源多段线的**线宽、颜色、图层、线型和线型比例**——几何外观没有任何变化，只是现在变成了若干独立的图元，而不再是一条相连的多段线。

拆分操作可以像其他任何编辑一样，通过 [Undo](../undo/) 一步撤销。

## 命令执行期间的选择

| 方式 | 行为 |
|------|------|
| **单击** | 切换光标所在多段线的选中状态；单击非多段线图元不会有任何效果 |
| **向右拖动**（严格模式） | 仅选择完全位于框内的多段线 |
| **向左拖动**（相交模式） | 选择与框边界相交的多段线 |
| **Enter** / **空格键** | 确认并拆分选中的多段线 |

## 支持的图元

| 图元 | 是否支持 |
|--------|-----------|
| Polyline / Rectangle | 是 |
| Line, Arc, Circle, Ellipse | 否 — 没有可拆分的内容 |
| Text, Spline, Dimension, Leader, Hatch | 否 |
