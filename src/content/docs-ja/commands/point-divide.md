# Point Divide

`pointdivide` コマンドは、オブジェクトを等しい長さの区間に分ける[点](../point/)を置きます。オブジェクト自体は変更されません。点は現在のレイヤーと色の新しいエンティティで、スナップに便利です。

## オブジェクトを分割する

1. ターミナルに `pointdivide` と入力するか、Edit パネルの配列ドロップダウンから **Point Divide** を選びます。
2. **オブジェクトをクリック**します — 線、ポリライン、円弧、円、楕円、スプライン。それ以外は拒否され、選び直せます。
3. **区間数を入力**します（2〜32767 の整数）。入力中、オブジェクト上に点がプレビューされます。
4. **Enter** または **Space** を押すと点が置かれ、コマンドが終了します。

## 点が置かれる位置

- 間隔は角度ではなくオブジェクトに沿った長さで決まるため、楕円やスプラインも等しい長さに分けられます。ポリラインの円弧区間は、その曲線に沿ってたどられます。
- 開いたオブジェクト（線、開いたポリライン、円弧、部分楕円、開いたスプライン）では、点は区間の間に置かれ、端には置かれません。5 区間なら 4 点です。
- 閉じたオブジェクト（円、閉じたポリライン、完全な楕円、閉じたスプライン）では、始点から一周して点が置かれ、始点にも点が置かれます。円は角度 0、閉じたポリラインは最初の頂点から始まります。5 区間なら 5 点です。
- 2〜32767 以外の数値は拒否されます。ターミナルが理由を表示して入力を消去するので、入力し直せます。

Backspace で最後の数字を削除します。Escape でやり直し、別のオブジェクトを選べます。オブジェクトを選ぶ前の Enter または Space でコマンドが終了します。
