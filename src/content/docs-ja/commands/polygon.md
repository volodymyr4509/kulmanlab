# Polygon

`polygon` コマンドは、3〜1024辺の正多角形（すべての辺と角が等しい）を描きます。ターミナルに `polygon` と入力します。結果は**閉じた `LWPOLYLINE`** なので、配置後は他の [Polyline](../polyline/) と同じように扱え、すべてのポリライン編集が適用されます。

## 多角形を描く

1. ターミナルに `polygon` と入力し、**辺の数**（3〜1024の整数）を入力して **Enter** または **Space** を押します。プロンプトには前回使った数があらかじめ入力されています（初回は 4）。入力を始めると置き換わります。それ以外の値は拒否され、修正のためプロンプトに残ります。
2. **中心をクリック**するか、`X,Y` を入力して **Enter** を押すと正確な座標を指定できます。辺から始めたい場合は先に `E` を押します（後述）。
3. **半径をクリック**するか（多角形がライブプレビューされます）、半径を入力して **Enter** または **Space** を押します。
4. 多角形が配置され、コマンドが終了します。

## オプション

| オプション | キー | 効果 |
|---|---|---|
| Edge | `E` | 最初の点が中心ではなく辺の一方の端になります。もう一方の端を指定すると、残りの頂点は反時計回りに、最初の端から2番目の端へ向かう辺の左側に作られます。もう一度 `E` を押すと中心に戻ります。 |
| Inside | `I` | 既定でオンで、多角形から次の多角形へ引き継がれます。オン：頂点が指定半径の円上に乗ります。オフ：多角形はその円の外側に置かれ、各辺の中点が円上に乗ります。 |

- クリックすると、カーソルのある位置にちょうど頂点（Inside オン）または辺の中点（Inside オフ）が置かれるため、カーソルが向きも決めます。
- 入力した半径には狙う方向がないため、多角形は最も下の辺が水平になるように置かれます。角度ロックがオンの場合は、ロックされた角度に従います。
- 各オプションはそれぞれのステップで提示され、数値の入力中でも切り替えられます。

## キー操作一覧

| キー | 動作 |
|---|---|
| `0`–`9`, `.` | 辺の数、半径、座標または長さを入力 |
| `E` | Edge のオン／オフ（最初の点のステップ） |
| `I` | Inside のオン／オフ（半径のステップ） |
| `Enter` / `Space` | 辺の数または半径を確定 |
| `Escape` | キャンセル |

## DXF — LWPOLYLINE エンティティ

多角形は、各頂点につき1つの頂点を持つ閉じた `LWPOLYLINE` として保存されます。DXF には専用の多角形タイプがありません。頂点座標、色、レイヤー、線種、線種尺度、厚さなどすべてのプロパティが損失なく往復し、どの DXF ビューアでも閉じたポリラインとして読み込まれます。
