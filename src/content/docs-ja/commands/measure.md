# Measure

`measure` コマンドは、点を指定しなくても、カーソルを動かすだけでその周辺の図面を読み取ります。最も近いジオメトリまでの距離、そのジオメトリの長さや丸さ、線が交わる角度です。閉じた領域の内側をクリックすると、その面積と周長が得られます。図面は一切変更されません。

## 計測する

1. ターミナルに `measure` と入力するか、Measure パネルの最初のボタン **Measure** をクリックします。
2. **カーソルを動かします。** コマンドはカーソルから右・上・左・下に向かって最も近いジオメトリを探し、見つかったものを表示します。
3. **閉じた領域の内側をクリック**すると、その領域が塗りつぶされ、面積と周長が読み取れます（下記参照）。
4. **Enter**、**Space**、または **Escape** で終了します。

## 表示されるもの

- **横断距離** — カーソルが一方でぶつかるものから、反対側でぶつかるものまでの距離（水平方向と垂直方向）。片側にしか何もない場合は、カーソルから測ります。何かにぶつかった端には小さな塗りつぶしの点が付き、カーソル側の端には付きません。
- **長さまたは半径** — コマンドが到達した各オブジェクトが、その長さ（円の一部なら半径）とともに強調表示されます。
- **角度** — 到達した2本の直線が交わる場所に、その間の角度が書かれます。直角は小さな四角で示されます。

長さと角度は、現在の [DimensionStyle](../dimension-style/) の単位書式と精度で書かれます。

## 面積と周長

閉じた領域の内側をクリックすると、領域が塗りつぶされ、面積と周長がプロンプトと履歴に表示されます。領域は [Hatch](../hatch/) と同じ方法で見つけられます。端と端が接する別々の線は、ポリラインと同じように領域を閉じ、内側にある閉じた図形は島として除外されます。その縁は周長に含まれ、面積は差し引かれます。

面積は平方の図面単位の単なる数値です（フィートやインチでは面積を表せません）。周長は単位書式に従います。別の領域を測るには、その内側をクリックします。点の周りに閉じたものがない場合、ターミナルは Hatch と同じメッセージで理由を表示します：no boundary found、point is not enclosed、boundary is open。

## 知っておくと便利なこと

- 線、円弧、円、楕円、ポリライン、スプラインを対象に測ります。長さと面積は、楕円やスプラインでも正確です。
- フリーズされたレイヤーのオブジェクトは無視され、ロックされたレイヤーのオブジェクトは計測されます。
- 大きな図面では、カーソルの近くだけを調べるので、軽快さが保たれます。
