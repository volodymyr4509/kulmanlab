# Point

`point` コマンドは、指定のたびに点を置き、Enter、Space、Escape を押すまで有効のままです。点はサイズのない位置で、小さなドットとして描かれ、現在のレイヤーと色を持ちます。`POINT` エンティティとして保存されます。

## 点を置く

1. ターミナルに `point` と入力するか、Shapes パネルの最後のボタン **Point** をクリックします。
2. 点を置きたい場所を**クリック**するか、`X,Y` を入力して **Enter** を押すと正確な位置に置けます。指定のたびに点が置かれ、ターミナルにその座標が記録されます。コマンドは次の点のために有効のままです。
3. または、[ベクターピン](../../interface/vector-pins/)から方向を固定して距離を入力すると、その方向にちょうどその距離だけ離れた位置に点が置かれます。
4. 終了するには **Enter**、**Space**、**Escape** を押します。Enter と Space は、何も入力していないときだけ終了します。

## 点の見え方

点は、どのズームレベルでも半径 1 px のドットとして描かれるため、縮小しても見え、拡大しても大きくなりません。図面の点スタイル（`$PDMODE` と `$PDSIZE`）はまだ読み込まれないので、DXF に何が書かれていても、すべての点はドットです。

## 点の編集

選択した点にはグリップが1つあり、それで移動できます。窓選択は、点が窓の内側にあるとき、どちらの方向にドラッグしても点を選択します。

[Move](../move/)、[Copy](../copy/)、[Rotate](../rotate/)、[Mirror](../mirror/)、[Scale](../scale/) は、ほかのエンティティと同じように点にも使えます。プロパティウィンドウには Position X と Position Y のほか、色とレイヤーが表示されます。

## DXF — POINT エンティティ

点は、位置・色・レイヤー（グループコード 10/20、62、8）を持つ `POINT` エンティティとして DXF に読み書きされ、保存された JSON でも往復します。以前はインポート時にスキップされていました。[Export Manager](../export-manager/) では Points が独立した行になっているので、エクスポートから外すこともできます。
