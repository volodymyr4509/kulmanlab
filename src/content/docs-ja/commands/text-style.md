# TextStyle（文字スタイル）

`TextStyle` コマンドは文字スタイル管理画面を開きます。名前付きスタイルを作成して既定値を編集し、*現在のスタイル*を選べます。新しい [Text](../text/) は、作成時に現在のスタイルの設定をコピーします。

## 管理画面の使い方

`TextStyle` と入力するか、注釈パネルの **文字スタイル** をクリックします。✓ は現在のスタイルを示し、行をダブルクリックするとそのスタイルが現在のスタイルになります。

| 項目 | 内容 |
|---|---|
| 名前変更 | 名前の横の鉛筆で一覧内から編集します。`Standard` は名前を変更できません。 |
| フォント / 高さ | フォントと必須の正の高さです。0 以下の値は `1` になり、管理画面では `0` より大きい値のみ入力できます。 |
| 太字 / 斜体 | 個別に切り替えられる書式 |
| 行間隔 | 行と行の間隔 |
| 水平方向の位置合わせ | 左、中央、右、両端揃え |
| 枠 | 新しい文字を囲む長方形の枠 |

プレビューはキャンバスと同じレンダラーで2行の文字を描画します。フォント、高さ、太字、斜体、枠、行間、配置が即時反映され、表示値はフィット倍率を示します。新しいスタイルは既定で**左揃え**です。

**新規** は選択したスタイルを複製します。**削除** では `Standard` と現在のスタイルを削除できません。**現在に設定** は今後作成する文字だけに適用され、既存の文字は変わりません。空、重複、または DXF で無効な名前があると **OK** は無効になります。読み込まれた異尺度対応スタイルは非表示ですが、データは保持されます。

## 保存と DXF

名前、フォントファイル、太字、斜体、異尺度対応フラグは DXF 文字スタイルで保持されます。KulmanLab は STYLE グループ `40` を `0`（可変高さ）、最後に使用した高さをグループ `42` に書きます。これにより固定 STYLE 高さが寸法スタイル固有の文字高さを上書きしません。枠、行間、水平揃えは KulmanLab の文字ごとの既定値であり、DXF STYLE テーブルのフィールドではありません。
