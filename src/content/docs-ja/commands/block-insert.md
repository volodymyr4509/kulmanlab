# Block Insert

`blockinsert` コマンドは、図面内のすべてのブロックのプレビューを並べたパレットを開き、選んだものを配置します。ブロックは [Block Create](../block-create/) で作るか、ブロックを含む DXF ファイルを開きます。

## ブロックを配置する

1. `blockinsert` と入力するか、**ブロック** パネルの **ブロック挿入** をクリックします。パレットは左側にドッキングし、ブロックごとにプレビューのタイルが並びます（1 ページ 12 個）。タイルの下の矢印でページを送ります。
2. **ブロックを検索** に入力すると、名前でタイルを絞り込めます。
3. **尺度**（0 より大きい値）と **回転**（度）を設定します。**配置を繰り返す** は既定でオンです。
4. ブロックのタイルをクリックします。ブロックはカーソルに追従します。クリックすると基点で配置され、X,Y を入力すると正確な位置に置けます。カーソルが角度にロックされていれば、長さを入力することもできます。
5. **配置を繰り返す** がオンのあいだは、**Escape** を押すまでブロックは次のコピーのためにカーソルに追従し続けます。オフなら、1 つ置いたらコマンドが終わります。

## 知っておくこと

- ブロックを削除するには、タイルのごみ箱をクリックして確定します。図面に参照があるブロックは削除できず、タイルに **使用中のため削除できません** と表示されます。
- ブロックがない図面では、パレットに **この図面にはブロックがありません** と表示されます。
- 何も配置していないときは **Escape** でパレットが閉じます。パレットはドッキングパネルの 1 つで、左側には一度に 1 つだけ表示されます。
