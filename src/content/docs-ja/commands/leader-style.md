# LeaderStyle（引き出し線スタイル）

`LeaderStyle` コマンドは名前付き引き出し線スタイルの管理画面を開きます。新しい [Leader](../leader/) は、作成時に*現在のスタイル*の設定をコピーします。

## スタイルの編集

`LeaderStyle` と入力するか、注釈パネルの **引き出し線スタイル** をクリックします。✓ は現在のスタイルを示し、名前の横の鉛筆で名前を変更できます。プレビューは作図画面と同じレンダラーで即座に更新されます。

| 項目 | 内容 |
|---|---|
| 文字の位置合わせ | 上、中央、下、または下線 |
| 矢印 / 矢印のサイズ | 各引き出し線端の記号と大きさ |
| ランディングの間隔 | ランディングと文字の間隔 |
| 文字の回転 | ラベルの角度（度） |
| 文字スタイル | [TextStyle](../text-style/) からフォント、高さ、太字、斜体を一度だけコピー |
| フォント / 文字の高さ | ラベルの書体と高さ |
| 太字 / 斜体 | 個別に設定できる文字書式 |
| 文字の枠 | ラベルを囲む長方形の枠 |

**新規** は選択したスタイルを複製します。`Standard` は名前変更も削除もできず、現在のスタイルも削除できません。**現在に設定** は今後作成する引き出し線だけに適用され、既存のオブジェクトは変わりません。空、重複、または DXF で無効な名前があると **OK** は無効になります。読み込まれた異尺度対応スタイルは非表示ですが保持されます。

## 保存と DXF

KulmanLab は `MLEADERSTYLE` レコードを読み書きします。名前、矢印、矢印サイズ、ランディング間隔、文字高さ、文字アタッチ、枠、異尺度対応フラグはスタイル項目として維持されます。書き出し時、グループ `342` はフォント、太字、斜体、高さが引出線スタイルと一致する文字スタイルを参照し、一致しなければ `Standard` を使用します。この DXF 参照によってアプリ内の一度限りのコピーがライブリンクになるわけではありません。1つの文字アタッチ値は左右両方の DXF 項目に書かれます。
