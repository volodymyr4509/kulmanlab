# Point Interval

`pointinterval` コマンドは、経路に測点を打つように、オブジェクトに沿って一定間隔で[点](../point/)を置きます。オブジェクト自体は変更されません。点は現在のレイヤーと色の新しいエンティティで、スナップに便利です。

## 一定間隔で点を置く

1. ターミナルに `pointinterval` と入力するか、Edit パネルの配列ドロップダウンから **Point Interval** を選びます。
2. **開始したい端の近くでオブジェクトをクリック**します — 線、ポリライン、円弧、円、楕円、スプライン。それ以外は拒否され、選び直せます。
3. **間隔の長さを入力**します。入力中、オブジェクト上に点がプレビューされます。
4. **Enter** または **Space** を押すと点が置かれ、コマンドが終了します。

## 点が置かれる位置

- 最初の点は始点から 1 間隔の位置に置かれ、以降は 1 間隔ずつ続きます。距離は曲線部分も含めてオブジェクトに沿って測られます。始点そのものには点は置かれません。
- 開いたオブジェクト（線、開いたポリライン、円弧、部分楕円、開いたスプライン）では、クリックした位置に近い端から測ります。遠い端の余りには点が置かれず、間隔がちょうど割り切れるときだけ遠い端に点が置かれます。
- 閉じたオブジェクト（円、閉じたポリライン、完全な楕円、閉じたスプライン）では、どこをクリックしてもオブジェクト自身の始点から測ります。円は角度 0 から反時計回り、閉じたポリラインは最初の頂点からです。点は始点の手前で止まります。
- 0 以下の長さ、オブジェクトより長い長さ、32767 点を超える長さは拒否されます。ターミナルが理由を表示して入力を消去するので、入力し直せます。

Backspace で最後の文字を削除します。Escape でやり直し、別のオブジェクトを選べます。オブジェクトを選ぶ前の Enter または Space でコマンドが終了します。
