# LayerManager

`LayerManager` コマンドは、図面内のすべての画層を一覧するテーブルを開きます。**Freeze**、**Lock**、**Plot**、**色**、**線の太さ**、**線種** はいずれも行の中で直接編集できます。画層を追加し、未使用のものを削除し、既存の画層のふるまいを調整するための中心的な場所です。ほかの画層コマンド（[LayerMakeCurrent](../layer-make-current/)、[LayerMatch](../layer-match/)、[LayerIsolate](../layer-isolate/)、[LayerUnfreezeAll](../layer-unfreeze-all/)）は、これを開かずにそれぞれ一つの用途をこなします。

## Layer Manager を開く

- ターミナルに `LayerManager` と入力する、**または**
- レイヤーパネルの **Layer Manager** ボタンをクリックします。

ダイアログはフローティングパネルとして開きます。事前に何かを選択しておく必要はありません。

## レイヤー表

| 列 | 制御する内容 |
|----|----------------|
| Name | レイヤー名。表内では読み取り専用で表示されます(作成時に一度だけ設定) |
| Freeze | レイヤーのエンティティを非表示にし、解除するまで選択対象から除外します |
| Lock | レイヤー上のエンティティの編集を、非表示にせずに禁止します |
| Plot | レイヤーのエンティティを印刷や PDF エクスポートに含めるかどうか |
| Color | レイヤーの ACI 色 — スウォッチをクリックしてカラーピッカーを開きます |
| Lineweight | レイヤーの線幅 — チップをクリックして線幅ピッカーを開きます |
| Linetype | レイヤーの破線パターン — チップをクリックして線種ピッカーを開きます |
| ✕ | どこからも使われていない画層を削除します — [画層を削除する](#画層を削除する)を参照 |

Freeze、Lock、Plot の切り替えは即座に反映されます — 別途保存の手順はありません。色・線幅・線種が **ByLayer**(既定値)に設定されているエンティティは、ここで設定した内容を引き継ぎます。独自の明示的な上書きを持つエンティティは影響を受けません。

## レイヤーを追加する

1. 表の下部にある **+ Add Layer** をクリックします。
2. 名前を入力して **Enter** で確定するか、**Escape** でキャンセルします。

レイヤー名には英数字、スペース、`_`、`-`、`$` を使用できます。空の名前、既に使用されている名前、それ以外の文字を含む名前は、インラインのエラーとともに拒否され、行は再入力のために開いたままになります。

新しいレイヤーは**フリーズ解除、ロック解除、プロット可能**な状態で始まり、色は 7(白/黒)、線幅は Default、線種は Continuous です — これは [Import](../import/) が空の図面のレイヤー `0` に割り当てるのと同じ既定値です。

## 画層を削除する

各行の末尾には、その画層を図面から取り除く **✕** ボタンがあります。削除は即座に行われ、確認の手順はありません。ただし、何も依存していない画層に対してのみ提供されます。

| 状況 | ボタンの状態 |
|------|--------------|
| 画層が空 | 有効 — *Delete layer* |
| 画層が一つ以上のエンティティに割り当てられている | 無効 — *Cannot delete: assigned to at least one entity* |
| 画層 `0` | ボタン自体が出ない |

**「使用中」は図面全体を対象とします**。いま見えている範囲だけではありません。レイアウト（ペーパー空間）に置かれたエンティティも、モデル空間のものとまったく同じように数えられます。そのため、画面上では空に見える画層が削除を拒むことがあります。フリーズした画層も例外ではありません。フリーズはエンティティを非表示にするだけで割り当てを解除しないので、エンティティを抱えたフリーズ画層は削除できないままです。

画層 `0` は決して削除できません。どの図面にも必ず存在する予備の画層であるため、無効表示にするのではなく、ボタンそのものが描画されません。

### 「…is now in use and can't be deleted」

まれに ✕ が使えるように見えても、クリックがパネル上部のバナーで拒否されることがあります。

```
"WALLS" is now in use and can't be deleted
```

これは矛盾ではありません。どの画層が使用中かを調べるには図面内のすべてのエンティティをたどる必要があるため、結果はキャッシュされ、エンティティ数が変わったときにだけ作り直されます。数百のエンティティなら安価ですが、数十万では違います。既存のエンティティを別の画層へ移してもエンティティ数は変わらないので、行の無効状態が一瞬だけ古いままになることがあります。クリック時には削除の前に一から確認し直すため、まだ参照が残っているのに画層が消えるのではなく、クリックの時点で拒否されるわけです。

バナーは自身の **✕** で閉じられます。画層はそのままです。

## ここではできないこと

どの画層が *現在の* 画層かはテーブルに表示されません。それは画層パネルのドロップダウン、または [LayerMakeCurrent](../layer-make-current/) で設定するもので、このダイアログからは設定しません。画層名も作成時に固定されます。画層は削除して作り直せますが、名前の変更はできません。

## キーボードリファレンス

| キー | 操作 |
|-----|------|
| `Enter` | 新しいレイヤー名を確定する(追加中) |
| `Escape` | レイヤーの追加をキャンセルする、またはダイアログを閉じる |
