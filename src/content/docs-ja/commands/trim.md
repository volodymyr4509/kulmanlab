# Trim（トリム）

`trim` コマンドは2つの隣接する交差点の間にある[Line](../line/)、[Arc](../arc/)、[Circle](../circle/)、[Ellipse](../ellipse/)、または [Polyline](../polyline/) の部分を削除し、エンティティを1つ以上の残りの部分に分割します。カットするセグメントはカーソル位置によって決まります — 削除したい部分の上にカーソルを移動してクリックでトリムします。

## エンティティのトリム

1. ターミナルに `trim` と入力するか、**Trim** ツールバーボタンをクリックします。
2. **削除したいセグメントの上にカーソルを移動** — プレビューでカットされる部分が正確にハイライトされます。
3. **クリック**してそのセグメントを削除します。

各トリム後もコマンドはアクティブのままなので、同じエンティティまたは別のエンティティでカーソルを移動してクリックを続け、さらにセグメントをカットできます。**Enter**、**Space**、または **Escape** を押して終了します。

```
  前:                     交差点の間のセグメントをトリム後:

  ──────●──────●──────        ──────●          ●──────
      交差    交差           （左部分）        （右部分）
                              （中間セグメントが削除された）
```

## トリムセグメントの決定方法

コマンドはカーソル位置をホバーしたエンティティに投影し、そのエンティティが他のエンティティと持つすべての交差点を検索します。これらの交差点がエンティティをセグメントに分割します — Line、Arc、または開いた Polyline の場合、エンティティ自体の端点が追加の固定境界として機能します。完全な Circle や Ellipse、または閉じた Polyline（Rectangle を含む）には独自の端点がないため、そもそもトリムする前に少なくとも2つの交差点が必要です。カーソルの投影を含む区間のセグメントがハイライトされ、クリックで削除されます。

- **Line、Arc、開いた Polyline** — 削除されるセグメントは、先頭部分（最初の交差点より前）、中間部分（2つの交差点の間、エンティティを2つに分割）、または末尾部分（最後の交差点より後）になります。
- **Circle、Ellipse、閉じた Polyline/Rectangle** — 固定された開始点や終了点がないため、2つの*交差点*の間の弧のみ削除できます。交差点が2つ未満の場合、プレビューは表示されず、クリックしても何も起こりません。形状の残りの部分が唯一残る部分になります。

## トリムの結果

| エンティティ | トリム後の結果 |
|--------|------------------------|
| Line | 最大2つの短い Line エンティティ |
| Arc | 最大2つの短い Arc エンティティ |
| Circle | 1つの [Arc](../arc/) エンティティ — 円の閉じた形状が失われるため、残りの部分は円弧として保存されます |
| Ellipse | 開始角と終了角を持つ1つの Ellipse エンティティ — 残りの部分は Ellipse のままですが、部分的になります |
| Polyline（開いた） | 最大2つの短い Polyline エンティティ |
| Polyline（閉じた）/ Rectangle | 1つの開いた Polyline エンティティ — 閉じた形状が失われるため、残りの部分は開いた状態で保存されます |
| スプライン | 最大 2 つの短い Spline — 各部分は同じ曲線のより短い区間で、制御点として保存されます（Fit スプラインのフィットポイントは破棄されます）。閉じたスプラインは 1 つの開いた部分を残します |

## キーボードリファレンス

| キー | 操作 |
|-----|------|
| `Enter` / `Space` | トリムモードを終了 |
| `Escape` | トリムモードを終了 |

## サポートされるエンティティ

| エンティティ | トリム可能？ |
|---------|----------|
| Line | あり |
| Arc | あり |
| Circle | あり — 交差点が2つ以上必要 |
| Ellipse | あり — 交差点が2つ以上必要 |
| Polyline（開いた） | あり |
| Polyline（閉じた）/ Rectangle | あり — 交差点が2つ以上必要 |
| スプライン | はい — 閉じたスプラインは 2 つ以上の交点が必要 |
| テキスト、寸法、引出線 | なし |

**切り取りの境界**として使われるオブジェクトは Line、Arc、Circle、Ellipse、Polyline、Spline のいずれかです。Text、Dimension、Leader は交点を登録しないため、境界としても使えません。

Polyline の**円弧セグメント**（Arc トグルで描画したもの、またはインポートしたもの）は、直線セグメントとまったく同じようにトリムされます — 2 つの交点間の円弧部分にカーソルを合わせてクリックします。トリムされた端はその曲率を保持し、長さのみが変化します。

## Trim と Extend の比較

| | Trim | Extend |
|---|------|--------|
| 機能 | エンティティのセグメントを削除 | 直線の端点を境界まで伸ばす |
| トリガー | カットするセグメントの上にカーソル | 延長する端点の近くにカーソル |
| 結果 | エンティティが分割または短くなる | 直線の端点が境界まで移動 |
| サポートされるエンティティ | Line、Arc、Circle、Ellipse、Polyline、スプライン | Line、Arc、Ellipse、Polyline |
