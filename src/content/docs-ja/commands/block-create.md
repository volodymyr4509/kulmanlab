# Block Create

`blockcreate` コマンドは**ブロック**を作ります。ブロックは名前のついたオブジェクトのグループで、図面に 1 回だけ保存され、[Block Insert](../block-insert/) で何度でも配置できます。選んだオブジェクトがブロックになり、図面ではそれへの 1 つの参照に置き換わるので、見た目は変わりません。

## ブロックを作る

1. 必要なら先にオブジェクトを選択し、`blockcreate` と入力するか、**ブロック** パネルの **ブロック作成** をクリックします。選択済みの状態でポップアップが開きます。
2. **名前**を入力します。空にはできず、`< > / \ " : ; ? * | , =` やバッククォートは使えず、別のブロックと同じ名前にもできません。
3. **オブジェクトを選択** をクリックしてオブジェクトを追加・除外します。ポップアップが隠れるので、オブジェクトをクリックするか範囲をドラッグします。**Enter** または **Space** でポップアップに戻ると、**オブジェクト** に数が表示されます。
4. ブロックを配置する点である**基点**を設定します。X と Y を入力するか、**点を指定** をクリックしてキャンバスをクリックします（そこで X,Y を入力することもできます）。初期値は 0,0 です。
5. **OK** をクリックします。ブロックが保存され、オブジェクトは基点にあるそれへの 1 つの参照に置き換わり、ターミナルにブロック名と含まれるオブジェクト数が記録されます。

## 知っておくこと

- 問題がある間は **OK** は無効のままで、フィールドの下のメッセージが理由を示します。名前が空または使えない、名前がすでに使われている、オブジェクトがない、のいずれかです。
- オブジェクトや基点の選択中に **Escape** を押すと、ブロックはそのままでポップアップに戻ります。ポップアップで **Escape** を押すとコマンドが取り消されます。
- ブロックは図面と一緒に保存され、参照とともに DXF に書き出されます。
