# Explode

`explode` コマンドは[ポリライン](../polyline/)を個々の[ライン](../line/)と[アーク](../arc/)のエンティティに分解します — セグメントごとに1つずつ、ちょうどポリライン自身の頂点があった位置に。分解されたパーツはポリラインをその場で置き換え、その線幅、色、レイヤー、線種を引き継ぎます。

Explode は **Polyline** エンティティと**ブロック参照**に使えます。

## explode の使い方

実行方法は2通りあり、[Delete](../delete/)と同じパターンです：

**先に選択してから explode** — 最も速い方法：

1. キャンバス上で1つ以上のポリラインを選択します。
2. ターミナルに `explode` と入力するか、Edit パネルのドロップダウンから **Explode** を選びます。

選択したポリラインは即座に分解されます — すでに何かが選択されているため、別途確認のステップはありません。

**コマンドを起動してから選択**：

1. 何も選択していない状態で `explode` と入力するか、ドロップダウンから **Explode** を選びます。
2. **ポリラインまたはブロック参照を選択**します — クリックで切り替え、ドラッグで範囲選択。
3. **Enter** または **スペース** を押して、選択したポリラインを確定して分解します。

選択中に拾われるのはポリラインとブロック参照だけです。Line、Circle などほかのエンティティをクリックしても何も起こらず、範囲ドラッグでも内側や交差するそれ以外のものは無視されます。

## 分解すると何が得られるか

ポリラインの各セグメントはそれぞれ独立したエンティティになります：

- **直線セグメント**は**ライン**になります。
- **円弧セグメント**（Polyline の[Arc オプション](../polyline/)によるもの）は、元の曲線の中心・半径・スイープに正確に一致する**アーク**になります。

生成された各ラインとアークは、元のポリラインの**線幅、色、レイヤー、線種、線種尺度**を引き継ぎます — ジオメトリの見た目は何も変わらず、1つの連結されたポリラインだった代わりに複数の独立したエンティティになっただけです。

**ブロック参照**は、そのブロックが描くエンティティになり、参照が表示していた位置に置かれます。ブロックが非表示にしているエンティティ（ダイナミックブロックのほかの状態）は除かれ、各属性はその値を持つ通常の Text になります。ByBlock で描かれた部分は参照の色を、画層 0 の部分は参照の画層を受け継ぎます。入れ子のブロックはそれ自体がブロック参照として出てくるので、さらに分解できます。X と Y で尺度が異なる参照は選択されません。円を楕円にしなければならないためです。

分解は他の編集操作と同じく、[Undo](../undo/) で1ステップとして取り消せます。

## コマンド実行中の選択

| 方法 | 動作 |
|------|------|
| **クリック** | カーソル下のポリラインまたはブロック参照を選択に追加・解除します。ほかのエンティティをクリックしても何も起こりません |
| **右へドラッグ**（窓） | 枠の中に完全に入ったポリラインとブロック参照だけを選択 |
| **左へドラッグ**（交差） | 枠の境界と交わるポリラインとブロック参照を選択 |
| **Enter** / **Space** | 確定して選択を分解 |

## サポートされるエンティティ

| エンティティ | サポート |
|--------|---------|
| Polyline / Rectangle | あり |
| ブロック参照 | はい（X と Y の尺度が異なる場合を除く） |
| Line, Arc, Circle, Ellipse | なし — 分解するものがない |
| Text, Spline, Dimension, Leader, Hatch | なし |
