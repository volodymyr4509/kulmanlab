# Object Snap Settings

`objectsnapsettings` コマンドは、コントロールバーのすべての設定をまとめたウィンドウを開きます。各設定はリストの横に小さな図つきで説明されます。コントロールバーの歯車ボタンで開くか、`objectsnapsettings` と入力します。ここで設定を変えるのは、バーのボタンを切り替えるのと同じです。

## 設定

### カーソルの止まる位置

| コントロールバー | 働き |
|---|---|
| `Snap` | カーソルが最も近いグリッド点にジャンプし、選んだ点がきりのよい座標に乗ります。カーソル近くのオブジェクトへのスナップは引き続き優先されます。グリッドの間隔はズームに合わせて変わります。 |
| `TANG` | ある点から線を引いている間、円・円弧・楕円・スプラインにちょうど接する位置へカーソルを近づけると、そこにスナップします。線分、ポリラインなどのコマンドや、線分・ポリラインの端点をドラッグするときに使えます。 |

### 作図中のガイド

| コントロールバー | 働き |
|---|---|
| `ANGL` | 最後の点からカーソルがこれらの角度のいずれかに近づくと、その方向にロックされ、破線の光線で示されます。ロック中に長さを入力して Enter を押すと、その距離に点を置きます。 |
| `Pins` | スナップ点の上にカーソルを少し止めるとピン留めされます。ピン留めした点から水平・垂直のガイド線が伸び、カーソルはその線と交点にスナップします。 |
| `Dist` | 最後にピン留めした点を始点として使います。ピンからの角度にカーソルがロックされたら、長さを入力して Enter を押すと、そこからその距離に点を置きます。ベクトルピンが必要です。 |

### 入力と選択

| コントロールバー | 働き |
|---|---|
| `Rel` | 入力した X,Y の点は、@ で始まったかのように最後に選んだ点から測られます。Backspace で @ を消すと図面の座標になります。オフのときは、オフセットに @ を自分で入力します。 |
| `Lasso` | 何もない場所で押してドラッグすると、四角形の代わりに自由な輪を描いて囲めます。輪の中に入ったものが選択されます。 |

### 表示

| コントロールバー | 働き |
|---|---|
| `Grid` | 背景のグリッドを表示します。間隔はズームに応じて変わります。オフにしてもグリッドへのスナップは止まりません。 |
| `LWT` | 線をその線の太さで描くので、太い線ほど太く見えます。オフのときはすべての線が細く描かれ、込み入った図面が読みやすくなることがあります。 |

**ANGL** はステップ用の行を持ちます。10°、20°、30°、45°、90° から選ぶか、**カスタム** を選んで 1° から 180° の好きな角度を入力します。

接線スナップ、相対入力、投げ縄は既定でオフです。**既定値に戻す** はすべての設定を初期状態に戻します。
