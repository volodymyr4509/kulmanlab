# Array Polar

`ArrayPolar` コマンドは、選択したオブジェクトのコピーを中心点の周りに、一周または一部に均等に配置します。元のオブジェクトが最初のアイテムで、それ以外はすべて中心を軸に回転させたコピーです。Rotate をオフにすると、向きは変えずに移動だけを行います。

## 円形配列を作成する

1. オブジェクトを選択し、ターミナルに `arraypolar` と入力するか、ツールバーの **Array Polar** ボタンをクリックします。何も選択せずに開始した場合は、先にオブジェクトの選択を求められます。**Enter** または **Space** で確定します。
2. コピーが周回する**中心をクリック**するか、`X,Y` を入力して **Enter** を押すと正確な座標を指定できます。
3. 配列を確認します。すべてのコピーがライブプレビューされ、ターミナルに `Change [Items=6] [Angle=60°] [Fill=360°] [Rotate=true]` と表示されます。変更するオプションの文字を押してください。
4. **Enter** または **Space** を押すとコピーが作成されます。元のオブジェクトはそのままで、選択は解除されます。

## オプション

| オプション | キー | 効果 |
|---|---|---|
| Items | `I` | 元を含めたアイテム数。2〜1024 の整数。初期値は 6 です。 |
| Angle | `A` | あるアイテムから次のアイテムまでの角度（度）。反時計回りで、負の角度は時計回りです。最大 180°。 |
| Fill | `F` | 最初のアイテムから最後のアイテムまでの角度（度）。360（既定）は一周で、それより小さい値だとアイテムは一部にだけ配置されます。負は時計回り。最大 360°。 |
| Rotate | `R` | オン（既定）：各コピーは周回しながら回転します。オフ：各コピーは所定の位置へ移動するだけで、元と同じ向きのままです。その場で切り替わり、入力する数値はありません。 |

- Angle と Fill は同じことを別の言い方で表したものなので、一方を変えるともう一方が再計算されます。一周の場合、最後のアイテムは最初のアイテムの一歩手前で止まり、一部の場合は Fill の角度にちょうど位置します。
- 数値を変更するには、そのオプションの文字を押します。プロンプトには現在の値があらかじめ入力されているので、入力して置き換え、**Enter** または **Space** を押します。変更せずに確定すると、配列はそのままです。
- Items は整数のみ。Angle と Fill は小数と、時計回りを表す先頭の `-` を受け付けます。0 の角度や Fill、180° を超える Angle、360° を超える Fill は拒否され、ターミナルが理由を表示します。
- すべてのアイテムが収まらないほど小さい Angle にすると、入りきらないアイテムが除かれ、ターミナルが新しい数を知らせます。
- すべてのエンティティタイプで使えます。各コピーは、[Rotate](../rotate/) や [Move](../move/) と同じ方法で、元を中心の周りに回転または移動したものです。

## キー操作一覧

| キー | 動作 |
|---|---|
| `Enter` / `Space` | 選択、配列、または入力した数値を確定 |
| `I` `A` `F` `R` | 数値を入力して Items、Angle、Fill を変更。Rotate を切り替え |
| `0`–`9`, `.`, `-` | 数値を入力（`.` と `-` は Angle と Fill のみ、`-` は先頭） |
| `Backspace` | 最後に入力した文字を削除 |
| `Escape` | キャンセル |
