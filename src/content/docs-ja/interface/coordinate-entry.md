# 座標入力

コマンドが点を求めるとき — [Line](../../commands/line/) の始点、[Rectangle](../../commands/rectangle/) の角、[Move](../../commands/move/) の基点、ドラッグ中のグリップなど — はクリックの代わりに入力できます。数字を打ち始めるとターミナルに入力内容が表示され、**Enter** または **Space** で点が置かれます。

## 点の 4 つの書き方

| 入力 | 点の位置 |
|---|---|
| `100,50` | X 100、Y 50 |
| `@100,50` | 直前の点から X 方向に 100、Y 方向に 50 |
| `100<45` | 原点から 100、45° の方向 |
| `@100<45` | 直前の点から 100、45° の方向 |

角度は度単位で、X 軸から反時計回りです。`@50<90` は真上に 50、`@50<180` は左に 50 です。どちらの値も負にできます。

## 直前の点

`@` は、どのコマンドでも最後にクリックまたは入力した点から測ります。前のコマンドの最後のクリックも、ドラッグしたばかりのグリップも含まれます。直前の点がまだないときは、`@100,50` は `100,50` として読まれます。モデル空間とレイアウトを切り替えたときと、図面を開いたときに直前の点は消えます。

## Rel：既定で相対

コントロールバーの **Rel** トグルをオンにすると、入力する点はすべて相対で始まります。最初の数字を打つと前に `@` が入り、`100,50` は `@100,50` になります。`@` の上で **Backspace** を押すと、その点だけ絶対になります。直前の点がまだないときは `@` は付きません。Rel は既定でオフで、ほかのコントロールバーのトグルと一緒に記憶されます。

## 入力中のキー

| キー | 動作 |
|---|---|
| `0`–`9`, `.`, `-` | 数値を入力（`-` は先頭のみ） |
| `@` | 点を相対にする（X の先頭で） |
| `,` または **Space** | X を終えて Y へ |
| `<` | X を距離として終え、その角度へ |
| **Enter** または **Space** | Y に値があれば点を置く |
| **←** **→** **Home** **End** | 入力中の値の中でカーソルを動かす |
| **Backspace** | カーソルの前を削除。空の Y の先頭では X に戻る |

数値として読めない点は、直せるようにターミナルに残ります。入力した点は、入力したとおりの行をターミナルの履歴に残し — `入力: @100<45` — その後にコマンドが置いた位置の行が続きます。

## 入力した点と角度トラッキング

カーソルが角度トラッキングの光線にロックされているときは、数値を入力すると X ではなくその光線に沿った距離になります。先に `@` を入力すると完全な点の入力が始まるので、ロック中の光線でも `@100,50` が使えます。
