# 選択フィルタ

一度に多数のエンティティを選択すると、プロパティパネルは複数選択ビュー（「Selection (N)」）で開きます。閉じるボタンの隣にある **フィルタアイコン** を使うと、一括編集の前にその選択をプロパティで絞り込めます。

## フィルタを開く

1. 複数のエンティティを選択します — 選択枠をドラッグする、Shift クリック、または Ctrl+A。
2. プロパティパネルのヘッダーにある **フィルタアイコン**（じょうご）をクリックします。
3. ボタンの下にポップアップが開き、選択内で実際に値がばらついているプロパティごとにチェックリストが並びます。

## ファセット

ポップアップには最大 5 つのファセットが表示され、いずれも現在の選択から動的に組み立てられます。

| ファセット | 表示される値 |
|------------|--------------|
| **種類** | エンティティ型の名前（Line、Circle、Hatch など） |
| **画層** | 画層名と、その画層の色に合わせた色見本 |
| **色** | ACI カラー番号 |
| **線の太さ** | 線の太さの値 |
| **線種** | 線種の名前 |

ファセットは、その項目について選択内に実際に複数の異なる値があるときにだけ現れます。同じ画層にある 10 本の線を選んでも画層ファセットは出ません。チェックしても何も絞り込めないからです。そのプロパティをそもそも持たないエンティティ（たとえば Hatch と Text には線の太さも線種もありません）は、そのファセットの集計に単に含まれません。そしてそのファセットによって除外されることもありません。

## 選択を絞り込む

いずれかのファセットで 1 つ以上の値にチェックを入れると、選択は **チェックしたすべてのファセット** に合致するエンティティへ絞り込まれます（エンティティは、あなたが触れた *すべての* ファセットでチェック済みの値の少なくとも 1 つに合致する必要があります。どれか 1 つのファセットだけではありません）。各ファセットのチェックボックスと件数は、*他の* チェック済みファセットがすでに絞り込んだ結果を反映します。そのためファセットが自分自身のチェック済み項目を隠してしまうことはありません — ファセット検索の標準的なふるまいです。

チェックのオン・オフに応じて件数はその場で更新され、キャンバス上の選択自体も一緒に絞り込まれます。これは表示上のフィルタではありません。合致しなくなったエンティティは実際に選択解除され、絞り込んだ部分集合をそのまま一括編集できる状態になります。

## フィルタを解除する

ポップアップのリセット操作ですべてのチェックを外し、元の選択全体に戻せます。あるいはポップアップを閉じてください（次に別の選択でフィルタアイコンをクリックすると、新しい基準で開き直します）。
