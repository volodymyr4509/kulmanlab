# ClipboardCopy

Η εντολή `ΑντιγραφήΣτοΠρόχειρο` γράφει τις επιλεγμένες οντότητες στο **πρόχειρο του συστήματός** σας ως κείμενο JSON. Επειδή χρησιμοποιεί το πραγματικό πρόχειρο και όχι μια ενδιάμεση μνήμη, η αντιγραμμένη γεωμετρία επιβιώνει έξω από το σχέδιο: επικολλήστε την σε άλλο αρχείο, σε δεύτερη καρτέλα του browser ή σε παράθυρο που θα ανοίξετε αργότερα, με την [ClipboardPaste](../clipboard-paste/).

Αυτή είναι η διαφορά από την [Copy](../copy/): η Copy αναπαράγει οντότητες μέσα στο τρέχον σχέδιο με μία κίνηση, ενώ η ClipboardCopy τις αφήνει κάπου απ' όπου μπορούν να ανακτηθούν από ένα εντελώς διαφορετικό σχέδιο.

## Δύο τρόποι εκκίνησης

**Πρώτα επιλογή, μετά αντιγραφή** — η γρήγορη διαδρομή:

1. Επιλέξτε μία ή περισσότερες οντότητες στον καμβά.
2. Πατήστε `Ctrl+C` (`Cmd+C` σε macOS) ή πληκτρολογήστε `ΑντιγραφήΣτοΠρόχειρο` στο τερματικό.
3. Οι οντότητες γράφονται αμέσως στο πρόχειρο και η εντολή τερματίζεται.

**Πρώτα ενεργοποίηση, μετά επιλογή** — ξεκινώντας χωρίς επιλογή:

1. Πατήστε `Ctrl+C` ή πληκτρολογήστε `ΑντιγραφήΣτοΠρόχειρο` με κενή επιλογή.
2. Η προτροπή δείχνει **pick objects to copy — Enter or Space to confirm**.
3. **Επιλέξτε αντικείμενα** — κάντε κλικ για να βάλετε ή να βγάλετε μεμονωμένες οντότητες από την επιλογή, ή σύρετε για επιλογή με περιοχή.
4. Πατήστε **Enter** ή **Space** για να αντιγράψετε την επιλογή και να βγείτε.

Το πάτημα **Enter** ή **Space** χωρίς επιλογή απλώς τερματίζει την εντολή χωρίς να αγγίξει το πρόχειρο.

## Τι αντιγράφεται

Το περιεχόμενο του προχείρου μεταφέρει περισσότερα από σκέτη γεωμετρία, ώστε μια επικόλληση σε ξένο σχέδιο να δείχνει και πάλι σωστή:

| Στοιχείο | Σκοπός |
|----------|--------|
| **Οντότητες** | Η πλήρης σειριοποιημένη μορφή κάθε επιλεγμένης οντότητας |
| **Σημείο αναφοράς** | Η κάτω αριστερή γωνία της συνολικής έκτασης της επιλογής — αυτό που η ClipboardPaste αγκυρώνει στον δρομέα |
| **Επίπεδα** | Μόνο τα επίπεδα στα οποία πραγματικά παραπέμπουν οι αντιγραμμένες οντότητες, κατ' όνομα |
| **Τύποι γραμμής** | Μόνο οι τύποι γραμμής στους οποίους πραγματικά παραπέμπουν οι αντιγραμμένες οντότητες, κατ' όνομα |

Μαζί με το αντίγραφο ταξιδεύουν μόνο οι *αναφερόμενες* εγγραφές πινάκων — όχι οι πλήρεις πίνακες επιπέδων και τύπων γραμμής του σχεδίου προέλευσης. Τα μοτίβα διαγράμμισης δεν συμπεριλαμβάνονται καθόλου, ούτε χρειάζεται: ο πίνακας μοτίβων ενός σχεδίου είναι το ενσωματωμένο προεπιλεγμένο σύνολο, και όσα αρχεία `.pat` έχετε ανεβάσει βρίσκονται σε αποθήκη ανά χρήστη που ήδη μοιράζεται μεταξύ καρτελών, οπότε μια επικολλημένη διαγράμμιση βρίσκει μόνη της το μοτίβο της.

## Επιβεβαίωση

Σε επιτυχία, το τερματικό αναφέρει πόσες οντότητες γράφτηκαν:

```
3 entities copied to clipboard
```

Αν ο browser αρνηθεί την πρόσβαση στο πρόχειρο, το τερματικό δείχνει **Copy failed: clipboard access denied** και δεν γράφεται τίποτα. Πρόκειται για απόφαση δικαιωμάτων του browser, όχι για σφάλμα του σχεδίου — δείτε τα [Δικαιώματα προχείρου](#δικαιώματα-προχείρου) παρακάτω.

## Επιλογή κατά τη διάρκεια της εντολής

| Μέθοδος | Συμπεριφορά |
|---------|-------------|
| **Κλικ** | Βάζει ή βγάζει την οντότητα κάτω από τον δρομέα από την επιλογή |
| **Σύρσιμο προς τα δεξιά** (αυστηρό) | Προσθέτει οντότητες που βρίσκονται εξ ολοκλήρου μέσα στο πλαίσιο |
| **Σύρσιμο προς τα αριστερά** (τεμνόμενο) | Προσθέτει οντότητες που τέμνουν το όριο του πλαισίου |
| **Enter** / **Space** | Επιβεβαιώνει την επιλογή και αντιγράφει |

## Αναφορά πληκτρολογίου

| Πλήκτρο | Ενέργεια |
|---------|----------|
| `Ctrl+C` / `Cmd+C` | Ενεργοποίηση ClipboardCopy |
| `Enter` / `Space` | Αντιγραφή της τρέχουσας επιλογής, ή έξοδος αν δεν έχει επιλεγεί τίποτα |
| `Escape` | Ακύρωση χωρίς αντιγραφή |

## Δικαιώματα προχείρου

Η εγγραφή στο πρόχειρο του συστήματος απαιτεί άδεια από τον browser. Στην πράξη, μια αντιγραφή που ξεκινά από πάτημα πλήκτρου εγκρίνεται χωρίς ερώτηση στους σημερινούς επιτραπέζιους browsers, αλλά μια σελίδα που έχει χάσει την εστίαση, ή ένας browser με αυστηρές ρυθμίσεις προχείρου, μπορεί να αρνηθεί. Αν δείτε το μήνυμα άρνησης πρόσβασης, κάντε ένα κλικ στον καμβά για να δώσετε εστίαση στη σελίδα και δοκιμάστε ξανά.

Επειδή το περιεχόμενο είναι απλό κείμενο JSON, οτιδήποτε άλλο αντιγράψετε στη συνέχεια το αντικαθιστά — μια γραμμή κειμένου, ένας σύνδεσμος. Αντιγράψτε ξανά πριν επικολλήσετε, αν στο μεταξύ χρησιμοποιήσατε το πρόχειρο για κάτι άλλο.

## Υποστηριζόμενες οντότητες

Η ClipboardCopy λειτουργεί με κάθε τύπο οντότητας. Οι οντότητες σειριοποιούνται με τον ίδιο μηχανισμό που χρησιμοποιεί η εγγενής εξαγωγή `.json`, οπότε τίποτα δεν χάνεται στη διαδρομή.
