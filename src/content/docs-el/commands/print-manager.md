# Print Manager

Η εντολή `PrintManager` ανοίγει τον **Print Manager** — ειδικό παράθυρο εξαγωγής με ζωντανό καμβά προεπισκόπησης, επιλογέα μορφής (PNG / JPEG / WebP / PDF), επιλογέα στυλ (Default / Monochrome / Blueprint) και προαιρετική περικοπή περιοχής. Τίποτα δεν αποστέλλεται σε φυσικό εκτυπωτή· η έξοδος λαμβάνεται ως αρχείο.

## Άνοιγμα του Print Manager

Κάντε κλικ στο κουμπί **Print** της γραμμής εργαλείων ή πληκτρολογήστε `PrintManager` στο τερματικό. Ο Print Manager ανοίγει αμέσως εμφανίζοντας προεπισκόπηση του τρέχοντος viewport.

Η προεπισκόπηση αποδίδεται μέσω ακριβώς της ίδιας διαδρομής κώδικα, στην ίδια ακριβώς ανάλυση pixel, με το αρχείο που τελικά θα εξάγετε — η αλλαγή Quality, Style ή της περιοχής εξαγωγής αποδίδει ξανά αμέσως την προεπισκόπηση, οπότε αυτό που βλέπετε είναι αυτό που κατεβαίνει, όχι μια προσέγγισή του.

## Διάταξη Print Manager

Το παράθυρο έχει δύο πάνελ:
- **Αριστερή πλαϊνή στήλη** — όλα τα controls εξαγωγής.
- **Δεξί πάνελ** — ζωντανός καμβάς προεπισκόπησης που ενημερώνεται καθώς αλλάζετε ρυθμίσεις.

### Controls πλαϊνής στήλης

| Control | Περιγραφή |
|---------|-----------|
| **Change Area** | Περικοπή σε προσαρμοσμένο ορθογώνιο στον καμβά (βλ. παρακάτω) — περικόπτει πραγματικά την εξαγόμενη εικόνα, ακόμη και σε layout με χώρο χαρτιού, όχι μόνο την προεπισκόπηση στην οθόνη |
| Αναπτυσσόμενο **Quality** | Ορίζει την ανάλυση εξαγωγής (βλ. παρακάτω) |
| Αναπτυσσόμενο **Style** | Default, Monochrome, ή Blueprint — βλ. *Στυλ εκτύπωσης* παρακάτω. Monochrome από προεπιλογή για καθαρή εκτύπωση |
| Αναπτυσσόμενο **Format** | PNG, JPEG, WebP ή PDF |
| Κουμπί **Export** | Δημιουργία και λήψη αρχείου |

## Στυλ εκτύπωσης

Το αναπτυσσόμενο **Style** ελέγχει τόσο το χρώμα μελανιού με το οποίο σχεδιάζονται οι οντότητες όσο και το φόντο της σελίδας:

| Στυλ | Μελάνι | Φόντο σελίδας |
|------|--------|----------------|
| **Default** | Το δικό της χρώμα κάθε οντότητας | Λευκό |
| **Monochrome** *(προεπιλογή)* | Συμπαγές μαύρο, ανεξαρτήτως χρώματος οντότητας/επιπέδου | Λευκό |
| **Blueprint** | Συμπαγές λευκό, ανεξαρτήτως χρώματος οντότητας/επιπέδου | Βαθύ πρωσικό μπλε, με ένα διακριτικό πλέγμα αναφοράς |

Το Blueprint αναπαράγει την εμφάνιση μιας παραδοσιακής αρχιτεκτονικής εκτύπωσης κυανοτυπίας — λευκές γραμμές πάνω σε ένα σκούρο μπλε φύλλο. Το πλέγμα αναφοράς του έχει μέγεθος σχετικό με το μέγεθος της σελίδας και όχι με το DPI, οπότε φαίνεται με την ίδια πυκνότητα σε οποιαδήποτε ρύθμιση Quality αντί να γίνεται πιο πυκνό καθώς αυξάνεται η ανάλυση.

## Ποιότητα και ανάλυση

Το αναπτυσσόμενο μενού **Quality** ορίζει το DPI στο οποίο αποδίδεται η εξαγωγή:

| Quality | DPI |
|---------|-----|
| Draft | 72 |
| Normal *(προεπιλογή)* | 150 |
| Presentation | 300 |
| Max | 600 |

Υψηλότερη Ποιότητα παράγει μεγαλύτερη, πιο ευκρινή εικόνα στο ίδιο φυσικό μέγεθος — τα πάχη γραμμών κλιμακώνονται μαζί με την ανάλυση, οπότε μια γραμμή διατηρεί το ίδιο *φυσικό* πάχος στο χαρτί σε οποιαδήποτε ρύθμιση Ποιότητας, αντί να φαίνεται λεπτότερη καθώς αυξάνεται το DPI. Η μόνη εξαίρεση είναι μια πολύ λεπτή γραμμή (πάχος γραμμής `0`), η οποία ορίζεται συμβατικά ως «η λεπτότερη γραμμή που μπορεί να σχεδιάσει η συσκευή εξόδου» — παραμένει σε σταθερό πλάτος 1 pixel σε κάθε επίπεδο Ποιότητας, όπως ακριβώς συμπεριφέρεται στον ζωντανό καμβά.

Η αλλαγή της Ποιότητας αποδίδει ξανά αμέσως την προεπισκόπηση, ώστε να βλέπετε την πραγματική ευκρίνεια (και τον συμβιβασμό στο μέγεθος αρχείου) πριν την εξαγωγή.

## Επιλογή προσαρμοσμένης περιοχής εξαγωγής

Από προεπιλογή η προεπισκόπηση εμφανίζει ακριβώς ό,τι ήταν ορατό στον καμβά όταν ανοίξατε τον Print Manager. Για εξαγωγή συγκεκριμένης περιοχής:

1. Κάντε κλικ στο **Change Area** — ο Print Manager κρύβεται και ο καμβάς γίνεται διαδραστικός.
2. **Κάντε κλικ στην πρώτη γωνία** του ορθογωνίου εξαγωγής.
3. **Κάντε κλικ στην απέναντι γωνία** — ο Print Manager ανοίγει ξανά με την επιλεγμένη περιοχή στην προεπισκόπηση.

Πατήστε `Escape` κατά την επιλογή περιοχής για ακύρωση και επαναφορά της προηγούμενης περιοχής.

Ο καμβάς προεπισκόπησης αλλάζει μέγεθος δυναμικά ώστε να ταιριάζει με **ακριβώς την αναλογία διαστάσεων** της επιλεγμένης περιοχής, οπότε η προεπισκόπηση είναι pixel-ακριβής.

## Μορφές εξαγωγής

| Μορφή | Καλύτερο για | Σημειώσεις |
|-------|-------------|-----------|
| **PNG** | Χωρίς απώλειες, ευκρινείς γραμμές | Το φόντο σελίδας του στυλ ενσωματωμένο, χωρίς διαφάνεια |
| **JPEG** | Μικρότερο αρχείο για κοινοποίηση | Ποιότητα 95%, ελαφρά συμπίεση |
| **WebP** | Μικρότερο αρχείο για web | Ίδια ποιότητα 95%, καλύτερη συμπίεση από JPEG |
| **PDF** | Έτοιμα για εκτύπωση έγγραφα | Εικόνα ενσωματωμένη σε PDF container στο DPI της επιλεγμένης Quality, με μέγεθος ώστε η σελίδα να εκτυπώνεται σε πραγματική φυσική κλίμακα |

Το εξαγόμενο αρχείο ονομάζεται `kulman-<timestamp>.<ext>` και γίνεται λήψη αυτόματα.

## Ανάλυση εξαγωγής και φόντο

- **Εξαγωγή model space / viewport**: περιορίζεται στα 2000 × 2000 pixels στην προεπιλεγμένη ποιότητα Normal (150 DPI), κλιμακωμένη αναλογικά στην επιλεγμένη περιοχή· το όριο κλιμακώνεται και αυτό με την Quality — το Draft έχει χαμηλότερο όριο, τα Presentation και Max υψηλότερο (έως 8000 × 8000 στο Max/600 DPI).
- **Εξαγωγή layout (χώρος χαρτιού)**: με μέγεθος απευθείας από τις διαστάσεις χαρτιού του layout στο επιλεγμένο DPI — π.χ. ένα φύλλο A4 (210 × 297 mm) σε ποιότητα Normal εξάγεται περίπου σε 1240 × 1754 px — άρα δεν υπόκειται στο όριο των 2000 px του viewport.
- Το φόντο ακολουθεί το επιλεγμένο **Style** εκτύπωσης — λευκό για Default και Monochrome, βαθύ πρωσικό μπλε για Blueprint (βλ. *Στυλ εκτύπωσης* παραπάνω).
- Τα επίπεδα που είναι σημειωμένα ως **non-plotting** εξαιρούνται από την εξαγωγή.

## Αναφορά πληκτρολογίου

| Πλήκτρο | Ενέργεια |
|---------|----------|
| `Escape` (κατά την επιλογή περιοχής) | Ακύρωση επιλογής περιοχής, επαναφορά προηγούμενης περιοχής |
| `Escape` (στον Print Manager) | Κλείσιμο Print Manager |
