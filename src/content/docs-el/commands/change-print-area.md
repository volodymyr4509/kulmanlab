# ChangePrintArea

Η εντολή `ΑλλαγήΠεριοχήςΕκτύπωσης` ορίζει την ορθογώνια περιοχή που εξάγει ο [Print Manager](../print-manager/). Εκτελείται στον γυμνό καμβά με τον Print Manager κρυμμένο και δέχεται δύο απέναντι γωνίες — τα ίδια δύο κλικ με το [Rectangle](../rectangle/), οπότε οι πληκτρολογημένες συντεταγμένες και η προσκόλληση συμπεριφέρονται ακριβώς το ίδιο.

## Επιλογή περιοχής

1. Πληκτρολογήστε `ΑλλαγήΠεριοχήςΕκτύπωσης` στο τερματικό ή κάντε κλικ στο **Change Area** στην πλαϊνή μπάρα του Print Manager. Ο Print Manager κρύβεται και ο καμβάς γίνεται διαδραστικός.
2. **Κάντε κλικ στην πρώτη γωνία** ή πληκτρολογήστε `X,Y` και πατήστε **Enter** για ακριβή συντεταγμένη.
3. **Κάντε κλικ στην απέναντι γωνία** ή πληκτρολογήστε ξανά `X,Y`.

Ο Print Manager ανοίγει ξανά με τη νέα περιοχή στην προεπισκόπηση, η οποία προσαρμόζεται στην ακριβή αναλογία της.

Οι γωνίες προσκολλώνται σε λαβές και τομές όπως κάθε άλλη επιλογή σημείου, ώστε να περικόπτετε πάνω στη σχεδιασμένη γεωμετρία αντί με το μάτι. Η σειρά των δύο γωνιών δεν έχει σημασία: απέναντι γωνίες ορίζουν το ίδιο ορθογώνιο.

Πατήστε `Escape` για ακύρωση. Δεν γράφεται τίποτα, οπότε ο Print Manager ανοίγει ξανά με την περιοχή που είχε ήδη.

## Πού θυμάται την περιοχή

Η επιλογή αποθηκεύεται ανά περιβάλλον, όχι καθολικά:

| Περιβάλλον | Θέση |
|---|---|
| Χώρος μοντέλου | Μία κοινή θέση |
| Κάθε διάταξη | Δική της θέση, που κρατείται ξεχωριστά |

Το άνοιγμα του Print Manager ξανά στην ίδια διάταξη — ή στον χώρο μοντέλου — επαναφέρει την τελευταία περικοπή εκείνου του περιβάλλοντος αντί να την μηδενίσει, και η εναλλαγή μεταξύ διατάξεων αφήνει ανέπαφη την περιοχή της καθεμιάς.

Αυτό κρατείται μόνο στη μνήμη. Η επαναφόρτωση της σελίδας καθαρίζει όλες τις αποθηκευμένες περιοχές και ο Print Manager επιστρέφει στις παρακάτω προεπιλογές.

## Προεπιλεγμένη περιοχή

Χωρίς τίποτα αποθηκευμένο για το τρέχον περιβάλλον, ο Print Manager ανοίγει σε:

| Περιβάλλον | Προεπιλογή |
|---|---|
| Χώρος μοντέλου | Το πλαίσιο οριοθέτησης όλων των οντοτήτων — η ίδια έκταση στην οποία κάνει ζουμ το [Fit](../fit/) |
| Κάθε διάταξη | Ολόκληρο το φύλλο |

## Σχετικές εντολές

| Εντολή | Τι κάνει |
|---|---|
| [Print Manager](../print-manager/) | Το παράθυρο εξαγωγής στο οποίο εφαρμόζεται αυτή η περιοχή |
| [Rectangle](../rectangle/) | Η ίδια επιλογή δύο γωνιών, αλλά σχεδιάζει πολυγραμμή |
| [Fit](../fit/) | Κάνει ζουμ στην έκταση που ο χώρος μοντέλου χρησιμοποιεί ως προεπιλογή |
