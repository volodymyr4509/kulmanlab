# Extend

Η εντολή `Επέκταση` επεκτείνει το πλησιέστερο τελικό σημείο μιας [Line](../line/), [Arc](../arc/), [Ellipse](../ellipse/) ή ανοιχτής [Polyline](../polyline/) που περνά ο δείκτης μέχρι την πλησιέστερη τομή που θα σχημάτιζε με άλλη οντότητα στο σχέδιο. Περάστε τον δείκτη κοντά στο τελικό σημείο που θέλετε να επεκτείνετε — μια προεπισκόπηση δείχνει την επεκταμένη οντότητα — μετά κάντε κλικ για εφαρμογή.

Μόνο οντότητες με πραγματικό τελικό σημείο μπορούν να επεκταθούν. Ένας [Circle](../circle/) και μια πλήρης (360°) Ellipse είναι πάντα κλειστά σχήματα χωρίς τελικό σημείο, οπότε δεν μπορούν ποτέ να επεκταθούν — το ίδιο ισχύει για μια κλειστή Polyline ή ένα Rectangle. Μια μερική Ellipse (ένα ελλειπτικό τόξο) και ένας Arc έχουν τελικά σημεία και επεκτείνονται με τον ίδιο τρόπο όπως μια Line.

## Επέκταση μιας οντότητας

1. Πληκτρολογήστε `Επέκταση` στο τερματικό ή κάντε κλικ στο κουμπί **Extend** της γραμμής εργαλείων.
2. **Περάστε τον δείκτη κοντά σε ένα άκρο** της οντότητας που θέλετε να επεκτείνετε — η προεπισκόπηση τη δείχνει επεκταμένη στο πλησιέστερο όριο προς εκείνη την κατεύθυνση.
3. **Κάντε κλικ** για εφαρμογή της επέκτασης.

Η εντολή παραμένει ενεργή μετά από κάθε επέκταση, ώστε να μπορείτε να συνεχίσετε να περνάτε τον δείκτη και να κάνετε κλικ για να επεκτείνετε περισσότερες οντότητες. Πατήστε **Enter**, **Space** ή **Escape** για έξοδο.

```
  Πριν:                      Μετά:

  ──────           |           ──────────────|
  (κοντή γραμμή)  (όριο)      (επεκταμένη στο όριο)
```

## Πώς επιλέγεται το τελικό σημείο

Η εντολή εξετάζει ποιο άκρο είναι πλησιέστερα στον κέρσορα:

- **Line και ανοιχτή Polyline** — κέρσορας πλησιέστερα στο τελικό σημείο επεκτείνει το τέλος εμπρός· κέρσορας πλησιέστερα στο αρχικό σημείο επεκτείνει την αρχή προς τα πίσω.
- **Arc και μερική Ellipse** — κέρσορας πλησιέστερα σε ένα από τα γωνιακά άκρα κάνει το τόξο να μεγαλώνει προς εκείνη την κατεύθυνση, γύρω από το ίδιο κέντρο και ακτίνα (ή το ίδιο σχήμα έλλειψης), μέχρι να φτάσει στο επόμενο όριο.

Μια ακτίνα — ή, για Arc και Ellipse, ο ίδιος ο κύκλος ή η καμπύλη της οντότητας — εκπέμπεται από το επιλεγμένο άκρο, και η **πλησιέστερη τομή** με οποιαδήποτε άλλη οντότητα (εξαιρουμένης της ίδιας της οντότητας και των αγνοούμενων τύπων) γίνεται το νέο τελικό σημείο.

Αν δεν βρεθεί τομή προς εκείνη την κατεύθυνση, δεν εμφανίζεται προεπισκόπηση και το κλικ δεν κάνει τίποτα.

## Εξαιρέσεις ορίων

Οι ακόλουθοι τύποι οντοτήτων αγνοούνται ως όρια — μια οντότητα δεν επεκτείνεται για να τους συναντήσει:

- Text / Mtext
- Multileader
- Spline

Όλοι οι άλλοι τύποι (Line, Arc, Circle, Ellipse, Polyline, Dimension) χρησιμεύουν ως έγκυρα όρια.

Αν το πρώτο ή το τελευταίο τμήμα ενός Polyline είναι το ίδιο τοξωτό τμήμα (σχεδιασμένο με τον διακόπτη Arc), η επέκτασή του μεγαλώνει το τόξο κατά μήκος του δικού του κύκλου — ακριβώς όπως η επέκταση ενός ανεξάρτητου Arc — αντί να αντιμετωπίζεται ως ευθύγραμμο τμήμα.

## Αναφορά πληκτρολογίου

| Πλήκτρο | Ενέργεια |
|---------|----------|
| `Enter` / `Space` | Έξοδος από λειτουργία extend |
| `Escape` | Έξοδος από λειτουργία extend |

## Υποστηριζόμενες οντότητες

| Οντότητα | Μπορεί να επεκταθεί; |
|----------|---------------------|
| Line | Ναι |
| Arc | Ναι |
| Ellipse | Ναι — μόνο αν είναι ήδη μερικό τόξο· μια πλήρης έλλειψη δεν έχει τελικό σημείο |
| Circle | Όχι — πάντα κλειστό σχήμα χωρίς τελικό σημείο |
| Polyline (ανοιχτή) | Ναι |
| Polyline (κλειστή) / Rectangle | Όχι — πάντα κλειστό σχήμα χωρίς τελικό σημείο |
| Text, Spline, Dimension, Leader | Όχι |

## Extend vs Trim

| | Extend | Trim |
|---|--------|------|
| Τι κάνει | Επεκτείνει το τελικό σημείο μιας οντότητας σε όριο | Αφαιρεί τμήμα μιας οντότητας |
| Έναυσμα | Hover κοντά στο τελικό σημείο για επέκταση | Hover πάνω από το τμήμα για κοπή |
| Αποτέλεσμα | Το τελικό σημείο μετακινείται προς τα έξω | Η οντότητα διαιρείται ή συντομεύεται |
| Υποστηριζόμενες οντότητες | Line, Arc, Ellipse, Polyline | Line, Arc, Circle, Ellipse, Polyline |
