# Block Insert

Η εντολή `ΕισαγωγήΜπλοκ` ανοίγει μια παλέτα με προεπισκοπήσεις κάθε μπλοκ του σχεδίου και τοποθετεί αυτό που διαλέγετε. Δημιουργήστε μπλοκ με το [Block Create](../block-create/) ή ανοίξτε ένα αρχείο DXF που έχει.

## Τοποθέτηση μπλοκ

1. Πληκτρολογήστε `ΕισαγωγήΜπλοκ` ή κάντε κλικ στο **Εισαγωγή μπλοκ** στον πίνακα **Μπλοκ**. Η παλέτα προσαρτάται αριστερά με ένα πλακίδιο προεπισκόπησης ανά μπλοκ, δώδεκα ανά σελίδα· τα βέλη κάτω από τα πλακίδια γυρίζουν σελίδα.
2. Πληκτρολογήστε στο **Αναζήτηση μπλοκ** για να περιορίσετε τα πλακίδια ανά όνομα.
3. Ορίστε **Κλίμακα** (πρέπει να είναι μεγαλύτερο από 0) και **Περιστροφή** σε μοίρες. Το **Επανάληψη τοποθέτησης** είναι ενεργό από προεπιλογή.
4. Κάντε κλικ στο πλακίδιο ενός μπλοκ. Το μπλοκ ακολουθεί τον κέρσορα: κάντε κλικ για να το τοποθετήσετε από το σημείο βάσης του ή πληκτρολογήστε X,Y για ακριβή θέση. Όταν ο κέρσορας είναι κλειδωμένος σε γωνία, μπορείτε να πληκτρολογήσετε μήκος.
5. Με το **Επανάληψη τοποθέτησης** ενεργό, το μπλοκ συνεχίζει να ακολουθεί τον κέρσορα για το επόμενο αντίγραφο μέχρι να πατήσετε **Escape**. Με αυτό ανενεργό, η εντολή τελειώνει μετά από ένα αντίγραφο.

## Καλό είναι να ξέρετε

- Για να διαγράψετε ένα μπλοκ, κάντε κλικ στον κάδο στο πλακίδιό του και επιβεβαιώστε. Ένα μπλοκ με αναφορές στο σχέδιο δεν διαγράφεται: το πλακίδιό του γράφει **Χρησιμοποιείται, δεν μπορεί να διαγραφεί**.
- Ένα σχέδιο χωρίς μπλοκ δείχνει **Το σχέδιο δεν έχει μπλοκ** στην παλέτα.
- Το **Escape** κλείνει την παλέτα όταν δεν τοποθετείται τίποτα. Είναι ένας από τους προσαρτημένους πίνακες, από τους οποίους αριστερά φαίνεται μόνο ένας κάθε φορά.
