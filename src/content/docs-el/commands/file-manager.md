# File Manager

Η εντολή `ΔιαχείρισηΑρχείων` ανοίγει ένα **πλέγμα μικρογραφιών** όλων των σχεδίων που έχουν αποθηκευτεί στην τοπική αποθήκευση του browser σας, ταξινομημένων ανά τον χρόνο της τελευταίας αποθήκευσης καθενός. Χρησιμοποιήστε το για να ανοίξετε ξανά ένα προηγούμενο σχέδιο, να το μετονομάσετε ή να το διαγράψετε.

## Άνοιγμα του File Manager

- Πληκτρολογήστε `ΔιαχείρισηΑρχείων` στο τερματικό, **ή**
- Κάντε κλικ στο κουμπί **File Manager** (εικονίδιο ιστορικού) της γραμμής εργαλείων στο πάνελ File στο πάνω μέρος της οθόνης.

Το πάνελ ανοίγει στην αριστερή πλευρά του καμβά και κλείνει αυτόματα μόλις ξεκινήσετε άλλη εντολή ή [εισάγετε](../import/) ένα αρχείο — έτσι ποτέ δεν παραμένει πάνω από ένα σχέδιο που δεν έχει ακόμα καταχωρίσει. Ανοίγει ξανά με ανανεωμένη λίστα κάθε φορά.

## Το πλέγμα μικρογραφιών

Κάθε αποθηκευμένο σχέδιο είναι μια κάρτα που εμφανίζει μια μικρογραφία σε πραγματικό χρόνο, το όνομά του και τον χρόνο της τελευταίας ενημέρωσης. Οι μικρογραφίες δημιουργούνται επιτόπου κάθε φορά που ανοίγει το πάνελ — τίποτα δεν προαποδίδεται ή αποθηκεύεται — έτσι μια κάρτα εμφανίζει για λίγο ένα εικονίδιο δεσμευτικής θέσης ενώ σχεδιάζεται η μικρογραφία της. Το ίδιο εικονίδιο εμφανίζεται επίσης αν η δημιουργία αποτύχει, ή αν το σχέδιο πράγματι δεν έχει ακόμα οντότητες.

| Ενέργεια | Πώς |
|--------|-----|
| **Άνοιγμα** σχεδίου | Κλικ στη μικρογραφία του — αντικαθιστά το τρέχον περιεχόμενο του καμβά |
| **Μετονομασία** | Κλικ στο εικονίδιο μολυβιού, ή διπλό κλικ στο όνομα |
| **Διαγραφή** | Κλικ στο εικονίδιο κάδου, στη συνέχεια επιβεβαίωση |

Αν δεν έχουν αποθηκευτεί αρχεία ακόμα, το πάνελ εμφανίζει "No files saved". Με περισσότερα αρχεία από όσα χωρούν σε μία οθόνη, εμφανίζονται στοιχεία ελέγχου **Page 1 of N** κάτω από το πλέγμα.

Η κάρτα του αρχείου που είναι αυτή τη στιγμή ανοιχτό στον επεξεργαστή επισημαίνεται με έναν δακτύλιο σε χρώμα έμφασης και **δεν έχει κουμπί διαγραφής** — η διαγραφή του ανοιχτού αρχείου θα διέγραφε τα αποθηκευμένα δεδομένα του ενώ ο καμβάς θα συνέχιζε να το εμφανίζει, και η επόμενη επεξεργασία απλώς θα το αποθήκευε ξανά. Η μετονομασία παραμένει διαθέσιμη.

## Διαγραφή αρχείου

Το κλικ στο εικονίδιο κάδου δεν διαγράφει αμέσως — ενεργοποιεί ένα επίπεδο επιβεβαίωσης πάνω σε αυτή την κάρτα ("Delete this file?" με τα κουμπιά **Delete** / **Cancel**), καθώς η διαγραφή είναι μόνιμη και δεν μπορεί να αναιρεθεί. Το κλικ στο **Cancel**, στο εικονίδιο κάδου άλλης κάρτας, ή οπουδήποτε αλλού στην κάρτα, ακυρώνει την εκκρεμή επιβεβαίωση χωρίς να διαγράψει τίποτα.

## Μετονομασία αρχείου

Κάντε κλικ στο εικονίδιο μολυβιού (ή διπλό κλικ στο όνομα του αρχείου) για να το επεξεργαστείτε επιτόπου, στη συνέχεια πατήστε **Enter** για επιβεβαίωση ή **Escape** για ακύρωση. Μια μετονομασία απορρίπτεται αν το νέο όνομα:

- είναι κενό, ή μεγαλύτερο από 100 χαρακτήρες,
- χρησιμοποιείται ήδη από άλλο αποθηκευμένο αρχείο (χωρίς διάκριση πεζών/κεφαλαίων),
- τελειώνει σε τελεία, ή
- είναι δεσμευμένο όνομα συσκευής των Windows όπως `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, ή `LPT1`–`LPT9`.

Χαρακτήρες που δεν είναι έγκυροι σε όνομα αρχείου (`\ / : * ? " < > |`) αφαιρούνται αυτόματα καθώς πληκτρολογείτε. Η μετονομασία αλλάζει μόνο την ετικέτα — δεν επηρεάζει τη θέση του σχεδίου στο πλέγμα, καθώς αυτή ταξινομείται με βάση τον χρόνο τελευταίας αποθήκευσης, όχι το όνομα.

## Δημιουργήστε αντίγραφο ασφαλείας της εργασίας σας — η αποθήκευση browser δεν είναι μόνιμη

Το KulmanLab αποθηκεύει σχέδια στο **IndexedDB**, μια βάση δεδομένων ενσωματωμένη στον browser σας:

- Τα αρχεία αποθηκεύονται **μόνο τοπικά στη συσκευή σας** — τίποτα δεν ανεβαίνει σε διακομιστή.
- Κάθε browser και συσκευή έχει τη δική της ανεξάρτητη αποθήκευση. Ένα σχέδιο αποθηκευμένο στο Chrome σε έναν υπολογιστή δεν εμφανίζεται στο Firefox, ή σε άλλη συσκευή.
- Αυτή η αποθήκευση **μπορεί να εκκαθαριστεί χωρίς προειδοποίηση** — με εκκαθάριση δεδομένων ιστότοπου ή ιστορικού περιήγησης, με χαμηλό χώρο δίσκου, με χρήση παραθύρου ιδιωτικής περιήγησης/incognito, με επανεγκατάσταση του browser ή του λειτουργικού συστήματος, ή με αλλαγή συσκευής. Καμία από αυτές τις περιπτώσεις δεν σας δίνει την ευκαιρία να ανακτήσετε ό,τι υπήρχε.

**Ο μόνος αξιόπιστος τρόπος να διατηρήσετε ένα σχέδιο ασφαλές είναι να το [εξάγετε](../export-manager/)** στη δική σας αποθήκευση. Χρησιμοποιήστε `.json` (το εγγενές μορφότυπο του KulmanLab) όποτε είναι δυνατόν — διατηρεί κάθε οντότητα με ακρίβεια· χρησιμοποιήστε `.dxf` όταν χρειάζεστε συμβατότητα με άλλα εργαλεία CAD. Κάντε το αυτό για οτιδήποτε θα λυπόσασταν να χάσετε, και πριν εκκαθαρίσετε δεδομένα browser, αλλάξετε browser ή συσκευή, ή αποθηκεύσετε τη συσκευή για κάποιο διάστημα.

## Αυτόματη φόρτωση αρχείου κατά την εκκίνηση

Όταν ανοίγετε το KulmanLab CAD, η εφαρμογή φορτώνει αυτόματα το **πιο πρόσφατα τροποποιημένο αρχείο** από την αποθήκευση. Δεν χρειάζεται να το ανοίγετε χειροκίνητα από το File Manager κάθε φορά.

## Διαχείριση αποθήκευσης

Δεν υπάρχει σταθερό όριο στον αριθμό σχεδίων που μπορείτε να αποθηκεύσετε, αλλά η αποθήκευση browser είναι πεπερασμένη. Αν παρατηρήσετε προειδοποιήσεις αποθήκευσης, διαγράψτε παλαιότερα αρχεία από το File Manager — ή, ακόμα καλύτερα, εξάγετέ τα πρώτα ώστε να μη χαθεί τίποτα.

Για αφαίρεση όλων των αποθηκευμένων σχεδίων ταυτόχρονα, χρησιμοποιήστε την εντολή [WipeStorage](../wipestorage/).

## Ονόματα αρχείων

Τα νέα και εισαγόμενα αρχεία λαμβάνουν ένα απλό όνομα — χωρίς ενσωματωμένη χρονική σήμανση. Αν αυτό το όνομα είναι ήδη κατειλημμένο, προστίθεται αυτόματα μια κατάληξη στο στιλ Finder/Explorer (`plan (2)`, `plan (3)`, …) ώστε τίποτα να μην αντικατασταθεί. Μπορείτε πάντα να δώσετε σε ένα αρχείο πιο σαφές όνομα αργότερα χρησιμοποιώντας [μετονομασία](#μετονομασία-αρχείου).

## Σχετικές εντολές

- [Import](../import/) — φόρτωση σχεδίου από το σύστημα αρχείων σας στην αποθήκευση browser
- [Export Manager](../export-manager/) — λήψη σχεδίου στο σύστημα αρχείων σας
- [New File](../new-file/) — εκκίνηση κενού σχεδίου (αποθηκεύεται επίσης αυτόματα)
- [WipeStorage](../wipestorage/) — εκκαθάριση όλων των αποθηκευμένων αρχείων από την αποθήκευση browser
